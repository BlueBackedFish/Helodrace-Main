# 차량 아트 작업 규칙

이 절은 Vehicle Framework 차량 모델·차량 텍스처 작업에만 적용한다. 가구 등 다른 아트에는 적용하지 않는다.

- 새 차량 제작과 기존 차량 수정 전에 `VEHICLE_ART_STYLE.md`를 읽고 적용한다.
- 목표 아트 스타일·차량 외형·디테일 배치는 RimThunder를 기준으로 한다. Legion은 3D 모델 기반 렌더 방식을 참고한다. 한 면 한 색 제한은 취소했다.
- Legion의 별도 차량 디자인이나 생략 수준을 실제 Bradley의 형상 기준으로 사용하지 않는다. RimThunder에 가까운 식별력과 디테일을 구현한다. 높은 부분을 밝게 하는 채색을 중심으로 곡면의 명도 분할/보간을 허용하고, 일부 장비는 별도의 어두운 색을 사용한다.
- 사용자 제공 3D 파일은 비율·장비 배치의 근거, 청사진은 투영 검수와 디테일 선택의 근거로 사용한다. 두 자료의 차종/형식이 다르면 기록한다.
- 현재 Bradley 출력이나 기존 스크립트 수치를 승인된 스타일 표준으로 간주하지 않는다.
- 형상 변경이 별도로 요청되지 않으면 제공된 3D 형상을 보존하고 부품·면별 채색으로 가독성을 먼저 확보한다. 현재 Bradley는 2차 전 형상을 바탕으로 요청된 연결부·주포·해치 부속·원본 연막탄을 복구하고 평판 덮개를 유지한다.
- 새 차량 폴더에 `VEHICLE_ART_BRIEF_TEMPLATE.md`를 복사해 `ART_BRIEF.md`를 작성한다. 미확인 값은 추측으로 확정하지 않는다.
- 공통 스타일과 차량별 부품 매핑을 분리한다. 원본 오브젝트 이름을 공통 채색 알고리즘에 직접 박아 넣지 않는다.
- 원본 보존 → 부품·면별 명도 설계 → 분리 렌더 → 실제 출력 크기 비교 순으로 작업한다. 형상 재구성은 요청된 경우 별도 단계로 진행한다.
- 폴리곤 수 감소를 목표로 삼지 않는다. 장갑판에 일괄 collapse를 적용하거나 작은 부품을 크기만으로 삭제하지 않는다.
- 평면별 색은 부품 역할·방향·기울기를 함께 고려한다. 해치 전체를 일괄 암색 처리하지 않는다. 안쪽 홈/바닥은 의도적으로 어둡게 할 수 있지만, 삼각형 얼룩이 되지 않게 이어진 표면 단위로 처리한다.
- 사라진 부품을 복구할 때 해당 오브젝트만 보지 말고 상위 메시 안의 연결 받침과 장착대도 원본과 함께 대조한다.
- 높이/방향 때문에 어두워진 페인트는 채도도 낮춰 회색에 가깝게 한다. 의도적인 어두운 부품색·홈 강조와 원인을 구분한다.
- 높이 규칙은 최종 색에서 검증한다. 같은 TAN 상면은 지붕 < 그 위 해치 < 더 높은 관측장비 순서로 밝아야 한다. 부품별 기본색이 이 순서를 뒤집지 않게 한다. 보정 계수 검사만으로 통과시키지 않는다.
- 같은 차량의 RimThunder 레퍼런스가 있으면 부품 대응을 확인하고 높이 순서를 지키면서 재질·명도 관계를 맞춘다. 해치 손잡이와 뒤쪽 힌지처럼 인접한 다른 부품을 혼동하지 않는다.
- 같은 차량 화면 크기로 레퍼런스와 256px/512px 결과를 비교한다. 캔버스 크기가 같다는 이유만으로 동일 스케일이라고 판단하지 않는다.
- 원본 계층, 포탑·포신·문 피벗, 투명 배경, 그림자 없음, 일관된 투영을 유지한다.
- 작업 완료 시 모델 검증과 실제 크기 시각 검수 결과, 남은 차이 및 미실시한 게임 내 검증을 구분해 기록한다.

커밋과 브랜치는 상위 `AGENTS.md`를 따른다.
