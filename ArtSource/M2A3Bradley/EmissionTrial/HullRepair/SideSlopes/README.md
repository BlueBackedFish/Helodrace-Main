# 좌우 측면 경사 밝기 조정

기준 `73e2926a`. 사용자가 지정한 차체 좌우 외부 경사면만 표시 명도 **108 → 132**로 밝혔다. 지붕 168과의 차이는 60 → 36으로 줄었다. 정면 경사 144와의 차이는 12로 두어 과도하게 벌리지 않는다. 장착 단차를 구분해야 하는 인접 부품의 단계 차이는 유지한다.

포탑은 외곽선 효과 후 합성된다는 사용자 설명에 따라, 차체와 포탑의 비슷한 밝기를 이유로 추가 명암 보정을 하지 않았다. 외곽선 효과 자체를 이번 단계에서 새로 구현한 것은 아니다.

`../side_slopes.py`는 `WT_@root`의 넓은 외부 경사 연결 면을 선택한다. 기존 108 색을 쓰던 89면만 132로 변경했다. 얇은 그릴·장착물·수직 벽·앞뒤 경사면과 다른 145개 오브젝트의 색은 보존한다. 모든 형상·부모·피벗도 동일하다.

- `before.json`: 이전 모델의 오브젝트/형상/색 해시와 차체 원래 색, 선택 면 목록. 덮어쓰지 않는다.
- `validation.json`: 지정한 89면의 색 변경과 나머지 면·오브젝트 보존 검사.
- `before_front.png`, `before_east_256.png`: 수정 전 비교 기준.
- `before_after.png`: 측면 경사 조정 전후와 실제 크기 EAST 비교.

재생성은 상위 시험본 빌드/렌더와 `../check_side_slopes.py`를 사용한다. 기존 차체 검수와 포탑 검수는 이 단계의 차체 본체 색 변경만 이 검사에 넘기고 나머지 기준은 유지한다. 기본 시험본·TOW 전개 모델·256/512px EAST 출력을 갱신했다. 게임 내 검증은 미실시다.
