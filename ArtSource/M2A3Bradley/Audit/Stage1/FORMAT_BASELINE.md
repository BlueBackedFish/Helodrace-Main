# 1차 형식 기준과 대조 결과

2026-10-22. 목적은 후속 모델링이 서로 다른 형식을 임의로 섞지 않도록 기준을 고정하는 것이다.

## 고정한 기준

- **작업 형상 기반:** 사용자가 지정한 War Thunder M3A3 OBJ. 현재 축/스케일/주요 장비 배치를 보존한다.
- **청사진의 역할:** 사용자가 제공한 M2A3 이미지의 큰 패널, 해치, 비율과 장비 실루엣을 대조한다.
- **목표 아트:** RimThunder의 식별 디테일과 면 구분. **표현 방식:** Legion식 3D 렌더/한 면 한 색.
- 현재 결과를 정밀 M2A3 복제라고 명명하지 않는다. 1차에서 차체/포탑 비율이나 장비 위치를 변경하지 않는다.
- OBJ에 명시적 단위가 없으므로 실제 m 단위로 확정하지 않는다. 수치가 바뀌는 실측 스케일 작업은 별도 근거가 필요하다.
- ERA는 보류한다. `ex_armor_l/r_01..07`은 렌더에서 얇은 하부 스커트 패널로 확인했으며 ERA로 분류하지 않는다.

## 직접 대조한 항목

| 항목 | 청사진 | 원본/현재 자료 | 후속 처리 |
|---|---|---|---|
| 표기 형식 | M2A3 | 원본 이름 M3A3 | 이름 차이를 기록. 이 차이만으로 모든 외형 차이를 차종 차이라고 단정하지 않음 |
| 차체 비율 | 상면이 길쭉한 약 1.9:1 외형. 정식 치수 표기 없음 | 전체 부착물 포함 bbox 길이 약 6.577, 폭 약 3.432 원본 단위, 약 1.917:1 | 큰 비율에 뚜렷한 모순은 보이지 않음. 여기서 세부 비율 통과나 실측 정확도를 주장하지 않음 |
| 바퀴 | 측면 로드휠 6개 | 원본 road wheel 좌/우 각 6개 | 필수 보존. 상부 롤러와 현가 링크는 별도 숨은 부품으로 구분 |
| TOW | 차체 왼쪽의 쌍열 박스형 발사기 | `roll_05`에서 쌍열 개구부 확인, `rocket_mount_01`과 연결 | 원본 측면·좌표 유지. 발사기를 관측장비로 오분류하지 않음 |
| 지휘관 관측장비 | 높은 관측 박스와 외부 보호 구조 | `bone_commander_sight_v`=박스, `ex_armor_03`=외부 보호 구조 | 두 부품이 별도임을 유지. `ex_armor_03`을 TOW로 채색하던 예외는 2차 이후 교체 |
| 포탑 후방 | 상면도는 주로 곡선형 외곽을 간략 표시 | bone_turret 안에 5개의 개방형 수납함 형상 확인 | 원본 부품으로 보존/단순 대체. 연막탄 발사기로 바꾸지 않음 |
| 전방 덮개 | 포탑 전방 작은 판과 장비가 도면에서 간략하게 표현됨 | ex_decor_02/03에서 상·하 판형 덮개 확인. 상부 덮개는 현 메시가 비어 있음 | 구체적 장비 기능을 단정하지 않고 front upper/lower cover로 등록. 상부는 복구 대상 |
| 후방 지붕 해치 | 큰 사각 해치와 대표 힌지 | `hatch_05`가 해당 위치/외형에 대응 | 큰 판과 힌지를 남기고 잔구조만 정리 |
| 출입문/램프 | 후면 문과 해치가 별개 | `hatch_04`와 파생 `rear_ramp` 별도 힌지 | 애니메이션 분리 보존 |
| 연막탄 발사기 | 이 도면만으로 확실한 발사기 배치를 지정하기 어려움 | 추출 OBJ에서 대응 그룹은 미식별. 후방 5개 수납함은 대체 근거가 아님 | 필수 역할을 누락시키지 않고 미확정 항목으로 유지. 잘못된 위치에 임의 추가 금지 |

치수 bbox는 단위가 검증된 실차 제원이 아니며, 청사진과의 정밀 중첩 검수도 아직 아니다.
확인된 형상 차이와 자료가 생략한 부분을 모두 M2/M3 형식 차이라고 해석하지 않는다.

## 연막탄 관련 외부 교차 확인

[War Thunder Wiki의 M3A3 항목](https://wiki.warthunder.com/unit/us_m3a3_bradley)은 지원 장비에
Smoke grenades와 ESS를 기재한다(2026-10-22 확인). 이는 게임 차량의 장비 존재 확인에만 사용한다.
이 페이지의 텍스트로 추출 OBJ의 메시 이름이나 정확한 장착 위치를 확정할 수는 없다.
따라서 해당 역할은 역할 설정의 `unresolved_required_roles`에 남기며 2차 완료 판정 전에 시각 근거를 보강한다.
