# Bradley 현재 상태 검수와 수정 계획

검수일: 2026-10-22. 기준: `ArtSource/VEHICLE_ART_STYLE.md` v1.
대상: `RimWorld/bradley_rimworld.blend`, 해당 EAST 레이어와 256px/512px 출력.
이 작업은 읽기 전용 검수와 계획 작성이다. 모델·재질·기존 게임용 PNG는 수정하지 않았다.

## 결론

현재 결과는 원본 디테일의 일부를 삭제하고 법선으로 색을 나눈 상태다.
Legion처럼 큰 형상을 간단한 부품으로 재구성한 상태까지는 도달하지 못했다.
작은 잔선은 남고 주요 해치·포탑 장비의 읽기 쉬운 테두리와 면 구분은 부족하다.
따라서 **부품 역할 정리 → 주요 형상 대체 → 면 팔레트 설계 → 화면 크기 검수** 순서로 수정한다.
전체 밝기나 감량 비율을 다시 일괄 조절하는 작업은 우선하지 않는다.

## 확인 근거와 한계

- [무채색 비교판](style_comparison.png): Legion / 현재 / RimThunder 순서. 차체 폭 400px,
  포탑+포신 전체 폭 300px로 맞춤. 포탑 몸체 자체의 비율 판정에는 포신 길이 차이를 별도 고려해야 한다.
- [비교 크기 기록](style_comparison_metrics.json): 현 EAST의 실제 차량 폭은 256px 캔버스에서 195px,
  512px에서 388px. 작은 디테일 검수는 이 크기를 기준으로 한다.
- [모델 검사](current_model_stats.json): 메시 객체 83개, 43,344면. 이 중 15개는 면이 없는 빈 메시다.
  면적 0 검사에서는 퇴화 면이 발견되지 않았다. 이는 겹침·자기 교차·구멍 전체를 검증한 결과는 아니다.
- 앞/뒤 등각 PNG와 EAST 합성·분리 레이어를 확인했다. 게임 실행 검수와 새 청사진 3면 중첩 검수는 미실시다.
- 사용자 청사진은 M2A3, 현재 형상 원본은 사용자 제공 War Thunder M3A3 OBJ다.
  형식 차이를 이미 기록했으나 어떤 외형을 최종 기준으로 고정할지는 아직 모델 수준에서 정리하지 않았다.
- 비교판의 타 모드 이미지는 검수용 인용 자료이며 게임 에셋으로 사용하지 않는다.

P2는 품질을 안정화하는 정리다. 추정과 확인된 사항을 구분한다.

## 수정 순서와 작업 단위

### 1차: 원본 역할표와 형식 기준

- M3A3 원본의 비율/배치를 현재 기반으로 보존하고, M2A3 청사진과 다른 부분을 목록화한다.
  차종 변환을 조용히 수행하지 않는다. 기존 사용자 요청대로 OBJ 기반 작업을 이어간다.
- 83개 메시와 root 내부 면 집합을 부품 역할에 매핑한다. 빈 메시 15개의 원래 기능도 확인한다.
- 연막탄, 광학창, 힌지 등 작은 필수 부품을 먼저 지정한다.
- 산출물: ART_BRIEF 부품표, 역할 설정 파일. 검수 후 의미 있는 첫 작업 단위로 커밋.

### 2차: 포탑부터 간단한 새 형상으로 교체

- 포탑 두 해치 → 관측장비/TOW → 후방 장비 순서로 대체한다.
- 큰 포탑 장갑 경사는 원본 실루엣을 유지하면서 평면 단위로 정리한다.
- 필수 외형 보존과 큰 덩어리의 가독성을 먼저 확인한다. 재료 색은 임시 무채색으로 둔다.
- 완료 기준: Legion 포탑과 같은 몸체 크기로 비교해 잔선 밀도가 과하지 않고 주요 장비가 구분됨.

### 3차: 차체 지붕·후방 해치·그릴 정리

- 정면 서비스 패널/조종수 해치/후방 지붕 해치를 역할에 맞는 단순 판으로 정리한다.
- 겹침/의도하지 않은 선을 검사하고 그릴별 패턴을 개별 구성한다.
- 후방 램프와 출입문 피벗, 의도한 개구부를 유지한다.

### 4차: 공통 팔레트와 역할별 면 색

- TAN을 입히기 전 무채색으로 지붕/정면경사/측면경사/수직면/테두리를 맞춘다.
- 포탑/차체가 각각 독립적으로 읽힌 뒤 평균 밝기를 조정한다.
- 해치 상면은 주변 지붕에 가깝게, 테두리·측벽은 명확하게 한다.
- 높이/깊이 보정은 마지막에 켠다. 최종 PNG의 중요한 인접 면은 약 15~30 명도 차이를 시작점으로 비교한다.
- 수치 자체보다 Legion과 나란히 놓았을 때의 단순함과 가독성으로 판단한다.

### 5차: 축소·합성·동작 검수

- 현 크기인 차량 폭 195px/388px를 기준으로 비교하고 drawSize가 정해지면 다시 확인한다.
- 차체/포탑/포신 개별 레이어와 합성 결과를 확인한다. 포탑 몸체 폭 비교에서는 포신 길이를 제외한다.
- 앞/뒤 등각, 문 개폐, 포탑 회전, 서로 다른 배경, 알파 테두리를 검수한다.
- 결과를 ART_BRIEF에 기록하고, 승인 가능한 기준 샘플 후보로 제시한다.

## 이번 검수에서 유지할 것

직교 투영과 분리 레이어, 포탑/포신/문 피벗, 투명 배경, 광원/투사 그림자 없음은 유지한다.
43,344면이라는 숫자를 새 감량 목표로 삼지 않는다. ERA는 보류 상태를 유지한다.
기존 검증 파일의 통과 표시는 구조 검증 근거로만 사용하며 아트 스타일 통과로 확대 해석하지 않는다.
