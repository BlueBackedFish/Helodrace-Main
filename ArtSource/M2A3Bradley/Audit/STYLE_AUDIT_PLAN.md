# Bradley 현재 상태 검수와 수정 계획

**최신 방향 변경:** 사용자가 2차 포탑 재구성을 철회했다. 현재 작업은 2차 이전 모델의 형상을 보존하고
부품간 색 차이를 약 3배 확대하는 채색 전용 방식이다. 아래 2~5차 형상 재구성 순서는 현재 실행 계획이 아니라 이전 계획 기록이다.
활성 설정/재생성은 `../part_contrast.json`, `../recolor_bradley.py`를 사용한다.

검수일: 2026-10-22. 기준: `ArtSource/VEHICLE_ART_STYLE.md` v1.1.
대상: `RimWorld/bradley_rimworld.blend`, 해당 EAST 레이어와 256px/512px 출력.
검수 뒤 1차 역할표/형식 기준과 2차 포탑 재구성을 완료했다. 2차에서 포탑과 게임용 PNG를 갱신했다.

## 결론

현재 결과는 원본 디테일의 일부를 삭제하고 법선으로 색을 나눈 상태다.
RimThunder의 식별 디테일과 패널 구분을 단색 3D 면으로 재구성한 상태까지는 도달하지 못했다.
작은 잔선은 남고 주요 해치·포탑 장비의 읽기 쉬운 테두리와 면 구분은 부족하다.
따라서 **부품 역할 정리 → 주요 형상 대체 → 면 팔레트 설계 → 화면 크기 검수** 순서로 수정한다.
전체 밝기나 감량 비율을 다시 일괄 조절하는 작업은 우선하지 않는다.

### 기준 정정

Legion은 Bradley 기반의 별도 디자인이다. 그 디자인이나 생략 수준은 목표가 아니다.
**RimThunder의 차량 외형·디테일·가독성을 목표로, Legion의 3D 렌더·한 면 한 색 방식을 적용한다.**
기존 비교판은 유지하되 Legion과 디테일 수가 비슷해야 한다는 판단은 사용하지 않는다.
단순화로 없어져 RimThunder/청사진 대비 식별력이 낮아진 필수 부품은 먼저 복구한다.

## 수정 순서와 작업 단위

### 1차: 원본 역할표와 형식 기준

**완료(2026-10-22):** [역할표](Stage1/PART_ROLES.md), [형식 기준](Stage1/FORMAT_BASELINE.md),
차량별 `bradley_roles.json`, 원본 면 집합과 검증 기록을 작성했다. 112개 그룹 전체와 현 83개 객체를 대조했다.
빈 메시 15개 중 필수 복구 대상은 TOW 연결부 `roll_03`, 포탑 전방 상부 덮개 `ex_decor_02`다.
포탑 뒤 5개는 개방형 수납함이며 연막탄 발사기로 단정하지 않는다. 연막탄은 필수 역할로 유지하고
원본 대응/실제 배치를 미확정 항목으로 명시했다. 2차 완료 전 별도 확인한다.

- M3A3 원본의 비율/배치를 현재 기반으로 보존하고, M2A3 청사진과 다른 부분을 목록화한다.
  차종 변환을 조용히 수행하지 않는다. 기존 사용자 요청대로 OBJ 기반 작업을 이어간다.
- 83개 메시와 root 내부 면 집합을 부품 역할에 매핑한다. 빈 메시 15개의 원래 기능도 확인한다.
- 연막탄, 광학창, 힌지 등 작은 필수 부품을 먼저 지정한다.
- 산출물: ART_BRIEF 부품표, 역할 설정 파일. 검수 후 의미 있는 첫 작업 단위로 커밋.

### 2차: 포탑부터 간단한 새 형상으로 교체

**완료(2026-10-22):** [구현/근거/검증 보고서](Stage2/REPORT.md), [포탑 비교판](Stage2/turret_comparison.png).
필수 덮개/TOW 연결부 복구, 해치·관측장비·TOW·후방 수납함 대체, 원본 큰 장갑 경계 보존을 수행했다.
연막탄은 전방 양측 2×4 참고 배치로 원본 장갑에 부착했다. 정확한 A3 좌표가 아닌 아트 해석임을 명시했다.
포탑 3,654면, 전체 33,945면. 차체 형상/부모는 1차와 동일하며, 색은 4차에서 통일할 임시 역할 팔레트다.

- 포탑 두 해치 → 관측장비/TOW → 후방 장비 순서로 대체한다.
- 큰 포탑 장갑 경사는 원본 실루엣을 유지하면서 평면 단위로 정리한다.
- 필수 외형 보존과 큰 덩어리의 가독성을 먼저 확인한다. 재료 색은 임시 무채색으로 둔다.
- 완료 기준: RimThunder 포탑과 같은 몸체 크기로 비교해 장비·해치·손잡이·발사기의 식별력이 유지됨. 각 표면은 단색으로 읽힘.

### 3차: 차체 지붕·후방 해치·그릴 정리

- 정면 서비스 패널/조종수 해치/후방 지붕 해치를 역할에 맞는 단순 판으로 정리한다.
- 겹침/의도하지 않은 선을 검사하고 그릴별 패턴을 개별 구성한다.
- 후방 램프와 출입문 피벗, 의도한 개구부를 유지한다.

### 4차: 공통 팔레트와 역할별 면 색

- TAN을 입히기 전 무채색으로 지붕/정면경사/측면경사/수직면/테두리를 맞춘다.
- 포탑/차체가 각각 독립적으로 읽힌 뒤 평균 밝기를 조정한다.
- 해치 상면은 주변 지붕에 가깝게, 테두리·측벽은 명확하게 한다.
- 높이/깊이 보정은 마지막에 켠다. 최종 PNG의 중요한 인접 면은 약 15~30 명도 차이를 시작점으로 비교한다.
- 수치 자체보다 RimThunder와 나란히 놓았을 때의 형상·디테일·가독성으로 판단한다. 곡면 그라데이션은 여러 의도된 단색 면으로 재해석한다.

### 5차: 축소·합성·동작 검수

- 현 크기인 차량 폭 195px/388px를 기준으로 비교하고 drawSize가 정해지면 다시 확인한다.
