# 블루프린트 검수 후 수정 결과

`REVIEW.md`의 수정 전 항목을 기준으로 작업했습니다. 기존 모델의 좌표 단위를
그대로 사용했으며, 아래 수치는 실제 차량 치수 측정값이 아닙니다.

| 검수 항목 | 수정 결과 |
|---|---|
| 주요 장비 좌우 | 전방을 아래로 본 상면에서 엔진 그릴은 왼쪽, 조종수 해치/TOW는 오른쪽. 포탑 자체의 횡방향 편심은 유지. CITV 위치도 반대편으로 정리. |
| 포탑 전후 위치 | 전체 피벗과 부속품을 +Y 방향으로 0.75 이동. 장갑 앞끝은 Y=-0.63으로, 차체 앞끝에서 약 42% 지점. |
| 포탑 길이 | 뒤쪽 장갑을 0.15 연장해 외피 길이 2.32, 차체 길이 대비 약 37%. |
| 포신 | 0.40 단축. 포탑 이동을 합쳐 포구는 Y≈-2.52로 차체 앞끝 -3.25 안쪽. |
| 로드휠 | 지름 0.86→0.74, 최소 중심 간격 0.75, 중앙 간격 1.01. 최소 0.01 간극을 코드로 검증. 구동륜에 톱니 추가. |
| 그릴/해치 접합 | 평탄한 기관실 데크를 전방으로 확장해 그릴과 조종수 해치가 수평 지붕 위에 놓이도록 변경. |
| 전면 점검판 | 차체 경사식에 맞춘 실제 경사판으로 재작성. 장갑 내부에 묻히지 않으며 외곽 볼트 추가. |
| 후방 램프/문 | 둥근 모서리 출입문과 실제 개구부로 교체, 후면에서 왼쪽으로 위치 수정. 오른쪽 타원형 외곽선/고정구/손잡이 추가. 문 피벗 및 열림 부호 갱신. |
| 측면 디테일 | 한쪽에 큰 사각 루버와 9개 슬랫 추가. 좌우 비대칭 반영. |
| TOW | 측면 덮개, 힌지, 잠금장치, 끝단 캡 추가. 이동한 포탑에 지지대가 연결되도록 폭 조정. |
| 포탑 장갑 | 경사면을 유지하고 측판 이음선 추가. 연막탄 발사기 장착점도 경사면에 맞춰 재계산. |
| 관측 장비 | 주요 조준경 창을 중앙 프레임으로 분할. |
| 후방 지붕 | 경사진 테두리를 갖춘 해치로 변경, 뒤로 이동/축소. 양쪽 수납함 길이와 위치를 다르게 정리. |
| 기타 외형 | 전조등 보호대와 고리 형태 전방 견인부 추가. |

## 검증

- 생성 단계에서 좌우 배치, 포구의 차체 앞끝 안쪽 위치, 포탑 전후 위치,
  타이어 비중첩을 검사합니다.
- `.blend` 재열기, 애니메이션 피벗 계층, 무조명 설정, PNG 투명도와 잘림을 검사합니다.
- `render_audit.py`로 상면/측면/정면/후면을 재출력합니다.
- `render_vf_east.py`로 east 전체 및 차체/포탑/포신 분리 레이어를 재출력합니다.

## 표현 범위

치수 없는 일러스트를 해석한 게임용 모델입니다. 작은 체결 볼트의 정확한 개수,
해치 곡면, 용접선, 궤도 가이드 및 실내는 여전히 단순화되어 있습니다.
TAN 재질과 투사 그림자 없음, 포탑·포신·램프·출입문의 독립 움직임을 유지합니다.
VF 게임 내 drawSize/offset 연결 및 실제 플레이 검증은 별도입니다.
