# 차량 아트 작업 기록 — Bradley A3 BUSK III 외장 시안

## 자료와 목표

- 요청 차종/형식: 현재 Bradley에 BUSK 장착. BUSK III 외형을 작업 가정으로 사용.
- 원본: `../EmissionTrial/TOWDeploy/bradley_tow_deploy.blend`, SHA-256 `9626560c347450ddc43a292efcf3580aefeff4e916c7dd7330f8e8186eee9e44`.
- 실차 장착 청사진: 치수 기입 도면 미확보. 사용자가 처음 준 기본 Bradley 삼면도에는 이번 BUSK 치수가 없다.
- 외장 근거: `REFERENCES.md`의 GD/Rafael 수량표, MENG 조립도/외형도, 실차 외관 사진.
- 단위/좌표: 기존 장면의 m 기준, 전방 -Y, 위 +Z, 차량 좌측 +X. 원본 축/스케일 유지.
- 원본과 형식 차이: 기존 폴더는 M2A3, 형상 출발점은 WT M3A3. 이번에도 대체/수정하지 않음.
- 스타일: 기존 Bradley Emission TAN을 유지. RimThunder 외형/가독성 목표, Legion은 렌더 방식 참고. 추가 장갑 면도 고정 Emission.
- 최종 해상도: 1024 마스터와 256/512. 검수 외피 폭은 `output/OutlinedReview/report.json`에 기록. 게임 drawSize 미확인.
- 공통 도구: 기존 Bradley 빌더/카메라와 공통 `images.py`, `outline_review.black_outline` 재사용. 범용 새 차량 `vehicle.json`으로 기존 Bradley를 덮어쓰지 않음.
- 상태: 외장 초안. 실차 치수 및 번호별 위치 미검증을 기술 검사 통과와 구분함.

## 면 색과 렌더 설정

- 기존 본체/해치/손잡이/홈/그릴 채색 보존. 넓은 곡면 고정 색 보간도 기존 값 유지.
- 추가 차체 케이스의 기본 표시 명도: 상부 192 / 전후면 168 / 측면 144 / 하부 96.
- 추가 포탑 케이스: 216 / 192 / 168 / 108. 하부 구획: 168 / 144 / 132 / 96, 중앙 분할 108.
- 방향/기울기를 고정 면색에 적용. 조명/카메라 거리로 재질 값을 바꾸지 않는다. 음영 때문에 낮은 명도는 기존 팔레트 함수의 채도 저하를 따른다.
- 후방 해치, 포탑 지붕/해치/장비는 기존 관계 보존. 추가 케이스 사이에 전역 높이 순위를 강제하지 않는다.
- 기존 패킹된 사각 그릴 유지. 이번에 그릴 밀도/기존 부품 디테일을 다시 줄이지 않음.
- 그림자/광원 없음, 투명 배경. 차체 EAST 64°, 포탑 EAST 90°, 직교 스케일 약 8.7.
- 포탑 중심은 원래 yaw 피벗. 검수 후처리는 차체와 포탑 각 1px/256px 검은 실루엣을 적용하고 합성. `turret_full`은 포신 포함.
