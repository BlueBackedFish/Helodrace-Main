# M2A3 Bradley — TAN

제공된 5면 도면을 참고한 림월드 차량 스프라이트용 3D 아트 모델입니다.
도면의 차체, 6개 로드휠, 각진 포탑, 쌍열 TOW 발사기, 조준경,
후방 램프 실루엣을 재현했습니다. 제조용 정밀 CAD 모델은 아닙니다.
포탑은 좁은 하단 베이스, 넓은 장갑 어깨, 안으로 기울어진 전면·측면,
그 경계에 맞춘 좁은 지붕으로 구성합니다. 후면은 상대적으로 수직에 가깝게
유지하며, 측면 볼트도 경사면에 붙어 있습니다. `manifest.json`에 실제 모델의
주요 경사각을 기록합니다(이미지 도면을 해석한 모델 값이며 실차 사양값은 아님).
상면도(전방이 아래) 기준 엔진 그릴은 왼쪽, 조종수 해치와 TOW는 오른쪽입니다.
검수 후 포탑을 0.75 뒤로 이동하고 장갑 후부를 0.15 연장했으며 포신을 0.40 줄였습니다.
로드휠 지름은 0.74, 최소 중심 간격은 0.75이고 중앙 간격은 더 넓습니다.
큰 측면 루버, TOW 덮개/힌지, 후면 타원형 요소와 둥근 출입문도 포함합니다.

## 파일

- `m2a3_bradley.blend`: 메시, 재질, 카메라, 피벗과 데모 애니메이션을 포함한 편집 원본.
- `m2a3_bradley.glb`: 계층과 애니메이션을 포함한 교환용 모델.
- `bradley_iso_front.png`, `bradley_iso_rear.png`: 1024×1024 등각 투영 미리보기.
- `bradley_north/east/south/west.png`: 게임 스프라이트 제작용 4방향 원본.
- `bradley_ramp_open.png`, `bradley_personnel_open.png`: 문 동작 확인 이미지.
- `build_bradley.py`: 모델과 렌더 재생성 스크립트.
- `manifest.json`: 저장된 모델 재열기 및 PNG 검증 결과.

## 편집과 애니메이션

전방은 **-Y**, 위쪽은 **+Z**입니다. 전체 이동에는 `BRADLEY_ROOT`를 사용합니다.

| 피벗 | 상위 | 회전축 | 용도 |
| --- | --- | --- | --- |
| `HULL` | `BRADLEY_ROOT` | 전체 | 차체 및 궤도 |
| `TURRET_YAW` | `HULL` | 로컬 Z | 포탑 회전 |
| `GUN_ELEVATION` | `TURRET_YAW` | 로컬 X | 포신 고저, 양수로 올림 |
| `REAR_RAMP_HINGE` | `HULL` | 로컬 X | 후방 램프, 약 -100°로 내림 |
| `PERSONNEL_DOOR_HINGE` | `REAR_RAMP_HINGE` | 로컬 Z | 램프 안쪽 출입문, 음수로 바깥쪽으로 열림 |

각 부품의 세부 메시는 해당 피벗 아래에 묶여 있습니다. 궤도와 바퀴는
독립 메시지만 주행 애니메이션은 구성하지 않았습니다. 상부 해치는 정적 디테일입니다.
후방 개구부에는 단순한 내부 바닥과 어두운 칸막이가 있으며 전체 실내는 없습니다.

타임라인은 24fps, 1–120프레임입니다. **1프레임이 닫힌 기본 자세**이며,
25프레임은 작은 문, 40프레임은 포탑과 포신, 80프레임은 램프 동작 예시입니다.
직접 포즈를 만들 때는 각 피벗의 데모 액션을 해제하거나 새 키프레임을 넣으세요.

## 렌더

설치된 **RimThunder - Desert Sabre - Continued** (Workshop ID `3724793908`)의
`Textures/Vehicles/M2A3/vehicle_east.png`, `vehicle_turret_full.png`와
`Textures/Vehicles/M1A2/vehicle_south.png`를 직접 비교해 채색했습니다.
원본의 회색 명암 텍스처와 `CutoutComplexPattern` 셰이더를 참고하여,
노란 기가 적은 TAN, 넓은 면 사이의 명도 차이, 밝은 패널 모서리와
짙은 회색 궤도를 적용했습니다. 원본 이미지 자체를 복사하거나 포함하지 않았습니다.

상면 RGB `(213,204,180)`, 측면 `(169,159,135)`, 전후면 `(150,141,120)`,
모서리 `(237,230,209)`, 궤도 고무 `(30,31,29)`를 사용합니다.
주요 장갑과 해치의 0.012m 모서리 면에 밝은 고정 색을 넣어 GLB에도 유지합니다.

TAN 팔레트를 면 방향별로 배정한 Emission 재질에 카메라 방향/깊이 명도 보정을
적용합니다. 카메라를 향하고 가까운 면은 밝아지며 포탑 도장은 별도 1.18배
선형 RGB 보정으로 차체보다 밝습니다. 조명, 바닥,
그림자와 AO를 사용하지 않으며 배경은 투명합니다. 면 사이의 명도 차이는
입체감을 위한 색상 및 카메라 보정으로, 투사 그림자가 아닙니다.

해치 구분을 위해 TAN 도장의 높이 보정 범위를 지붕 주변으로 좁혔습니다.
차체 Z=2.10~2.23m, 포탑 Z=2.96~3.09m에 선형 RGB 배율 0.84~1.00을
연속 적용합니다. 해치의 기존 밝기를 유지하고 아래 상판을 어둡게 하므로
수 cm의 단차도 명도로 구분됩니다. 범위 밖은 끝값으로 고정됩니다.
높이는 차량 루트 기준이며 비도장 재질은 기존 0~4.2m / 0.90~1.00 보정을 유지합니다.

포탑 장갑과 지붕의 모서리는 밝은 흰 테두리 대신 상판/경사면 사이의 TAN
`(191,182,157)`를 사용합니다. 후방 문 위에는 고정 `Rear roof closure` 판을
추가해 상판과 후방 문틀 사이를 메웠으며, 램프를 내려도 천장이 유지됩니다.

별도 ERA 장착형과 블록별 개별 파일은 [ERA/README.md](ERA/README.md)를 참고하세요.

등각 카메라는 하향 35.264°, 4방향 카메라는 기존 저장소 아트에 맞춰 하향 64°입니다.
모두 직교 투영, 동일한 중심과 스케일(8.7)을 사용합니다.
4방향 이름은 카메라 위치 기준입니다(N=+Y, E=+X, S=-Y, W=-X).
차량 프레임워크의 실제 방향 명명과 drawSize에 맞춰 연결해야 합니다.
이번 작업은 아트 에셋 제작이며 게임 Def 또는 차량 모드 코드 연결은 포함하지 않습니다.

GLB는 카메라/높이 보정 셰이더 대신 고정 Emission 색상을 사용하는 교환용입니다.
다른 뷰어의 재질 처리에 따라 표시가 달라질 수 있으므로
그림자 없는 최종 스프라이트 출력은 Blender 원본을 기준으로 하세요.

```powershell
& 'C:\Program Files\Blender Foundation\Blender 5.1\blender.exe' --background --python '.\ArtSource\M2A3Bradley\build_bradley.py'
```
