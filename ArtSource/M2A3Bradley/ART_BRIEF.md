## 채색

- 주포/포신/전방 덮개의 옛 삼각형별 재질 배치를 폐기하고 실제 법선 방향으로 기본색을 재계산한다. 같은 평면의 기본색 일치를 검증했다.
- 높이 2.1 기준 선형 광량을 높이당 0.22 조정하고 0.62~1.18로 제한한다. 카메라 깊이는 0.985~1.015의 약한 보정이다.
- 곡면 해치에는 높이와 부드러운 법선 명도 보간을 사용한다. 해치 02 후방 상부 연결봉·힌지·끝 받침은 밝은 TAN(246,228,187)으로 강조한다.
- TOW·관측장비 보호대·평판·후방 수납함의 어두운 TAN을 (145,122,84)로 강화했다. 포탑 후방 바구니 안쪽 바닥은 (126,106,75)로 칠해 인접 경사보다 어둡게 만든다.
- 일반 방향 대비는 기존값 대비 1.4배, 나머지 부품 차이 보정 계수는 4다. 해치/명시적 역할 팔레트에는 이 수치를 일괄 적용하지 않는다.
- 안쪽 홈은 용접 위치 기준의 오목한 모서리와 이어진 표면 영역으로 분류해 광량 0.62의 별도 페인트를 적용한다. 그림자/AO가 아니다.
- 평면 삼각형을 하나의 표면으로 묶으며 단독 삼각형은 자동 홈 채색에서 제외한다. 곡면 해치와 포신은 자동 홈 마스크에서 제외해 삼각형 얼룩을 방지한다. 포신 내부/유리/금속은 별도 어두운 재질을 유지한다.
- 설정은 `part_contrast.json`, 표면 역할·홈 분류는 `surface_accents.py`, 연결 영역 판별은 `mesh_regions.py`, 복구는 `turret_repairs.py`다.

## 출력·검증

- 편집 모델: `RimWorld/bradley_rimworld.blend`, 교환 모델: `.glb`.
- EAST 차체 64도, 포탑/포신 90도 상면 직교 투영. 1024px 마스터와 256px/512px 분리 PNG·미리보기·피벗 정보를 갱신했다.
- 앞/뒤 등각 뷰, 포탑 확대 앞/뒤, 512px EAST를 시각 확인했다. 확대 전후 기록은 `Audit/TurretFollowup/REPORT.md`에 있다.
- `recolor_validation.json`: 원본 그룹·연막탄 면 위치, 변경 범위, 주포 평면 기본색, 밝은 연결부·어두운 후방 바닥·홈 검증.
- `validation.json`: 저장 모델의 면적 0 면 없음, 4개 애니메이션, 투명·무광원·ERA 제외 검증.
- 112개 원본/파생 그룹 목록과 입력 해시 검증 통과. 역할표의 43,344면은 역사적 1차 입력 통계이며 현재 출력 통계가 아니다.
- ERA는 보류한다. 실제 게임 drawSize·줌에서의 검수는 미실시다. BLEND/PNG가 최종 채색 기준이며 GLB는 고정 Emission 대체 색만 포함한다.
