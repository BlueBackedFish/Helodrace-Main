# M2 방열구멍·총열 단차·CROWS 총몸 디테일

기준 커밋 `17ab00d8`에서 M2HB의 방열 슬리브 외피와 안쪽 총열이 같은 금속색이어서 실제 구멍이 묻혔다. 총열 기부·단차·가는 구간도 같은 색이었다. CROWS 원본 M2는 별도 메시인 슬리브와 총열뿐 아니라 총몸 내부의 덮개·조준기·체결부 구분도 약했다.

`VEHICLE_ART_STYLE.md`의 원본 형상 보존, 구멍 내부의 별도 암색 재질, 직접 장착 경계 대비, 원통 원주 측면 단색 규칙을 적용했다. 형상을 다시 만들거나 구멍을 임의로 그리지 않았다. 카메라·부품 배율·피벗·레이어·외곽선 두께·FDE 도색은 유지했다.

- 방열 슬리브: 바깥 원통 외피 `(103,111,106)`, 구멍 벽/안쪽 총열 `(25,32,29)`, 연결 가장자리 별색. 원본 구멍을 통해 안쪽 총열이 보인다. 내향 방사 법선과 실제 방열구간으로 구멍 안쪽을 분류한다. 원주 둘레를 광원 방향별 명암 띠로 나누지 않는다.
- 총열: 실제 원본 정점 링에서 굵은 기부, 어깨/단차, 가늘어지는 긴 구간, 총구 위치를 확인해 축 방향 부품색을 지정했다. 각 원통 구간의 원주 전체가 같은 고정색이다. 총구 안쪽은 암색 재질이다.
- CROWS 총몸: 원본 `.50CAL` 연결 부품과 범위를 대조해 덮개, 급탄부, 조준기, 손잡이, 체결부를 색으로 구분했다. 부품 ID는 `CROWSII/build.py`의 `M2_COMPONENT_ROLES`에 기록했다. CROWS 전용 프레임·탄통·센서 하우징은 이전 색을 유지했다.

공통 팔레트·두 모델의 축/단차 좌표는 `m2_detail.json`, 고정 재질 분류는 `m2_detail.py`에 있다. 각 모델의 `detail_paint.json`에도 실제 적용 설정을 저장한다. M2HB/M1917의 기존 원본 면·정점·UV, 피벗·크기, 탄통/탄띠, 장착 등록·반동값 검사를 통과했다. CROWS도 빌더 내부에서 원본 면·정점·UV를 비교했다.

`review_m2_detail.py --baseline 17ab00d8`는 출력의 방열구멍 내부와 외피, 기부·단차·가는 구간·총구의 불투명 픽셀을 검사한다. 마스터·게임용 PNG 35개에서 이전 알파와 동일함을 확인했으며, M1917 및 CROWS 프레임/받침의 픽셀도 동일하다. `output/m2_detail_validation.json`에 결과가 있다. `output/m2_detail_comparison.png`는 같은 총의 전후 길이를 맞춘 무윤곽 확대 비교다. 실제 1024 출력과 축소된 각 자산의 `output/preview.png`에서도 구멍과 연결부를 시각 검수했다. 작은 체결부는 축소 시 일부 합쳐진다.

M2HB 교체 텍스처는 설치 모드에 백업 후 반영했다. CROWS는 기존 아트 자료의 범위이며 게임 정의를 추가하지 않았다. 실제 게임 실행·사격 검증은 하지 않았다.
