# 기관총·CROWS 차량 채색 규칙 적용

요청 범위는 M2HB·M1917·CROWS II의 채색 수정이다. 컴퓨터와 차량 본체는 수정하지 않았다. 수정 직전 기준 커밋은 `49c640ed`이다.

이전 출력은 탄통·CROWS의 넓은 장비 면이 같은 FDE 색으로 합쳐져 부품 경계가 약했다. `../VEHICLE_ART_STYLE.md` 4·5·14절을 근거로 평판의 상면/정면/측면/바닥을 구분하고, 직접 장착된 뚜껑과 지지부의 경계 대비를 고정 팔레트로 표현했다. 표시 명도가 낮아질수록 페인트 채도를 낮춘다. FDE 색상 계열은 유지한다. 전체 월드 높이 순위나 광원·AO로 색을 계산하지 않는다.

표면 유형과 변경 범위:

- 탄통·뚜껑·CROWS의 평판 플랫폼과 관측장비 하우징: 역할·방향별 고정색. 탄통 상면→뚜껑과 받침→상단 캡의 실제 표시 RGB 명도 차이는 약 24.5이다. CROWS 플랫폼(142)과 장비 상면(170)은 별도의 역할색이다.
- M1917 수랭 재킷·삼각대 다리·CROWS의 작은 원통 기구: 측면 원주 전체 단색. 수랭 재킷과 수직 받침대는 축 방향 끝면만 별색으로 구분한다.
- 총열·고무·급탄 슈트·유리·탄피·탄두·탄띠: 별도 고유 재질. M2HB/M1917의 목재 및 탄띠 채색과 총열색을 유지했다. CROWS 총몸의 평판에는 고정 금속 면색을 적용하고 총열·슬리브는 단색을 유지했다.

유지한 변수는 원본 면·꼭짓점·UV, 피벗, 형상, 비율, 장착 자세, 카메라, 캔버스, 1024px 게임용 해상도, 0.026칸 외곽선과 10px 아이콘 외곽선이다. 수치 팔레트는 `weapon_paint.json`, 계산은 `surface_paint.py`, 실제 부품 선택은 각 자산의 `build.py`에 있다. 차량 문서의 색상 수치를 승인된 실측 팔레트로 간주하지 않고 이번 무기용 FDE 역할 팔레트를 명시적으로 저장했다.

검수 결과:

- `output/weapon_paint_review.png`: 256px/512px 컬러·무채색 검수. 256px에서도 밝은 탄통·어두운 장착대가 분리되고 CROWS의 주요 장비 경계가 보인다. 512px에서 평판 색 구분과 원통의 단색 유지, 외곽선 이음새를 확인했다. 작은 총몸 내부 디테일은 축소 시 일부 합쳐진다.
- 각 자산 `output/paint_revision_comparison.png`: 직전 결과와 같은 크기로 놓은 전후 비교.
- `output/weapon_paint_validation.json`: 마스터·게임용 PNG 35개의 이전 알파 해시가 모두 동일하다. 윤곽선 실루엣과 두께·등록 위치를 유지했다. 최종 PNG의 불투명 픽셀에서 목표 팔레트가 실제 출력됐음을 확인했다.
- 기관총의 원본 면/꼭짓점/UV 대조, 회전축·크기·M2 탄띠와 닫힌 탄통, M1917 실제 DLL 보정에 따른 8방향, 등록 파일·반동값 검사를 통과했다. CROWS도 빌더에서 원본 면/꼭짓점/UV 보존 검사를 통과했다.

M2HB/M1917의 교체 아트는 설치 모드에 백업 후 반영했다. CROWS는 기존과 같이 후속 연결용 텍스처·편집 모델 자료이며 새 게임 정의는 추가하지 않았다. 실제 게임 실행 검증은 하지 않았다. 공유 팔레트는 두 자산 빌더에서 읽으므로 팔레트를 바꾸면 양쪽을 다시 출력한다. 기본 재생성 명령은 각 자산 README에 있다.
