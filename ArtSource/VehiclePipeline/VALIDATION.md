# 공통 차량 제작 도구 검증

검증일: 2026-10-23. Windows / Python 3.12.14 / Blender 5.1.2 / Pillow 12.3.0 / numpy 2.3.5.

## 코드 검사

`python -m unittest discover -s ArtSource/VehiclePipeline/tests -v`: 6개 통과.

- 음수 OBJ 인덱스, UV/normal 인덱스, 반복 group 선언, 여러 group에 속한 한 면의 중복 방지.
- 앞/위 축 변환과 좌표계의 handedness 보존. Bradley `(X,Y,Z) → (-Z,-X,Y)` 확인.
- 미확인 그룹 보존, 면 집합 추출 후 나머지 면 자동 배정, 중복 추출/미승인 삭제 거절.
- 직접 겹침 그래프만 밝기 순서를 생성. 독립 부품 같은 명도 허용. 순환·팔레트 상한 초과 거절.
- UV seam의 중복 위치를 연결 성분 선택에 사용하면서 원본 데이터 불변.
- 선형광 축소/합성의 50% 흑백 명도 약 188, 투명 검정 경계의 암색 번짐 방지.

## 다른 이름/형상의 차량으로 통합 검사

Bradley 오브젝트 이름을 사용하지 않는 시험 차량을 임시 생성한다. 7개 그룹·37개 면, 서로 다른 좌표계, 평면 그릴, 포탑/포신/문을 사용했다.

- 37/37 원본 면과 월드 좌표 보존, 7개 메시 유지.
- 포탑 yaw → 포신 elevation 부모 구조와 독립 문 피벗 생성.
- 각 rig의 설정 각도 도달 및 원본 닫힌 자세 복귀, GLB animation 3개 확인.
- 직접 겹친 상면 실제 명도 168→192→216, 최소 간격 각각 24 확인.
- 상면 명도 설정만 정상이고 실제 roof override가 120으로 뒤집힌 실패 사례는 빌드를 거절하며 성공 report를 남기지 않음.
- packed 사각 그릴, GLB unlit texture/UV 유지, 불필요한 `COLOR_0` 없음.
- 조명 없음 ↔ 강도 100 SUN: 렌더 RGBA 최대 차이 **0/255**.
- 차체 64도·포탑/포신 90도 분리 및 공통 스케일·피벗 합성.
- 256/512px 선형광·알파 선곱 축소, 투명 여백 검사. 실제 크기 이미지에서 격자·밝은 겹침 부품·암색 포신 표시 확인.
- 게임/청사진/RimThunder 비교 미검수 플래그를 그대로 유지해 결과는 draft로 기록.

이 시험용 상자 차량은 아트 스타일 승인 샘플이 아니다. 이름이 다른 입력에서 공통 도구가 동작하는지 확인하는 fixture다.
