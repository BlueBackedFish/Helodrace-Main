# 2000s multi-tasking mill-turn machine

Original 4x3 circa-2000-2008 mill-turn center. The broad enclosure, opposed main/subspindle chucks, shared stock, angled B-axis milling head, large guard windows and compact display console establish its later generation. The central roof is presented with a service opening and the sliding guards are partly open. This is fixed authored geometry in every view, not a camera-dependent visibility trick. Window colors are opaque proxy paint; there is no physically simulated glass.

`build_multitask.py` exports `HD_MultiTaskMachine2000.blend`, four actual 64-degree orthographic views, 1024px transparent color/mask pairs and fixed 12px outlines. drawSize is (6,6); any headroom offset is recorded in `validation.json`. The neutral machine palette matches the older industrial set, with restrained blue-gray windows and screen.

The active staffed electric worktable uses 6500W, work-speed factor 5 and the combined turning/milling recipes of the early CNC machines. It supplies both lathe and milling facilities to firearm benches. Research: integrated mill-turn machining, following industrial automation. The game abstracts automatic machine cycles into staffed bills.

Period-family guidance: [Mazak history](https://www.mazak.com/uk-en/about-us/company-history/) records the late-1990s INTEGREX and 2001 e-series development. This model borrows that equipment family without reproducing a branded machine. No additive-manufacturing head, robot cell or modern network display is added. No in-game visual/play test has been performed.
