## 원본 모델 대비 생략 (렌더 비교)

- 천·자루·위장망·로프·케이블·공구·난간 같은 부드럽거나 가는 적재물은 지운다(M1A2 모래주머니, M18 침낭·케이블·난간).
- 수납함과 블로아웃 패널은 깨끗한 상자·판으로 남기고 손잡이·볼트만 굵은 점과 고리로 표시한다(M10, M1A2).
- 엔진 그릴은 패널 모서리에 맞춘 규칙적인 줄이나 격자로 다시 그린다. M10·M18은 약 2px 줄이고, M2A3는 1px 수준의 촘촘한 망이라 256px에서 회색 면처럼 보인다.
- 포탑 밑 차체 지붕은 그리지 않는다. 검은 원(M1A2·M10·M18)이나 지붕색 고리(M2A3)로 둔다.
- 오픈탑 포탑 내부는 검정 바탕에 큰 장비 몇 개만 남긴다(M18).
- 바퀴는 부드러운 방사형 명암의 타원, 궤도는 거의 검은 단색이다. 둘 다 도색하지 않는다.
- 판 윗모서리에 1–2px 밝은 선을 넣어 벽과 판을 나눈다. 내부 검은 선은 쓰지 않는다. 바깥 검은 윤곽선은 차체·포탑에 각각 구워져 있고 1024px에서 약 8–10px다.
- 실루엣·비율·포탑 위치·주요 해치·관측장비 배치는 원본을 따른다.
