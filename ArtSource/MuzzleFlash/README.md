# Corrected side-profile muzzle flashes

Final assets: ../../Textures/Things/Mote/MuzzleFlash_{Radial,Upward,Bare,Suppressed}.png

256 x 256 RGBA PNGs. Shared muzzle root (48,128), top-left image coordinates. Forward is right. Faint glow extends a few pixels behind the root. Assets only; mote definitions have not been changed.

Built-in image generation used collective style references from both requested Workshop folders. Black-matte sources retained here. ImageMagick export uses maximum-channel alpha and unpremultiplied RGB to remove the matte, discarding coverage below 0.015 while retaining partial alpha. Suppressed opacity is reduced to 78%. See export.ps1.

Comparison backgrounds are for review only, not part of exported textures. Reviewed side by side at 256,64,32 pixels.
