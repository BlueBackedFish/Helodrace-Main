# M8 AGS · C-17 · HELLVADS

M8 AGS는 LEVEL 3 한 종류를 제공한다. 3인 승무원, 3×5칸, 기본 중량 25,000kg, M35 105mm 자동장전 주포(준비탄 21발), M240(800발), 지휘관용 M2HB(100발)를 사용한다. M2HB는 큐폴라 중심에서 독립 조준하며 주포와 별도로 반동한다. 브래들리 기본 중량은 23,000kg, BUSK 추가 장갑은 2,000kg이다.

`중장비 공수 체계` 연구 후 차량 메뉴에서 M8과 C-17을 제작하고 기계가공대에서 팔레트와 낙하산을 따로 만든다. `HELLVADS 차량 팔레트`는 완충재·고정끈을 포함해 700kg이고 `HELLVADS 화물 낙하산 묶음`은 낙하산 4개·현수줄을 포함해 300kg이다. 두 장비 모두 회수·재사용한다. 이전 통합 키트 정의는 제거했다.

C-17은 아스널 항공기 프레임워크의 조종사·급유·지도 비행·월드맵 원정을 사용한다. 텍스처는 3243px, 표시 크기는 19×19타일이다. 공중 표시 위치에만 고도에 따른 화면상 높이를 적용하여 차량이 기체 꼬리 아래에서 자연스럽게 이탈한다. 비행 경로와 실제 지도 좌표는 유지한다.

사용 순서:

1. 정지한 브래들리 또는 M8의 인벤토리에 팔레트와 낙하산 묶음을 하나씩 넣고 `HELLVADS 강하 준비`를 누른다.
2. 무장을 차체 전방으로 돌리고 반동·조준·사격 대기를 해제한다. 브래들리는 TOW와 장전 해치를 접는다. 준비 시작부터 장비 해제까지 새 탑승·이동·발사를 차단한다. 이미 걸어오는 탑승 작업도 중단한다. 기존 승무원은 유지한다.
3. 무장·액추에이터 정렬이 끝나면 주기 중 C-17에서 `장갑차량 적재`를 누른다. 14타일 이내 차량 한 대를 싣고 5초간 적재 중 이륙을 차단한다.
4. 수평 비행 중 `HELLVADS 강하 지점`을 지정한다. 실제 투하 순간의 항공기 방위로 차량을 정렬한다. 차량·팔레트·고정끈·낙하산·현수줄을 모두 항공기보다 아래 레이어에 그린다.
5. 6초 강하의 전반부에는 수평 관성이 줄어들며 대각선으로 이동하고, 55% 이후에는 수직 낙하한다. 낙하산은 펼쳐지며 이동 방향에 맞게 기울었다가 안정된다. 현수줄은 움직이는 낙하산 림과 팔레트 고정점을 연결한다. 마지막 10%에서 착륙용 4방향 자세로 부드럽게 정렬한다.
6. 착륙 후 `강하 장비 해제`를 누르면 두 장비가 인벤토리로 돌아오고 탑승·이동·발사가 복구된다.

총중량 한도는 30,000kg이다. VF 차체·인벤토리 중량에 승무원과 개인 장비, 장전 탄약, 연료, 설치된 장비와 BUSK를 합산하며 인벤토리 장비를 중복 계산하지 않는다. 준비·적재·강하 지정·실제 투하에서 검사한다. 이번 변경은 일반 차량의 연료별 중량 시스템을 추가하지 않는다.

강하 지점은 차량 전체 칸의 지형 지지력·물·지붕·건물·폰·주기 항공기·다른 강하 화물과의 겹침을 검사한다. 투하 전 막히면 화물칸에 유지하고, 투하 후 막히면 12타일 안의 빈 지면을 찾는다. 없으면 실제 차량과 승무원을 보존하며 기다린다. 착륙 지점 변경도 12타일 이내로 제한한다.

실제 `VehiclePawn`을 항공기 화물칸 → 낙하 화물 → 지도로 옮긴다. 부품 손상·탄약·연료·승무원·BUSK/ERA·인벤토리·장비를 깊은 저장하며 강하 시작 위치·방위·경과 시간도 저장한다. 지도에 없는 차량의 전체 Tick은 호출하지 않고 승무원·인벤토리 홀더만 갱신한다.

아트 원본은 메인 저장소 `ArtSource/HeavyAirdrop/`이다. 팔레트·고정끈·현수줄·낙하산은 개별 등록 레이어이고 원본 메시와 UV를 유지한다. 실행 중 현수줄은 방향별 등록 좌표로 동적 생성한다. `configure_gameplay.py --mod-root <Arsenal>`이 장비 정의·아이콘·번역·차체 중량·림 연결점을 갱신한다.

빠른 검증은 `Source.Vehicles.Tests/DropMotion.Tests.csproj`(낙하 전환 계산)와 `DropRenderSmoke.csproj`(실제 VF 홀더·탑승·무장·중량 및 네이티브 GPU 캡처)를 사용한다. 테스트 DLL은 별도 시험 모드에만 넣는다. 이번 검증은 장시간 지도 생성·월드맵 비행·저장 복원 통합 루프를 실행하지 않았다. 검수 이미지와 기록은 메인 저장소 `ArtSource/HeavyAirdrop/output/descent_*`에 둔다.
