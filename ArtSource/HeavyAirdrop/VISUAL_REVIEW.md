# 시각 검수

세 차량의 동서남북 모델 렌더와 런타임 레이어를 확인했다. 첫 출력에서는 전방 낙하산이 차량을 가리는 문제가 있어 낙하산을 높이고 등록 캔버스를 18타일로 넓혔다. 수정본은 차량의 차체·포탑과 팔레트, 네 낙하산 및 현수줄의 연결을 함께 구별할 수 있다.

색은 기존 차량의 고정 TAN을 유지하고, 팔레트는 회색, 완충 블록은 갈색, 고정끈은 탁한 올리브, 낙하산은 미색으로 구분했다. 실제 광원으로 볼륨을 굽지 않고 낙하산 고어마다 고정 색을 배정했다. 현수줄은 신규 곡선 모델이며 원본 차량 메시를 재가공하지 않았다.

`output/rig_review.png`는 장비와 원본 차량의 연결을 보는 모델 검수 이미지다. 게임 레이어에는 차량을 포함하지 않는다. 팔레트·낙하산의 최종 12px 검은 윤곽선과 안티앨리어싱은 `output/*/Textures/`에 적용되어 있으며, 고정끈·현수줄은 자체 형상의 굵기를 유지한다. 자동 검증 결과는 `output/delivery_validation.json`에 기록한다. 게임 내 표현과 기능 검증은 아스널의 별도 통합 테스트 결과로 관리한다.
