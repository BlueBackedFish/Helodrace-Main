# Converter

Original simplified Bessemer-family vessel with an open narrow neck, broad pear-shaped body, lateral trunnions, two bearing columns, a tilting drive and bottom air feed. The gray industrial palette matches the other machinery; only stone footings respond to construction material. No flames, dense fasteners, lights or texture noise.

Footprint 3×3, native 768px, 12px outline, four 64-degree orthographic views. `build_converter.py` creates `HD_Converter.blend` and aligned color/mask pairs. Run the shared density publisher after later edits. Existing recipes and blast-furnace facility linking are retained.

Form guidance: [Science Museum Group, original pilot Bessemer converter (1865)](https://collection.sciencemuseumgroup.org.uk/objects/co19568/original-pilot-bessemer-converter-1865). The model is a related early-industrial game asset, not a reconstruction of that exhibit. Original game texture/mask are preserved in Reference. No in-game verification is claimed.
