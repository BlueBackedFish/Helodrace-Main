# 1970s electric-hydraulic press

Original 3x3 circa-1970-1978 straight-side production press. Two heavy columns, a deep crown, large top hydraulic cylinder, moving ram, upper/lower die gap and separate motor-pump hydraulic unit distinguish it from the older shaft-driven press. A broad pressure/return main and analog pressure panel with two coarse controls explain the drive system without dense pipework or decorative bolts.

`build_press.py` exports `HD_ElectricHydraulicPress.blend`, four real 64-degree orthographic views, 768px color/mask pairs and fixed 12px outlines. drawSize is (4.5,4.5); use the compensated drawOffset in `validation.json`. The same fixed neutral palette and geometry are used in every view.

The active electric worktable uses 4500W and work-speed factor 3. It keeps the existing press-component bills and the M1 helmet's generated pressing recipe. Research: industrial automation. It requires an operator and electricity rather than a shaft network.

Form-family guidance: [Schuler's press history](https://www.schulergroup.com/minor/uk/about_us/history_schulergroup/). This is a simplified conventional electrohydraulic press of the requested era, not a particular historical factory reconstruction. No modern servo-transfer line or light-curtain detail is implied. No in-game visual/play test has been performed.
