# Dynamic Thought System Archive

Archived on 2026-07-28.

This directory preserves the retired backstory-driven dynamic thought-description
system. It is outside RimWorld's active `Defs`, `Patches`, `Languages`, and compiled
source paths, so none of these files are loaded or built.

## Contents

- `Source/`: personality-axis selection, pawn seed cache, and backstory extension.
- `Defs/`: original backstory vectors, pawn component registration, and dynamic
  thought definitions as they existed when archived.
- `Patches/`: Blancas Drugs compatibility patch.
- `Languages/`: Korean dynamic-description keys.
- `Tools/`: the dedicated thought-translation editor and launcher.

The active thought definitions remain in `Defs/WildWest/Thoughts_WildWest.xml`,
but now use their ordinary fixed stage descriptions. The active backstories and
pawn base no longer contain personality-system extensions or components.
