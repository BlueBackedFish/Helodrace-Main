## 의도적으로 달라진 점 / 한계

- 지원 버전은 실제 컴파일 대상인 RimWorld 1.6으로 명시했다. Harmony와 Biotech는 계속 필요하다.
- 예전 이벤트 `chance=15`를 명시적 15% 확률로 구현했다. HAR의 가중치 기반 선택은 다른 종족 모드 등록 상황에 따라 달랐으므로 과거 출현 비율과 완전히 같지는 않다.
- HAR의 `atlasScale=4` 고해상도 캐시는 재구현하지 않고 바닐라 렌더 캐시를 사용한다. 확대 시 선명도 차이가 날 수 있다. 실제 GPU 메모리·성능 효과는 측정하지 않았다.
- 명시적인 커스텀 종족형과 신생아 유전 상속은 존중하며 금지 유전자만 걸러낸다. 개발자 강제 조작이나 다른 모드의 직접 필드 변경까지 모두 차단하는 전역 프레임워크는 아니다.
- 외부 모드가 HAR 전용 API로 헬로드를 다루던 호환 기능은 자동 유지되지 않는다. 다른 종족 모드를 위해 HAR를 설치하는 것은 별개의 문제다.
- 무기명 `M1918A2 HAR`는 종족 프레임워크와 관계없으므로 변경하지 않았다.

## 검증 결과

설치된 RimWorld 1.6 DLL 기준:

```powershell
dotnet build Source/Helodrace/Helodrace.csproj --no-restore -v minimal
powershell -NoProfile -ExecutionPolicy Bypass -File Source/Verify-StandaloneRace.ps1 -PatchSmokeTest
```

- 빌드 경고 0 / 오류 0. `Assemblies/Helodrace.dll`과 PDB 갱신.
- 활성 XML 270개 파싱 성공. 아카이브와 머리·의류·유전자·종족형 목록 및 의류 경로 비교 통과.
- 활성 코드/정의의 HAR 참조 및 컴파일된 DLL의 AlienRace 어셈블리 참조 없음.
- 관리 코드 테스트: 신생아 상속 요청, 특성 단계 제한, 금지 유전자, 양방향 종족형 필터 통과.
- `Patch_Helod*` 31개(이번 추가 20개와 기존 11개)의 Harmony 설치 smoke test 통과. 이는 패치 대상·IL 적용 검증이며 실제 게임 플레이 검증은 아니다.

**아직 하지 않은 검증:** HAR를 비활성화한 실제 게임 부팅, Def 교차참조 로딩, 새 식민지 생성, 인게임 렌더링/이벤트/출산/수술/저장 후 재로드. 게임 설치·모드 설정·기존 세이브는 변경하지 않았다.

게임 확인 순서: (1) Harmony + Biotech + 본 모드로 새 게임, (2) 성인·아동·아기 및 네 방향/초상화/침대 외형, (3) 헬멧 착탈·귀/꼬리 상실, (4) 의류 생성/착용/제작과 인간의 전용 의류 제한, (5) 방랑자·난민·노예·출산·성장 특성·수술, (6) 새 세이브 저장/재로드. 오류 로그와 시각적 어긋남을 확인해야 출시 검증이 완료된다.

## 제거의 이점

HAR 설치·버전·로드 순서에 대한 필수 의존성이 사라진다. 종족 규칙과 렌더링의 수정 지점이 프로젝트 내부로 모여 디버깅과 기능 변경이 쉬워진다. 다른 종족까지 지원하는 프레임워크의 광범위한 개입을 줄일 수 있다. 대신 필요한 게임 API 대응과 모드 호환성 유지 책임은 이 프로젝트가 갖는다. FPS/메모리 개선 수치는 벤치마크 전에는 주장하지 않는다.
