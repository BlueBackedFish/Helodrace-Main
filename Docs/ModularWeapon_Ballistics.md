# 모듈형 총기 피해·관통·파편화

2026-10-17. 모딩창의 원시/환산 스탯과 실제 탄환이 같은 탄도 모델을 사용한다. 일반 무기 정보창도 장착 탄종의 피해와 관통을 표시한다. 총열 길이·탄속 차이는 직접 피해/관통에 적용하지 않고 파편화에만 반영한다. 표시값은 총구·방어구 미통과 기준이며, 파편 추가 피해는 직접 피해량에 합산하지 않는다.

## 원시 입력

탄환 Def의 `Helodrace.BulletBallisticsExtension`에 탄종의 기준을 입력한다. 수치는 게임 밸런스용이며 렌더링용 `<projectile><speed>`와 분리했다.

| 필드 | 의미 |
|---|---|
| `projectileMassGrams` | 탄자 질량(g). 탄피·화약을 포함한 파츠 무게 `massKg`와 다름 |
| `referenceVelocityMetersPerSecond` | 기준 총열에서의 탄속(m/s) |
| `referenceBarrelInches` | 기준 총열 길이(in) |
| `barrelVelocityExponent` | 총열/탄속 환산 곡선, 기본 0.35 |
| `velocityHalfDistance` | 탄속이 절반으로 줄어드는 게임 내 거리(셀) |

탄종의 기존 `damageAmountBase`와 `armorPenetrationBase`는 기준 총열·총구에서의 보정 기준이다. 질량/기준 에너지를 다시 직접 곱해 탄종의 기존 피해 차이를 이중 반영하지 않는다.

파츠별 `internalStats`에는 다음 항목을 추가했다. 기존 부품 수치와 함께 [중앙 밸런스 XML](../Patches/ModularWeapon_Balance.xml)에 저장한다.

| 필드 | 합성 방식 |
|---|---|
| `barrelLengthInches` | 총열의 명시적 실제 길이. 15종 입력. 팔레트·그림·오프셋 변경에 영향받지 않음 |
| `muzzleVelocityOffsetMetersPerSecond` | 장착된 기계 부품들의 탄속 보정 합계. MP5SD 포팅 총열에는 -90 입력 |
| `damageTransfer` | 전달 효율 보정 합계. +10은 기본 100%에서 110%로 변경 |
| `penetrationEfficiency` | 관통 효율 보정 합계. -10은 기본 100%에서 90%로 변경 |

효율 합계는 각각 25~200%로 제한한다. 별도 광학 액세서리는 위 탄도 기여를 하지 않는다. 총열 파츠의 `damageTransfer`와 `penetrationEfficiency`도 직접 피해/관통 보너스로 합산하지 않는다. 조정창에서 네 항목을 편집·XML 내보내기·되돌리기 할 수 있다. 원시 화면에는 탄자 질량, 총열 길이, 기준/총구 탄속, 총구 운동에너지, 두 효율, 탄종 기준 피해/관통을 표시한다.

## 환산과 실제 피격

기준 탄속 대비 실제 탄속 비율을 `v`라고 하면 다음과 같이 환산한다.

```text
총구 탄속 = 기준 탄속 × clamp(총열/기준총열, 0.25, 2)^총열지수 + 파츠 탄속 보정
총구 탄속 범위 = 기준의 0.25~1.5배
탄종 거리 감쇠 r = 0.5^(d/탄속 반감거리)
파편화용 피격 탄속 비율 v = 총구 탄속/기준 탄속 × r
운동에너지 J = 0.5 × 탄자 질량 kg × 탄속²
피해 = round(품질·무기 배율 적용 후의 탄종 피해 × r^0.7 × 전달 효율)
관통 = 탄종 관통 × 무기 관통 배율 × r^1.2 × 관통 효율
```

피해는 기존 바닐라와 같은 순서로 무기 배율을 반올림한 다음 탄도 보정을 적용한다. 양의 기준 피해를 가진 탄환의 최소 피해는 1이다. 환산 화면에는 피해, 방어구 관통력, 파편화 확률을 표시한다. 거리 증가에 따른 피해·관통 감소도 실제 피격에 적용된다.

같은 탄종·거리라면 총열을 바꿔도 직접 피해/관통은 같다. 거리 감쇠는 탄종 기준으로 유지한다. 파편화는 위의 피격 탄속 비율 `v`에 통과한 의복·플레이트의 저항과 탄종의 파편화 문턱을 적용한다. 기존의 국소 인접 부위 분산, 파편별 상한, 방어구 통과 후 실제 상처량 기반 예산, 한 탄환 한 번 처리 규칙은 유지한다. AP탄 등 파편화 확장이 없는 탄종은 확률 0이다.

2026-10-19 조정: EPR(M855A1·M80A1)의 파편은 최대 1개이며, M249도 공용 M855A1 투사체를 통해 동일하게 적용된다. 파편 1개당 공통 피해 상한은 2.5에서 5로 높였다. 총 추가 피해는 여전히 `방어구 통과 후 실제 주 상처 피해 × damageFraction × 파편화 강도`를 넘지 않는다. 파편화 확률·추가 피해 비율·다른 탄종의 파편 수·직접 피해/관통은 변경하지 않았다.

기본 품질·총구 기준 예시:

| 구성 | 직접 피해 | 관통 | 파편화 확률 |
|---|---:|---:|---:|
| M4 기본 14.5 in / M855A1 | 13 | 28.0% | 70.4% |
| MK18 기본 10.3 in / M855A1 | 13 | 28.0% | 55.5% |
| M16 기본 20 in / M855A1 | 13 | 28.0% | 75.0% |
| P320 기본 / M882 | 10 | 14.0% | 0% |
| M1911 기본 | 12 | 12.0% | 0% |

발사 시점의 탄속, 거리 감쇠 계수, 품질 포함 피해/관통 기준값, 두 효율을 탄환에 캡처하고 저장한다. 날아가는 동안 부품을 바꾸거나 무기를 버려도 기존 탄환은 변하지 않는다. 유탄·폭발탄·산탄은 이 단일 탄환 모델을 적용하지 않는다. 같은 탄환 Def를 공유하는 비모듈형 총기는 기존 직접 피해/관통을 유지한다. CE의 별도 발사체에는 적용하지 않으며 CE 사용 중 이 바닐라 탄도 표시도 숨긴다.

## 검증

사거리의 파츠 입력, 조준 그룹별 배율, 엔진 적용은 [총기 밸런스 문서](ModularWeapon_Balance.md)의 모딩 사거리 절을 따른다. 사거리 배율은 피해·관통 계산에 사용하지 않는다.

- `ModularWeaponBalance`: 실제 패치·21개 프리셋과 런타임 코드로 피해/AP/파편화 연계, 거리 감소, 품질 배율, 광학 중첩 방지, XML 내보내기·되돌리기를 검사한다.
- `BulletFragmentation`: 네이티브 방어구/부상 후처리 바인딩과 파편화, 실제 탄환 속성, 발사 후 변경, Scribe 저장·복원, 비모듈형 피해 유지 등을 검사한다.

게임 내 실제 교전과 UI 시각 확인은 별도 플레이 검증이 필요하다.
