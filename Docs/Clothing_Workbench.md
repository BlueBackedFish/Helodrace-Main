# 의류 작업대

`HD_ClothingBench`는 `Buildings/HD_ClothingBench`의 기존 방향별 PNG를 사용하는 의류 제작·개조 작업대입니다. 총기 작업대와 같은 3×1 점유 크기, 표시 크기 3.1×3.1, 상호작용 오프셋 (0,0,-1), 기본 그래픽 오프셋 (0,0,0)을 사용합니다.

헬로드 건축 메뉴에서 건설합니다. 연구는 `HelodFrontierSpirit`, 건설 기술은 4가 필요하며 목재 또는 금속 100개, 강철 40개, 일반 기계 부품 2개를 사용합니다. 기존 의상 제작법과 모듈형 방어구 부품 제작법도 작업대에서 사용할 수 있고 각 제작법의 연구·기술·재료 조건은 그대로 적용됩니다.

작업대의 **의상 커스터마이징** 버튼에서 정착민이 입은 모듈형 의상 또는 지도에 보관된 의상을 선택합니다. 기존 의상과 착용자의 독립 개조 버튼은 제거했습니다. 정보창을 열어 두었어도 작업대가 철거되거나 소유권·지도 조건이 바뀌면 개조를 계속할 수 없습니다.

실물 부품을 장착하려면 의상을 착용해야 합니다. 착용자는 부품을 가져온 뒤 작업대의 상호작용 칸에서 장착합니다. 기존 부품 회수와 보관 방식은 유지합니다. 앞뒤 방탄판 교환도 커스텀 창에서 시작하여 작업대에서 진행합니다. 작업대는 예약되며 접근할 수 없거나 작업 중 철거되면 작업이 취소됩니다. 기존 저장에서 작업대 정보가 없는 대기 중 장착 작업은 중단됩니다.

작업대는 `Building_ClothingWorkbench`에서 두 그리기 색을 흰색으로 고정합니다. `Cutout` 셰이더로 원본 PNG 색을 표시하며 건축 재료 색이나 컬러 마스크를 적용하지 않습니다.

커스터마이징 창은 실제 의상과 분리된 임시 구성을 편집합니다. 파츠 장착·제거, PALS 위치 이동, 앞뒤 방탄판 교환을 반복해도 창이 닫히지 않습니다. **작업 시작**을 누르면 필요한 부품을 모두 가져와 의류 작업대에서 한 작업으로 처리하며, 작업이 끝날 때 전체 구성을 적용합니다. 취소·닫기·작업 중단 시 원래 구성은 유지되고 가져온 부품은 인벤토리에 남습니다. 기존 부품과 방탄판의 실제 아이템 및 내구도를 보존하며, 제거한 부품은 반환합니다. 일반 작업은 의상 착용자가 수행합니다.

작업 주문과 진행 중인 변경 계획은 저장됩니다. 창을 연 뒤 원래 구성이 다른 작업으로 변경되었거나 필요한 부품이 부족하면 적용하지 않습니다.

검증 명령:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File Source/Verify-ClothingWorkbench.ps1
```

검증은 건물 정의·텍스처·제작 목록·컴파일된 컴포넌트와 작업대 없는 개조의 차단을 확인합니다. 실제 게임의 건설 및 이동·부품 장착은 별도 플레이 확인이 필요합니다.
