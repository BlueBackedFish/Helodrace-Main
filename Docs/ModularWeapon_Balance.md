# 모듈형 총기 밸런스

차기 개편 방향은 [스탯 역할·정확도 분리 설계](ModularWeapon_StatDirection.md)를 참고한다. 해당 문서는 설계안이며, 아래의 현행 환산 코드를 이미 교체한 것은 아니다.

2026-10-17. 모듈형 총기 본체 10종, 장착 가능한 파츠·탄종 선택 항목 156종을 조정했다. 파츠별 값과 기본 쿨다운·명중률은 [중앙 밸런스 표](../Patches/ModularWeapon_Balance.xml)에 있다. 무게는 해당 부품 하나의 무게다. 기계식 RPM은 유지한다. 처음 웜업으로 잘못 적용한 일괄 상향은 취소했고 사격 후 쿨다운을 조정했다.

## 순정 기준

설치된 바닐라 `Data/Core/Defs/ThingDefs_Misc/Weapons/RangedIndustrial.xml`의 쿨다운은 자동권총 1.0초, 리볼버 1.6초, 기관권총 0.9초, 중기관단총 1.65초, 돌격소총 1.70초, 볼트액션 1.5초, 경기관총 1.6초다. 기본 쿨다운에 반동·총구 제어, 조작성, 무게중심의 회복 배율을 적용한다. 이 회복 배율은 연사 중 기계식 발사간격과 분리했다.

아래 값은 **기본 생성 프리셋, 가스 설정 1.0, 기본 품질, 날씨 제한 및 사수 능력/전술 기술 보정 전**의 계산값이다. 사거리별 명중률은 총기 자체의 정확도이며 실제 최종 명중 확률이 아니다. M4A1·M16A4 기본 프리셋은 TA11 고정배율 조준경을 사용한다. 조준선 가림은 사거리에도 반영된다.

## 조준 그룹: 합산하지 않고 최댓값 선택

피해·관통의 원시/환산 스탯과 탄자 파편화 연결은 [탄도 스탯 문서](ModularWeapon_Ballistics.md)를 따른다.

조준선 높이·앞뒤 배치·가림으로 유효 그룹을 구분하는 기존 판정은 유지한다. 각 유효 그룹의 성능을 따로 계산한 뒤 **각 거리의 명중률은 가장 높은 값 하나**, **웜업은 가장 빠른 값 하나**를 취한다. 두 그룹을 곱하거나 더하지 않는다. 동일한 조준경을 추가해도 명중률 이득은 없고 무게·관성·조작성 비용은 추가된다.

예를 들어 고정배율과 다른 높이의 레드닷을 함께 쓰면 근거리·획득 속도는 레드닷, 장거리는 고정배율 값을 사용할 수 있다. 같은 조준선 그룹 안의 주 조준경과 확대기는 하나의 확대 조준 방식으로 취급한다. 개별 광학 파츠의 내부 정밀도·식별거리 값이나 기존 `statFactors`를 추가 명중률 경로로 중첩시키지 않는다.

완전히 가려진 그룹은 유효 선택지에서 제외한다. 측면 조준선은 50% 효율을 적용한다. UI/자세용 주 조준 그룹 선택과 거리별 성능 최댓값 선택은 구분된다.

| 조준 방식 | 웜업 배율 | 초근 | 근 | 중 | 원 |
|---|---:|---:|---:|---:|---:|
| 유효 조준선 없음 | 1.12 | 0.95 | 0.90 | 0.82 | 0.70 |
| 완성 아이언사이트 | 1.02 | 0.99 | 1.00 | 0.99 | 0.94 |
| 레드닷/리플렉스 | 0.94 | 1.02 | 1.025 | 1.00 | 0.90 |
| 홀로사이트 | 0.96 | 1.00 | 1.03 | 1.015 | 0.92 |
| 홀로/리플렉스 + 확대기 | 1.12 | 0.88 | 0.95 | 1.045 | 1.075 |
| 고정배율 조준경 | 1.20 | 0.80 | 0.90 | 1.055 | 1.10 |
| 향후 LPVO / 사통장치용 프로필 | 1.00 | 1.00 | 1.02 | 1.04 | 1.08 |

수치는 조준 방식에 대한 한 번의 배율이다. 현재 LPVO·사통장치 파츠를 새로 추가한 것은 아니며, 일반 고정배율과 다른 프로필을 명시적으로 예약했다. 아이언사이트는 완성된 앞·뒤 조합 또는 슬라이드 일체형 조준선이 필요하다. M16 캐링핸들, M14, M249, M1911의 일체형 조준선도 등록했고, 기계 부품의 고유 성능은 유지한다.

## 모딩 사거리

파츠 `internalStats.rangeAdjustmentPercent`에 사거리 보정(%p)을 저장한다. 예를 들어 AR 10.3인치는 -12, 14.5인치는 0, 20인치는 +8이며, Flux Raider 킷은 +15다. 파츠 성능 가중치가 적용된 합계로 `MechanicalRangeFactor = clamp(1 + 합계/100, 0.65, 1.35)`를 만든다. 원시 화면에는 기계적 배율과 최종 배율을, 환산 화면에는 셀 단위 유효 사거리를 표시한다. 조정창 XML 내보내기·되돌리기도 지원한다.

완전한 조준선의 사거리 배율은 아이언 1.00, 도트 0.97, 홀로 0.98, 확대기 조합 1.06, 고정배율 1.08이다. 향후 LPVO/사통장치는 1.10/1.12로 구분한다. 가려짐·측면 효율을 반영하고 **여러 그룹 중 최댓값 하나만** 취한다. 유효 조준선이 없으면 0.75다. 개별 광학 파츠의 `rangeAdjustmentPercent`는 추가 합산하지 않는다.

`RangeFactor = clamp(기계적 배율 × 조준 그룹 배율, 0.5, 1.5)`를 바닐라 `RangedWeapon_RangeMultiplier`에 한 번 적용한다. 실제 발사 가능 거리, 일반 정보창, 모딩창 및 전술 사격 판정/미리보기가 이 값을 사용한다. 대체 사격은 자기 기본 사거리를 유지한 채 같은 배율을 쓴다. 유탄은 소총 모딩 배율을 상쇄해 별도 사거리를 유지한다. 최종 날씨 제한은 보너스/페널티 적용 뒤에 걸며 공유 `VerbProperties`를 수정하지 않는다.

사거리 증가는 직접 피해·관통력 증가가 아니다. 총열이 직접 피해/관통에 영향을 주지 않는 규칙은 유지하며, 총열에 따른 살상력 차이는 파편화만으로 처리한다.

## 파츠 성능 방향

- 총열: 긴 총열은 정밀도·총구 안정성에 소폭 이득이 있고 무게·관성·조준 획득에 비용이 있다. 짧은 총열은 반대다. 기존 총열 길이 기반 파편화/총구 효과 계산도 유지한다.
- 개머리판: 고정식은 반동·총구 제어, 짧은 신축식은 조작성에 중점을 둔다. Flux 킷도 무게·조준 획득 비용과 제어 이득을 함께 갖는다.
- 핸드가드·그립: 가벼운 핸드가드는 조작성을, 무거운 섀시는 안정성·정밀도를 일부 제공한다. 전방손잡이는 한 개분만 보너스를 적용한다.
- 총구장치: 보정기는 반동·총구 제어를, 소음기는 소폭 제어 이득과 무게·조준속도 비용을 갖는다. SEI 2000V의 시각 효과 분류도 `MuzzleBrake`로 맞췄다.
- 광학장비·마운트·조명: 장착한 모든 장비의 무게와 조작성 비용을 반영한다. 광학 성능은 위 그룹 표에서만 적용한다.
- 탄창: 긴 탄창·전방 예비탄창·탄통의 무게와 조작성 비용을 차등화했다. 용량·탄약 파우치 기능은 유지한다.
- 소형 부품: 볼트·트리거·가스계·슬라이드 등은 개별 무게와 소폭의 신뢰성/정밀도 차이를 갖는다. 공통 0.2kg를 쓰던 탄약 선택 노드의 질량도 구경별 값으로 맞췄다.

## 검증

`dotnet run --project Source/Tests/ModularWeaponBalance/ModularWeaponBalance.Tests.csproj -- .`

실제 밸런스 패치를 XML에 적용하고 상속을 해석한 뒤, 21개 프리셋의 팔레트 배율·소켓·마운트로 조립 기하를 만든다. 런타임 코드를 직접 호출해 순정 쿨다운 범위, 과도한 명중률, 그룹 중복, 단일 조준 방식의 약점, 광학 중첩 방지, 고정배율→홀로사이트 교환과 회복/RPM 분리를 검사한다. 게임 내 전투·사수 능력·엄폐·거리를 모두 재현하지는 않으므로 최종 체감 밸런스는 플레이 피드백으로 조정한다.
