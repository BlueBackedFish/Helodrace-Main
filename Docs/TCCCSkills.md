# TCCC 스킬

TCCC `LOW` 헤디프는 지혈과 부상자 이동을, `HIGH` 헤디프는 이 두 스킬에 더해 진통제 투여·지혈제 투여·MIST 작성을 활성화한다. 처치자는 방탄복에 의료 파우치를 실제로 장착해야 한다.

| 스킬 | 장비와 소모 | 시간과 효과 |
|---|---|---|
| 지혈 | 소형 또는 대형 파우치 일반 충전량 1칸 | 출혈 부위 최대 6곳. 3곳까지 5초, 4곳 10초, 5곳 15초, 6곳 20초. 작업 시간의 2/3부터 임시 압박으로 출혈 70% 감소. 완료 후 12시간 동안 해당 부위 출혈 80% 감소, 부위당 고통 5% 추가(최대 20%). |
| 부상자 이동 | 소형 또는 대형 파우치 일반 충전량 1칸 | 연결 시간 1초. 연결 중 손을 비운 채 이동할 수 있으나 이동속도와 작업속도가 감소한다. |
| 진통제 투여 | 대형 파우치 일반 충전량 1칸 | 호흡 능력 70% 미만이면 케타민, 이상이면 펜타닐을 자동 선택해 정량 1회 투여한다. 별도 약물 아이템이나 투여량 제한은 없다. 해당 약물의 기본 중독 확률을 30% 낮춘다. |
| 지혈제 투여 | 대형 파우치의 별도 지혈제 적재량 1개 | 1초. 6시간 동안 전신 출혈 70% 감소, 혈액순환 -10%, 의식 -5%. 부위 지혈과 함께 적용된다. |
| MIST 작성 | 소형 또는 대형 파우치 일반 충전량 1칸 | 5초. 후송 인계서를 작성한다. |

소형 파우치는 일반 충전량 4칸, 대형은 8칸이다. 산업약품 1개로 일반 충전량을 2칸 회복하며 최대치를 넘지 않는다. 대형 파우치는 지혈제 아이템 2개를 별도로 적재한다. 적재와 충전은 착용한 폰의 명령에서 실행한다. 매딕가방 지혈에도 부위 수에 따른 같은 시간 규칙을 적용하며 기존 최대 4부위 제한을 유지한다.
