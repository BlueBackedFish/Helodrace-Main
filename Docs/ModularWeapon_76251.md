## 듀플렉스 발사

`Projectile_DuplexBullet`은 정상 발사 경로로 첫 탄자를 발사한 뒤 같은 Def의 동반 탄자를 한 개 생성한다. 동반 탄자는 생성 전에 분리 완료 표시를 받으므로 재귀 증식하지 않는다. 재장전·탄약 소비·발사 간격·총구 화염·탄피 배출은 기존 발사 한 번으로 처리하며, 추가 탄자는 Verb를 다시 호출하지 않는다.

동반 탄자의 분산은 명중/빗나감/엄폐물 처리가 끝난 첫 탄자의 실제 궤적을 기준으로 한다. 원래 조준점으로 다시 유도하지 않으며, 기본 추가 분산 한도는 좌우 1.2도다. 각 탄자는 바닐라의 충돌·엄폐·방패·방어구 처리를 독립적으로 받는다. 한 번 맞았다고 피해만 두 번 주는 방식이 아니다.

각 탄자는 기존 탄도 스냅샷을 따로 캡처한다. 비행 중 무기를 바꿔도 값은 유지하며, 스냅샷과 분리 완료 표시는 Scribe에 저장된다. 모딩창에는 한 발당 탄자 수와 탄자당 피해를 표시하고, 무기 정보창에는 `9 × 2`처럼 표시한다. 두 탄자 모두 맞고 관통해야 총 피해를 얻는다.

이 구현은 바닐라 발사체 경로용이다. CE는 기존 방침대로 별도 탄약/발사체를 관리하며, CE 세션에서 이 수치를 중복 적용하지 않는다.

## 검증

- `ModularWeaponBalance`: 8종 각각의 실제 파츠 선택 → 원시 스탯 환산 → 투사체 피해/관통/탄자 수, 고유 투사체, MATCH 정밀도·사거리, OTM 반동, AP/SLAP 비파편화 및 총열 독립성.
- `BulletFragmentation`: 실제 듀플렉스 런타임을 호출하고, 엔진 발사/피격 진입점만 헤드리스 대역으로 바꿔 정확히 두 번 발사되는지, 독립 스냅샷·피격, 메타데이터 보존, 저장/복원 후 재증식 방지를 검사한다. 실제 맵 충돌 시뮬레이션과 UI 시각 확인은 게임 내 추가 검증 대상이다.
