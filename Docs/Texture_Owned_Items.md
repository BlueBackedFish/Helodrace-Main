# 보유 텍스처 아이템과 12.7mm 혼합 급탄

2026-11-04. TEX-01~15의 최신 범위다. 새 일반 아이템은 알루미나·알루미늄 합금·실리콘·접이식 진압봉·Ironhide Riot 방패의 5종이다. 기존 전자 부품은 재사용한다. 탄약 아이템, 혼합 탄약 아이템, 탄약 제조법은 추가하지 않는다.

## 산업 재료와 제작

| 공정 | 투입 | 산출 | 작업대 / 연구 | 작업량 |
|---|---|---|---|---:|
| 알루미나 추출 | 점판암 벽돌 25 + 화학연료 4 | 알루미나 20 | 교반식 반응기 / 완전 합성 의약 연구 | 4000 |
| 실리콘 제련 | 사암 벽돌 25 + 목탄 10 | 실리콘 10 | 잠호 아크로 / 기초 전자 기술 | 4000 |
| 알루미늄 합금 정제 | 알루미나 6 + 목탄 4 + 실리콘 1 | 합금 4 | 잠호 아크로 / 기초 전자 기술 | 5000 |
| 반도체 전자 부품 | 실리콘 2 + 합금 4 + 은 4 + 화학연료 4 + 기초 전기 부품 2 | 전자 부품 1 | 기존 반도체 팹 / 실리콘 혁명 | 6000 |

새 원석이나 채굴 광맥은 만들지 않는다. 바닐라 석재 벽돌을 원료로 쓴다. 점판암은 알루미늄을 함유한 셰일의 변성암이라는 점에서 알루미나 원료로, 사암은 석영 성분을 근거로 실리콘 원료로 선택했다. 이는 바닐라 암석 중에서 고른 **게임용 대체 원료**이며 점판암이 일반적인 상업용 보크사이트 원광이라는 뜻은 아니다. 침출·소성·전해 환원·주조·반도체 정제의 세부 장치는 기존 작업대 공정에 통합해 추상화한다. 잠호 아크로 자체가 현실에서 알루미나를 전해 환원한다는 뜻은 아니다.

근거: [USGS 알루미늄 분포](https://pubs.usgs.gov/sir/2017/5118/elements/Aluminum/Al_txt.html), [BGS 암석과 광물](https://www.bgs.ac.uk/discovering-geology/rocks-and-minerals/), [BGS 암석 구성](https://www.bgs.ac.uk/discovering-geology/rocks-and-minerals/rock-rumble/). 점판암 선택과 생산 수율은 이 자료에서 출발한 게임 설계 판단이다.

기준가는 알루미나 **3**, 실리콘 **6**, 합금 **8** 은으로, 바닐라 산업 부품 32보다 낮다. 전자 부품은 계속 32다. 공업 회사 상단·민간 정착지·군수 정착지 3곳에 재료를 연결한다. Ironhide IV 방패의 기존 플라스틸 80 중 40을 알루미나 40으로 대체하고 기존 방호 성능은 유지한다. 누락됐던 아크로 제작 작업 제공자를 추가한다. 새 진압 방패는 기계가공대의 Smithing 작업으로 제작한다. 기본 제조 재료 필터가 비어 있었던 Ironhide IV에도 투입재를 명시해 제작을 막는 조건을 고친다.

알루미나·합금은 보유한 두 스택 이미지를 쓴다. 실리콘은 전용 그림이 없어 어둡게 착색한 바닐라 플라스틸 스택 그래픽을 **임시 그림**으로 사용한다. 신규 실리콘 그림은 후속 교체 대상이다.

## 진압 장비

| 장비 | 제작 | 주요 기능 |
|---|---|---|
| 접이식 진압봉 | 탄소강 8 + 합금 4 + 화학연료 2 / 기계가공대 / 냉전 기술 / 제작 5 | 둔기 공격력 9, 쿨다운 1.3초, 관통 8%, 질량 0.65. 목록에서는 접힌 그림, 실제 장비는 펼친 그림을 사용한다. |
| Ironhide Riot 방패 | 합금 20 + 강철 20 + 화학연료 12 / 기계가공대 / 냉전 기술 / 제작 6 | 내구도 220, 질량 5. 정면 100도 근접 둔기 방어 115%·근접 날카로움 65%·원거리 날카로움 18%. 권총과 진압봉 병용. |

진압 장비는 군수 정착지에서도 구할 수 있다. 방패의 이동 속도 보정은 -0.12, 조준 지연은 +0.20, 사격 정확도 배율은 0.85다. 관측창 손상·내구도·측후방 우회는 기존 방향성 방패 체계를 사용한다. 근접 방어 값은 진압 방패에서만 활성화되며 기존 방탄 방패는 원거리 전용으로 유지한다. 방패는 환경 피해와 폭발을 근접 공격으로 막지 않는다. 세 방향 원본 그림을 연결하고 서쪽은 동쪽 그림의 기본 반전을 사용한다.

진압봉은 기본 근접무기로 추가한다. 수동 접기/펴기 전환이나 별도 보조무기 시스템을 새로 만들지 않는다. 둔기 피해는 비살상 보장을 뜻하지 않는다.

## M2HB / CROWS 혼합 발사체

M167의 `Verb_ShootMixedMagazine`을 재사용한다. CROWS는 이 발사 기능을 상속하면서 기존 전력·연결·실제 조작자·장착 무기·잔탄 조건을 발사 직전에도 검사한다.

- 반복 순서: **M8 API ×4 → M20 API-T ×1**. 10발 점사는 이 순서를 두 번 실행한다. 새 점사는 첫 M8부터 시작하고, 실패한 발사는 순서를 진행시키지 않는다.
- 두 발사체의 기본 직접 피해 32, 관통 0.42, 저지력 2.2, 속도 90은 기존 M2HB 기준을 유지한다. 둘 다 기존 소이탄 충돌 처리를 공유하며 명중 지점 발화 확률 15%·불 크기 0.15를 쓴다. M20은 보유 예광탄 그림과 발광 셰이더를 사용한다.
- M2HB와 CROWS의 M2HB QCB 장착형에만 12.7mm 순서를 연결한다. M240B·M249·Mk 19는 기존 구경을 유지한다. 항공 지원용 M2HB 발사체와 M167 순서는 유지한다.
- 기존 **강철 보충**, 장탄 용량, 발사당 소비 1을 유지한다. 개별 탄종 선택·탄약 생산·탄약 거래·탄약 아이템은 없다.

4:1 API/API-T 조합의 탄종 구분과 링크 비율은 [미 육군 MAS Handbook 2025](https://jpeoaa.army.mil/Portals/94/MAS/Documents/MASHandbook_2025.pdf?ver=ldx6e69WnWk9ujK5iF55Eg%3D%3D)를 참고했다. 게임 피해·발화 수치는 현실 성능의 환산 결과가 아닌 임시 게임 값이다.

12.7mm 보유 리소스 **10종·30PNG**는 모두 임시 리소스로 저장한다. 각 탄종의 목록 그림 2장에는 아이템 정의를 붙이지 않는다. M8·M20의 발사체 그림 2장만 현재 급탄에 사용한다. M1·M2·M17·M903·M962·Mk169·Mk211·Mk300 발사체 그림은 미사용 임시 리소스다. 파일명만으로 이들의 효과나 해금을 확정하지 않는다. 총기 전체 재밸런싱 T2-32는 공개 이후 검토 원칙을 유지한다.

## 검증

실제 RimWorld 1.7.4995 rev309의 `.codex-staging/TextureItems/native-13`에서 **107 PASS, COMPLETE, FAIL 없음**. [검사 원문](Data/TextureOwnedItems/native-checks.txt), [버전·배포 DLL 해시](Data/TextureOwnedItems/verification.json).

실제 전력망·작업 제공자·제작 작업을 사용해 세 재료→전자 부품과 진압봉·진압 방패·알루미나를 소비하는 Ironhide IV를 생산하고 투입/산출 수량을 확인했다. 헤로드가 제작 장비를 착용하며 정면 둔기 흡수·방패 마모·후면 우회·고관통 총탄 우회·환경 피해 제외·기존 방탄 방패의 근접 방어 제외를 확인했다. 두 M2HB 점사와 실제 재료/작업을 통한 CROWS M2HB 장착, 원격 조작자 작업 및 실제 Projectile.Launch 순서·발사당 소비를 검사했다. 조작자 부재와 연결 해제는 발사를 차단하며 실패한 발사는 순서/잔탄을 진행시키지 않는다. 다른 CROWS 구경과 M167 정의·항공 지원 발사체는 보존됐다.

외부 조달재는 검사 작업장에 별도로 공급하고 세 신규 중간재는 앞 공정의 실제 생산물을 다음 공정에 사용한다. Quicktest 맵에는 접근 불가능한 기존 재고가 있어 단순 맵 전체 합계를 조달 가능량으로 쓰지 않는다. 검사장은 실제 보관 구역과 지붕을 사용하며 기후·욕구·임의 방해를 제어한다. 방패 방어는 실제 착용 컴포넌트의 피해 전처리를 호출한다. 장기 밸런스·자연 명중률·모든 외부 모드 조합·스크린샷 외형 승인을 뜻하지 않는다.

관련 검증: 레시피 연결 **89 RecipeDef·541 ThingDef**, 중간재 가격 **25종**, 기존 탄도 방호 **128개**, CROWS 기존 운용/설치 회귀와 PNG **39장** 디코딩 통과. 최종 ERROR는 작업 전부터 있던 Workshop 항목 3781143823 폴더 부재 1건뿐이다. 초기 검사에서 발견한 실리콘 그래픽 형식·아크로 작업 제공자·방패 기본 재료 필터는 수정했다. 검사장의 재고 접근성·보관/운반·날씨와 장비를 착용할 종족·작업 시간 제한도 실제 계약에 맞췄다.

배포 DLL/PDB는 이 최종 호스트에서 검증한 파일과 동일하다. 신규 Unity 의존성이나 게임 타입 경계는 추가하지 않는다. 새 방어 판단은 스칼라 값과 기존 엔진 피해 계약만 사용한다.
