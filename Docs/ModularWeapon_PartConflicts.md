# 충돌 파츠

파츠의 `CompProperties_ModularWeaponNode` 안에 함께 장착할 수 없는 ThingDef를 지정한다.

```xml
<incompatibleParts>
  <li>HD_ModularPart_Barrel_M1A16_Part</li>
</incompatibleParts>
```

- 한쪽에만 선언해도 양방향으로 적용되며 장착 순서와 무관하다.
- 같은 소켓뿐 아니라 무기 전체의 부모·형제·하위 파츠를 검사한다. 이미 조립된 파츠를 붙일 때는 그 내부 조합도 검사한다.
- 모딩창은 충돌 후보를 빨간 상태로 표시하고 툴팁으로 충돌 파츠를 알려준다. 교체할 기존 파츠와 그 하위 파츠는 사전 검사에서 제외한다.
- 실제 장착, 교체 시 하위 파츠 이식, 프리셋 생성은 모두 `TryAttach`의 검사를 거친다. 충돌 프리셋은 기존 무기를 변경하기 전에 거부된다. 이식할 수 없는 하위 파츠는 기존 처리대로 보관함으로 반환한다.
- 충돌 파츠를 자동으로 삭제하지 않는다. 기존의 잘못된 조합이 있더라도 분리·교체로 수정할 수 있다.
- 위치 조정 XML 내보내기에도 충돌 목록이 포함된다. 충돌 목록은 위치/회전이나 연구 조건, 레일의 물리적 겹침 검사와 별개다.

현재 M14 나무 스톡은 SOCOM 16 총열 및 EBR 외장(핸드가드·피스톨 그립·개머리판)과 충돌한다. SOCOM 16 스톡도 EBR 외장과 충돌하지만 SOCOM 16의 16인치 총열과는 호환된다. EBR 샤시는 16인치 총열과 충돌하며, 18·22인치 총열과는 호환된다. 정상적인 M14, MK14 EBR, SOCOM 16 프리셋은 유지한다.

## 총열에 따른 M4/AR-15 프런트 사이트 간섭

`conditionalIncompatibleParts`는 선언한 파츠와 `part`가 함께 있을 때, `whenAnyParts` 중 하나까지 장착되어 있으면 충돌한다. 조건 부품을 마지막으로 추가하거나 총열을 교체할 때도 같은 검사를 거친다. 조건이 없으면 해당 두 파츠는 이 규칙으로 금지하지 않는다.

```xml
<!-- 고정식 프런트 사이트 가스블록의 설정 예시 -->
<conditionalIncompatibleParts>
  <li>
    <part>HD_ModularPart_Handguard_HACURXUP</part>
    <whenAnyParts>
      <li>HD_ModularPart_Barrel_AR15103_Part</li>
      <li>HD_ModularPart_Barrel_AR15145_Part</li>
    </whenAnyParts>
  </li>
</conditionalIncompatibleParts>
```

2026-10-19 기준, 현재 텍스처와 장착점에 맞춰 `HD_ModularPart_GasBlock_AR15_Part`에 다음 규칙을 적용한다. 총열 길이 자체보다 해당 총열의 가스블록 장착 위치를 기준으로 정한 조합이다.

| 총열 | 고정식 프런트 사이트와 함께 사용할 수 없는 핸드가드 |
|---|---|
| 10.3인치 5.56 / 10.3인치 .300 BLK | HAC RIS FDE, HAC URX, HAC URX M4, M16A1, M16A2 |
| 14.5인치 5.56 | HAC RIS FDE, HAC URX, M16A1, M16A2 |
| 20인치 / 20인치 펜슬 | 위 조건부 충돌 없음 |

14.5인치+URX M4의 정상 M4 기본형, 20인치 M16 기본형, 저상형 MK12/.300 BLK 가스블록 조합은 유지한다. 상부 핸드가드를 막으면 그에 달리는 하부 익스텐션도 우회 장착할 수 없다. 사이트를 숨기거나 레이어로 덮는 방식이 아니라 장착 조합을 거부한다.

모딩창의 빨간 후보 표시와 거부 툴팁에는 사이트·핸드가드뿐 아니라 조건이 된 총열도 표시한다. 조건부 목록은 위치 조정 XML 내보내기에도 보존한다. 기존 잘못된 조합을 자동 삭제하지 않으며, 무관한 부품 장착이나 호환 총열·가스블록으로의 교체를 통한 수리는 허용한다.

검증은 실제 XML 75개 조합(총열 5 × 핸드가드 5 × 가스블록 3)을 각각 6가지 장착 순서로 검사한다. 이미 조립된 하위 트리, 교체 제외, 기존 충돌 수리, 전체 21개 프리셋, XML 내보내기도 검사한다. 게임 내 모딩창 시각 확인은 별도 플레이 검증 대상이다.
