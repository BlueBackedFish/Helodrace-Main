# CROWS II와 제어 컴퓨터

본체 모드의 건설 메뉴 `헤로드`에 컴퓨터(`HD_CrowsComputer`, 2×1칸)와 CROWS II 고정진지(`HD_Building_CrowsII`, 2×2칸)를 추가했다. 컴퓨터는 트랜지스터 연구, 진지는 트랜지스터와 대구경 기관총 연구를 요구한다. 신규 연구나 아스널 확장팩 의존성은 없다.

## 사용

1. 진지를 건설하면 **화기와 급탄 슈트가 없는 상태**로 완성된다. 진지를 선택해 **화기 선택**에서 M2HB QCB·Mk 19·M240B·M249 중 하나를 고른다. 선택 메뉴에 추가 자재 비용이 표시된다.
2. 건설 작업이 활성화된 건설 6 이상의 폰이 추가 자재를 운반하고 장착한다. 전력이나 컴퓨터 조작자는 장착 작업에 필요하지 않다. 자재가 부족하면 운반 대기 상태이며, 전부 운반된 뒤에만 장착 작업량이 쌓인다. 완료 전에는 빈 외형을 유지하고 조준·사격·탄약 보급을 하지 않는다.
3. 장착이 끝나기 전에는 **화기 선택**으로 선택을 바꾸거나 **장착 취소**를 누를 수 있다. 운반된 자재는 진지 옆에 반환되고 작업량은 초기화된다. 작업 중단과 저장/불러오기는 현재 선택·보관 자재·진행도를 유지한다. 완성된 화기는 이 단계에서 교체·해체하지 않는다.
4. 장착 완료 후 탄약을 보급하고 두 건물에 전력을 공급한다. 소비 전력은 컴퓨터 200W, 진지 100W다. 어느 건물이든 선택해 **CROWS 연결**을 누르고 반대 건물을 지정한다. 같은 맵·같은 세력끼리 한 대씩 연결한다. 기존 연결이 있으면 해제하고 새로 연결한다.
5. 연결된 컴퓨터에 컨트롤러가 자동 표시된다. 연결 해제 시 기본 컴퓨터 그래픽으로 돌아간다. 전원을 끄는 것만으로 연결이나 컨트롤러가 사라지지는 않는다.
6. 폭력이 가능한 폰을 선택하고 컴퓨터를 우클릭해 **CROWS II 조작**을 명령한다. 폰이 조작 위치까지 이동해 실제 조작 단계에 들어가면 진지가 바닐라 포탑 방식으로 표적을 찾고 사격한다. 진지의 강제 표적·사격 중지 명령도 유지한다. 컴퓨터 조작의 자동 작업 배정은 하지 않는다.

화기가 장착된 CROWS II를 선택하면 바닐라 **강제 사격 표적 지정**을 사용할 수 있다. 직접 조작하는 `CompMannable` 없이도 플레이어 진지에 이 명령을 허용한다. 표적은 조작자 배치 전에도 지정할 수 있지만, 실제 조준·사격은 컴퓨터 조작자가 있을 때만 시작한다. 다른 세력의 진지에는 플레이어의 표적 지정 기능을 제공하지 않는다.

폰이 자리를 떠나거나 다른 작업을 하거나 쓰러지거나 정신 이상에 빠지거나 필요한 조작/시각 능력을 잃으면 사격을 허용하지 않는다. 두 건물의 전력·스위치, 정전 조건, 세력·맵·상호 연결, 폰의 실제 작업과 조작 단계까지 검사한다. 조작 중단·연결 해제 시 진행 중인 조준/점사를 초기화하고, 발사 동작에서도 매 탄마다 조작 조건을 검사한다. 정전으로 작업이 끝났으면 전력 복구 후 다시 조작을 명령한다.

연결은 두 건물의 참조로 저장한다. 건물 제거·포장·파괴·세력 변경 시 연결을 해제한다. 다른 맵이나 세력으로 연결할 수 없다.

## 사격·아트

| 화기 | 총열 / 일반 기계 부품 / 탄소강 / 프레스 부품 | 장착 작업량 | 탄약 용량 | 사거리 / 점사 / 간격 |
| --- | --- | ---: | ---: | --- |
| M2HB QCB | 1 / 8 / 70 / 4 | 1800 | 100 | 42.9칸 / 10발 / 7틱 |
| Mk 19 | 1 / 10 / 80 / 6 | 2200 | 48 | 44.9칸(최소 5.9칸) / 3발 / 11틱 |
| M240B | 1 / 6 / 45 / 3 | 1500 | 200 | 37.9칸 / 10발 / 6틱 |
| M249 | 1 / 5 / 35 / 3 | 1400 | 200 | 32.9칸 / 10발 / 5틱 |

표의 성능·자재·작업량은 게임 설정이다. M2HB 장착 비용과 작업량은 이전의 일체형 진지에서 분리했으므로 기본 진지+M2HB의 총 건설 비용·작업량은 이전과 같다. 무기 프로필은 `Defs/ModernWar/Buildings/CrowsWeapons.xml`의 `CrowsWeaponDef`에 있다. 모든 화기는 기존 보급 방식인 `Steel`을 사용하며 발사마다 1씩 소비한다. 장착 시 탄약을 무료로 채우지 않는다. 탄약 용량과 보급 필터는 진지별로 복사한 속성에 적용해 다른 진지나 공유 ThingDef를 변경하지 않는다.

- M2HB는 기존 본체 진지와 같은 탄환·발사음을 유지한다. M240B는 기존 7.62mm M80A1, M249는 기존 5.56mm 탄환, Mk 19는 전용 고속 유탄을 사용한다.
- 전용 `Verb_Crows`가 조작자 확인을 담당한다. 기존 포탑이나 다른 총기의 발사 코드를 전역 패치하지 않는다.
- 밑판은 고정된 별도 윤곽선 텍스처다. 빈 상태는 Base → Unarmed Frame만, 장착 후에는 선택한 무기의 Frame → Barrel → Body → Feed 순서로 그린다. M2HB 포신만 사격 후 최대 0.0375칸 후퇴해 6틱 동안 복귀한다. 나머지 세 무기의 고정 총열에는 이 반동을 적용하지 않는다.
- 상부 각 레이어의 캔버스 크기는 `turretTopDrawSize`의 3.2칸이다. `MeshPool.plane10`은 실제 1칸 메시이므로 크기를 10으로 나누지 않는다. 밑판의 3.2칸 캔버스와 같은 비율로 표시한다.
- CROWS만 날씨 명중률 페널티의 30%를 받는다. 날씨 계수가 50%라면 `1-(1-0.5)×0.3 = 85%`로 반영하며 맑은 날은 100%를 유지한다. 무기 정확도는 접사 48%를 유지하고 근거리 70→72%, 중거리 78→82%, 장거리 68→74%로 소폭 올렸다. 이 수치는 최종 명중 확률이 아닌 무기 계수이며 실제 거리에 따라 바닐라가 보간한다.
- 컴퓨터는 기본/연결 상태 모두 기존 4방향 정사영, drawSize 3칸을 사용한다. 연결 즉시 보이도록 실시간 건물 그래픽을 전환한다. 화면 내부 표시는 양쪽 모두 빈 화면이다.

## 검증

```powershell
dotnet run --project Source/Tests/Crows/Crows.Tests.csproj
powershell -NoProfile -ExecutionPolicy Bypass -File Source/Tests/Crows/Verify-GameApi.ps1
```

실제 제작 코드로 연결·조작·즉시 사격 차단·조준/점사 초기화·건물 제거·컨트롤러 전환·리코일 레이어를 검증했다. 추가로 빈 상태, 네 화기의 자재/작업량 조건, 실물 자재 이동과 소비, 취소/선택 변경 반환, 반환 실패 시 자재 보존, 설치 진행 상태의 Scribe 호출과 복원, 건설 작업 선택/완료, 무기별 그림/verb/탄약 속성 분리를 검증한다. 테스트의 맵/폰/렌더러와 직렬화는 최소 게임 스텁이다. 별도로 실제 RimWorld 1.6 어셈블리에 대해 전체 본체를 빌드하고 새 XML 필드·클래스·프로필·작업/WorkGiver와 텍스처 파일을 확인한다. Unity 게임 실행과 실제 맵의 저장/불러오기 테스트는 하지 않았다.
