# CROWS II와 제어 컴퓨터

본체 모드의 건설 메뉴 `헤로드`에 컴퓨터(`HD_CrowsComputer`, 2×1칸)와 CROWS II 고정진지(`HD_Building_CrowsII`, 2×2칸)를 추가했다. 컴퓨터는 트랜지스터 연구, 진지는 트랜지스터와 대구경 기관총 연구를 요구한다. 신규 연구나 아스널 확장팩 의존성은 없다.

## 사용

1. 두 건물을 건설하고 전력을 공급한다. 소비 전력은 컴퓨터 200W, 진지 100W다.
2. 어느 건물이든 선택해 **CROWS 연결**을 누르고 반대 건물을 지정한다. 같은 맵·같은 세력끼리 한 대씩 연결한다. 기존 연결이 있으면 해제하고 새로 연결한다.
3. 연결된 컴퓨터에 화면·조이스틱·버튼·케이블이 있는 컨트롤러가 자동 표시된다. 연결 해제 시 기본 컴퓨터 그래픽으로 돌아간다. 전원을 끄는 것만으로 연결이나 컨트롤러가 사라지지는 않는다.
4. 폭력이 가능한 폰을 선택하고 컴퓨터를 우클릭해 **CROWS II 조작**을 명령한다. 폰이 조작 위치까지 이동해 실제 조작 단계에 들어가면 진지가 바닐라 포탑 방식으로 표적을 찾고 사격한다. 진지의 강제 표적·사격 중지 명령도 유지한다. 자동 작업 배정은 하지 않는다.

폰이 자리를 떠나거나 다른 작업을 하거나 쓰러지거나 정신 이상에 빠지거나 필요한 조작/시각 능력을 잃으면 사격을 허용하지 않는다. 두 건물의 전력·스위치, 정전 조건, 세력·맵·상호 연결, 폰의 실제 작업과 조작 단계까지 검사한다. 조작 중단·연결 해제 시 진행 중인 조준/점사를 초기화하고, 발사 동작에서도 매 탄마다 조작 조건을 검사한다. 정전으로 작업이 끝났으면 전력 복구 후 다시 조작을 명령한다.

연결은 두 건물의 참조로 저장한다. 건물 제거·포장·파괴·세력 변경 시 연결을 해제한다. 다른 맵이나 세력으로 연결할 수 없다.

## 사격·아트

- 본체 M2HB 진지와 같은 탄환·발사음·사거리 42.9칸·10발 점사/7틱 간격·100발 보급을 사용한다. 본체의 기존 M2HB와 동일하게 `Steel`로 탄약을 보충하고 탄마다 1씩 소비한다.
- 전용 `Verb_Crows`가 조작자 확인을 담당한다. 기존 포탑이나 다른 총기의 발사 코드를 전역 패치하지 않는다.
- 밑판은 고정된 별도 윤곽선 텍스처다. 본체는 기존 Base → Frame → Barrel → Body → FeedOverlay 순서의 Cutout 레이어를 사용한다. 포신만 사격 후 최대 0.0375칸 후퇴해 6틱 동안 복귀한다.
- 상부 각 레이어의 캔버스 크기는 `turretTopDrawSize`의 3.2칸이다. `MeshPool.plane10`은 실제 1칸 메시이므로 크기를 10으로 나누지 않는다. 밑판의 3.2칸 캔버스와 같은 비율로 표시한다.
- 컴퓨터는 기본/연결 상태 모두 기존 4방향 정사영, drawSize 3칸을 사용한다. 연결 즉시 보이도록 실시간 건물 그래픽을 전환한다. 화면 내부 표시는 양쪽 모두 빈 화면이다.

## 검증

```powershell
dotnet run --project Source/Tests/Crows/Crows.Tests.csproj
powershell -NoProfile -ExecutionPolicy Bypass -File Source/Tests/Crows/Verify-GameApi.ps1
```

실제 제작 코드로 연결·재연결·다른 맵/세력 거부·조작 위치와 작업 단계·13가지 즉시 사격 차단 상황·조준/점사 초기화·연결 참조 저장 호출·건물 제거·컨트롤러 전환·리코일 레이어를 검증했다. 테스트의 맵/폰/렌더러는 최소 게임 스텁이며, 별도로 실제 RimWorld 1.6 어셈블리에 대해 전체 본체를 빌드하고 XML 필드·클래스·참조와 텍스처 파일을 확인했다. Unity 게임 실행과 실제 맵의 저장/불러오기 테스트는 하지 않았다.
