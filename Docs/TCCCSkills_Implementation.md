# TCCC 구현

## 사용 조건과 파우치

`HD_TCCCTraining_LOW`는 지혈·부상자 연결, `HD_TCCCTraining_HIGH`는 모든 TCCC 스킬을 허용한다. `CompMedicalPouch`는 방탄복에 설치된 물리적 파우치 모듈의 일반 충전량과 별도 지혈제 적재량을 저장한다. 소형은 4칸, 대형은 8칸과 지혈제 2개다. 탈착하거나 저장하고 다시 불러와도 해당 모듈에 남는다. 산업약품 한 개를 소비해 일반 충전량 2칸을 회복한다. 지혈제 아이템은 대형 파우치에 한 개씩 적재한다.

지혈·부상자 연결·진통제·MIST는 완료 시 일반 충전량 1칸, 지혈제 투여는 별도 지혈제 1개를 소비한다. 지혈은 소형 또는 대형 파우치에서 가능하며 진통제와 지혈제는 대형만 허용한다. 명령 실행 중 파우치를 벗거나 충전량이 사라지면 작업을 중단한다. 전술 자동 치료는 지혈 가능한 파우치가 없는 폰에게 TCCC 지혈 작업을 지정하지 않는다. 매딕가방은 기존 재고·쿨타임 체계를 유지한다.

## 지혈 시간과 효과

`TcccRules.HemostasisDuration`은 출혈 중인 부위가 3곳 이하면 300틱(5초), 4곳 600틱, 5곳 900틱, 6곳 이상이면 1,200틱(20초)을 반환한다. TCCC는 출혈량이 큰 최대 6부위를 작업 시작 시 고정하고, 매딕가방은 주요 장기를 제외한 최대 4부위에 같은 시간 규칙을 적용한다. TCCC 임시 압박은 작업 시간의 2/3가 지난 때 해당 부위의 출혈을 70% 줄이며, 작업이 중단되면 제거된다.

완료한 TCCC와 매딕가방 처치는 같은 `HD_FieldHemostasis` 부위 표시를 남긴다. 30,000틱(12시간) 동안 해당 부위의 출혈을 80% 줄이고 부위당 고통 5%를 추가하며 총합은 20%로 제한한다. 같은 부위를 다시 처치하면 표시의 만료 시각을 갱신한다. 상처를 치료하거나 잃은 혈액을 회복하지 않는다. 전신 지혈제 효과는 부위 표시와 곱연산으로 적용된다.

## 진통제와 지혈제

진통제는 환자의 `Breathing` 능력이 0.70 미만이면 Blanca's Drugs의 `BD_Ketamine`, 이상이면 `BD_Fentanyl`을 선택한다. 별도 약물 아이템을 찾거나 분할하지 않고 약물의 기본 정량 1회를 투여한다. 투여 횟수 제한은 두지 않는다. 약물 고유의 효과와 부작용은 유지하며 TCCC 투여에 한해 `CompDrug` 중독 확률에 0.70을 곱한다.

지혈제는 대형 파우치에 따로 적재한 `HD_TCCC_HemostaticAgent` 1개를 60틱(1초)에 사용한다. 15,000틱(6시간) 동안 전신 출혈을 70% 줄이고 혈액순환 -0.10, 의식 -0.05를 적용한다. 새 상처와 부위 없는 출혈에도 적용되며 다시 투여해도 효과를 중복 생성하지 않는다. 부상자 연결은 60틱(1초), MIST는 300틱(5초)이다.

## 검증

`Source/Tests/RaidTacticalBindings/PartHemostasisTests.cs`는 3~6부위 시간 경계값, 파우치별 사용 조건, 일반 충전량과 별도 지혈제 소모, 중독 확률 배율을 검사한다. `TCCC_TESTS`와 `HEMOSTASIS_TESTS` 조건부 빌드는 게임 통합 검증 코드를 포함한다. 이전 검증 기록은 [TCCC 검증](TCCCSkills_Validation.txt)과 [부위별 지혈 검증](PartHemostasis_Validation.md)에 보존하며 변경 전 결과로 취급한다.

2026-10-16. 격리 `TCCC_TESTS` 게임 검증에서 파우치 장착·별도 지혈제 적재·펜타닐 정량 투여 및 중독 확률 감소·산업약품 재충전·저장과 불러오기·부상자 연결·MIST 후송까지 통과했다. 격리 `HEMOSTASIS_TESTS` 게임 검증에서도 지혈과 매딕가방 작업 시간을 확인했다.
