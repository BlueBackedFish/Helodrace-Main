# 파츠 스탯 점검

2026-10-18. XML 상속과 중앙 밸런스 패치를 적용한 뒤 실제 런타임 환산 코드로 검사한다.

- 사용 가능한 파츠·무기 루트 166개 모두 명시적인 원시 스탯과 양의 질량을 갖는다.
- 탄약 19개는 `projectileOverride`의 탄도·피해·관통을 사용한다. 질량 외 원시 기여가 없다고 성능 누락은 아니다.
- `HD_ModularPart_MagazineWrap_StanagTapeBlue`는 장식용 테이프다. 무게 외 성능 보너스를 주지 않는다.
- `HD_ModularPart_Slide_M1911A1_DOWN`은 마운트가 없는 비활성 구형 정의다. 실제 슬라이드는 `UP` 파츠 하나가 상·하 레이어를 함께 그리므로 별도 스탯을 중복 합산하지 않는다.
- 7.62×51 신규 6종의 M80A1 투사체 공유를 제거했다. 8종 모두 별도 탄도 프로필을 사용하며, [탄종별 수치와 듀플렉스 구현](ModularWeapon_76251.md)을 따로 검증한다.

## 머즐 장착 효과

머즐·소음기 11종에 반동과 들림 감소를 적용한다. 소염기보다 제퇴기가 강한 제어 효과를 내며, 소음기는 무게·조작성 불이익과 소음·섬광 억제 역할을 유지한다. 나사 보호캡·어댑터에도 작은 제어 이득을 준다.

자동 테스트는 같은 기준 무기에 각 파츠를 장착했을 때 반동 제어, 들림 제어, 바닐라 사격 후 회복, CE 환산 반동이 개선되는지 확인한다. 무게는 늘어나며 조준 준비 시간까지 무조건 개선하는 것은 아니다. 머즐은 직접 피해·관통을 늘리지 않는다.
