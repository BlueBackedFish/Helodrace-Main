# 총잡이 특성·권총 명사수 모드 조정

2026-11-04 사용자 요청. 기존 총잡이 백스토리, 의료·BTX 보급과 구조 이벤트 조건은 유지한다.

특성 표시 이름은 한국어 **총잡이**, 영어 **gunslinger**다. 조준 준비 시간은 기존의 80%인 `AimingDelayFactor ×0.8`, 원거리 발사 후 대기는 기존의 85%인 `RangedCooldownFactor ×0.85`로 설정했다. 고정 백스토리의 native forcedTraits로 부여하며 다른 폰에게 무작위로 추가하지 않는다.

단위는 기본 사거리 칸 수다. 기존 명사수 모드 권총은 해당 모드 사거리만 3칸 증가했다. 기존 모드가 없던 권총은 일반 발사 방식·웜업·점사 수를 유지하는 사거리 확장 모드를 추가했다. 고유 리볼버는 Odyssey 정의가 있을 때만 연결한다. 새 모드도 기존 헤로드/명사수 유전자 자격과 전환 제한을 따른다. 소총·기관단총·산탄총·신호총·도구형 무기는 변경하지 않는다.

모듈식 무기의 실제 사거리는 기존 부품·조준기 배율을 곱하므로 증가량도 그 배율의 영향을 받는다. 날씨와 실제 표적 판정은 현재 엔진의 EffectiveRange/OutOfRange/발사 경로를 그대로 사용한다. 공용 VerbProperties를 런타임에 수정하는 코드는 추가하지 않았다. 수정은 native XML statFactors/Verb/Comp 정의와 기존 명사수 구현만 사용한다.

패닝의 발사 후 쿨다운은 기존 **모드 쿨다운 배율의 절반**이다. 여기에 총잡이 특성의 ×0.85가 별도로 곱해진다. 탄창 내 연속 발사 수와 발사 간 틱은 바꾸지 않았다. 사거리만 늘어난 새 모드는 별도 속사 보너스를 주지 않는다.

## 실제 1.7 검증

최종 `.codex-staging/Gunslinger/pistols-02`에서 **226 PASS, COMPLETE**. 기존 구조자·담배 95개와 특성 영어 이름 1개, 권총 10종×13개 검사다. 각 권총의 native 생성·모드 전환, 일반 사거리 유지, 명사수 사거리와 현재 부품 보정, 쿨다운 배율과 총잡이 특성의 결합, 이전 한계를 넘는 거리의 실제 발사·전체 발사 사이클, 새 사거리 밖 거부, 일반 모드 복귀를 확인했다. 기존 구조자 검사도 새로운 ×0.8/×0.85 비율로 갱신했다.

실제 설치된 RimWorld 1.7.4995 rev309를 사용했다. 지도·날씨·온도·기타 필요·무작위 이벤트를 제어했으며 자연 명중률·장기 DPS 비교나 모든 외부 모드 권총의 호환성 측정은 아니다. 수집 로그에는 기존의 없는 Workshop 폴더 메시지가 남으며 제품 예외·패치 실패는 없었다. 제품 및 검사 모듈 빌드는 경고·오류 0개다.
