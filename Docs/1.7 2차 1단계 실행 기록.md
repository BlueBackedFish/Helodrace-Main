# 1.7 2차 1단계 실행 기록

대상: [2차 수정 계획](헤로드%202차%201.7%20수정%20계획.md)의 T2-01·07·02·03·16. 엔진: RimWorld 1.7.4995 rev309 / Harmony 3.

## 작업대 수정

- 기계 작업대의 사용 가능 조건을 `Building_WorkTable.UsableForBillsAfterFueling`에 연결했다. 이 판정은 작업 생성과 진행 중인 바닐라 `DoBill` 양쪽에서 사용된다.
- 작업 생성 시 무동력인 경우에는 정상적인 작업 불가 사유를 반환한다. 기존 `MakeNewToils` 추가 실패 조건은 바닐라의 공통 판정으로 통합했다.
- 의류작업대에 빠져 있던 재봉 작업의 `WorkGiverDef`와 한국어 작업 문구를 추가했다. 의류 조합법 연결과 작업 배정을 모두 검사하도록 기존 검증 스크립트도 보완했다.
- 제품·테스트 코드에 Unity API 의존성을 추가하지 않았다. 테스트 호스트 종료는 Waylith API를 사용한다.

검증:

- 초기 실게임 기록: `.codex-staging/ProductionStage1/baseline/Evidence/checks.txt`. 무동력 상태에서도 `UsableForBillsAfterFueling=True`, 의류작업대 작업 배정자는 없음.
- 수정 후 실제 Job 검증: `.codex-staging/ProductionStage1/worktable-jobs-7/Evidence/checks.txt`. 동력원·샤프트 연결, 작업 중 연결 제거, 연결 복구 후 단일 제품 완성, 의류 제작, 방탄판 교체, 장비 개조가 모두 통과하고 `COMPLETE`를 기록했다.
- 해당 게임 로그의 오류는 초기 기준에도 있던 미설치 WorkshopItem 경고성 오류뿐이며, 생산·예약·Job 복구 오류는 없었다. 종료 코드는 수집 시 핸들이 없어 `null`로 기록되었으므로 0으로 보고하지 않는다.
- `Source/Verify-ClothingWorkbench.ps1` 통과: 37개 조합법 연결 목록, 작업 배정, 편집 초안 격리, 취소, 물리 부품 보존, 일괄 적용과 작업 지시 복구.
- 저장/불러오기와 연료·대량 정련의 공통 검증은 다음 연료 작업에서 함께 마무리한다. 이 기록만으로 1단계 전체 완료로 처리하지 않는다.
