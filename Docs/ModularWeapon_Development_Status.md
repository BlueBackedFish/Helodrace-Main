# 모듈러 총기 시스템 개발 현황 및 계획

- 갱신일: 2026-09-04
- 최종 목표 대비 진행률: 약 82%
- 개발용 트리·렌더러·편집기 진행률: 약 99%

최종 목표는 실제 아이템으로 존재하는 총기 파츠를 트리 구조로 조립하고, 레일 위 임의 위치 배치와 전투 능력치 반영까지 지원하는 타르코프식 모딩 시스템이다. 현재 개발용 조립체·편집 도구와 플레이어용 모딩 화면의 1차 구현이 동작하며, 실제 아이템/작업대 작업 흐름과 전투 스탯 집계가 남아 있다.

## 이번 반영 내용

- 모든 모듈러 파츠에 `Required`, `Functional`, `Optional` 작동 분류를 추가했다.
  - 필수 부품이 기본 장착 소켓에서 빠지면 격발을 시작하지 못하며, 누락 부품을 메시지와 모딩 UI에 표시한다.
  - 상·하부 총몸, AR-15 볼트·트리거·총열을 필수 부품으로 지정했다.
  - 가스 시스템과 버퍼 튜브가 빠지면 단발만 가능하고, 탄창이 빠지면 용량이 1발로 제한된다.
  - 나머지 부품은 선택 부품이며 없어도 기본 작동을 제한하지 않는다.
  - 편집기에서 분류와 기능 저하 효과를 바꾸고 XML로 출력할 수 있다.
  - 필수 부품은 렌더링할 때 자동 생성하지 않아 불완전 조립 상태가 저장·유지된다.

- 최신 애니메이션 출력 `20260830_094943`을 반영했다. AR-15 공용 볼트 후퇴량은 `-0.078`, 모든 M4/M16 상부 리시버의 탄피 배출점은 `(-0.096,0,0)`, 급탄 경로는 `(-0.076,0,-0.01)`에서 `(-0.023,0,-0.004)`로 통일했다.
- 최신 배치 출력 `20260830_082152`의 위치값을 다시 대조했으며 현재 M4 Def와 일치한다. 생략된 0 기본값과 XML 표기 형식 외에 새 위치 차이는 없다.
- 사격 기즈모와 모딩 명령 아이콘이 하부 리시버만 표시하지 않도록 M4/M16A1/M16A2/M16A4 개발 총기에 기존 완성형 총기 텍스처를 `uiIconPath`로 지정했다. 아이콘은 대표 완성형 이미지이며 현재 장착 파츠를 동적으로 합성하지는 않는다.
- 내장 편집기를 `Placement`와 `Animation` 작업 탭으로 분리했다. 애니메이션 탭에서 볼트·트리거 이동 범위/회전 중심/회전량, 탄피 배출점/방향/주기/크기, 급탄 시작점과 도착점을 독립적으로 편집할 수 있다.
- 탄피 텍스처의 시작 각도를 비행 방향 기준 반시계 90도로 회전하고, 탄피·급탄탄 크기를 기존의 75%로 조정했다.
- 내장 편집기에 `Feed start`/`Feed end` 편집 대상을 추가했다. 상부 리시버의 급탄 시작점과 도착점을 프리뷰 드래그·X/Z 슬라이더·축 고정으로 조정하고 실행 취소 및 XML 출력할 수 있다.
- 최신 편집기 저장본 `20260830_082152`의 볼트·트리거 오프셋을 반영하고 모든 AR-15 계열에 공통 적용했다.
- 급탄 중인 실탄은 전체 총기 파츠보다 아래, 합성 외각선보다 위에 그려지는 전용 중간 레이어를 사용한다.
- 모든 모듈러 `_Outline.png`의 RGB를 `(0,0,0)`으로 만들어 완전한 검정 외곽선으로 통일했다. 외곽선 형태를 결정하는 알파와 해상도는 유지한다.
- 새 AR-15 볼트와 트리거를 실제 모듈러 파츠로 등록했다.
  - 볼트는 모든 M4/M16 상부 리시버, 트리거는 모든 개발 총기 하부 리시버의 필수 기본 파츠다.
  - 새 총기 기본 조립에는 포함되지만, 제거한 뒤에는 자동 복구되지 않고 격발 불가 상태가 유지된다.
  - 트리거 후퇴·복귀와 볼트 후퇴·전진이 각 총기의 실제 RPM 기반 발사 간격에 맞춰 재생된다.
- 탄피 배출과 차탄 급탄 표시를 동일한 발사 사이클에 연결했다.
  - 격발 직후 28% 지점에서 탄피를 배출하고, 55~92% 구간에 차탄이 약실 쪽으로 이동한다.
  - M855A1과 .300 BLK TACTX는 각자 별도의 실탄 텍스처를 사용한다.
- 모든 파츠 아웃라인은 본체보다 아래에서 합성하되, 아웃라인끼리 겹칠 때 상부 리시버가 최상단에 오도록 우선순위를 추가했다.
- 편집기 XML 출력에 아웃라인 우선순위, 내부 파츠 애니메이션, 급탄/배출 타이밍 및 급탄 텍스처 항목을 추가했다.
- 모듈러 총기가 매 격발 성공 시 상부 총몸의 배출구에서 탄피를 배출한다.
  - 선택 탄종에 따라 5.56x45mm와 .300 BLK 탄피 텍스처가 자동 교체된다.
  - 배출구 위치는 상부 총몸 파츠 데이터, 탄피 종류는 탄종 파츠 데이터가 담당한다.
  - 조준 방향에 맞춰 배출 위치와 방향을 회전시키며, 탄피는 회전·포물선 이동 후 사라진다.
  - .30-06 탄피 Mote도 후속 탄종 연결용으로 등록했다.
  - 레이저·조명·탄피는 `DrawEquipmentAiming`의 실제 장비 위치를 공유해 동쪽
    조준 시 왼쪽으로 밀리던 효과 시작점을 수정했다.
  - 탄피 텍스처의 북쪽을 앞방향(0도)으로 취급해 초기 회전을 배출 진행각과
    정확히 맞추고, 이후 회전 운동은 별도로 적용한다.

- 탄종 파츠가 실제 투사체 Def를 교체하도록 연결했다.
  - M855A1 표준탄: 피해 11, 관통 0.18, 저지력 0.5, 속도 100.
  - .300 BLK TACTX: 피해 14, 관통 0.14, 저지력 1.0, 속도 75.
  - .300 BLK는 표준탄보다 피해량과 저지력이 높고 관통력과 탄속이 낮다.

- 상·하부 반전 장착 파츠가 바닥과 장비 상태에서 사라지는 렌더링 문제를 수정했다.
  - 원인은 세로 반전을 위해 사용한 음수 메시 스케일이 RimWorld의 맵/장비 렌더 메시에서 면 방향을 뒤집는 것이었다.
  - 계층 좌표에는 부착점 반사 계산을 위한 부호 있는 스케일을 유지한다.
  - 실제 월드 렌더에서는 메시 크기를 항상 양수로 만들고, 캐시된 전용 머티리얼의 UV만 세로 반전한다.
  - 바닥 정적 맵 메시, 바닥 실시간 렌더, 장비 조준 렌더, `_Outline`에 같은 처리를 적용했다.
  - 반전 머티리얼은 원본 머티리얼별로 한 번만 생성해 프레임마다 새 머티리얼이 생기지 않는다.

- 피카티니 레일과 파츠 마운트에 `Top`, `Bottom`, `Side` 방향 분류를 추가했다.
  - 측면형 파츠는 측면 레일에만 장착된다.
  - 상부형과 하부형 파츠는 상·하부 레일 양쪽에 장착할 수 있다.
  - 상부형을 하부에, 하부형을 상부에 장착하면 마운트점을 축으로 그래픽과 하위 트리를 세로 반전한다.
  - 반대면 장착 시 파츠마다 추가 보정할 수 있는 `oppositeSurfaceOffset` 데이터를 제공한다.
  - 방향이 지정되지 않은 피카티니 소켓/마운트는 호환 대상으로 인정하지 않고 Def 설정 오류로 보고한다.
- 기존 파츠 방향을 분류했다.
  - 상부형: EXPS, G33, AN/PEQ-15, TA51
  - 하부형: Dalton/HAC 수직손잡이, URX 하단 패널
  - 측면 전용: M600, URX Mid 패널
- 개발 편집기에서 레일 방향, 파츠 고유 방향, 반대면 X/Z 보정 오프셋을 실시간 설정하고 XML로 출력할 수 있다.
- 플레이어 모딩 UI의 소켓·카탈로그·호버 정보에 방향과 상하 반전 장착 여부를 표시한다.

- `Player.log`에서 모딩 카탈로그 호버 시 반복 발생하던 `Texture2D.GetPixels32` 예외를 수정했다.
  - RimWorld가 CPU 읽기 불가 상태로 불러온 텍스처는 직접 읽지 않는다.
  - 임시 GPU 렌더 텍스처에서 읽기 가능한 복사본을 만들어 알파 경계를 계산한다.
  - 복사나 분석에 실패해도 전체 텍스처 미리보기로 안전하게 폴백해 모딩 창의 `OnGUI`가 중단되지 않는다.
- 왼쪽 조립 트리를 단계형 파츠 탐색 UI로 교체했다.
  - 현재 선택 파츠를 큰 카드로 표시한다.
  - 전체 트리를 한꺼번에 펼치지 않고 현재 파츠에 직접 연결된 파츠만 카드 목록으로 표시한다.
  - 상위 파츠/루트 이동과 현재 조립 경로를 제공한다.
  - 직결 파츠 카드에서 장착 소켓과 레일 위치를 바로 확인하고 클릭해 하위 단계로 이동한다.

- 최신 M4 편집기 출력 `20260826_012325`와 M16A4 출력 `20260826_012834`의 파츠별 중심점·마운트·소켓·점유 길이·기본 레일 위치를 Def에 반영했다.
- M4 개발 총기에 M16 하부와 같은 탄창 소켓 좌표 `(-0.075, 0, -0.019)`를 적용했다.
- 기존 M4 개발 조립체 세이브에도 누락된 STANAG 탄창을 한 번 자동 보충한다.
- 점 형태 Picatinny 소켓을 수평 직선 레일 데이터로 확장했다.
  - 소켓: `isRail`, `railLength`
  - 파츠 마운트: `railOccupancy`
  - 실제 부착 상태와 기본 조립 설정: `railOffset`
- 하나의 레일에 여러 파츠를 부착할 수 있다.
- 파츠가 레일 범위를 벗어나거나 다른 파츠의 점유 구간과 겹치면 부착·이동을 거부한다.
- 레일 각도는 항상 로컬 수평인 0도로 강제한다. 총기 전체가 회전할 때는 레일도 총기와 함께 회전한다.
- 편집기에 다음 기능을 추가했다.
  - 소켓 생성 시 일반 소켓/연속 수평 레일 선택
  - 레일 길이 설정
  - 파츠 마운트의 레일 점유 길이 설정
  - 부착된 파츠의 레일 위치 슬라이더
  - 미리보기에서 레일 전체 길이를 선으로 표시
  - 레일 위치까지 실행 취소와 XML 내보내기에 포함
- 기존 저장에는 레일 위치 배열이 없으므로 모두 0으로 자동 복구한다.
- M4/M16A4 상부 총몸의 앞·뒤 레일을 각각 하나의 연속 레일로 유지하면서 최신 출력값을 적용했다.
  - M4 상부 레일은 중심 X `-0.114`, 길이 `0.152`이며 G33은 `-0.034`, EXPS는 `+0.036`에 배치된다.
  - M16A4 상부 레일은 중심 X `-0.112`, 길이 `0.146`이며 TA51은 `-0.022`에 배치된다.
  - M4 출력 원본의 길이 `0.145`는 새 EXPS 점유 길이 `0.08`을 수용하지 못해, 파츠 위치를 유지하는 최소 유효 길이 `0.152`로 보정했다.
  - 구형 세이브의 `rail_receiver_rear`/`rail_receiver_front` ID는 새 `rail_receiver_top`으로 자동 변환한다.
- M16A4 하단 핸드가드의 구형 `rail_bottom_grip`과 `rail_bottom_panel`을 중심 X `0.124`, 길이 `0.263`인 단일 `rail_bottom`으로 통합했다.
  - HAC VFG는 `-0.036`, 하단 패널은 `+0.059`에 배치되어 두 점유 구간이 겹치지 않는다.
  - 구형 mid/side 패널 레일과 새 조립체의 기본 mid 패널 장착은 제거했다.
  - 기존 세이브의 손잡이/하단 패널 소켓은 단일 레일로 자동 이전하고, 기존 mid 패널 `Thing`은 삭제하지 않고 상부 핸드가드의 측면 레일로 옮긴다.
- 편집기 미리보기에 전체 레일은 파란 선, 선택 파츠의 실제 점유 구간은 굵은 노란 선과 양 끝 표시로 나타난다.
- M4 가변 개머리판과 M16A4 고정 개머리판에 위치 조절 트랙을 추가했다. 개머리판 트랙은 한 파츠만 허용한다.
- 방어구 모딩 화면의 구성을 따른 플레이어용 총기 모딩 UI를 추가했다.
  - 조립 트리, 중앙 합성 미리보기, 소켓/레일 목록, 호환 파츠 카탈로그로 구성된다.
  - 현재 개발 단계에서는 파츠 아이템을 요구하지 않고 선택 즉시 새 파츠 `Thing`을 생성해 장착한다.
  - 교체·제거된 가상 파츠와 그 하위 트리는 안전하게 제거한다.
  - 연속 레일은 가장 가까운 빈 구간을 자동으로 찾고, 장착 후 위치 슬라이더로 조정할 수 있다.
  - 파츠 타일에 마우스를 올리면 투명 여백을 제외한 실제 파츠 중심 기준 확대 미리보기가 표시된다.
- 현실 RPM 기반 발사 지연 하한을 추가했다.
  - M4/M16A4 개발 총기의 명목 기계적 한계는 800 RPM이다.
  - 기본 발사 지연은 최소 지연보다 20% 길다.
  - 각 파츠의 `fireDelayMultiplier`를 곱해 조정하며, 최종 지연은 `60 / RPM` 아래로 내려가지 않는다.
  - 점사 내부 틱 간격과 `RangedWeapon_Cooldown`에 같은 제한을 적용한다.
  - 개발 편집기에서 현실 RPM, 기본 지연 배수, 파츠 지연 배수를 실시간 조정하고 XML로 출력할 수 있다.
