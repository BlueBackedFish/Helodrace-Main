# 공유 지혈·전신 지혈제 검증

2026-10-08. 자가 지혈과 매딕가방의 완료 효과를 같은 부위 표시로 통일했다. 12시간/80% 감소, 부위당 고통 +5%/총 최대 +20%. 지혈제는 별도의 6시간/전신 70% 감소이며 혈액순환 -0.10, 의식 -0.05 능력 오프셋을 적용한다. 함께 사용한 부위는 출혈 ×0.06. 자동 치료 AI는 포함하지 않는다.

## 약식 검증

- 배포 및 전용 검증 빌드: 경고·오류 0.
- `dotnet run --project Source/Tests/RaidTacticalBindings/RaidTacticalBindings.Tests.csproj --no-restore -- --hemostasis`: 15항목 통과. 설치된 실제 출혈 getter 3종 바인딩, 부위 분리, 중복·만료·제거, 전신/부위 동시 적용, 부위 없는 출혈, 중복 부위 고통 배제 및 20% 상한을 확인했다.
- `HEMOSTASIS_TESTS` 격리 게임 `-quicktest -batchmode -nographics`: 실제 헬로드 군인·상처·장착 가방·TCCC 작업으로 22항목 통과 및 `COMPLETE`. [실제 실행 원문](PartHemostasis_Validation.txt).
- 변경 XML 8개 파싱 및 번역 키 중복 검사 통과. 구형 자가 지혈 완료 Def 제거 확인.

실제 고통 수치가 지혈 1부위에서 +0.05, 6부위에서 +0.20임을 확인했다. 다른 팔은 부위 지혈의 영향을 받지 않지만 전신 지혈제를 함께 쓰면 출혈 ×0.30, 지혈한 팔은 ×0.06이었다. 지혈제를 투여한 이후 생긴 다리 상처에도 전신 효과가 적용됐다. 실제 혈액순환/의식 수치 저하와 제거 후 혈액순환 복귀도 확인했다. 의식 최종 수치는 혈액순환 등 바닐라 능력 연동에도 영향을 받는다.

실제 3초 지혈제 작업은 부위 표시 없이 전신 효과 1개와 약물 1개 소모를 확인했다. 자가 지혈의 20초 임시 압박 및 중단 시 제거, 완료 시 공유 표시를 확인했다. 실제 매딕가방 작업은 기존 자가 지혈 표시를 재사용하며 새 부위에만 표시를 추가했다. 보급품 1개 소모, 두 부위 고통 합계 +0.10, 두 상처 `IsTended()` false를 확인했다.
