- 최초 타인 완료 검사는 첫 처치 전의 부위 순위와 중단 후 새 처치의 결과를 비교해 실패했다. 후속 fixture는 상처가 시험 도중 빨리 사라지지 않게 하고, 실제 완료의 6부위 상한·상처 부위 소속·뇌 포함을 직접 확인했다. 고정 출혈률의 정확한 합계/순위는 독립 검사에서 따로 확인했다.
- 이번 약식 실행에서는 실제 저장/로드 왕복·절단 상처·대규모 CPU 비교를 추가 실행하지 않았다. 별도 지도/게임 틱 처리는 추가하지 않았다.
- headless 실행의 기존 아틀라스·셰이더 오류와 의료 작업 예외를 구분했으며, 최종 실행에서 의료 작업 예외는 없었다.
