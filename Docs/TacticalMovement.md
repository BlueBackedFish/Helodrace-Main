림월드용 CQB/사격 스킬 시스템을 설계한다.

전체 설계 방향은 다음과 같다.

* CQB에서는 가능한 한 난수 의존도를 줄인다.
* 단순 명중률 보너스보다 거리, 방향, 자세, 이동, 노출 상태, 조준 상태 등 명확한 조건으로 결과를 결정한다.
* 강력한 기술은 높은 확률 페널티보다 좁은 사용 조건으로 제한한다.
* 같은 상황에서는 가능한 한 비슷한 결과가 나오도록 한다.
* 플레이어가 실패 원인을 명확하게 이해할 수 있어야 한다.
* 일반 사격을 완전히 대체하는 스킬보다는 특정 전술 상황을 해결하는 기술을 만든다.

## 조준

CQB 세부 기즈모는 `CQB 모드` 토글을 켰을 때 표시한다. 기본값은 꺼짐이며 폰별로 저장한다. 토글은 명령 표시만 제어하며, 진행 중인 행동이나 패시브 설정은 변경하지 않는다.

지정한 지점을 계속 주목하는 지속형 사격 자세다. 이동하면 현재 위치에서 그 지점을 향하도록 조준 방향과 사격 부채꼴이 갱신된다. 폰을 클릭해도 클릭 당시 지점을 저장하며, 움직이는 폰 자체를 추적하지 않는다.

조준 해제 후 재사용 대기시간은 10초다. 최초 준비시간 1.5초는 유지한다. 조준 시작·지점 전환 시 현재 총구 각도에서 부드럽게 회전하며, 최단 전환 각도에 따라 0.1~0.6초가 걸린다(90도 0.35초, 180도 0.6초). 실제 사격 표적 전환 및 사격 후 복귀 동작은 유지한다.

정지 상태:

* 집중 범위는 총 90도.
* 90도 안에 있는 대상에 대한 Warmup을 50%로 조정한다.
* 90도 밖의 표적에 대해서는 Warmup을 150%로 조정한다.
* 조준 상태에서는 이동속도가 감소한다.

이동 상태:

* 집중 조준 범위는 기존과 동일하게 90도.
* 실제 사격 가능 범위는 총 120도.
* 90도 안의 적은 정상적인 조준 효과를 받는다.
* 90~120도 구간의 적은 사격할 수 있지만 조준 보너스를 받지 못하거나 별도의 페널티를 적용한다.
* 120도 밖의 대상은 아예 조준 및 사격할 수 없다.
* 이동 중 사용 시에는 `기동` 패시브의 설정에 따른 추가 페널티를 적용한다.

조준의 핵심 역할은 명중률 상승이 아니라 사전에 예상한 방향에 대한 빠른 대응이다.

## 급작 사격

현재 행동을 대부분 중단하고 극근거리의 위협에 즉시 사격한다.

* 사거리는 매우 짧게 설정한다.
* 기준안은 약 4타일.
* Warmup을 거의 또는 완전히 무시한다.
* 일정 발수만 사격한다.
* 조건을 만족하면 대부분의 일반 명중 요소를 무시하고 명중하도록 한다.
* 엄폐, 완전 차폐, 시야 단절처럼 실제로 탄도가 막히는 요소는 유지한다.
* 부위 명중까지 자동 확정시키지는 않는다.

일반적인 DPS 증가 기술이 아니라 눈앞의 돌발 위협을 빠르게 처리하는 기술이다.

## 정확한 사격 — 패시브

사격 시 우선적으로 노릴 신체부위를 지정할 수 있다.

선택 가능 부위:

* 머리
* 흉부
* 팔
* 다리

단순 확률 가중치보다는 부위에 따라 필요한 조준시간이나 조건을 다르게 설정하는 방향을 우선한다.

예:

* 흉부는 빠르고 안정적.
* 머리는 가장 긴 조준시간 필요.
* 팔은 무장 및 조작능력 무력화 목적.
* 다리는 기동력 제거 목적.

조건이 충분히 충족되었을 경우 선택한 부위를 확실하게 노릴 수 있도록 설계한다.

## 강타

장총으로 근접한 적을 밀어내 사격거리를 다시 확보하는 기술이다.

* 권총 사용 불가.
* 사거리 1타일.
* 대상에게 2타일 넉백.
* 약 1초 스턴.
* 밀리는 경로에서 벽에 충돌하면 스턴 시간이 2배가 된다. 다른 폰이나 맵 경계에 막힌 경우는 제외한다.
* 대형 대상은 넉백이나 스턴이 감소하거나 무효화될 수 있다.
* 직접적인 살상 기술보다는 근접한 적과 거리를 벌리는 기술로 설계한다.

## 기동 — 패시브

급작 사격, 다중 목표 사격, 조준 등 다른 사격 스킬을 이동 중 사용할 때 어떤 페널티를 받을지 결정한다.

두 방식 중 하나를 선택한다.

정확도 유지형:

* 명중률은 최대한 유지한다.
* 대신 Warmup이 크게 증가한다.

반응속도 유지형:

* Warmup 증가는 최소화한다.
* 대신 명중률이 감소한다.

이 패시브는 이동 중 사격 자체를 제공하는 것이 아니라, 원래 정지 상태에서 사용하는 기술을 이동 중 사용할 때의 성격을 결정한다.

## 기동사격

대상은 현재 시야 밖에서도 지정 가능하다. 이동 도중 시야·사거리·조준 각도 조건이 충족되면 발사하며, 잠시 시야가 막혀도 지정을 유지한다.

이동지점과 사격 목표를 동시에 지정한다.

* 지정 위치로 이동하면서 지정 대상에게 사격한다.
* Warmup 증가 또는 명중률 감소 중 하나를 선택할 수 있다.
* `기동` 패시브를 이용해 일반 기술을 이동 중 사용하는 것보다 페널티가 작다.
* 이동과 사격을 처음부터 동시에 수행하도록 설계된 전용 기술이다.

## 고속 기동

짧은 거리를 매우 빠르게 이동하는 기술이다.

* 지정 위치로 이동.
* 이동속도 약 200%.
* 최대 이동거리를 제한한다.
* 이동 중 사격이나 조준에는 제한을 둔다.

방어 페널티는 엄폐 효율 감소가 아니다.

대신 고속 기동 중인 폰 자체의 `표적 크기/명중 보정 계수`를 조정하여, 적이 해당 폰을 목표로 사격할 때 최종 명중률을 낮춘다.

즉:

* 실제 엄폐물의 성능은 그대로 유지.
* 대상이 빠르게 이동하기 때문에 맞히기 어려워지는 것을 별도의 명중률 하향 계수로 표현한다.

## 다중 목표 사격

실행 시 매 발 선딜레이는 각종 조준·이동 배율과 무관하게 12틱(0.2초)으로 고정하고 무기 후딜레이는 제거한다. 거리 반영된 사수 정확도 계수 x는 3x²−2x³으로 조정한다. 7타일 이내에서는 조준 명중률을 2배(최대 100%)로 보정하며, 엄폐·방호 판정은 유지한다.

사용 무기는 연발수 3발 이상 또는 사수·무기 보정 후 원거리 재사용 대기시간 1초 이하 중 하나를 만족해야 한다.

최대 3개의 표적을 지정할 수 있다.

두 가지 사격 방식을 선택한다.

### 사격 우선

여러 표적에 화력을 빠르게 분산한다.

예:
A 1발 → B 1발 → C 1발 → A 1발 → B 1발 → C 1발

* 지정된 표적을 번갈아 가며 한 발씩 사격한다.
* 한 표적을 완전히 처리하기보다 여러 위협에 동시에 사격하는 것이 목적이다.
* 다수의 적에게 빠르게 피해를 분산하거나 반응을 강요하는 용도다.

### 제압 우선

한 표적을 먼저 확실히 제압한 다음 다음 표적으로 넘어간다.

예:
A 지속 사격 → A 제압/다운 → B 지속 사격 → B 제압/다운 → C

* 지정 순서대로 표적을 공격한다.
* 현재 표적이 쓰러지거나 충분히 제압될 때까지 해당 표적에게 사격을 집중한다.
* 현재 표적이 처리되면 다음 지정 표적으로 이동한다.
* 여러 적을 동시에 건드리는 것보다 하나씩 확실하게 전투불능 상태로 만드는 것이 목적이다.

표적 사이의 최대 각도 제한을 둘 수 있다.

## 선제 사격

두 발씩 끊어서 발사한다. 두 발 사이 최소 12틱(0.2초), 마지막 발 이후 다음 묶음까지 최소 60틱(1초)을 기다린다. 원래 무기 후딜레이가 더 길면 그 시간을 유지한다.

사선 통과 명중률은 사격 레벨과 무관하게 `clamp(0.5 × (1 + 2 × (BodySize - 1)), 0, 1)`로 계산한다. 표준 크기 1에서 50%, 크기 차이에 따른 보정 폭은 2배다.

전술 스킬의 수동 대상 지정은 적대·중립·우호 진영을 구분하지 않는다. 스킬 사용자 제어권 조건과 자동 사격의 적 탐색 정책은 유지한다.

지정한 직선 구역에 미리 화력을 준비하는 기술이다.

* 특정 직선 또는 매우 좁은 사격구역을 지정한다.
* 해당 구역을 폰이 지나가면 즉시 사격한다.
* 일반 명중 판정을 사용하되 최종적으로 약 90% 수준의 명중 보정을 적용한다.
* 기술 최초 사용 시 준비 Warmup이 존재한다.
* 준비가 완료된 이후에는 해당 구역에 진입한 적에게 별도의 일반 Warmup 없이 빠르게 사격한다.
* 이동하거나 조준 상태가 무너지면 취소될 수 있다.

조준과의 차이:

* 조준은 비교적 넓은 방향의 적에게 빠르게 대응한다.
* 선제 사격은 적 유무와 무관하게 지정 직선으로 계속 발사한다. 탄도와 만나는 폰에게 명중 판정을 하며 아군도 피격 가능하다. 탄약, 후딜레이와 장애물 판정은 유지한다.

문, 복도, 코너, 통로 차단용 기술이다.

## 근거리 저격 / 협동 조준

현재 실행 방식: 인접한 협동 폰을 먼저 선택하고, 사수→협동 폰 방향 중심 60도 내의 표적을 선택한다. 해당 표적의 남아 있는 치명 부위(머리 우선)에 `ceil(무기 연발수 / 2)`발만 사격하고 종료한다. 지속 자세가 아니며, 이동·대형 이탈 시 취소한다. 방호와 엄폐는 유지한다.

2명의 폰이 협동하여 특정 방향에 고정밀 사격을 준비한다.

* 뒤쪽 폰이 사수.
* 앞쪽 폰의 방향을 기준으로 약 60도 범위 지정.
* 사격 스킬에 따라 최대 적용 거리가 증가한다.
* 범위 안에서는 폰 자체의 사격 능력 계수와 총기 자체의 거리 정확도 계수를 100%로 조정한다.
* 엄폐, 연막, 시야 방해 등 외부 환경 요소는 정상 적용한다.
* 최종 명중률에 약 120% 조정을 적용한다.
* 아군 오인사격은 비활성화한다.
* 둘 중 하나가 이동하거나 다운되는 등 협동 상태가 깨지면 해제된다.

핵심은 능력치나 총기의 거리 정확도 저하를 제거하되, 실제 환경으로 인한 방해는 남겨두는 것이다.

# 신속한 처리 계열

공통 개념:

이미 플레이어가 충분히 유리한 조건을 만들었다면 확률을 굴리기보다 매우 빠르고 확실하게 적을 처리할 수 있게 한다.

## 사살

극근거리에서 적을 신속하게 제거하는 사격 기술이다.

기본 시퀀스:

1. 흉부 2발.
2. 즉시 안면 1발.

일반적인 모잠비크 드릴처럼 두 발을 쏜 뒤 적의 상태를 확인하고 세 번째 사격을 결정하는 방식이 아니다.

처음부터 흉부 2발 + 안면 1발을 하나의 연속 행동으로 실행한다.

연속 발사 간격은 2틱, 두 번째 흉부탄 이후 첫 머리탄까지는 4틱으로 설정한다.

추가 규칙:

* 사거리는 매우 짧다.
* 대부분의 일반 명중 요소를 무시한다.
* 사용 조건을 만족하면 명중은 거의 확정적으로 처리한다.
* 실제 엄폐, 완전 차폐, 시야 단절은 무시하지 않는다.
* 흉부 사격이 방호구를 관통하지 못하면 기본 흉부→흉부→머리 이후 머리 2발의 추가 더블탭을 수행한다.
* 비관통 시 추가 머리 더블탭은 최대 5회(추가 10발)로 제한한다. 대상 사망 또는 사격 불가 시 중단한다.
* 안면이나 머리 방호가 존재하면 해당 방호는 정상 적용한다.

신속하고 확실한 근거리 살상이 목적이다.

## 테이크다운

전투가 본격적으로 시작되기 전에 유리한 위치와 능력 차이를 이용해 적을 즉시 제압하거나 제거하는 기술이다.

사용 조건:

* 대상까지 거리 4타일 이하.
* 대상 후방에서 접근.
* 벽 뒤 대상도 지정 가능하며, 대상의 바라보는 방향 기준 후방 여부를 판정한다. 이후 실제 접근 경로를 따라 근접한 뒤 타격한다. 이동 불능·기절·경로 단절·대상 무효화 시 취소한다.
* 대상이 사용자를 발견하지 않은 상태.
* 보호되지 않은 치명부위가 최소 하나 존재.
* 날카로움 방어력 20% 이하인 의복은 방호가 없는 것으로 취급한다. 그보다 높은 방어력의 의복 및 해당 부위를 덮는 모듈 장갑은 방호로 판정한다.
* 사용자 격투 레벨이 대상보다 최소 2레벨 이상 높음.
* 이상현상 계열 생명체에는 사용 불가.
* 노출된 치명부위의 `현재 체력`이 아니라 `해당 치명부위의 최대 체력`이 일정 기준 이하일 때 사용 가능.

즉 대상 전체가 이미 부상당했는지가 아니라, 해당 생명체의 치명부위가 구조적으로 한 번의 테이크다운으로 파괴 가능한 크기인지 판단한다.

예:

* 인간의 목, 머리, 심장 등은 조건 충족 가능.
* 최대 체력이 지나치게 높은 대형 생명체나 거대 개체의 치명부위는 조건을 만족하지 못할 수 있다.

모든 조건이 충족되면 성공 확률을 따로 굴리지 않는다.

사용 가능 = 성공.
조건 불충족 = 기술 지정 불가.

실행 시 두 방식 중 선택 가능.

즉살:

* 접근 후 지정 당시 선택한 치명부위를 확정 파괴하고 즉시 사망 처리한다. 도착 시 후방과 방호 등 조건을 다시 확인한다.

제압:

* 대상을 넘어뜨리거나 제압.
* 무장 해제.
* 일정 시간 행동불능.
* 이후 체포나 구속으로 연결 가능.

테이크다운은 체력 손실량을 보고 약해진 적을 마무리하는 기술이 아니라, 대상의 체격·구조와 치명부위의 내구도가 사용자의 공격으로 즉시 처리 가능한 수준인지를 판단하는 기술이다.

# 전체 역할 요약

* 조준: 예상 방향에 대한 빠른 대응.
* 급작 사격: 눈앞의 돌발 위협 즉응.
* 정확한 사격: 특정 신체부위 선택.
* 강타: 근접한 적과 사격거리 재확보.
* 기동: 이동 중 다른 사격기술의 페널티 방식 결정.
* 기동사격: 이동과 사격을 동시에 수행.
* 고속 기동: 빠르게 위치를 바꾸면서 적의 명중률을 떨어뜨림.
* 다중 목표 사격 / 사격 우선: 여러 표적에 한 발씩 번갈아 화력 분산.
* 다중 목표 사격 / 제압 우선: 한 표적을 쓰러뜨릴 때까지 집중한 뒤 다음 표적으로 전환.
* 선제 사격: 예상 통로에 미리 사격 준비.
* 근거리 저격 / 협동 조준: 2인 협동 고정밀 사격.
* 사살: 극근거리 연속 사격을 통한 신속한 확정 살상.
* 테이크다운: 조건을 만족한 비경계 표적의 확정 즉살 또는 제압.

새로운 스킬을 추가하거나 기존 스킬을 조정할 때는 각 스킬의 역할이 중복되지 않는지, 일반 사격을 완전히 대체하지 않는지, 그리고 확률 대신 플레이어의 위치 선정과 행동 선택으로 결과를 통제할 수 있는지를 우선 평가한다.
