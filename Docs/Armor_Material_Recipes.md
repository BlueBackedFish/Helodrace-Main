# 섬유 색상 마스크와 방탄 장비 제작 재료

2026-11-04. 나일론·아라미드 그림과 방탄 장비 제작 재료의 후속 연결이다. [항목별 이전/현재 재료와 유지한 기본 수치](Data/ArmorMaterials/recipe-materials.json).

## 천 그래픽

두 재료는 Core의 `Things/Item/Resource/Cloth` 스택 이미지를 직접 사용한다. `CutoutComplex`와 `_MaskTex` 텍스처 매개변수로 전용 2x2 빨강 마스크 `Items/SyntheticFibers/ClothTintMask`를 적용하고, 나일론은 `(215,220,215)`, 아라미드는 `(203,174,76)`로 색칠한다. 원본 천의 접힘과 검은 외곽선·투명 영역은 원본 이미지가 담당한다. 마스크는 이 두 재료의 셰이더에만 지정한다.

현재 1.7 `Graphic_Collection.Init`은 스택 하위 그래픽을 만들 때 요청의 `maskPath`를 그대로 전달하지 않는다. 대신 하위 그래픽에도 전달되는 `shaderParameters`를 사용했다. 원본 게임 이미지를 재배포하거나 Core 텍스처 경로를 덮어쓰지 않는다. 이전 자체 롤 PNG 4장·섬유 Blender 원본 2개와 생성 분기는 제거했다. 방사 모듈의 3D 원본·그림은 계속 사용한다.

세라믹 판의 기존 플라스틸 수량을 알루미나 타격면으로, 기존 강철 수량을 아라미드 백킹으로 바꾸고 소량의 나일론 외피를 추가했다. 여기서 새 재료 배정은 게임 제작 공정 설정이며 실제 모든 제조사 제품의 세부 조성을 확정한 것은 아니다.

알루미나 적용 기준은 현재 게임의 `CompProperties_ArmorPlateSet.material`이다. RAMPART는 개발 메모에 따른 현재 UHMWPE 분류와 핵심 재료를 유지하고 나일론 외피만 추가한다. 실제품 참고 자료의 세라믹/Spectra 설명과 현재 게임용 단순화 분류는 구분한다. [기존 소재 참고와 방어 규칙](Ballistic_Reference_Notes.md).

고정 재료에서 자동 생성되는 제작법의 기본 허용 필터를 함께 보완했다. 작업량·가격·질량·방호 수치·판 내구도·게임 소재 판정은 기존 값을 유지한다.

## 검증

실제 RimWorld 1.7.4995 rev309 `.codex-staging/ArmorMaterials/native-03`: **108 PASS, COMPLETE, FAIL 없음**. [검사 원문](Data/ArmorMaterials/native-checks.txt), [버전·동일 배포 DLL 해시](Data/ArmorMaterials/verification.json).

각 섬유의 1/75/150개 스택에서 실제 Material의 mainTexture가 바닐라 Cloth 하위 그래픽과 같은 텍스처인지, `_MaskTex`가 전용 마스크인지, 실제 색상이 정의된 섬유 색상과 같은지 확인했다. 19종 장비의 자동 생성된 제작법과 기본 허용 필터를 실제 엔진에서 대조했다. 실제 전력망·작업 제공자·제작 작업으로 M1952A, IBTV 본체, 어깨 보호대, 탄창 파우치, SAPI, RAMPART를 만들어 정확한 재료 소비와 물품 산출을 확인했다. 네 세라믹 계열과 RAMPART의 기존 게임 소재 판정도 유지됐다.

별도 검증: 19종 재료표와 변경 전 기본 수치 보존, 기존 탄도 방호 128개, 레시피 연결 93개·ThingDef 544개, 중간재 가격 27종, 모듈 아트/천 마스크 검사 통과. 배포 DLL/PDB는 위 호스트와 동일하다. 장기 밸런스나 자연 피격 확률을 새로 측정한 것으로 세지 않는다.

초기 실행은 임시 텍스처 캐시가 디스크를 채워 검사 시작 전에 종료됐다. 해당 대화의 이전 격리 검사에서 생성한 TextureCache만 경로·일반 폴더 여부를 확인해 정리했으며 로그·저장·검증 자료는 보존했다. 최종 실행의 ERROR는 기존 Workshop 항목 3781143823 폴더 부재 1건뿐이다.
