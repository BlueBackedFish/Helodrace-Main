# 조합법-작업대 배치표

이 문서는 2차 3단계 이후의 공정 배치 기준표다. `Source/Verify-RecipePlacement.ps1`가 작업대 배치, 7개 공통 부품군의 단품·5개·10개 규격과 연구·재료·진행 보존을 검사한다.

## 핵심 공정

| 시대 | 공정 | 제품군/조합법 | 작업대 |
|---|---|---|---|
| 서부 | 수동·동력 선삭 | 축(기본·5개·10개) | `HD_TreadleLathe`, `HD_LineShaftTurretLathe` |
| 서부 | 밀링 | 범용 기계 부품(기본·5개·10개) | `HD_LineShaftMillingMachine` |
| 서부 | 유압 프레스 | 프레스 부품(기본·5개·10개) | `HD_LineShaftHydraulicPress` |
| 서부 | 압연 | 균일 압연 강판(기본·5개·10개) | `HD_LineShaftRollingMachine` |
| 서부 | 전기·전자 조립 | 기초 전기 부품·기초 전자 부품(기본·5개·10개) | `HD_BasicWorkbench` |

## 배치 원칙

- 기본·대량 조합법은 같은 제품군이면 `recipeUsers`와 연구 선행 조건이 같아야 한다.
- 성형 부품은 프레스, 압연 강판은 압연기, 밀링 부품은 밀링 머신에 둔다. M1 철모와 방탄 장구는 의류 작업대에서 연결된 프레스를 사용한다.
- 축은 수동·동력 선반을 모두 허용한다. 범용 기계 부품의 정규 공정은 밀링으로 통합하고 더 비싼 중복 선삭 조합법은 제거한다. 선반과 밀링 머신은 총기 조립의 연결 시설 역할도 유지한다.
- 공통 부품은 1·5·10개 규격을 쓴다. 재료 할인은 없고, 5개는 단품 4.5개분의 작업(개당 10% 절감), 10개는 단품 8개분의 작업(개당 20% 절감)이다. 모두 미완성 산업 배치로 진행량을 보존한다.
- 주철·탄소강의 소·중·대 배치는 고로에서 미완성 제련 배치를 사용해 진행량을 보존한다. 전로는 탄소강을 해금하는 연결 시설이며, 연료가 없는 별도 제작 작업대로 사용하지 않는다.
- `HD_BasicWorkbench`는 최종 조립 및 저기술 대체 공정에 사용한다. 전용 기계 공정을 가진 기본·대량 파생 조합법을 이 작업대에 따로 흩어 놓지 않는다.

## 검증

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File Source\Verify-RecipePlacement.ps1
```

검사는 다음을 실패로 처리한다.

- 중복 `ThingDef` 또는 `RecipeDef`
- `recipeUsers`가 없는 고립된 `RecipeDef`
- 존재하지 않거나 작업대가 아닌 헤로드 `recipeUsers`
- 같은 제품군의 기본·5개·10개 조합법 간 작업대 또는 연구 조건 불일치
- 위 표의 핵심 공정 매핑 변경
- M1 철모가 유압 프레스가 아닌 곳에 배치됨

## 2026-11-05 전용 작업대·필요 설비

[이동 범위와 동작 검증](Equipment_Worktables.md). 무기 62개와 방어구/부속 27개, 총 89개 실제 제작법을 정리했다. 기존 기초 작업대의 59개 대상 제작법은 병행 유지한다. 프레스는 M1 철모의 직접 제작대에서 연결 설비로 역할을 옮겼으며 원래 부품 성형 기능도 유지한다.
