# 총기 모딩 화면 조작과 그룹 정의

- 휠 또는 `−` / `+`: 커서 위치를 기준으로 25~800% 확대·축소. 버튼은 화면 중앙 기준.
- 총기 화면 안에서 왼쪽 버튼 드래그: 위치 이동. 짧게 클릭하면 파츠·레일을 선택하며 드래그를 마칠 때는 선택하지 않는다. 박스·슬라이더 등 조작부에서는 화면 이동을 시작하지 않고, 이동 중에는 화면 밖까지 포인터를 따라간다. `화면 초기화`: 현재 그룹에 맞는 100% 배율과 중앙 위치 복원.
- `보기`: 전체 조립체, 주 무기, 조준기 전체, 개별 조준기 그룹, 부착 무기 중 선택.
- 그룹을 선택하면 미리보기에는 해당 파츠만 표시하고 트리에는 상위 연결 경로를 흐리게 남긴다. 상위 파츠를 선택하면 전체 보기로 돌아간다.
- 트리의 파츠 이미지에 마우스를 올리면 확대 미리보기, 클릭하면 별도 이미지 창. 별도 파츠 이미지 창은 휠·가운데 버튼 드래그를 지원한다.
- 하단 파츠 목록은 높이 206, 타일 148×122로 압축하고 그룹 버튼도 줄인다. 타일 이미지는 공용 아이콘 대신 외곽선·추가 그래픽을 포함한 실제 파츠 경계를 사용해 넓은 이미지 영역 중앙에 맞춘다.
- 작업대의 총기 선택창은 개별 무기의 `ModularWeaponIconCache` 이미지를 사용한다. 현재 모딩 상태를 넓은 미리보기로 확인하고 소유자·총기 이름과 함께 선택한다. 캐시 이미지의 투명 여백을 제외해 중앙에 맞추고 화면에 보이는 행만 이미지 생성을 요청한다.
- 개별 파츠는 하위 파츠 없이 생성한다. `defaultAttachments` 정의와 자동 생성·복구 코드는 제거했으며, 총기의 초기 모딩은 루트의 `spawnPreset`에 명시된 트리만 사용한다. 필수/기능 파츠 누락 판정은 소켓의 `expectedPart`로 보존하며 이 필드는 파츠를 생성하지 않는다. MP5·M249를 포함한 모든 총기는 완전한 초기 프리셋을 가진다.
- 파츠 교체 시 같은 ID의 소켓으로 기존 하위 파츠와 그 하위 구성을 옮긴다. 총열 교체도 호환 머즐을 유지한다. 기존 레일 위치를 우선 사용하고 필요하면 빈 구간을 찾되, 한 레일의 묶음을 전부 옮길 수 없으면 해당 묶음 전체를 분리한다. 호환되지 않는 파츠는 작업대 부품 상자로 반환한다. 선택한 레일 파츠와 하나만 달리는 레일 파츠는 직접 교체할 수 있다.
- 파츠 이미지는 본체, `_Outline`, `additionalGraphics`를 합친 경계로 맞춘다. 테두리 파일이 없는 레이어는 검은 실루엣 테두리를 그린다. 원본 텍스처는 수정하지 않는다.
- 조립체 파츠는 불투명하게 표시하며 모든 파츠의 외곽선을 본체보다 먼저 그린다. 선택한 파츠는 본체만 맨 앞에 그리고 연노란 선택 색상 마스크를 적용한다. 트리·총기 화면·소켓 박스에서 호버한 파츠 본체에는 하늘색 마스크를 적용한다. 선택해도 외곽선의 그리기 순서는 바뀌지 않으며, 다른 파츠에 마우스를 올려도 선택 본체는 맨 앞에 유지한다.
- 오른쪽은 총기 전체의 최종 환산 스탯 바다. 인체공학·반동 제어 등의 중간 지표 대신 실제 무기 인스턴스의 무게, 조준 시간 배율, 재사용 대기시간, 발사속도·간격을 표시한다. 바닐라는 거리별 명중률, CE는 반동·탄퍼짐·흔들림 계수·조준 효율·부피를 표시하며 StatDef의 단위와 표시 형식을 사용한다. 식별 거리는 칸 단위로 표시한다. 교체 전후 값 사이를 실제 시간 기준 감쇠 이징으로 움직이고, 연속 교체 시 현재 값과 속도를 이어받는다. 바와 숫자가 함께 움직이며 변화 방향과 색상, 목표값 눈금으로 변경을 보여준다. 가스 유량과 추가 수치는 스크롤 아래에 있다.
- 고정 소켓과 하나만 달리는 레일은 소켓 이름·파츠 이름·작은 이미지가 있는 기존 가로 박스를 사용한다. 작은 이미지를 누르면 하위 소켓을 편집하고, 박스 본문은 교체 대상을 선택한다. 피카티니 등 다중 레일만 정사각형 이미지 박스를 사용하며 클릭은 선택/화면 이동, 더블클릭은 하위 소켓 편집이다. 각 소켓의 위치를 기준으로 총기 본체와 다른 박스를 피해 주변에 분산 배치하며, 공간이 부족하면 페이지를 나눈다. 배치를 캐시해 호버·화면 이동·확대 때 재배열하지 않으며 박스는 총기를 따라 움직인다. 화면 밖으로 간 박스는 미리보기 경계에서 잘리며 화면 가장자리에 고정되지 않는다.
- 스탯 패널의 `표시: 환산 스탯` 버튼을 누르면 `표시: 원시 스탯`으로 전환하고, 다시 누르면 돌아온다. 기본은 환산 스탯이며 원시 보기에는 인체공학·반동 제어·총구 제어·관성 취급·표적 획득·조준 정밀도·작동 신뢰성·가스 효율 등 기존 성능 지표를 표시한다. 전환 시 스크롤과 이징 상태를 초기화해 서로 다른 표현 간의 가짜 변화가 나타나지 않게 한다. 두 보기 모두 파츠 교체 시 이징을 적용한다.
- 레일은 실제 장착 구간을 강조한다. 다중 레일을 누르면 누른 위치를 장착 후보로 지정하고 아래 호환 목록에서 파츠를 고른다. 위치 슬라이더는 부모 레일 양 끝의 화면 좌표로 길이·방향을 맞추고 레일 위에 표시한다. 별도 너비 제한이나 추가 줌 배율은 없으며 두께는 16픽셀이다. 배경·제목·값 표시 없이 슬라이더만 그리며 값은 툴팁에 표시한다. 위치 조절 중에는 카메라를 자동 재맞춤하지 않아 부모 레일이 밀리지 않으며 `화면 초기화`로 현재 전체 경계를 다시 맞출 수 있다. 개머리판처럼 `maxAttachments=1`인 레일은 기존 이름 박스를 사용하고 별도 추가 박스는 만들지 않는다. `×`는 파츠를 제거해 작업대의 부품 상자로 돌려보낸다.
- 다중 레일의 추가 모드에서는 가득 차면 기존 파츠를 자동으로 빼지 않는다. 해당 파츠의 박스를 선택하면 그 파츠만 교체한다. 하나만 달리는 레일과 단일 소켓은 바로 교체한다.

조준기 그룹은 기존 광축 판정의 실제 멤버를 사용한다. 가늠쇠·가늠자, 확대경, 비활성 조준기와 광축별 구분을 유지하며 조준기 자체에 달린 하위 파츠도 포함한다. 서로 다른 무기에 속한 조준기는 광축 높이가 같아도 보기 그룹을 나눈다.

독립적으로 보고 싶은 부착 무기의 `CompProperties_ModularWeaponNode`에 다음 값을 지정한다.

```xml
<isWeaponSubassembly>true</isWeaponSubassembly>
```

그 파츠와 하위 파츠가 별도 무기 그룹에 속한다. 더 아래에 다른 무기 그룹이 시작되면 해당 부분은 다시 독립한다. M203A2 본체에 적용했으므로 총열·트리거와 함께 `부착 무기` 메뉴에 나타난다. 이 표시는 모딩 화면의 그룹 소속을 정하며 발사·탄약 로직은 바꾸지 않는다.

검증:

```powershell
dotnet build Source/Helodrace/Helodrace.csproj --no-restore -p:IntermediateOutputPath=obj/ModularWeaponNavigation/ -v minimal
dotnet run --project Source/Tests/ModularWeaponNavigation/ModularWeaponNavigation.Tests.csproj
python Source/Tests/ModularWeaponDefinitions/verify_definitions.py
```

자동 검증은 트리 탐색·그룹 소속·카메라 좌표·이미지 경계·이징 속도 연속성·박스 배치/페이지·회전된 레일의 클릭 좌표를 다룬다. 게임 내에서는 M203A2와 조준기가 달린 총기로 그룹 전환, 확대 후 소켓/레일 선택, 박스 추가·제거·위치 조절, 일시정지 중 연속 교체의 스탯 변화, 창 크기 변경을 확인한다.
