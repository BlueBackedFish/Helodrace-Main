  - 확인: 무동력, 정상 동력, 작업 중 동력 차단, 저장 후 불러오기.

- [x] **M-02. 시나리오 연구 비용 배율과 즉시 완료 기능 호환** `[버그/구현 완료]`
  - `ResearchProjectDef.Cost` 후처리로 늘린 비용과 `ResearchManager`의 저장 진행량/완료 판정이 충돌하는지 확인한다.
  - 개발자 모드 즉시 완료와 연구 완료 아이템을 사용했을 때 진행량이 기존 최대치로 되돌아가며 완료되지 않는 현상을 수정한다.
  - 배율 계산은 UI 표시, 정상 연구, 즉시 완료, 외부 모드의 연구량 주입에서 같은 기준을 사용해야 한다.
  - 확인: 새 게임, 기존 저장, 정상 연구 완료, 개발자 즉시 완료, 연구량 지급 아이템.
  - 구현: 명시적인 연구 완료 호출 뒤 저장 진행량을 시나리오 배율이 적용된 `Cost`까지 보정한다. 전체 연구 완료 개발자 기능도 같은 처리를 사용한다.

- [ ] **M-03. 장기 플레이 후 남는 모드 전역 틱 지연 수정** `[성능 버그/수정 적용·장기 재검증 필요]`
  - 2년차 테스트 결과 시추기 자체의 틱 비용이 아니라, 맵의 모든 요소를 지운 뒤에도 저장에 남는 모드 전역 지연으로 범위를 수정했다.
  - 유전 맵 컴포넌트의 상시 틱을 제거하고 유전 레코드는 조회·저장 시에만 정리하도록 변경했다.
  - 파괴가 아닌 디스폰 경로에서도 기계망 노드를 해제하고, 장기 저장에 남아 있는 무효 노드를 주기적으로 제거한다.
  - 모듈러 무기 애니메이션의 만료 상태를 개수와 관계없이 정리하고, 매 틱 발생하던 임시 리스트 할당을 제거했다. 별도 `DoSingleTick` 패치도 기존 스케줄러와 통합했다.
  - 모든 아이템의 시장가 조회에 걸리던 패치는 비대상 Def를 게임 컴포넌트 조회 전에 상수 시간으로 거르도록 변경했다.
  - 완료 조건: 문제가 발생한 2년차 저장에서 수정 전후 RimDoctor 결과를 비교하고, 맵 요소 삭제 후에도 남던 지연이 사라졌는지 확인한다.
  - 추가 확인: 새 게임, 기존 2년차 저장, 기계 건물 설치·철거·재설치, 모듈러 무기 반복 사격, 저장·불러오기.

- [x] **F-01. `dead`·`cry` 선형 눈꺼풀 아래 눈동자 숨김** `[렌더링 버그/재검증]`
  - `dead`는 현재 `DeadLidPatch.cs`에서 눈동자 레이어를 숨기는 코드가 들어가 있으므로 먼저 실제 사망 상태를 재검증한다.
  - `cry`는 선으로 표현된 눈꺼풀 텍스처를 사용할 때도 눈동자가 비치므로 `disableEyeball` 적용 또는 상태별 가시성 제어를 추가한다.
  - Facial Animation 본체에 해당 ShapeDef가 이미 있을 때도 패치가 빠지지 않도록 `nomatch` 전용 추가가 아닌 기존 Def 보정 경로를 확인한다.
  - 확인: 사망, 높은 고통, 치명적 고통, 표정 전환 직후, 저장·불러오기.

- [x] **F-02. 높은 고통 표정의 `tight` 입 모양 교체** `[표정 매핑 오류]`
  - `HD_FA_HelodPainHigh`에서 `tight`를 제거하고 `down` 또는 `sad` 중 실제 텍스처에 맞는 모양으로 교체한다.
  - 높은 고통과 치명적 고통이 자연스럽게 이어지되 서로 구분되는지 확인한다.
