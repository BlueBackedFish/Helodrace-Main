# 모듈러 총기 플래시라이트 이식 현황

- 갱신일: 2026-08-26
- 대상 파츠: `HD_ModularPart_Light_BrightStrikeM600`
- 구현 상태: 코드·Def·편집기·설치본 반영 완료, 실제 게임 화면 QA 대기

## 동작

- 총기를 든 폰이 유효한 목표를 조준하는 동안만 플래시라이트가 켜진다.
- 조준선에는 근거리 폭과 원거리 폭이 다른 사다리꼴 빔을 표시한다.
- 목표 지점에는 거리와 무관한 원형 광원 풀을 표시한다.
- 가까운 목표에서는 빔 끝과 광원 풀이 자동 축소되어 뭉개짐을 줄인다.
- 최대 조사 거리 밖에서는 빔과 눈부심 효과를 모두 적용하지 않는다.
- M600이 트리 안의 어느 레일로 이동해도 파츠 변환을 따라 발광점이 이동한다.
- 상하 반전 파츠에도 같은 계층 변환을 사용하므로 발광점이 함께 반전된다.
- 렌더 콜백 대신 `MapComponentUpdate`에서 매 프레임 그려 줌 단계 변경 시 빔이 사라지는 현상을 방지한다.

## 대상 효과

- 조준 대상이 폰이면 `HD_WeaponFlashlightDazzle`을 매 틱 등록한다.
- 여러 플래시라이트가 같은 대상을 비추면 강도가 합산된다.
- 조사에서 벗어나면 3틱 유예 뒤 빠르게 사라진다.
- 기본 M600 설정은 메카노이드에는 적용하지 않고 동물과 일반 폰에는 적용한다.

## 편집기

- 개발자용 attachment editor에 `Light` 탭을 추가했다.
- 발광점 X/Z, 빔 시작 폭, 빔 끝 폭, 광원 풀 반경, 최대 거리, 길이 오버슈트를 실시간 조절할 수 있다.
- 미리보기에는 발광점과 빔 외곽선을 표시한다.
- 편집 내용은 실행 취소와 XML 복사/파일 저장에 포함된다.

## 검증

- Release 빌드: 경고 0, 오류 0
- 관련 XML 2개 구문 검사: 통과
- 작업 폴더와 RimWorld 설치 모드 폴더의 DLL/PDB/Def SHA-256 비교: 모두 일치

- 동서 방향 반전과 조준 반동 중 빔 시작점 추적 확인
- 카메라 줌 단계별 빔 유지 확인
- 24칸 이내/밖 경계와 근접 목표 광원 크기 확인
- 사람·동물·메카노이드 대상 눈부심 적용 규칙 확인
