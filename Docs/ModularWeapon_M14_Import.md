# M14 대기 텍스처 적용

- Waiting의 본체/파츠 18종과 Outline 18개를 Actions, Barrels, GasSystems, Magazines, MuzzleDevices, Receivers, Stocks로 이동했다. 원본 픽셀은 변경하지 않았다.
- ModularWeapons_M14_Development.xml에 M14 본체, 교체 파츠 17개, 7.62 M80 탄종 선택 파츠를 등록했다.
- 총몸은 총열, 볼트, 작동봉, 트리거 그룹, 개머리판, 탄창을 받는다. 총열은 총구 장치와 가스계를, 트리거 그룹은 트리거를, 탄창은 탄종 선택 파츠를 받는다.
- 16인치 SOCOM 총열에는 전용 총구/가스계 태그를 사용한다. SOCOM 나사 어댑터는 일반 M14 총구 장치 소켓을 제공한다.
- 기본 프리셋: 22인치 총열, 목재 개머리판, 20발 탄창. 디버그 메뉴: Spawn modular M14 development rifle.
- 볼트와 작동봉 이동, 트리거 회전은 초기 애니메이션 값이다. 소켓 위치, 총열 변형별 정렬, 가늠쇠 높이, 성능 수치는 게임 내 최종 보정이 필요하다.
- 탄종은 기존 HD_Bullet_M60E3_Proj(7.62 NATO)를 사용한다. 전용 탄약 그림이 없어 5.56 아이템 그림을 임시 공유한다. 전용 탄피/급탄 그림 및 CE 전용 패치는 이번 등록에 포함하지 않았다.
- XML 파싱, 기본 부착물의 소켓 태그 호환, 텍스처 존재 검사 및 빌드 통과. 게임 내 렌더링은 별도 확인 필요.

## 스프라이트 부착점 초안

- 1024px 캔버스의 그림 위치를 기준으로 x=(pixelX-512)/1024, z=(512-pixelY)/1024로 좌표를 지정했다.
- 총몸의 총열 소켓은 (527,528)px, 22인치 총열 자체 부착점은 (323,528)px로 잡아 캔버스 차이를 보정했다. 18/16인치 총열 부착점은 (527,528)px다.
- 볼트, 작동봉, 트리거 그룹, 개머리판, 탄창 및 각 총열의 가스계/총구 소켓을 그림 위로 배치했다. 트리거 그림은 그룹의 가드 쪽으로 이동하도록 별도 부착점을 지정했다.
- 일반형/SEI/SOCOM 총구 장치와 SOCOM 어댑터의 출구 소켓도 각 그림 위치에 맞췄다. 모든 원점 임시 소켓을 대체했으며 XML과 기본 연결 참조 검사를 통과했다.
- 일부 원본 PNG에 흰 가이드 선이 보인다. 이번에는 PNG를 수정하지 않았으므로 게임에서도 보일 수 있다. 최종 미세 정렬은 내장 편집기에서 확인한다.
