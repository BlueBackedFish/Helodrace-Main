# 금융 우호도

- 금융 우호도는 팩션별로 저장하며 범위는 -100~100이다. 일반 우호도와는 별도 수치다.
- 상단 거래의 선물, 정착지에 방문한 여행 상단의 선물, 운송 포드 선물은 일반 우호도 대신 금융 우호도를 올린다. 선물 가치는 바닐라 계산을 따르되 감소율과 상한 판정에는 금융 우호도를 사용한다.
- 금융 우호도는 일반 우호도의 자연 기준점에 더해진다. 예를 들어 원래 기준점 0에 금융 우호도 20이면 기준점은 20이다. 팩션 화면의 자연 우호도 설명에도 해당 항목이 표시된다.
- 금융 우호도가 양수인 팩션은 일반 우호도가 기준점보다 낮을 때 하루에 1점씩 회복한다. 첫 회복은 최초 선물로부터 하루 뒤이며 추가 선물은 회복 일정을 미루지 않는다. 일반 우호도는 팩션의 최대 우호도를 넘지 않는다.
- 회복 시각도 저장한다. 로드 직후 즉시 회복하거나 밀린 일수를 한 번에 지급하지 않는다.
- 영구 적대, 멸망, 임시 팩션과 우호도가 없는 팩션은 금융 우호도에 의한 자동 회복 대상에서 제외한다. 퀘스트 등 바닐라 우호도 변경 제한도 유지된다.
- 선물 이외의 일반 우호도 증감(상단 요청 비용, 공격, 퀘스트 보상 등)은 기존 처리를 유지한다.
- 금융 우호도는 아직 가격, 결제 또는 계약 조건에 사용하지 않는다.

검증: `TelegraphNetwork.Tests`의 저장·회복 검증과 `Verify-FinancialGiftHooks.ps1`의 설치된 게임 대상 Harmony 패치 검증. 게임 내 UI와 실제 선물 전달은 별도 플레이 확인 대상이다.
