# Gameplay Node Inventory

이 목록은 플레이어가 선택·사용·획득·소비하거나, 다른 플레이 요소의 조건·결과가 되는 항목을 노드 후보로 정리한 것이다. `구현`은 현재 정의나 동작 코드가 있는 항목, `부분`은 플레이어 경험의 일부만 구현된 항목, `기획`은 자료에 명시된 구상이다. 같은 항목이 여러 절에 보이면 상위 시스템과 그 시스템에 속하는 구체적 콘텐츠·행동·상태의 관계를 표시한 것이며, 각각 별도 시스템이라는 뜻은 아니다. 내부 판정식, 개발자 도구, 시각 효과용 정의는 제외했다.

주요 근거: [플레이테스트](헤로드%20테스트%201차.md), [전진기지 계약](ForwardBase_Contract_System.md), [헬기 지원](ForwardBase_Helicopter_Support.md), [전술 사격](TacticalMovement.md), [TCCC](TCCCSkills_Implementation.md), [분대 구현](SquadSystem_Implementation.md), [방탄 메모](Ballistic_Reference_Notes.md), [생산 공정](Recipe_Worktable_Mapping.md), [모듈 총기 현황](ModularWeapon_Development_Status.md), `Defs`의 콘텐츠·연구·시나리오 정의. 개별 자료의 구상과 구현 상태가 충돌하면 구현 현황을 우선했다.

# 1. 핵심 시스템

## 헬로드 종족·제노타입 [구현/부분]

- 유형: 종족 / 병력 구성
- 간단 설명: 헬로드 종족과 제노타입의 고유 유전 특성이 전투·내정 인력의 역할을 바꾼다. 다섯 제노타입은 정의되어 있으나 기획 메모의 모든 특화 능력이 구현되었다고 보기는 어렵다.
- 주요 하위 요소: 매켄지 계곡·텍사스·북극·동부·멕시코 헬로드, 사격 특성, 결속·사회성 특성, 체격·기후 적응.
- 관련 플레이 영역: 시작 인원 선택, 인력 배치, 전투, 내정.

## BTX 생리·의존 [구현]

- 유형: 종족 / 생존 자원 / 상태
- 간단 설명: 헬로드의 유전적 BTX 의존을 나프타·방향족 기초유·개껌 공급으로 관리한다. 공급 지연은 결핍과 의식 저하로 이어지며, 비헬로드가 BTX를 섭취하면 독성 위험이 있다.
- 주요 하위 요소: BTX 욕구·의존, 나프타, 방향족 기초유, 개껌, BTX 안정화·결핍·독성.
- 관련 플레이 영역: 생존, 석유 정제, 의료, 자원 비축.

## 연구·기술 시대 [구현]

- 유형: 장기 진행 / 해금
- 간단 설명: 서부 개척에서 대전기·냉전기·현대·미래 장비로 넘어가는 연구망이다. 산업 공정, 전력, 통신, 무기와 방호 장비의 사용 가능 여부를 바꾼다.
- 주요 하위 요소: 시대별 연구, 선행 연구, 산업 연구, 군사 연구, 전신·무선, 연계 연구, 시나리오의 연구 비용 조건.
- 관련 플레이 영역: 장기 계획, 산업, 전투 장비, 전진기지·시장 접근.

## 산업·제작 [구현]

- 유형: 생산 / 시설
- 간단 설명: 원료를 중간재로 가공한 뒤 무기·장비·탄약을 제작한다. 선삭·밀링·프레스·압연·제강·화학 합성은 서로 다른 시설과 연구를 요구한다.
- 주요 하위 요소: 수동·동력 선삭, 밀링, 프레스, 압연, 제강, 화학 합성, 최종 조립, 의류·총기 작업대.
- 관련 플레이 영역: 자원 확보, 시설 배치, 전력·동력, 군수 생산.

## 유전 개발·석유 정제 [구현]

- 유형: 채굴 / 정제 / 생존 자원
- 간단 설명: 시추기로 유전을 개발하고 펌프잭으로 원유를 뽑아 연료와 나프타 등으로 분별한다. 디젤 발전과 BTX 공급이 같은 원유 생산량을 놓고 경쟁한다.
- 주요 하위 요소: 유전 개발·유지보수, 시추기·펌프잭, 중질·고품질 원유, 증류탑·배치 증류기, 디젤·등유·나프타·화학연료.
- 관련 플레이 영역: 산업 확장, 발전, BTX, 시장 거래.

## 기계 동력·전력 [구현]

- 유형: 에너지 / 시설 운용
- 간단 설명: 증기기관·디젤 엔진의 동력을 라인샤프트 설비에 전달하고 발전기로 전력을 만든다. 연료·시설 연결·공급 부족은 생산과 냉난방에 영향을 준다.
- 주요 하위 요소: 소형·대형 증기기관, 산업용 디젤 엔진, 라인샤프트, 발전기, 전기 모터, 열펌프, 전력.
- 관련 플레이 영역: 생산, 기지 운영, 연료 수급, 방어 시설.

## 금융시장·원격 거래 [구현]

- 유형: 경제 / 자원 조달
- 간단 설명: 전신기와 금융망을 통해 금·석유·연료·채권·스탈레르를 시세에 따라 매매한다. 신용 한도, 매수·매도 차이, 정산 지연이 거래 선택을 만든다.
- 주요 하위 요소: 스탈레르, 금, 은 기준, 석유 지수, 시세 조회, 매수·매도, 신용 한도, 거래 정산, 채권.
- 관련 플레이 영역: 자원 조달, 산업 수익, 계약 비용.

## 전진기지 계약 [구현]

- 유형: 월드맵 / 군사 계약 / 비용
- 간단 설명: 협력 팩션과 PB·FB·COP·FOB 중 하나를 건설하고 선택한 서비스를 계약 기간 동안 사용한다. FFP는 기간별 사용 횟수를 선구매하고, 비용 상환은 사용한 만큼 나중에 정산한다.
- 주요 하위 요소: 협력 팩션, 기지 종류·위치, 건설·계약 기간, FFP·비용 상환, 군사 신용, 서비스별 사용 재고, 지원 범위, 기지 철수.
- 관련 플레이 영역: 외교 관계, 방어, 공격 지원, 보급, 스탈레르 지출.

## 전진기지 군사·군수 지원 [구현]

- 유형: 외부 지원 / 전투·보급
- 간단 설명: 계약한 전진기지의 병력·화력·보급 서비스를 전신 또는 무전으로 호출한다. 서비스마다 사거리, 사용 재고, 탄약·항공기 운용 제한이 다르다.
- 주요 하위 요소: 보병 파견, 저격·박격포 지원, 105/155mm 포병, W48, CAS, 헬기 QRF·MEDEVAC, 식량·의약품·무기 보급.
- 관련 플레이 영역: 전술 선택, 위기 대응, 군수, 계약 관리.

## 전술 사격·CQB [구현]

- 유형: 전투 / 플레이어 명령
- 간단 설명: 폰의 위치·시야·방향·자세·표적을 이용해 근접전과 이동 사격을 수행한다. 훈련 자격이 사용 가능 여부를 결정하며, 기술마다 다른 상황과 비용이 있다.
- 주요 하위 요소: 조준, 급작 사격, 부위 지정 사격, 강타, 기동 패시브, 기동사격, 고속 기동, 다중 목표 사격, 선제 사격, 협동 조준, 신속 사살, 테이크다운.
- 관련 플레이 영역: 야전, 실내전, 방어선, 병력 훈련.

## 명사수 대체 사격 [구현/부분]

- 유형: 종족 특성 / 무기별 사격 선택
- 간단 설명: 명사수 유전자가 있는 폰이 일부 총기의 일반 사격과 대체 사격 모드를 전환한다. 리볼버 패닝, 속사, 정밀 조준, 기관총의 지속 사격처럼 무기에 따라 역할이 달라진다. Combat Extended용 동작은 별도 연동·검증 범위가 남아 있다.
- 주요 하위 요소: 명사수 유전자, 일반·대체 사격 모드, 패닝, 더블탭, 저격, 지속 제압 사격.
- 관련 플레이 영역: 종족 특성, 무기 선택, 야전 전투.

## 브리칭·돌입 [구현/부분]

- 유형: 전투 / 장애물 처리
- 간단 설명: 문과 벽을 절단기 또는 설치형 C-4로 열어 진입로를 만든다. 폭약과 절단기는 준비 시간·자원 소비·돌입 후 위험이 달라 독립된 전술 선택이다.
- 주요 하위 요소: C-4 설치, 도화선·쇼크튜브 기폭, 동력 절단기, 돌입 경로, 돌입 후 제압.
- 관련 플레이 영역: CQB, 정착지 공격, 방어선 우회.

## 방탄·모듈형 장구 [구현]

- 유형: 전투 / 장비 구성 / 방호
- 간단 설명: 연질 방탄재, 전·후면 및 측면 플레이트, 방패와 헬멧 부품이 탄환 관통과 생존성을 바꾼다. 방탄판의 소재·등급·내구도와 보호 범위를 고려해 방호·무게·기동성을 선택한다.
- 주요 하위 요소: 방호 등급, 연질 방호, SAPI 계열 플레이트, 플레이트 내구도, 전·후·측면 방호, 방패, 바이저, 의류 작업대에서의 부품 교체.
- 관련 플레이 영역: 장비 생산, 전투 준비, 생존, 기동.

## 모듈형 총기 [부분]

- 유형: 무기 구성 / 장비 선택
- 간단 설명: 총몸·총열·작동부·탄창·조준기·총구장치 등을 조합하는 무기 체계다. 개발용 조립체와 일부 전투 연동은 존재하지만 플레이어의 완전한 실물 파츠 교환·능력치 연동은 개발 중이다.
- 주요 하위 요소: 총기 본체, 필수 작동 부품, 탄창, 조준기, 레이저·손전등, 소음기·총구장치, 조립 프리셋.
- 관련 플레이 영역: 전투 장비, 제작, 전술 역할.

## 전술 응급처치(TCCC) [구현]

- 유형: 의료 / 전장 구조
- 간단 설명: 전투 중 출혈과 고통을 억제하고 부상자를 안전한 곳으로 옮긴다. 현장 처치와 MEDEVAC 요청의 선택이 환자 생존과 전투 인력 이탈 시간을 결정한다.
- 주요 하위 요소: TCCC 교육, 자가 지혈, 지혈제 투여, 정량 진통제, 부상자 끌기, MIST 인계 기록, 헬기 MEDEVAC.
- 관련 플레이 영역: 전투, 의료 자원, 후송, 전진기지 지원.

## 전장 의료가방 [구현]

- 유형: 의료 / 휴대 장비
- 간단 설명: 의료가방에 보급품을 채워 현장에서 지혈 또는 혈장 수혈을 수행한다. TCCC와 목적이 겹치는 의료 콘텐츠지만 별도의 장비·보급 흐름을 갖는다.
- 주요 하위 요소: 의료가방, 지혈, 혈장 수혈, 보급품 재충전.
- 관련 플레이 영역: 전투 후 치료, 의료 물자, 병력 유지.

## 분대·지휘 편제 [부분]

- 유형: 적 병력 구성 / 지휘 상태
- 간단 설명: 현재 현지인 조합의 대전기 습격대를 완편 단위로 구성하고 지휘관 손실 시 지휘권을 승계한다. 지휘 효율 수치는 기록되지만 명령 전달·전술 AI·실제 지원 호출에 아직 영향을 주지 않는다.
- 주요 하위 요소: 순찰조, 소총분대, 기관총·바주카·저격조, 증강 소총소대, 전투 역할, 지휘관 손실·승계.
- 관련 플레이 영역: 습격 규모, 적 전력 파악, 전투 결과.

## 화생방·비살상 제압 [구현]

- 유형: 전투 / 지역 통제 / 상태
- 간단 설명: 연막·백린·화학 가스·섬광탄·전기충격 장비가 엄폐, 접근과 행동불능 상태를 만든다. 탄종과 보호장구의 선택이 살상과 제압의 차이를 만든다.
- 주요 하위 요소: 연막, 백린, CN·CS 가스, 포토클로로젠, 섬광탄, 스펀지탄, ZAPER, 방독·CBRN 장구.
- 관련 플레이 영역: 공성·돌입, 비살상 제압, 보호장비, 의료.

## 방어 시설·대공 [구현]

- 유형: 기지 방어 / 승무원 화기
- 간단 설명: 고정식 기관총, 박격포·곡사포, 대전차 미사일과 대공포가 기지의 교전 범위와 대응 대상을 바꾼다. 탄약·승무원·전력과 배치 위치가 운용 조건이 된다.
- 주요 하위 요소: 중기관총, 37mm 포, 박격포, 105/155mm 곡사포, M220 TOW, M167 VADS, Switchblade 발사기.
- 관련 플레이 영역: 방어선 구축, 군수 생산, 습격 대응.

# 2. 주요 콘텐츠

## 종족·세력·시작

- 헬로드 제노타입: 매켄지 계곡, 텍사스, 북극, 동부, 멕시코. 각 아종의 전투·내정 역할은 기획 메모와 실제 유전자 정의를 구분해 본다.
- 세력: 플레이어 헬로드 식민지, 현지인 조합(Helod Mercantile Association), 베세니카 주/스테이트(Providence State).
- 구현된 시작 시나리오: `Helod Gilded Pioneers` — 네 개척자, 서부 수준 연구·장비·초기 자원.

## 휴대 무기

# 7. 진행 및 장기 목표

- **서부 개척 시작 [구현]:** `Helod Gilded Pioneers`의 네 개척자가 초기 산업 기지를 세우고 석유를 확보한다. 시나리오 정의에는 스탈레르·나프타·구식 총기가 들어 있다.
- **산업 사다리 [구현]:** 수동 공구 → 라인샤프트·증기 → 제강·석유 정제 → 전기·전자·화학 합성. 각 공정의 중간재와 시설이 다음 생산 단계의 조건이 된다.
- **군사 기술 세대 [구현/부분]:** 서부 화기 → 대전기 보병·포병 → 냉전기 미사일·비살상 무기 → 현대 장구·항공지원 → 미래 LANCE. 후반 세대 전체가 완성된 것은 아니다.
- **통신·금융 확장 [구현]:** 전신 연구 후 계약·원격 거래에 접근하고 금융망 연구가 시장 기능을 확장한다.
- **전진기지 확장 [구현]:** 군사 신용과 기지 종류에 따라 사용 가능한 지원·정산 방식을 늘린다.
- **제노타입별 플레이 역할 [구현/부분]:** 초반 인력의 전투·내정 적성을 달리한다. 메모상의 추가 아종 능력은 기획 상태가 섞여 있다.
- **다른 시대의 시작 시나리오 [기획]:** 현지인 조합 정찰대, 냉전기 캐러밴, 현대 피난민, 미래 강하분대가 메모에 있지만 현재 시나리오 정의는 서부 개척 하나다.
- **음질량 무기 세대 [기획/부분]:** LANCE LRA-7은 정의되어 있다. 1~6세대 체계 전체는 설정·무기 발전 구상으로 본다.
- **스토리 분기·엔딩:** 현재 자료에서 구체적인 플레이 조건이나 구현을 확인하지 못했다. 노드 후보로 등록하지 않는다.
