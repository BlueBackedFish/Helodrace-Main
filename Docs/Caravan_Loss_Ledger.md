# 상단 손해 장부

전신기 → LOW 세력 → 전국산업신용회사 → **상단 손해 장부**에서 조회한다. 해당 팩션을 기본으로 표시하며 **세력 선택**으로 다른 기록된 팩션 또는 모든 기록을 조회할 수 있다. LOW·HIGH 방문 상단에 가한 플레이어 공격만 대상으로 한다. 통행 보장이 없는 일반 방문 상단과 보장이 깨진 뒤의 추가 공격도 기록한다.

기존 우호도 감소와 완전히 별개인 기록이다. 장부를 추가해도 일반·금융 우호도 페널티는 기존대로 처리한다. 기록 자체는 우호도·현금·대출 잔액을 바꾸지 않고 배상 의무나 자동 청구도 만들지 않는다.

금액은 **은화 기준 시장가**다. 각 항목에는 진행 일차·시각의 원본 게임 틱, 팩션, 상단 방문 ID, 정착지, 폰 ID와 이름, 구분, 물품 정의·이름·수량·단가·금액을 저장한다. 목록과 구분별 합계를 표시하며 이전 방문 기록은 지우지 않는다.

- **떨어뜨린 물품**: 공격 처리·전투 무력화·사망 처리 중 실제로 바닥에 배치된 장비·의류·소지품·운반 물품을 기록한다. 드롭 직전 시가 × 실제 배치 수량이다. 기존 스택에 합쳐진 경우도 콜백이 알린 배치 수량만 사용한다. 실패한 드롭과 다른 폰의 물품, 일반 거래·자발적 투하는 기록하지 않는다. 회수에 따른 자동 상계는 하지 않는다.
- **부상**: 해당 방문에서 최초 플레이어 공격 직전의 폰 시가와 체력 비율을 고정한다. 이후 각 플레이어 공격의 체력 비율 감소를 그 기준 가치에 비례해 평가한다. 공격 사이에 제삼자가 입힌 피해는 소급해서 더하지 않는다. 중첩 피해의 이미 기록된 부분을 제외하며 누적 부상액은 기준 가치를 넘지 않는다. 치료가 기록을 지우거나 같은 폰의 가치 상한을 늘리지는 않는다.
- **사망**: 기준 가치에서 그 폰의 이미 기록된 부상액을 뺀 나머지를 기록한다. 부상과 사망을 합한 금액이 폰 기준 가치를 중복 청구하지 않게 한다. 폰 기준 가치는 화면에 별도로 표시하고, 물품 손해는 별도 합산한다. 사망은 한 번만 기록한다.

플레이어 공격으로 생기거나 악화된 부상의 ID를 저장한다. 이 부상 자체나 아직 출혈 중인 해당 부상에서 비롯된 출혈로 나중에 무력화·사망한 경우도 기록할 수 있다. 명시적으로 제삼자가 가한 마무리 공격이나 관계없는 질병·자연사는 제외한다. 이미 무력화되어 상단 Lord에서 빠진 폰도 같은 지도에 남아 있으면 기존 방문 기록을 이어 쓴다. 살아서 지도를 떠나면 방문을 종료하며 이후 새 방문은 별도 장부를 사용한다.

구현은 `CaravanLossLedger.cs`(저장·평가·합계), `CaravanLossTracking.cs`(공격 범위·실제 드롭·무력화·사망), `CaravanLossDialog.cs`(조회)로 나눈다. 공격 추적 범위는 중첩과 예외를 포함해 동기 호출이 끝나면 해제한다.

검증은 `CaravanLosses.Tests`의 실제 장부·추적 코드 실행과 `Communications/Verify-SafeConductHooks.ps1`의 설치된 게임 대상 패치 등록을 사용한다. 실제 전투, 물품 낙하와 장부 화면은 게임 내 확인 대상이다.
