## 선택과 제작

고정 슬롯 메뉴를 **즉시 제작 가능 부속 / 별도 제작품**으로 나누었다. PALS 카탈로그도 즉시 제작 부속임을 표시하고, 완성품 재고·즉시 제작·조건 미충족 상태를 보여 준다. 툴팁에 원재료 비용과 부족한 재료·연구·설비를 안내한다. 별도 제작품은 완성품이 없으면 선택할 수 없다.

기존 완성품이나 장착한 부속을 먼저 재사용한다. 새 부속이 필요한 경우 현재 아이템의 `costList`를 합산해 기존 전용 중간재와 나일론·아라미드 등의 재료를 사용한다. 기존 standalone 부속 제작법도 선택지로 유지하지만 방탄판·야투경 외에는 미리 만들 필요가 없다. 보호 부속을 새로 만드는 경우에는 기존 연구와 필요한 유압프레스 조건을 적용한다. 이미 만든 부속의 이동·장착에는 원재료나 제조용 프레스를 다시 요구하지 않는다. 총기 즉시 제작처럼 추가 제작 스킬 조건을 새로 붙이지 않는다.

편집은 미리보기만 바꾸며 취소해도 물품·재료를 소비하지 않는다. ‘작업 시작’ 시 전체 배치 비용을 검사하고 재료를 예약한다. 기존 의류 작업대 커스터마이징 작업에서 완성품과 원재료를 수집한 뒤 장착 작업을 수행한다. 원재료는 총기 작업과 같은 작업대 반경 12칸 내의 접근 가능한 재료와 착용자 소지품에서 찾는다. 큰 스택은 실제 운반 한도로 나누어 수집한다. 적용 과정의 대기·장착 시간은 유지하며 별도 부속 제작 Bill을 먼저 돌릴 필요를 없앤 것이다.

완료 시 전체 구성·기존 장착품·완성품 수량·원재료 총량·연구·설비를 다시 검사한다. 새 부속을 생성하고 기존 구성 이전이 성공한 뒤에만 원재료를 소비한다. 중단된 작업의 수집한 재료는 착용자 소지품에 남는다. 재료 부족·연구 부족·설비 상실 또는 구성 변경으로 실패하면 부분 구성이나 무료 부속을 남기지 않는다. 미리보기의 신체/부품 배치 검증과 기존 실제 부품 컨테이너를 사용하므로 파우치 탄약, 판 두 장의 독립 내구도와 각 장착품의 물품 정체성을 유지한다.

새 작업 주문·JobDriver는 즉시 만들 부속 목록과 실물 부속 수를 저장하고 Job의 기본 수량 큐를 사용한다. 현재 저장/불러오기는 아래 실제 검사에 포함하지 않았다. UI 계산은 Waylith Rect 및 .NET 수치/문자열을 사용하며 기존 Verse Widgets 호출 경계에서만 변환한다. 새 Unity API를 추가하지 않았다.
