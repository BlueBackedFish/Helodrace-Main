# Flux Raider 촬영용 임시 연출

개발자 모드에서 Flux Raider 섀시를 장착한 P320을 든 플레이어 폰을 선택하면 `CINE: start`가 표시된다. 연출은 해당 폰에게만 적용되며 `CINE: stop`으로 해제한다. 일반 전투 동작이나 무기 부품 구성을 바꾸지 않는다.

| 명령 | 연출 |
| --- | --- |
| `LowReady` / `Aiming` | 총을 내린 자세에서 14틱 동안 조준 자세로 올리고, 개머리판을 장착 레일의 신축 범위에 따라 동시에 인출한다. 사격 작업이나 발사가 시작되면 `LowReady`에서 자동으로 전환한다. |
| `tune low ready` | 로우레디 자세를 미리 보며 화면 기준 X·Z 위치와 총기 각도를 조절한다. `Reset`으로 기본값을 복원한다. |
| `Lean East/West` | 해당 방향을 향한 채 몸을 11도 기울인다. 자세 진입과 사격 때 먼지를 뿌린다. |
| `Prone East/West` | 동쪽 몸 텍스처를 사용해 누운 자세를 그린다. 서쪽 방향에서는 몸을 반대로 회전한다. 자세 진입과 사격 때 먼지를 뿌린다. |
| `reload` | 기존 탄창을 아래로 떨어뜨리고 전방 예비 탄창을 총의 탄창 위치로 이동시킨다. 완료 후 예비 탄창은 삽입 위치에 남는다. 실제 탄약량은 변경하지 않는다. |
| `edit reload keyframes` | 낙하 탄창과 예비 탄창의 키프레임에서 시간, X·Z 이동량, 각도와 예비 탄창의 삽입 진행도를 편집한다. 미리보기 슬라이더로 확인하고 `Play`로 재생한다. 재생 시간도 틱 단위로 조절한다. |
| `reset magazines` | 촬영용 탄창 위치를 장전 전 상태로 되돌린다. |
| `lights off/on` | 장착된 레이저와 손전등의 빔 및 손전등 효과를 함께 끄거나 켠다. 시작 시 꺼져 있다. |
| `lock current facing` / `lock North/East/South/West` | 현재 방향이나 지정한 방향으로 폰을 고정한다. `unlock facing`으로 해제한다. |

물 타일 위에서는 물 지형 재질을 폰과 무기 앞쪽 절반에 겹쳐 수면 아래에 잠긴 모습을 만든다. 게임 카메라에서 물 경계, 개머리판의 인입 위치, 탄창 경로를 확인하며 촬영 구도에 맞게 수치를 조정해야 한다.

이 연출 상태는 저장 파일에 기록되지 않는다. 게임을 다시 시작하면 `CINE: start`부터 다시 설정한다.
촬영 모드가 켜진 폰은 선택해도 선택 하이라이트가 그려지지 않으며, 조작 버튼은 계속 사용할 수 있다.
재장전 키프레임과 재생 시간은 모든 촬영용 Flux Raider가 공유하며, 게임의 모드 설정에 저장되어 다음 실행에도 유지된다.
프리셋에 전방 예비 탄창 부품이 없으면 촬영 모드에서만 현재 탄창 용량에 맞춘 예비 탄창을 시각적으로 표시한다. 무기 부품 구성은 바뀌지 않는다.
