# T2-29 클레이 사격·사냥 오락

2026-11-03 K 그룹 구현. T2-32 무기 밸런싱은 공개 이후 작업으로 남기고, 기존 무기 수치는 변경하지 않았다.

## 클레이 사격

- 오락 탭의 1×1 스프링식 발사기. 강철 70, 범용 기계 부품 2, 건설 3이 필요하며 전기는 쓰지 않는다.
- 2026-11-04 요청에 따라 표적은 자동 제공한다. 보충·장전·연료가 필요 없으며 사용하지 않는 소모품·제작 레시피·잔량 UI는 제거했다. 날아가는 3D 클레이 표적은 유지한다.
- 단발로 발사하는 일반 실탄 총을 장착해야 한다. 산탄총은 가능하고 자동 점사·폭발탄·곡사 무기는 제외한다. 별도 모의 명중 확률 대신 장착 무기의 실제 발사·투사체·명중 처리를 사용한다.
- 발사기 앞 14칸과 좌우 여유 공간에 지붕·건물·살아 있는 폰이 있으면 시작하지 않거나 중단한다. 다른 폰을 맞히지 않는 발사 옵션과 아군 보호 옵션을 사용한다.
- 3,000틱 동안 표적 사격 오락을 얻는다. 기본 시간 보상에 명중 +0.025/실패 +0.01을 더한다. 표적은 실제로 날아가고, 맞거나 수명이 끝나면 사라진다.
- [아트 소스와 건물 규칙](../ArtSource/ClayShooting/README.md): 이전 건물 제작 대화와 현행 공통 규칙을 확인한 뒤 Blender 모델 두 개를 제작했다. 발사기는 64도 정사영 4방향, 256px, 고정 12px 외곽선, 강철 색상 마스크를 사용한다. 클레이 피전은 별도의 3D 원본과 256px 표적 텍스처를 갖는다.

## 사냥 오락

일반 사냥 작업과 별도 오락 작업이다. 사냥 지정된 동물은 고르지 않으며 사냥 지정을 새로 만들지 않는다. 장착한 총이 명시적 사냥총 분류에 속해야 시작한다.

현재 분류는 바닐라 볼트액션 소총·펌프 산탄총·저격소총과 모드 Krag–Jørgensen, M1897, 두 Springfield M1903, Winchester M1887이다. 자동소총은 제외한다. 분류는 `Patches/RecreationalHuntingWeapons.xml`의 확장으로 관리한다.

- 주변 60칸 이내에서 도달·예약 가능한 야생동물 한 마리만 고른다. 포식자, 공격 시 광란 위험이 큰 동물, 쓰러진 동물, 소속 있는 동물, 금지·미탐사 구역의 동물은 제외한다. 몸집 범위는 0.15~1.5다.
- 탐색 5,000틱 → 실제 접근 → 추적 6,000틱 → 재접근 → 관찰·잠복 1,500틱 → 사격 위치 접근 순서다. **초탄까지 최소 12,500틱, 게임 시간 5시간**이며 이동 시간이 추가된다.
- 초탄의 실제 투사체가 동물에 맞지 않으면 즉시 사냥 실패로 끝나고 오락 **+0.55**를 받는다. 산탄총은 첫 탄약의 여러 펠릿 중 하나라도 맞으면 명중이다.
- 초탄 명중 후에는 같은 동물만 계속 사냥한다. 사냥에 성공하면 오락 **+0.65**, 이후 제한 시간 안에 마무리하지 못하면 +0.55다. 처음 사격을 시도한 뒤의 제한은 6,000틱이다.
- 처치한 사체는 금지하지 않고 일반 운반 작업으로 수거할 수 있게 한다. 이 오락이 다음 동물을 연달아 잡거나 사체를 자동으로 추가 사냥하지 않는다.
- 준비 중 강제 중단·총 교체·대상 소실에는 결과 보상을 지급하지 않는다. 진행 단계·남은 대기 시간·비행 표적·진행 중 투사체는 저장한다.

보상은 오락 필요의 0~1 척도 기준이며 최댓값과 해당 오락 내성은 게임의 `GainJoy` 처리를 따른다. 준비 중에는 완료 보상을 선지급하지 않는다.

## 검증

기존 2×1 모델의 위치·크기를 일괄 절반으로 줄이고 현행 밀도에서 다시 렌더링했다. 형상·재료는 유지하고 외곽선은 축소하지 않아 기존 12px 굵기를 유지한다.

실제 설치된 RimWorld 1.7.4995 rev309의 격리 호스트를 사용했다. 재현 절차와 저장 복원 검사는 [Stage K 검사](../Source/Tests/StageK/README.md)에 기록한다. 클레이의 실제 이동·명중, 안전 발사 옵션, 사냥의 5시간 준비 및 초탄 실패/성공 분기를 확인했다. 사냥 성공/실패 검사는 산탄 산포·조준 오차를 제어해 두 분기를 재현한 기능 검증이며 자연 명중률이나 T2-32 무기 성능 측정이 아니다.

렌더 PNG·마스크·게임 정의 연결도 별도 검사했다. 게임 내 스크린샷의 외형 검수나 장기 오락 선택 빈도의 밸런스 검증까지 완료했다는 의미는 아니다. 퀵드로우는 후속 콘텐츠로 남긴다.
