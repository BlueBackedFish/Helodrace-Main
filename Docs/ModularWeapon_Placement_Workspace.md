# 파츠 위치 조정: 다중 선택과 총기 통합 저장

2026-10-18. DEV 파츠 위치 조정창에서 여러 총기를 오가며 편집하고 한 파일로 내보낼 수 있다.

## 사용법

1. 기존 DEV attachment editor를 연다. 현재 총기가 자동으로 저장 목록에 들어간다.
2. **총기 전환**으로 다른 총기를 선택한다. 맵의 바닥·장비·인벤토리·컨테이너 안 총기와 이미 방문한 총기를 찾는다. 같은 총기 Def라도 실제 개체별로 전환할 수 있다.
3. 파츠 트리에서 일반 클릭으로 하나를 선택하고, **Ctrl+클릭**으로 선택을 추가/제거한다. 다중 선택 시 그림 위치 모드로 전환한다. 미리보기에서 왼쪽 드래그하면 선택한 그림들이 함께 이동한다. Shift/수평/수직 축 제한도 유지한다.
4. 원하는 만큼 다른 총기를 편집한 뒤 **전체 한 번에 저장**을 누른다. 방문한 모든 총기의 파츠 설정과 조립 문맥을 XML 한 파일에 넣는다. 공용 파츠는 DefName별 한 번만, 저장 시점의 최신값으로 내보낸다.

회전·팔레트 크기·좌우 반전이 다른 파츠도 같은 화면 거리만큼 이동한다. 같은 Def를 여러 번 선택한 경우 공용 설정을 한 번만 이동한다. 다중 이동 대상은 **그림 위치**다. 마운트·소켓·애니메이션 등은 기존처럼 현재 활성 파츠를 조정한다. 그림 이동은 부착점 구조를 동시에 옮기는 기능이 아니다.

총기를 바꿨다가 돌아오면 선택·확대·팬·트리 스크롤을 복원한다. 되돌리기(Ctrl+Z)는 한 창에서 총기에 관계없이 최근 편집부터 취소하고, 필요하면 해당 총기로 돌아간다. 공용 파츠 변경 시 방문한 다른 총기의 렌더·스탯 캐시도 갱신한다.

## 저장과 수명

저장 위치:

```text
RimWorld 설정/저장 데이터 폴더
└─ Helodrace/ModularWeaponExports/
   └─ PlacementBatch_날짜_시간_고유값.xml
```

이제 저장할 때 총기마다 별도 폴더나 파츠별 파일을 만들지 않는다. 다시 저장하면 새 통합 파일 하나를 만든다. **전체 XML 복사**도 같은 통합 내용을 복사한다. 기존 **Copy XML**은 현재 총기의 파츠 설정만 복사하는 용도로 남아 있다.

저장 목록은 같은 게임 세션의 조정창들이 공유하므로 창을 닫아도 사라지지 않는다. 다만 **게임 종료·불러오기 이후까지 보존하는 작업 파일은 아니다. 게임을 나가기 전에 XML로 내보내야 한다.** 창을 닫으면 그 창의 되돌리기 기록도 종료된다. 게임 저장 파일 자체에 이 개발용 대기 목록을 기록하지 않는다.

파일을 완전히 쓴 뒤에만 저장 완료로 표시한다. XML 직렬화나 파일 쓰기가 실패하면 편집값과 대기 목록을 유지한다. 클립보드 복사만으로는 파일 저장 완료로 표시하지 않는다. 파일은 개발용 내보내기 자료이며 모드의 Defs/Patches를 자동 수정하지 않는다.

## 통합 XML

루트는 `ModularWeaponPlacementBatchExport`다.

- `parts/li/thingDef`: 중복 제거한 파츠 DefName.
- `parts/li/settings`: 기존 내보내기와 같은 파츠 설정 조각. 위치·마운트·소켓·애니메이션·스탯 등의 현재 편집값을 포함한다.
- `assemblies/li`: 방문한 무기 개체별 `weaponDef`, `thingId`, `label`과 조립 목록.
- 조립 목록에는 `path`, `part`, `parentPath`, `socketId`, `mountId`, 레일 장착이면 `railOffset`을 넣는다. 같은 공용 파츠를 다른 총기에서 서로 다른 레일 위치에 놓은 경우도 보존한다.

## 검증

`ModularWeaponNavigation`은 공용 파츠 중복 제거, 최신값 읽기, 무기별 레일 위치, 저장 시점 스냅샷, 파일 충돌·실패 시 목록 보존을 검사한다. `ModularWeaponBalance`는 실제 편집창/워크스페이스 코드로 통합 XML, 공용 캐시 갱신 요청, 다중 선택·회전/반전/배율별 이동, 총기 전환·뷰 복원·공유 Undo 기록을 검사한다.

게임 내 실제 조정창의 화면 배치·마우스 조작은 별도 수동 확인이 필요하다.
