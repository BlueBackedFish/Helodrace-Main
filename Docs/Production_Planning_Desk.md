# 생산 계획대

헤로드 기술 건설 메뉴에서 개척 정신 연구 후 50 소재로 건설한다. 기존 기초 작업대 그림에 색을 달리해 사용한다. 설치 후 **생산 계획** 명령에서 여섯 기초 부품의 목표 재고를 설정한다. 계획대 자체는 전담 작업자나 전력이 필요하지 않다.

| 부품 | 자동 등록 공정 |
|---|---|
| 범용 기계 부품 | 밀링 |
| 프레스 부품 | 유압 프레스 |
| 축 | 선반 |
| 균일 압연 강판 | 압연기 |
| 기초 전기 부품 | 기초 작업대 |
| 기초 전자 부품 | 기초 작업대 |

같은 레시피를 지원하는 후대 기계도 사용할 수 있다. 연구·설비·동력과 재료를 만족하는 작업대 중 대기 작업이 적고 작업 속도가 높은 곳을 고른다. 산업 부품을 범용 부품으로 바꾸는 비상 조합법은 자동 선택하지 않는다.

모든 계획대는 맵 하나의 목표를 공유한다. 현재 재고와 수동·자동 예정 생산을 뺀 부족량만 1·5·10개 배치로 등록하고, 품목마다 동시에 한 자동 배치만 유지한다. 수동 ‘재고까지 제작’의 남은 생산량은 해당 기본 작업의 제품 카운터와 설정을 따른다. 재고는 금지되지 않은 바닥 물품과 플레이어 폰의 인벤토리·운반품을 센다. 방문 상인의 인벤토리는 제외한다. 기존 작업의 고정 재료 요구량을 먼저 예산에서 빼고, 여러 자동 작업이 같은 자재를 중복 배정받지 않게 한다. 미완성품에 이미 들어간 첫 배치 재료는 다시 예산에서 빼지 않는다. 실제 재료 예약·제작·운반은 기본 게임 작업 AI가 수행한다.

목표 0은 해당 품목의 자동 생산을 끈다. 재고가 들어오거나 목표가 낮아져 불필요해진 시작 전 자동 작업은 지운다. 작업자가 이미 시작한 배치는 미완성품을 보존하고 마칠 수 있으므로 그 경우 한 배치 분량의 초과 생산이 가능하다. 자동 생산을 끄거나 마지막 계획대를 철거하면 소유한 작업을 일시 중지한다. 다시 설치하거나 켜면 같은 작업을 이어간다. 수동 작업은 이 제어로 중지·삭제하지 않는다.

**현재 / 예정 / 누적 생산**은 각각 소유 재고, 활성 기본 제작 작업의 예정 산출, 계획대가 등록한 작업의 실제 완료 수량이다. 수동 ‘재고까지 제작’의 기본 자원 카운터는 저장 구역에 들어간 물품을 세므로 해당 수동 작업에는 저장 구역도 필요하다. 자동 작업은 반복 횟수 1회와 계획대의 목표 재고로 관리한다. 수동 제작·거래로 들어온 물건을 누적 생산에 더하지 않는다. 전자 부품에 소비된 전기 부품도 목표까지 다시 보충한다. 진행 중인 작업·소유권·목표·완료 집계와 미완성품은 저장/로드로 유지한다.
