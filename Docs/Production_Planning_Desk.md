# 생산 계획대

헤로드 기술 건설 메뉴에서 개척 정신 연구 후 50 소재로 건설한다. 전용 2×1 그림(서랍 받침·청사진·일정표 클립보드·장부·스탠드와 뒤쪽 칸반 게시판)을 쓴다. 가구 규칙(고정 색, 나무 기준색, 색 마스크 없음)에 따라 512px 4방향으로 만들었고 drawSize는 타일 밀도 규칙의 (3,3)이다. 원본은 `ArtSource/ProductionPlanningDesk`. 설치 후 **생산 계획** 명령으로 창을 연다. 계획대 자체는 전담 작업자나 전력이 필요하지 않다.

## 대상 품목

생산 계획에는 헤로드 생산 사슬의 자원과 중간재만 넣는다(`ProductionCatalog.IsPlanMaterial`). 보관 가능한 물품 중 직접 분류가 모두 원자재·제조품·직물·용광로 연료이고, `HD_` 물품이거나 헤로드 제작법(`HD_`)의 고정 재료·산출물인 것이다. 무기·의복·탄약·포탄·수류탄·방탄판·모듈 부품·화폐·식량은 자기 분류에 있으므로 제외한다. 요청에 따라 통나무·은·강철·플라스틸·중질유·M60 도화선 점화기·M81 점화기·P320 Flux Raider 파츠 상자·지혈제는 목록에서 뺐다(`NotPlanned`). 이 물품들도 순서도에는 재료로 계속 나온다. 2026-11-06 실제 1.7 게임 기준 28종이며 모두 자동 계획할 수 있다.

숯, 알루미나, 알루미늄 합금, 질산암모늄, 방향족 기초유분, 기초 전기·전자 부품, 기초 의료품, C-4, 탄소강, 화학연료, 산업용 부품, 디젤, 전자 부품, 범용 기계 부품, 등유, 나프타, 주철, 프레스 부품, 1차 전지, RDX, 축, 실리콘, TNT, 균일압연강판, 모듈 무기 부품 상자, 아라미드, 나일론.

자동 후보는 `Helodrace.ProductionPlanningExcluded` 확장이 없는 제작법이다. 산출물이 여럿인 제작법(방향족 기초유분 + 플라스틸)도 후보이며, 자동 작업은 어느 목표를 위해 등록했는지 저장하고 그 산출물 수량으로 부족량·완료를 센다. 다른 산출물은 예정 수량에만 더한다. 일반 부품으로 바꾸는 비상 조합법 3종은 이 확장으로 자동 선택하지 않는다. 범용 기계 부품을 부산물로 내는 그레이록 M1861→M1873 개조는 `hidden`까지 지정해 순서도에도 나오지 않는다. 같은 제작법을 지원하는 후대 기계도 사용한다. 연구·설비·동력과 재료를 만족하는 작업대 중 대기 작업이 적고 작업 속도가 높은 곳을 고른다.

## 목표 재고와 제작 수량

품목마다 두 주문을 따로 둔다.

- **목표 재고**: 현재 재고 + 예정 수량이 이 값보다 적으면 부족량만큼 만든다. 수동 작업과 미완성품도 예정 수량에 포함한다. 0이면 끈다.
- **제작 수량**: 재고와 관계없이 이만큼 더 만든다. 계획대가 등록한 제작 수량 배치가 끝날 때마다 그 산출 수만큼 줄고 0이 되면 끝난다. 0으로 바꾸면 시작 전 배치를 지운다. 작업 이름은 ‘(계획 수량)’이다.

두 주문은 품목마다 각자 한 자동 배치를 유지하고 같은 자재 예산을 쓴다. 목표 재고는 진행 중인 제작 수량 배치의 산출을 예정 수량으로 세지 않으므로 두 주문이 서로를 상쇄하지 않는다. 완성된 제작 수량 산출이 재고에 들어온 뒤에는 목표 재고도 그 재고를 센다.

계속 반복으로 설정한 활성 작업이 만드는 품목은 예정 칸에 **∞**로 표시하고 툴팁으로 이유를 보여 준다. 계획 계산에서는 기존처럼 충분한 예정 생산으로 취급하며, 일시 중지한 반복 작업은 무한으로 보지 않는다.

## 자동 생산

모든 계획대는 맵 하나의 목표를 공유한다. 현재 재고와 수동·자동 예정 생산을 뺀 부족량에 맞는 가장 큰 배치(예: 10·5·1개)를 등록한다. 모든 배치가 부족량보다 크면 가장 작은 배치를 등록한다. 품목마다 동시에 한 자동 배치만 유지한다. 수동 ‘재고까지 제작’의 남은 생산량은 해당 기본 작업의 제품 카운터와 설정을 따른다. 재고는 금지되지 않은 바닥 물품과 플레이어 폰의 인벤토리·운반품을 센다. 방문 상인의 인벤토리는 제외한다.

기존 작업의 재료 요구량을 먼저 예산에서 빼고, 여러 자동 작업이 같은 자재를 중복 배정받지 않게 한다. 고정 재료는 해당 물품을, 여러 물품을 허용하는 재료는 허용된 물품 중 재고가 가장 많은 한 종을 사용한다. 미완성품에 이미 들어간 첫 배치 재료는 다시 예산에서 빼지 않는다. 실제 재료 예약·제작·운반은 기본 게임 작업 AI가 수행한다.

목표 0은 해당 품목의 자동 생산을 끈다. 시작 전 자동 작업은 더 이상 필요 없거나, 더 작은 배치를 지금 등록할 수 있는데 목표를 넘기면 지운다. 작업자가 이미 시작한 배치는 미완성품을 보존하고 마칠 수 있으므로 그 경우 한 배치 분량의 초과 생산이 가능하다. 자동 생산을 끄거나 마지막 계획대를 철거하면 소유한 작업을 일시 중지한다. 다시 설치하거나 켜면 같은 작업을 이어간다. 수동 작업은 이 제어로 중지·삭제하지 않는다.

**현재 / 예정 / 누적**은 각각 소유 재고, 활성 기본 제작 작업의 예정 산출, 계획대가 등록한 작업의 실제 완료 수량이다. 수동 ‘재고까지 제작’의 기본 자원 카운터는 저장 구역에 들어간 물품을 세므로 해당 수동 작업에는 저장 구역도 필요하다. 수동 제작·거래로 들어온 물건을 누적 생산에 더하지 않는다. 진행 중인 작업·소유권·목표·완료 집계와 미완성품은 저장/로드로 유지한다. 목표와 누적이 모두 0인 품목은 저장하지 않는다.

## 창

왼쪽은 분류별로 접을 수 있는 자원·중간재 목록이다. 아이콘·이름·현재·예정·누적·목표를 표시하고, 검색과 ‘계획한 품목만 표시’로 거른다. 다른 곳에서 목표가 바뀌면 입력 칸도 새 값으로 바뀐다. 품목을 누르면 오른쪽에 생산 순서도를 연다.

오른쪽 순서도는 재료가 왼쪽에서 오른쪽으로 흐르는 상자와 연결선이다. 원자재 → 제작법 → 중간재 → 제작법 → 선택 품목 순으로 놓이고, 선택 품목은 오른쪽 끝 금색 테두리 상자다. 각 상자는 투입 재료들의 가운데 높이에 놓이며, 직각 연결선과 화살표가 재료의 오른쪽 변에서 소비하는 상자의 왼쪽 변으로 이어진다.

- 품목 상자: 아이콘·이름·선택 품목 1개당 필요 수량·현재 재고. 제작법 없는 품목은 초록, 순환 품목은 주황 테두리다. **열기**는 그 품목을 새 기준으로 연다.
- 제작법 상자: 이름, 배치당 산출과 필요 배치 수, 작업대, `LinkedFacilityRecipes.RequiredFacilitiesText`의 필요 설비. 자동 계획에서 제외한 제작법은 황색 테두리이고 툴팁에 ‘자동 등록 안 함’을 표시한다.
- 여러 물품을 허용하는 재료는 ‘다음 중 하나’ 상자로 묶고, 펼치면 허용 물품을 최대 12종까지 보여 준다.
- 상자 왼쪽 변의 +/− 표식이 있는 상자를 누르면 투입 재료를 펼치거나 접는다. 끌면 화면을 옮기고, 스크롤바와 휠도 쓸 수 있다.
- 품목을 열면 각 품목의 첫 제작법(헤로드 제작법 우선, 작은 배치 우선)만 원자재까지 펼친 주 경로를 보여 준다. 대체 제작법은 접힌 상자로 함께 표시한다. **모두 펼치기**는 모든 대체 제작법을 펼치고, **모두 접기**는 선택 품목의 제작법만 남긴다.
- 같은 사슬의 뒤쪽에 이미 있는 품목은 ‘순환’으로 표시하고 다시 펼치지 않는다. 깊이는 24단계, 상자는 1,500개로 제한한다.

## 성능

창을 열거나 사용할 때의 지연은 그리기마다 각 목표의 재고·예정 수량을 구하려고 맵의 모든 물건과 모든 작업을 다시 훑던 것이 원인이었다. 이 비용은 목표 수에 비례하므로 모든 헤로드 물품으로 확장하면 수십 배가 된다. 지금은 다음과 같이 나눈다.

- Def에서 나오는 품목·제작법·재료·작업대·설비 문자열은 `ProductionCatalog`가 처음 사용할 때 한 번 만든다.
- 맵 재고와 예정 수량은 `HaulableEver` 목록과 작업대 작업을 한 번 훑어 사전에 담는다. 60틱 또는 실시간 0.5초가 지나야(정지 중에는 2초) 다시 센다. 계획 갱신은 항상 새로 센다.
- 목록과 순서도 배치는 입력이 바뀔 때만 다시 계산하고, 화면에 보이는 행·상자·연결선만 그린다.
- 250틱 갱신은 목표나 자동 작업이 없으면 건너뛴다.
