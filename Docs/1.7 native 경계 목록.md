# 1.7 native 경계 목록

작업 중인 심볼 목록이다. 수학·기하와 내부 렌더 데이터의 전환은 아직 남아 있으며 이 목록만으로 3단계 완료를 선언하지 않는다.

## 시간·런타임

| 사용처/심볼 | 현재 경계와 근거 |
|---|---|
| UI 갱신·거절 알림·아이콘 안정화·스탯 easing·전신 창 애니메이션의 실시간 값 | `Waylith.Time.RealtimeSinceStartupAsDouble`. 마감 시각·시작 시각도 double로 바꿔 같은 시계에서 차이를 계산한다. |
| 조직/전술 오버레이·아이콘 작업 제한·프로파일러 프레임 | `Waylith.Time.FrameCount`. native 호스트 프레임 기준이다. |
| GenTicks·Verse.Rand | 게임 시뮬레이션/저장/결정성 계약이므로 유지한다. 벽시계로 게임 논리를 실행하지 않는다. |
| 자체 CLI 감사/검사 종료 | `Waylith.EngineApplication.Instance.Quit`. 해당 검사가 결과/저장을 기록한 뒤 호스트 종료를 요청한다. native Dispose의 OnShutdown 및 App.ShuttingDown 수명을 따른다. |
| TacticalAuditNativeErrors | `Waylith.Logging.LogStream.MessageReceived`, 실제 `LogLevel.Error/Critical`. 기존 main-thread 기록 범위와 재귀 방지를 유지한다. 게임 제공 logging abstractions DLL만 참조하며 동봉하지 않는다. |
| TacticalAuditBootstrap의 `Application.runInBackground` | 1.7 native `WaylithAppState`/`EngineApplicationOptions`에는 대응 setter가 없다. 숨긴 감사의 기존 게임 호환 상태와 Prefs를 함께 설정하는 단일 경계로 남긴다. `Waylith.UnityCompat`의 같은 상태를 호출하는 것만으로 native 전환으로 세지 않는다. |
| 저장 경로 `GenFilePaths.SaveDataFolderPath` | `-savedatafolder`의 게임 계약을 따른다. native PersistentDataPath는 사용자 LocalLow이고 CacheDataPath는 시험 Profile이었다. 저장 위치를 PersistentDataPath로 바꾸면 격리가 깨지므로 교체하지 않는다. |
| 엔진 data/log/cache/temp 경로 | `WaylithRuntime.Current.App`의 실제 값을 사용한다. 현재 제품에 직접 Unity Application 경로 호출은 없다. 실제 호스트 값은 `native-runtime17b/Evidence/runtime.json`에 기록했다. |

Unity 호환 시간은 UnityTimeState 생성 시점의 Stopwatch를, native 시간은 Waylith.Time의 정적 시작 시점을 사용한다. 호환 프레임은 BeginFrame, native 프레임은 EndFrame에서 증가한다. 절대 시간·프레임 번호를 섞지 않는다. 실제 검사에서는 8프레임 동안 두 프레임 카운터가 모두 8 증가했고 경과 시간은 각각 약 0.411초였다.

검사 코드의 Unity 시간/경로 사용은 native와 게임 경계를 비교하는 fixture에 한정한다. Blancas의 1.6 fixture 종료는 보존한 1.6 엔진 API를 사용한다.

## 스칼라 수학

`Source/NativeMathAliases.cs`는 제품의 스칼라 `Mathf`를 `Waylith.Math.Mathf`로 직접 바인딩한다. 제품 DLL에는 UnityEngine.Mathf TypeRef가 없다. 명시적으로 작성돼 있던 UnityEngine.Mathf 호출도 native로 바꿨다. 스칼라는 float/int 데이터이므로 이 변경은 벡터·행렬·렌더 데이터의 타입 전환과 구분한다.

native에 없는 각도 보간/이동은 `Core/AngleMath.cs`의 두 수학 연산으로 정의했다. native DeltaAngle·Clamp01·MoveTowards를 사용하며 호출자가 소유하는 각도 정규화 시점을 유지한다. 정수 3~4항 Min은 중첩 BCL Min을 써 float 배열 오버로드로 수량을 변환하지 않는다.

제품 소스를 직접 링크하는 독립 테스트 중 native 스칼라를 쓰는 여섯 프로젝트만 `HelodUsesNativeMath`로 Waylith와 동일 alias를 참조한다. 게임 객체 어셈블리는 추가하지 않는다. 실제 엔진 경계 비교 fixture에서는 UnityEngine.Mathf를 명시적으로 사용한다.
