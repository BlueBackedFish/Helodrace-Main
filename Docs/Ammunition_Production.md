# 냉전기 지원화기 탄약 제작

적용일: 2026-11-05. 기존 아이템 `HD_20x102mmMixedRound`, `HD_BGM71A_Round`에 무기 제작대 제작법을 추가했다. 탄종별 새 아이템은 만들지 않았다.

| 결과 | 재료 | 작업량 / 제작 기술 | 필요 연구 |
| --- | --- | --- | --- |
| 20×102mm 혼합 탄약 50발 | 탄소강 12, 화학연료 8, TNT 2, 범용 기계 부품 1 | 3000 / 6 | HelodAntiAirMachineGun |
| BGM-71A 미사일 1발 | 탄소강 10, 알루미늄 합금 12, 전자 부품 6, 기초 전기 부품 4, TNT 12, 화학연료 8 | 9000 / 8 | HelodWireGuidedMissile |

혼합 탄약은 탄체·추진제·일부 폭약·급탄 부품을 묶음으로 소비한다. 유도 미사일은 외피·유도 전자 장치·배선·탄두·추진제를 소비한다. 바닐라 부품·고급 부품은 사용하지 않는다. 해당 무기의 연구와 같은 조건에서 열리며, 필요한 재료의 기존 생산 연구는 선행 경로에 있다. 가격·무기 성능·기존 보급 경로는 변경하지 않았다. 신규 경로는 무기 제작대에만 추가했다.

## 실제 게임 검증

`Source/Tests/StageK/Start-Checks.ps1 -RuntimeRoot .codex-staging/TextContent/native-01 -TextContent`로 RimWorld 1.7.4995 rev309에서 다음을 확인했다.

- 연구 전 두 제작법 차단, 대응 연구 후 실제 작업대 목록 노출.
- 실제 작업자가 재료를 운반하고 제작을 완료하며 입력 전량과 출력 50발/1발이 정확함.
- 혼합 탄약이 기존 M167 연료 필터에 허용됨.
- 같은 실행에서 탄소강 20·강철 20·화학연료 12를 사용한 진압방패 제작 완료.

운용 정보 검사 포함 51 PASS / COMPLETE. [원본 검사 결과](Data/TextContent/native-checks.txt)와 [검증 메타데이터](Data/TextContent/verification.json)에 기록했다. 새 탄약은 기존 아이템 정의를 그대로 사용한다. 사격·TOW 재장전 동작 자체는 이번 실행에서 별도로 재검사하지 않았다.
