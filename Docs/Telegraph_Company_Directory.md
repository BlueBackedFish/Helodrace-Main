# 전신기 연락처와 회사명

전신기는 온라인일 때 세력별 가로 행을 보여 준다. 세력 행을 누르면 소속 회사·단체가 가로 행으로 펼쳐지고, 회사 행을 누르면 아래에 해당 회사의 업무 탭이 열린다. 세력 행에는 아이콘과 일반 우호도를, 회사 행에는 회사명과 업무 종류를 표시한다.

- 연락처 목록은 세로로 스크롤된다. 회사 수에 따라 가로 폭을 나누지 않는다.
- 업무 탭을 닫아도 펼친 회사 목록은 유지한다. 선택한 세력을 접으면 그 회사의 업무 탭도 닫힌다.
- 오프라인에서는 세력·회사 목록과 업무 탭을 숨기고 선택 상태를 초기화한다.
- 전진기지의 위치 지정·계약서 화면에서 복귀할 때는 파이오니어의 선택 상태를 복원한다.
- 현재 접근 대상은 개통을 제공한 LOW 팩션이다. 연락처 검색과 행 그리기는 분리되어 있으며, 회사 목록은 `TelegraphCompanies.All`을 열거한다. 이후 회사나 세력 추가 시 고정 4열 레이아웃을 수정할 필요가 없다.

회사 이름은 번역 키로 표시해 전신기·계약서·파견 안내에서 같은 이름을 사용한다. 상단의 DefInjected 이름도 맞췄다.

| 영문명 | 한국어 표시 |
|---|---|
| National Industrial Credit Corporation | 국영산업신용공사 |
| Central Hardware & Supply Co. | 중앙 철물·보급상사 |
| Pioneer Overseas Service Company | 파이오니어 해외사업회사 |
| Harrington Protective Services | 해링턴 경비회사 |

검증은 `Communications.Tests`의 연락처 선택 상태·번역·상단 이름 검사와 모드 빌드를 사용한다. 게임 내 화면 배치와 클릭 동작은 별도 플레이 확인 대상이다.
