# 방어구 커스텀 미리보기 정렬

미리보기는 현재 방향에서 보이는 의상과 장착 부품의 알파 영역을 합쳐 중앙에 정렬합니다. PNG 안에서 벨트나 바지 그림이 아래로 치우쳐 있어도 그림 전체의 중심을 사용합니다. 모든 레이어가 같은 UV 영역과 목적지 사각형을 사용하여 파츠의 상대 위치를 유지하고, 서쪽은 기존 좌우 반전을 적용합니다.

기존 `previewCrop`의 너비와 높이는 최소 표시 범위로 사용합니다. 그림이나 부품이 그 범위보다 크면 전체가 들어오도록 확대 범위를 조절합니다. 이미지 비율은 유지하고 가장자리에 여유를 둡니다. 완전히 투명한 레이어는 영역 계산에서 제외하며, 반투명 그림은 포함합니다.

텍스처 영역은 커스텀 창별로 한 번 계산해 캐시합니다. 읽을 수 없는 Unity 텍스처는 임시 렌더 텍스처를 통해 픽셀을 읽고 임시 자원을 해제합니다.

검증 명령:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File Source/Verify-ModularArmorPreview.ps1
```

투명·치우친·반투명 그림 및 실제 모듈형 장비 4종의 방향별 PNG 12개를 검사합니다. 가로형·세로형·정사각형 영역에서 그림 중심이 미리보기 중심과 일치하고 비율과 영역 경계가 유지되는지 확인합니다. 이 검증은 픽셀 영역과 배치 계산을 검사하며, 실제 게임 창의 렌더링 확인은 별도입니다.
