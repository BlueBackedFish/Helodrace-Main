# T2-20 제노타입 추천안 — 역할이 다른 다섯 계통

2026-11-03 작성한 추천안이다. 2026-11-04 사용자가 아래 생활·전투 역할 분담을 확정해 실제 유전자·생성 분포에 적용했다. 최신 구성과 검증은 [T2-20 구현 결과](T2_20_Xenotype_Redesign.md)를 따른다. 아래 표와 후속 순서는 원래 제안의 기록이다.

## 권장 방향

공통 정체성은 BTX 의존, 헤로드 외형, 총기 조작과 명사수 모드다. 공통 명사수 유전자의 현재 수치를 이 작업에서 조정하지 않는다. 아종마다 ‘주 역할 하나 + 보조 역할 하나 + 환경 적응 + 뚜렷한 대가’를 준다. 모든 아종에 식물·의료·지능 약점을 반복해서 붙이는 현재 방식은 줄여 4인 시작의 식량·치료·연구가 함께 막히지 않게 한다.

| 계통 | 주 역할 / 보조 | 적응·외형 | 권장 장점 | 대가와 제외할 과잉 장점 |
|---|---|---|---|---|
| 매켄지 계곡 | 대열 유지·지휘 / 야전 구조·치료 | 큰 체격, 짙은 털, 온대·한랭 | 사회 강점, 통증 저항, 의료 보조 | 느린 이동·많은 식량. 연구·제작까지 강하게 만들지 않는다. 기존 의료 약점은 이 역할과 충돌하므로 제거 후보 |
| 텍사스 | 개척지 추적·사냥 / 목축·농사 | 밝은 황갈색, 고온·건조 | 이동·고온 적응, 동물·식물 강점 | 추위 취약·얇은 체력. 최고 이동속도와 최상급 전투를 함께 주지 않는다 |
| 북극 | 정찰·장거리 사격 / 악천후 경계 | 흰 털, 낮은 실루엣, 극한 저온 | 저온 적응, 원거리 사격 전문성 | 더위·감염·혼잡 취약. 실내·근거리까지 정확도 이득을 넓히지 않는다 |
| 동부 | 연구·정밀 제작 / 거래 | 회색 털, 작은 체격, 도시 생활 | 지능·제작 강점, 사회는 중간 보조 | 연약함·느린 치유. 의료·연구·제작·최상급 사회·초능력을 모두 겸하는 현재 과밀 구성은 정리 |
| 멕시코 | 계약 전투·기동 / 전우 구조 | 짙은 갈색, 군인·PMC 인상 | 강건함, 회복·근접 보조, 부대 결속 | 별도 자극제 의존·보급 비용. 최고 이동·강건함·최상 회복을 한꺼번에 최대로 주지 않는다 |

‘권장 장점’은 역할 배치이며 아직 GeneDef별 확정 목록이나 신규 유전자 구현이 아니다. 체격을 바꾸면 피격 판정·장비 위치·식량·전투 수치를 함께 검증해야 하므로 외형만 바꾸는 척하며 전투 이득을 숨기지 않는다.

## 시작 구성과 생성 분포

- **권장 시작 4종**: 매켄지(지휘·의료), 텍사스(식량·사냥), 북극(정찰·사격), 동부(연구·제작). 멕시코는 선택 시작·용병·합류·군사 세력에서 두드러지는 다섯 번째 계통으로 둔다.
- 시작 선택에서 멕시코를 금지하지 않는다. 고정 4인 프리셋과 자유로운 제노타입 선택을 구분한다.
- 민간 세력은 매켄지·텍사스·동부, 극지대는 북극, PMC는 멕시코 비중을 높이는 분포를 후속안으로 권장한다. 이번에 현재 20%×5 확률을 임의로 바꾸지 않는다.
- 유전 가능한 계통과 BTX 공통 의존은 유지하는 방향을 권장한다. 단, 혼혈에서 좋은 유전자만 모으는 비용·공통 유전자 중복·생식 제약은 실제 구현 전에 따로 설계한다.

## 후속 설계 순서

1. 위 역할표를 확정한 뒤 현재 유전자별 유지/제거/대체 표를 작성한다.
2. 공통 명사수 수치와 아종별 사격 특성이 중복 적용되는지 분리한다. T2-32 산탄 밸런싱은 공개 이후 별도로 다룬다.
3. BTX·식량·치료·연구·온도·이동·체격을 동일한 4인 시작에서 비교한다.
4. 그때 시작 프리셋·세력 생성·번역·외형과 쓰지 않는 구형 참조를 한 번에 갱신한다.

크립조이너의 변칙 능력·대가·후속 사건은 이 다섯 계통의 일반 합류와 섞지 않고 별도 콘셉트로 남긴다.
