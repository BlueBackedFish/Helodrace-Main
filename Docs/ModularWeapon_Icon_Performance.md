# 모듈 총기 아이콘 합성 부하 수정

기존 구현은 캐시가 없는 외형마다 원본 크기(주로 1024×1024)의 GPU 텍스처를 ReadPixels/GetPixels로 읽고, 알파 영역 탐색 및 256×256 레이어 합성을 한 번의 GUI 호출에서 수행했다. 오프셋 변경은 새 외형을 계속 만들어 이 비용이 드래그 중 반복됐다.

- 입력/Layout 이벤트에서는 합성하거나 외형 키를 만들지 않는다.
- 마지막 외형 변경 후 0.2초가 지나면 합성을 시작한다. 변경 중에는 이전 아이콘 또는 기본 아이콘을 표시한다.
- 합성은 Repaint 프레임당 하나의 요청만 처리하며 Stopwatch 기준 약 2ms 작업 예산을 사용한다. GPU readback과 Unity 텍스처 업로드 자체는 중간에 분할할 수 없으므로 엄격한 최대 프레임 시간 보장은 아니다.
- 원본은 최대 256×256으로 GPU에서 축소한 뒤 Color32로 읽는다. 소스 픽셀과 알파 경계를 96개까지 공유해 보관한다(픽셀 배열 최대 약 24MiB).
- 픽셀마다 계산하던 sin/cos는 레이어마다 한 번만 계산하며 완전 투명 픽셀은 합성하지 않는다.
- 완성 아이콘 캐시 128개, 동일 외형 공유, 레이어/반전/회전 및 외형 변경 감지는 유지한다.
- 외형 변경 도중 진행 중인 합성은 폐기한다. 캐시에서 제거된 아이콘을 계속 재사용하지 않도록 확인한다.

검증: net48 빌드 경고 0/오류 0. 게임 내 프레임 시간 계측 및 조작 체감 테스트는 아직 수행하지 않았다. 최초 에셋 로드 및 다른 모드의 지연까지 해결됐다고 단정하지 않는다.
