# T2-19 담배 무드

2026-11-03. 기존 담배의 화학 오락 0.35·니코틴 내성/의존·각성 효과는 유지하고 `HD_NicotineRush`가 존재하는 동안 **무드 +3**인 상황 생각 `HD_CigaretteCalm`을 연결했다.

별도 기억이나 흡연 횟수별 보너스를 만들지 않는다. 같은 상황 생각은 하나이며 기존 니코틴 효과가 끝나면 즉시 비활성화한다. 기본 효과 강도 1과 하루 −12의 감소에서 최대 약 2게임시간이며, 내성으로 처음 받는 효과가 작으면 더 짧다. 연속 흡연으로 기억이 쌓이지 않고 기존 효과의 시간만 영향을 받는다. 금단 페널티는 원래 니코틴 의존 경로를 사용한다.

실제 1.7 `.codex-staging/StageK/events-mood-03`에서 네 폰에 대해 효과 없음→활성 +3→재흡연 시 효과 1개→종료 시 무드 해제의 16검사를 통과했다. 네이티브 맵에 등장한 폰과 실제 흡연 직후 강도 1로 확인했다. 전체 이벤트·무드 검증은 35 PASS·COMPLETE다. 담배 1,500틱 흡연 애니메이션이나 장시간 내성 누적 플레이는 이 검사의 범위가 아니다.
