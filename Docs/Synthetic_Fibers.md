# 합성섬유와 1x1 방사 모듈

2026-11-04. 교반식 탱크 반응기에 인접해 설치하는 방사 모듈 `HD_FiberSpinningModule`과 나일론 `HD_Nylon`, 아라미드 `HD_Aramid`를 추가한다.

## 생산

작업 목록은 **방사 모듈**에 있다. 반응기에 바로 붙여 설치하면 기본 게임 시설 연결이 만들어진다. 모듈과 같은 세력의 정상 교반식 탱크 반응기가 연결되고, 양쪽에 전력이 공급되며 스위치가 켜져 있어야 작업할 수 있다. 떨어진 모듈이나 고압 반응기는 이 조건을 충족하지 않는다. 모듈 설명과 조사 창에서 연결 조건을 안내한다.

| 제작법 | 원료 | 산출 | 작업량 / 제작 기술 | 연구 |
|---|---|---|---|---|
| 나일론 방사 | 화학연료 12 + 질산암모늄 1 | 나일론 20 | 4000 / 6 | 하버-보슈 `HelodHaberBosch` |
| 아라미드 방사 | 방향족 기초유분 12 + 질산암모늄 1 | 아라미드 20 | 6000 / 10 | 냉전 기술 `HelodColdWarTech` |

원료와 수율은 사용자 지정에 따른 게임 공정이다. 반응·방사·직물 마무리를 이 설비 조합으로 추상화한다. 방사 모듈은 하버-보슈 연구로 해금되며 강철 40·탄소강 30·범용 기계 부품 6·기초 전기 부품 4로 건설한다. 면적 1x1, 체력 200, 건설 작업량 2500, 전면 작업 칸 1칸이다.

작업 중 모듈은 500W, 연결 반응기는 기존 정격 1200W를 사용한다. 방사 작업이 반응기의 `UsedThisTick`도 호출하므로 반응기 가동 전력·열 처리가 함께 적용된다. 일반 유휴 상태는 각각 50W·120W다. 반응기 연결/전력/스위치가 끊어지면 진행 중 작업을 중단한다. 기존 미완성 산업 배치로 진행도와 원료를 보관하고 복구 후 이어 만든다.

기존 시설 요구 조합법에는 새 전력 조건을 강제하지 않는다. 두 섬유 조합법만 `RecipeExtension_RequiredFacility.requireOperationalFacility`를 켠다. 모듈 가동은 기본 작업대 사용 가능 검사에도 반응기 조건을 적용한다. 추가 저장 필드는 없으며 연결 목록과 미완성품은 기존 엔진 계약을 사용한다.

## 재료와 그림

두 재료는 `Fabric` 재료와 `Textiles` 분류를 사용하므로 일반 옷감 제작에 선택할 수 있다. 나일론은 가벼운 일반 합성 원단, 아라미드는 내구와 방어 쪽에 무게를 둔 원단이다. 시장가는 각각 **2.4 / 8 은**으로 산업 부품 32보다 낮다. 기존 25종과 합쳐 산업 중간재 27종에 같은 가격 기준을 적용한다.

| 게임 재료 수치 | 나일론 | 아라미드 |
|---|---:|---:|
| 날카로움 / 둔기 / 열 방어 재료 계수 | 0.45 / 0.10 / 0.25 | 1.25 / 0.35 / 0.80 |
| 추위 / 더위 단열 | 20 / 18 | 18 / 26 |
| 재료에 따른 제품 체력 배율 | 1.15 | 1.50 |
| 질량 | 0.018 | 0.026 |

이 값은 게임용 초기 설정이다. 방어는 해당 의류의 기본 수치와 재료 계수로 계산된다.

[Blender 원본·재생성·아트 검수](../ArtSource/FiberSpinning/README.md). 모듈은 기존 건물 규격의 네 방향 256px 렌더·마스크와 12px 윤곽선이다. 나일론·아라미드는 바닐라 천 스택 원본에 전용 공유 색상 마스크를 적용한다. 나일론은 회백색, 아라미드는 황금색이며, 이전 3D 롤 그림과 재생성 코드는 제거했다. [방탄 장비 제작 연결](Armor_Material_Recipes.md). 모듈의 카메라 보정과 XML drawOffset을 맞췄다.

## 검증

최초 모듈·생산 통합 검증(당시 3D 롤 그림): 실제 RimWorld 1.7.4995 rev309 `.codex-staging/FiberSpinning/native-02`: **50 PASS, COMPLETE, FAIL 없음**. [검사 원문](Data/SyntheticFibers/native-checks.txt), [버전·동일 배포 DLL 해시](Data/SyntheticFibers/verification.json).

기본 전력망·인접 시설 연결·작업 제공자·실제 제작 작업을 사용했다. 분리된 모듈 거부, 작업 목록 위치, 양쪽 스위치·반응기 전력 차단, 500W+1200W 작업 부하, 실제 나일론 작업 도중 차단·13개 원료 및 진행도 보존·같은 작업 재개와 정확한 20개 산출을 확인했다. 아라미드도 정확한 12+1 소비와 20개 산출을 확인했다. 두 재료의 기본 게임 Fabric 제작 허용·재료가 적용된 의류 생성, 두 스택 그림과 모듈 네 방향 그림, 반응기 철거/재설치 후 연결 복원을 검사했다. 욕구·기후·외부 방해를 제어한 기능 검사이며 장기 밸런스 실측이나 전체 저장/로드 검사는 아니다.

정적 레시피 93개·구체 ThingDef 544개, 중간재 27종 가격과 아트 출력 12PNG·세 Blender 원본 검증도 통과했다. 첫 실행은 스위치 복구 직후 전력망 갱신을 기다리지 않은 검사 조건을 바로잡았고, 최종 로그의 ERROR는 기존 Workshop 항목 3781143823 폴더 부재 1건뿐이다. 당시 DLL/PDB는 해당 호스트 파일과 동일했다. 현재 천 마스크·방탄 장비 제작 연결은 [후속 검증](Armor_Material_Recipes.md)을 따른다. 새 제품 코드는 Verse/RimWorld의 기존 작업대·시설·가동 계약과 .NET 타입을 사용하며 Unity API 경계를 추가하지 않는다.
