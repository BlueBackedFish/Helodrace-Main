# 모듈형 총기 스탯 역할·정확도 분리 설계

2026-10-18. **설계 제안이며 아직 정확도 코드·원시 필드·파츠 수치를 개편하지 않았다.** 이번에 적용한 것은 최신 파츠 배치 저장본이다. 다음 구현은 아래 계약을 기준으로 진행한다.

## 1. 결정할 큰 방향

**총기 고유 정밀도는 상한, 조준기는 그 상한을 활용하는 수단, 개머리판·그립은 조준 유지와 발사 후 회복 수단으로 나눈다.**

- 총기 자체가 흩뿌리는 탄착을 고배율 조준경이 줄여주지 않는다.
- 잘 맞는 총이어도 조준선이 없거나 불안정하게 들고 있으면 제 성능을 내지 못한다.
- 조준 준비 시간, 조준 유지 정확도, 사격 후 회복, 기계식 발사간격을 서로 다른 출력으로 둔다.
- 초근·근·중·원거리 정확도는 이 요소들을 합성한 장비 측 결과다. 사수 사격 능력·엄폐·표적 크기·이동 등의 최종 명중 판정은 바닐라에 남긴다.

현재 `ModularWeaponConvertedStats.cs`의 `aimingPrecision`에는 총열·탄약·트리거·총몸의 기여가 함께 들어간다. 이후 조작성·반동 값과 거리별 정확도로 환산하고 `ModularWeaponSightPerformance`의 그룹 배율을 곱한다. 광학 그룹 중첩 방지는 이미 있지만, 기계 정밀도와 조준 오차를 별도 출력으로 설명하기는 어렵다. 이 부분을 분리하는 것이 핵심이다.

## 2. 원시 스탯 정리안

0~100점은 실측 확률이 아닌 제작용 등급이다. 본체는 기준값을 갖고 파츠는 가감점을 준다. 점수를 피해량이나 관통력으로 재사용하지 않는다.

| 원시 항목 | 역할 | 기여하는 파츠 | 영향을 주지 않는 것 |
|---|---|---|---|
| `mechanicalPrecision` 신규 | 총기·탄종의 고유 탄착 정밀도 | 총열의 품질/구조, 총몸·폐쇄 정렬, 탄약 균일성 | 조준기, 조준 시간, 반동, 피해/AP |
| `aimStability` 신규 | 조준 중 흔들림·유지 오차 | 개머리판, 그립, 전방손잡이, 트리거 | 기계 정밀도, 기계식 RPM |
| `aimSpeed` 통합 | 조준 획득·무기 전환 속도 | 그립·개머리판·조작계의 사용성 | 기계 정밀도, 직접적인 원거리 정확도 보너스 |
| `recoilImpulse` 유지 | 발사 후 후방 반동 부담 | 머즐, 소음기, 개머리판, 탄약, 가스 설정 | 첫 발의 기계 정밀도 |
| `muzzleRise` 유지 | 발사 후 총구 들림 부담 | 머즐, 소음기, 개머리판, 전방손잡이 | 탄자 자체의 분산 |
| `massKg` / 무게중심 / 관성 유지 | 들고 조작하는 물리적 비용 | 모든 파츠 | 무료 기계 정밀도·조준 안정성 보너스 |
| 신뢰성·가스 유량 유지 | 작동·고장·기계적 순환 | 볼트·가스계·버퍼·스프링 | 조준 정밀도 |
| 식별거리 유지 | 표적 식별·관측 유틸리티 | 관측 가능한 조준 그룹·사통장치 | 피해/AP, 거리별 명중률의 두 번째 보정 |
| 총열 길이·탄속·탄도 효율 유지 | 기존 탄도·파편화 시스템 | 총열과 탄종 등 허용된 기계 부품 | 조준경의 탄도 강화 |

`aimingPrecision`은 폐기하고 기존 기여를 파츠 역할별로 `mechanicalPrecision` 또는 `aimStability`에 옮긴다. 단순 이름 변경이나 두 항목에 동시 복사하지 않는다. `ergonomics`와 `targetAcquisition`은 `aimSpeed`로 합쳐 중복 보너스 경로를 없앤다. 질량·무게중심·관성으로 계산하는 `Handling`은 환산 진단값으로 남기며 원시 보너스로 다시 입력하지 않는다.

조준기 종류·배율·시야·가림·조준축은 **조준 그룹 프로필**에 속한다. 별도의 일반 파츠 `mechanicalPrecision` 보너스로 입력하지 않는다. 현재 `sight.aimRadius`는 가림 판정용 공간 폭이므로, 조준 정확도 점수로 해석하지 않는다. 구현 시 `sightClearanceRadius`처럼 목적이 분명한 이름으로 바꾸는 것이 좋다.

## 3. 바닐라 4거리로 내보내는 방식

설치된 RimWorld 1.6 `Data/Core/Defs/Stats/Stats_Weapons_Ranged.xml`의 기준은 다음과 같다. 별도 실거리 환산을 섞지 않는다.

| 출력 | 기준 거리 | 주로 구분할 성질 |
|---|---:|---|
| `AccuracyTouch` | 3셀 이하 | 근접 조준 방식·무기 유지, 기계 정밀도 차이는 작게 |
| `AccuracyShort` | 12셀 | 빠른 조준과 안정적인 유지 |
| `AccuracyMedium` | 25셀 | 기계 정밀도·조준선 활용·유지의 균형 |
| `AccuracyLong` | 40셀 이상 | 기계 정밀도 상한, 정밀 조준과 흔들림의 큰 영향 |

각 거리에 대해 세 출력을 만든다.

```text
M_i = 총기·탄종의 기계 정밀도 상한 (기본 품질 기준)
A_i = 그 거리에서 쓸 수 있는 조준 그룹 중 가장 높은 조준 효율 (0~1)
H_i = 조준 유지 효율 (0~1)

장비 정확도 P_i = M_i × A_i × H_i
바닐라 적용 배율 F_i = P_i / 총기 Def의 기본 Accuracy_i
```

상한이므로 항상 `P_i <= M_i`다. 예를 들어 원거리 `M=0.80`, `H=0.95`인 총에서 아이언 조준 효율이 0.84면 63.84%, 스코프 효율이 0.96이면 72.96%다. 스코프가 총 자체를 더 정밀하게 만든 것이 아니라 같은 상한을 더 잘 활용한 것이다. 이는 설명용 수치다.

현재 조준 프로필의 1.02·1.10 같은 **배율**을 새 `A_i`에 그대로 넣으면 안 된다. 새 효율은 0~1로 다시 보정한다. 총기군별 순정 상태를 기준으로 `M_ref,i = 현재 순정 P_ref,i / (A_ref,i × H_ref,i)`를 잡아 현재 기본 성능을 보존한다. 필요한 상한이 0.97을 넘으면 상한을 억지로 올리는 대신 조준/유지 기준의 과도한 불이익을 줄여 재보정한다.

정밀도 점수에 따른 `M_i` 변화는 초근에서 작고 원거리에서 크게 한다. 조준 안정성에 따른 `H_i` 변화도 거리와 함께 커지되, 근거리까지 전혀 무관해지지는 않게 한다. 구체적인 곡선 계수는 10종 총기·21개 프리셋을 기준으로 교정할 구현 항목이며, 이 설계 문서에서 확정된 수치로 취급하지 않는다.

최종 합성은 한 곳에서만 수행한다. 기존 바닐라 기본 정확도를 다시 곱하는 이중 계산, 파츠 `Accuracy* statFactors`와 새 원시 정밀도의 동시 적용을 금지한다. 품질과 다른 게임 시스템의 정상적인 StatPart 보정은 바닐라 경로에서 한 번만 받는다. 위 상한은 기본 품질 장비 모델의 상한이지 사수·품질을 무시하는 전역 최종 확률 제한이 아니다.

## 4. 조준 그룹의 역할

- 아이언: 가볍고 무난하며 장거리 조준 효율은 광학장비보다 낮다.
- 도트/홀로: 초근·근거리 획득/활용에 강점, 원거리 조준 효율에 한계가 있다.
- 고정배율: 중·원거리 활용에 강점, 초근·획득 속도에 단점이 있다.
- 확대기: 주 조준기와 한 그룹으로 계산한다. 별도의 정확도 보너스를 더하지 않는다.
- LPVO: 배율 상태별 프로필을 사용하도록 설계한다. 미구현 상태에서 모든 거리의 장점이 동시에 켜진 것으로 간주하지 않는다.
- 사통장치: 식별·거리 보조의 유틸리티와 전원·무게·가격 같은 비용을 가진다. 기계 정밀도 상한을 제거하지 않는다.

독립 조준 그룹 여러 개는 거리마다 `max(A_group,i)` 하나만 쓴다. 가려진 그룹은 제외하며, 조준선을 추가해도 총기/유지 점수가 중복 증가하지 않는다. 유효한 그룹이 하나라도 있으면 무조준 대체 프로필이 스코프의 근거리 단점을 지우지 않게 한다. 장착된 모든 그룹의 무게·관성 비용은 계속 적용한다.

## 5. 파츠별 용도와 보너스 예산

| 파츠 | 핵심 용도 | 허용할 성능 방향 | 주된 비용·금지 사항 |
|---|---|---|---|
| 총열 | 구경·길이·탄도와 탄착 특성 | 품질/구조별 기계 정밀도, 사거리, 파편화용 탄속 | 무게·관성·획득 시간. 길다는 이유만으로 고유 정밀도가 무조건 좋아지지는 않음 |
| 총몸·상부·폐쇄부 | 플랫폼과 정렬·작동 | 기계 정밀도의 기준, 제한적인 정렬 차이, 신뢰성 | 구조·호환성 비용. 여러 부품이 같은 기본 정밀도를 중복 지급하지 않음 |
| 볼트·가스계·버퍼 | 작동과 순환 | 신뢰성, 가스 유량, 반동/회복 | 조준/기계 정밀도 만능 보너스 금지 |
| 트리거 | 당김 중 조준 유지 | 조준 안정성, 제한적 획득 개선 | 총열의 탄착 상한이나 기계식 RPM을 직접 올리지 않음 |
| 개머리판·그립 | 지지와 자세 | 조준 안정성, 획득 속도, 반동·들림 제어 | 무게·길이·관성. 기계 정밀도 보너스 금지 |
| 전방손잡이 | 보조 손 지지 | 유지 안정성·들림 제어 | 유효 한 개만, 장착면에 따른 효율 유지 |
| 핸드가드·섀시 | 부착 공간·지지 구조 | 무게/관성 차이, 필요한 경우 유지 안정성 | 레일 수가 많다고 정확도 보너스를 주지 않음 |
| 머즐·소음기 | 발사 후 제어·섬광/소음 | 반동·들림·회복, 기존 억제 기능 | 무게·조준 획득 비용. 피해/AP·기계 정밀도·정적 조준 효율 보너스 금지 |
| 조준기·확대기 | 조준선 활용 | 그룹별 거리 효율, 조준 속도, 식별 | 무게·시야·근거리/원거리 트레이드오프 |
| 마운트·어댑터 | 연결·높이·가림 해결 | 유효 조준 그룹을 성립시키는 구조적 효용 | 독립적인 정확도 가산 없이 질량/기하로 평가 |
| 레이저·조명 | 근접 표적 획득·관측 | 한 유효 레이저의 근접 조준 보조, 조명 기능 | 기계 정밀도와 무관, 중복 광학 보너스 금지 |
| 탄창·예비 탄창 | 용량·급탄·재장전 | 기존 용량/예비탄창 기능 | 질량·취급 비용. 직접적인 정밀도/피해 보너스 금지 |
| 탄약 | 탄자 성질과 균일성 | 탄약별 기계 정밀도, 피해/AP/저지력/파편화, 반동 | 총열의 직접 피해/AP 증가와 분리. 듀플렉스의 추가 탄자 분산도 별도 유지 |
| 레일커버·테이프 | 접촉면·외형 | 커버는 작은 조작성 이득, 테이프는 장식 | 커버 감쇠·무게 유지. 원거리 정밀도 보너스 금지 |

한 파츠의 보너스는 주 역할 한 개와 보조 역할 한두 개로 제한한다. 정밀도·조준 유지·조준 속도·반동을 모두 강화하는 만능 파츠는 만들지 않는다. 핵심 기계 부품은 먼저 기준 성능을 구성하고, 선택 파츠가 그 위에 제한적인 차이를 만든다.

## 6. 보존할 규칙

- 순정 쿨다운은 바닐라 동급 수준을 유지한다. `aimSpeed`를 쿨다운과 RPM의 공통 지름길로 쓰지 않는다.
- 머즐은 미장착 대비 제어·회복 이득을 유지하되 무게 비용도 유지한다.
- 총열 길이는 직접 피해·관통을 바꾸지 않으며, 살상력 차이는 기존 파편화 경로를 쓴다.
- 파츠의 사거리 보정과 조준 그룹 사거리, 식별거리는 정확도와 별도 출력으로 유지한다. 식별거리 보너스를 사거리·정확도에 자동 복제하지 않는다.
- 유탄/보조 무기 그룹의 정확도와 탄도를 주 총기에 합산하지 않는다.
- CE에서는 바닐라 `Accuracy*` 배율을 또 적용하지 않는다. 같은 원시 모델의 기계 정밀도는 spread, 유지 오차는 sway, 획득은 조준 시간으로 대응시키되 CE 보정 경로는 별도 검증한다.

## 7. 다음 구현 순서·합격 조건

1. 원시 필드와 편집기·XML 내보내기·Undo·환산 UI를 함께 교체한다. 배포 전이므로 구형 필드를 읽는 호환 분기를 남기지 않는다.
2. 각 파츠의 기존 정밀도 기여를 역할별로 분류해 이전한다. 예: 총열/MATCH 탄약 → 기계 정밀도, 트리거/개머리판 → 유지 안정성, 광학 → 그룹 효율만.
3. 현재 정상 프리셋의 최종 4거리 정확도를 기준으로 기본값을 교정한다. 스탯 이름 개편만으로 전체 총기 명중률을 일괄 상승시키지 않는다.
4. 네 거리의 기계 상한·조준 효율·유지 효율·최종 정확도를 추적 가능하게 표시한다. 단일 정확도 막대 하나로 다시 숨기지 않는다.
5. 다음 변형 테스트를 통과시킨다.

   - 조준기만 교체하면 기계 정밀도는 동일하다.
   - 총열/탄약만 교체하면 조준 그룹 프로필은 동일하다.
   - 같은 조준 그룹 중복은 정확도 이득이 없고 질량 비용만 생긴다.
   - 저정밀 총기에 고배율을 달아도 해당 총기의 기계 상한을 넘지 않는다.
   - 그립/개머리판의 유지 안정성은 원거리에서 더 드러나지만 기계 정밀도는 바꾸지 않는다.
