## T2-37 고압반응기 작업 복구 — 완료

- 실제 1.7 기준 실행에서 `HD_HaberBoschHighPressureReactor`의 작업 배정자가 없음을 확인했다. 질산암모늄 조합법은 `Crafting` 작업을 요구하지만 해당 작업대의 `WorkGiverDef`가 누락돼 있었다.
- `DoBillsHD_HaberBoschHighPressureReactor`와 한국어 작업 문구를 추가했다. 기존 지식 능력·전력·연구·조합법 조건을 유지하고, 교반식 탱크 반응기의 배정자는 변경하지 않았다.
- 기준 증거: `.codex-staging/IndustryStage3/reactor-baseline-1/Evidence/checks.txt`의 빈 giver 목록.
- 수정 후 실제 게임 증거: `.codex-staging/IndustryStage3/reactor-fix-4/Evidence/checks.txt`의 `COMPLETE`, `FAIL` 없음. 실제 발전기 7대와 전선으로 공급한 전력망에서 무전력 거절 → 전력 복구 → 직접 제작 40개 → 자동 제작 40개 → 저장/불러오기 후 자동 제작 40개를 확인했다. 교반식 반응기의 TNT 자동 제작도 정량 완료했다.
- 실제 저장 파일: 같은 실행의 `Profile/Saves/IndustryStage3.rws`. 로그의 ERROR는 기존 미설치 WorkshopItem 3781143823 한 건뿐이며 새 작업·예약·제작 예외는 없다. 종료 수집 시 핸들이 없어 종료 코드는 `null`로 기록되었고 0으로 간주하지 않았다.
- `Source/Verify-RecipePlacement.ps1`은 고압반응기의 조합법·작업 종류·작업 배정 연결까지 검사한다. 제품·실게임 검사 모듈 빌드와 이 검사가 통과했다. 새 Unity API 의존성을 추가하지 않았다.
