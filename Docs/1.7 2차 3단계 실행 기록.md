## T2-14 총열 중간재 제거 — 완료

- 일반 제작용 총열 3종과 조합법 6개, 한국어 번역, 후대 가공 설비의 제작 목록 및 사용하지 않는 런타임 PNG 3장을 제거했다. 모듈러 무기의 교체용 총열, 포신과 원본 아트 파일은 이 대상에 포함하지 않는다. 구형 Def 별칭은 남기지 않았다.
- 기존 총열 한 개의 원재료를 그대로 최종 비용에 합쳤다. 저품질 총열은 탄소강 20, 산탄총 총열은 탄소강 25, 서부 총열은 탄소강 30·범용 기계 부품 1이다. 조합법 17개와 무기/건설/CROWS 비용 13개, 총 30개 사용처를 정리했다.
- 무기 조합법에는 가장 빠른 기존 총열 공정의 작업량(1,500·1,800·2,100)을 개수만큼 합쳤다. 건설은 다른 작업 종류이므로 건설 작업량을 늘리지 않았으며, 비용만 합산했다. 예: M1861은 탄소강 50·목재 15·기계 부품 1, 작업량 37,500이다.
- 최종 무기 가치가 원재료 비용을 반영하면서 M9A1의 값이 1,315가 됐다. 바주카 사수의 최소 장비 예산을 975에서 1,350으로 맞춰 무장 없이 생성될 수 있는 상태를 없앴다. 최대 예산과 전투 포인트는 유지했다.
- 실제 게임: `.codex-staging/IndustryStage3/barrel-final-1/Evidence/checks.txt`의 `COMPLETE`, `FAIL` 없음. 제거한 9개 Def가 실제 DB에 없고, 무기 조립은 여전히 연결 선반을 요구한다. 수동 선반을 연결한 기본작업대에서 새 총열 아이템 없이 M1861을 자동 제작하고 위 재료를 정확히 소비했다. 바주카 사수가 발사기를 갖고 생성되는 것도 확인했다.
- 수집한 로그의 ERROR는 기존 미설치 WorkshopItem 한 건뿐이다. 제품 빌드·작업대 배치·전체 정의 참조 검사를 통과했다. 구현 커밋: `0e2f1ea2`.

## T2-09·T2-06 공통 부품 대량 제작과 작업 분배 — 완료

- 공통 부품 7개군을 1·5·10개로 통일했다. 산업 부품 전환, 프레스 부품, 범용 기계 부품, 축, 균일 압연 강판, 기초 전기 부품, 기초 전자 부품의 총 21개 조합법이다. 재료는 정비례하며 할인하지 않는다. 5개 배치는 단품 4.5개분, 10개 배치는 단품 8개분의 작업량이다. 기존 프레스 부품의 단품·5개·10개 작업량이 모두 600이던 오류도 수정했다.
- 주 작업대는 프레스 부품→프레스, 범용 기계 부품→밀링, 축→수동/동력 선반, 강판→압연기, 전기·전자 조립과 비상 산업 부품 전환→기본작업대다. 더 비싼 범용 부품 선삭 조합법 3개는 제거하고 후대 기계의 제작 목록도 정리했다. 선반은 축 제작과 총기 조립 시설 역할을 유지한다. 별도 생산 관리 건물은 추가하지 않았다.
- 모든 공통 부품 조합법에 미완성 산업 배치를 적용했다. 정량 재료와 작업량·제작자를 보존하고 중단한 제작을 이어갈 수 있다. 한국어 문구와 [배치표](Recipe_Worktable_Mapping.md)를 갱신했다.
- 실제 게임: `.codex-staging/IndustryStage3/components-3/Evidence/checks.txt`의 `COMPLETE`, `FAIL` 없음. 실제 증기기관·축망에서 기계 4종을 구동해 21개 조합법의 정량 산출과 재료 소비를 확인했다. 기존 지원 작업대의 단품·5개·10개 노출도 검사했다. 연료 지속시간을 측정하는 검사는 아니므로 각 배치 사이에 기관 연료를 채웠다.

- 제품·검사 빌드, 기존 1단계 검사 빌드, `Verify-RecipePlacement.ps1`의 85개 조합법·531개 정의 및 7개 부품군 검사를 통과했다. 수집 로그의 ERROR는 기존 미설치 WorkshopItem 한 건뿐이다. 구현 커밋: `4d1eaa6b`.
- 초기 재료 집계 실패는 다음 실행의 상세 수치에서 재현되지 않았다. 이후 테스트 fixture는 운반 중인 재료까지 집계하고 플레이어 소유 재고만 계산하며, storyteller를 꺼 외부 사건이 생산 장부에 섞이지 않게 한다. 제품의 재료 요구량을 줄여 검사를 우회하지 않았다.
