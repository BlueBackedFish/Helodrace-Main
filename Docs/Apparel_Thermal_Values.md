# 의상 단열값 보완

단열값이 없던 의복·방어구·모자 14종에 `Insulation_Cold`와 `Insulation_Heat` 기본값을 추가했습니다. 단위는 착용자의 쾌적 온도 범위를 넓히는 °C입니다. 품질이 적용되는 의상은 실제 단열값이 품질에 따라 달라집니다.

| 의상 | 추위 | 더위 |
| --- | ---: | ---: |
| M1952A 방탄조끼 | 1 | 0.5 |
| M1 헬멧 | 1 | 0.5 |
| Storm-front 안감 | 6.3 | 3.6 |
| Storm-front 외피 | 9.9 | 2.7 |
| Trench 군복 안감 | 6.3 | 3.6 |
| Trench 방어 코트 | 9.9 | 2.7 |
| ACS 전투 셔츠 | 3.6 | 4.5 |
| FAST MT 헬멧 | 1 | 0.5 |
| IBTV 방탄복 | 2 | 0.5 |
| UCP 상의 | 6.3 | 3.6 |
| UCP 바지 | 3.6 | 1.44 |
| 서부 정장 셔츠 | 4.5 | 4.5 |
| 서부 프록 코트 | 9.9 | 4.5 |
| 금속조끼 | 1 | 0.5 |

대전 군복 4종과 서부 정장 셔츠·프록 코트는 기존 단열 배율에 바닐라 Cloth의 단열값 18을 곱한 값을 직접 기본값으로 설정했습니다. 이 의상들은 고정 재료 제작이라 소재 배율이 작동하지 않습니다.

UCP 바지는 바닐라 천 바지의 배율 0.20/0.08을 참고했습니다. UCP 상의는 군복 안감과 맞췄으며 ACS는 추위 보호보다 더위 보호를 높게 설정했습니다. 조끼와 헬멧은 바닐라 방탄조끼의 추위 단열 1을 참고하여 낮은 보완값을 설정했습니다. 이는 실제 장비의 실측값이 아닌 게임 균형을 위한 값입니다.

기존에 정상 단열값 또는 유효한 소재 배율이 있는 의상은 유지했습니다. 벨트·파우치·보조 장비, 통풍, 방어력 및 제작 재료 설정은 이번 변경에 포함하지 않았습니다.
