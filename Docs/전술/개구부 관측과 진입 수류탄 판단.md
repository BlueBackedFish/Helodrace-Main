# 개구부 관측과 진입 수류탄 판단

진입 순서는 집결 → 돌파 → **개구부 관측** → 지원 투척 → 폭발/효과 및 투척자 복귀 대기 → 진입이다. 이미 점유한 방 정리는 이 과정을 새로 만들지 않는다.

공병이 작업하는 동안 다른 인원 한 명을 관측자로 선정해 개구부 밖 대각선 옆 칸으로 이동시킨다. 전방에는 벽이 있어야 하며 개구부 중앙과 정면 칸에는 서지 않는다. 현재 출발 방과 같은 영역의 도달·예약 가능한 위치만 고르고, 공병·다른 인원의 자리·진행 중인 장비/응급 작업과 겹치지 않게 한다. 가능한 벽 옆 자리가 없으면 무리하게 정면 관측을 만들지 않고 관측 불가를 기록한다.

개구부가 열린 다음 옆 칸에 도착한 관측자가 **최대 90틱(1.5초)** 안쪽을 본다. 걷거나 벽이 닫힌 시간은 관측 시간에 포함하지 않는다. 적을 실제로 발견하면 시간 만료를 기다리지 않고 즉시 몸 기울임을 풀고 원래 대형 자리로 뛰어 복귀한다. `PawnLeaner.ShouldLean`에 현재 관측 작업의 인접 시야 시작 칸을 연결해 바닐라 사격과 같은 반 칸 몸 기울임을 표시한다. 폰의 실제 위치를 개구부 안으로 옮기지 않는다. 관측 중에는 사격/연사를 시작하지 않으며, 작업을 중단하면 이 제한과 강제 기울임도 풀린다.

관측 중 개구부 너머 해당 공간의 14칸 범위에서 실제 LOS로 보이는 적을 매 틱 검사한다. 첫 적을 발견하면 `EnemyCell` 하나만 저장하고 가시 영역 기록을 지운다. 추가 적과 빈 셀 정보를 더 수집하지 않는다. 적을 못 봤을 때만 빈 공간의 가시 영역을 30틱 간격으로 갱신한다. 전 맵의 적 위치를 투척 판단에 사용하지 않는다. 관측자 사망·회피·작업 중단 시 대체 관측자를 선정할 수 있고, 관측 단계의 정상 대기 상한은 300틱이다. 수류탄 회피와 저격/지원 대응이 먼저 실행되므로 위험한 상황에서 관측을 강제하지 않는다. C4 후퇴 때는 관측 작업을 취소하고 폭파 후 다시 선정한다. 아군이 열 수 있는 재사용 문은 옆에서 수동으로 열어 관측하고, 적 잠긴 문은 공병 돌파가 필요하다.

지원 종류는 출발지가 아닌 **개구부 바로 너머 공간**으로 결정한다.

- 야외: HC 등 기존 안전 연막을 사용한다. 실내에서 야외로 나갈 때도 적용한다.
- 실내 17칸 이상: 해당 시대/교리에 맞는 기존 수류탄을 사용한다. 외벽에서 실내로 들어갈 때도 적용한다.
- 실내 16칸 이하: 적을 관측하지 못했으면 수류탄을 아낀다. 적을 직접 관측했으면 방 크기 제한을 무시하고 해당 위치에 투척을 시도한다. 고급 교리의 비살상 수류탄도 같은 기준을 적용한다.

방 크기는 고정된 습격 시작 구조 캐시의 바닥 면적이다. 가구가 놓인 칸도 포함하고 벽·문·야외 칸은 제외한다. 기존 백그라운드 구조 계산에 방별 면적 집계를 추가했고 저장 캐시 복원 시에는 기존 디코딩 루프에서 복구한다. 전술 판단마다 전 맵을 스캔하지 않는다. 새 벽으로 방이 분할되는 경우 면적 기준은 원래 캐시 방을 따른다.

적 접촉 기록이 있으면 **처음 본 적 위치 하나만** 투척 목표로 사용한다. 안전하게 던질 수 없으면 다른 빈 구역으로 바꿔 던지지 않는다. 야외 접촉은 기존 연막 종류를 유지하되 그 적 위치로 던진다. 적을 못 봤을 때만 관측 시야 밖 구역을 시도한다. 보이는 빈 셀은 무조건 던지는 대체 목표로 쓰지 않는다. 이미 방이 전부 보이고 적을 못 봤으면 수류탄을 쓰지 않을 수 있다. 목표가 관측 시야 밖이라는 이유로 벽 너머 투척을 허용하지 않으며, 실제 투척 위치의 기존 LOS·사거리·산포·파편·아군 안전 검사가 최종 실행을 결정한다. 관측 위치도 투척 위치 후보에 포함한다.

관측자는 지원 전 기존 대형으로 복귀한다. 관측 작업 자체에 종료 직후 복귀 이동 단계를 두고 `ReturnComplete`가 확인돼야 정상적으로 지원 단계에 넘긴다. 복귀 작업이 중단되면 실행 제어에서 원래 자리로의 이동을 이어간다. 관측/수류탄 작업의 이동에도 기존 진입 전 방 경계 이동 제한을 적용한다. 실제 발사체·폭발 효과·투척자 복귀 완료를 기다리는 조건은 유지하고, 기존 저급 교리의 고정 300틱 추가 진입 대기는 30틱으로 줄였다. 관측 기록은 실행 상태에 저장하고 다음 방 계획에서 초기화한다. 개발자 전술 상세 보고에 관측자·위치·진행 틱·복귀 완료·가시 셀·첫 적 위치를 표시한다.

검증: 관측 자리 4방향, 단일 적 위치만 선택/불가능한 접촉 투척은 중단/접촉 없는 미관측 구역 대체/전부 보이는 빈 방, 실제 바닐라 lean 연결과 중단 해제, 실제 생성 이동/관측/즉시 복귀 Toil 및 도착 이후 복귀 완료 표시, 첫 접촉 즉시 종료와 추가 정보 수집 거부, 사격 제한 해제, XML/한국어 보고, 공병 작업부터 관측으로의 인계 및 C4 후퇴·담당자·계획 변경 시 취소를 확인하는 29개 게임 클래스 검사와 Harmony 대상 검사를 포함한다. 순수 판단 검사에는 적 접촉이 16칸 제한을 무시하는 조건과 야외 접촉의 연막 유지 조건을 추가했다. 실제 게임 내 몸 기울임 표시, 위험 회피 중 대체 관측과 저장/로드 재현은 별도 실전 확인이 필요하다.

수류탄 이후 반복 오류: `Player.log`의 `[Ref 15F5DD1E]`는 `RaidMovementArea.cs`의 지원 수류탄 회피 판단에서 발생했다. 작업이 끝나 복귀 작업을 고르는 동안 `pawn.CurJob`이 비어 있는데 `jobGiver`를 직접 읽던 것이 원인이다. 현재 작업이 없는 상태를 정상 작업 전환으로 처리하도록 고쳤고, 작업 공백·실제 지원탄 회피·다른 폭발물·추적탄 없는 경우를 확인하는 회귀 검사 4개를 추가했다.
