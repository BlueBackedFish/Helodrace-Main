# 현황
성능 합격
약 1.3-1.7배 부하가 늘어도 문제 없을 정도의 성능 상황
성능 테스트는 개발 계획에서 제외하고 사용자가 직접 진행함. 성능 문제가 발견되면 그때 해당 부분만 조사·측정함. 개발 중에는 빌드와 직접 관련된 짧은 확인만 진행함. 구간별 메서드 분석과 세이브 안정성 테스트는 필수로 하지 않으며, 게임에서 약식 확인 가능한 기능은 별도 테스트 목록에 기록해 개발 진행과 분리함.

적 관측은 적대 관계뿐 아니라 실제 원거리 위협으로 볼 수 있는 공격 수단이 있는지도 확인해야 함. 원거리 위협으로 판단하기 무리가 있는 대상은 처음부터 적 관측·기억·보고에 등록하지 않음. 특정 동물 종류를 제외하는 규칙이 아님. 근접 DPS만으로 원거리 위협으로 판정하지 않음. 실제 공격을 받았을 때의 긴급 대응은 별도 유지함
