# 전술 AI 재설계 문서

2026-10-08. 현재 작업은 `main`에서 진행한다. R0/R1 실험 브랜치 기록은 fast-forward로 보존했다. 기존 상태 보존 커밋: `b837a006`.

새 전술 AI는 **바닐라 대비 메인 스레드 CPU 사용시간 2배 이하**를 목표로 처음부터 설계한다. 이전 코드의 캐시 맵·이동 마스크·전술 노드 구현을 유지할 의무는 없다. 사용자가 기대한 행동을 같거나 비슷하게 구현하는 것이 기준이다.

새 문서의 R0~R7은 이전 통합 계획 1~8단계, 구조 개편 A~D, 최적화 1~4순위와 다른 구분이다. **이전 구현 완료 상태를 새 구현 완료로 가져오지 않는다.** R0 정리와 R1 엔진 격리·대조 수집/실제 검증을 완료했다. R2 최소 돌파·진입과 최종 검증을 완료했다. 60/204명 일반 접근·외벽 돌파에서 각 3회 대조가 모두 CPU 2배 기준을 통과했고, 소규모 기능 회귀 6개도 통과했다. 현재 `New`는 지속 작업과 분대 지휘로 연결 스택·해머 돌파·공통 개구부 진입을 실행한다. 이 결과는 R2 최소 행동 범위의 합격이며 R3 이후 CQB·연락·야전의 완료를 의미하지 않는다. 실행 방법은 [R1 실행기](../../Source/Benchmarks/TacticalEngineAudit/README.md)에 있다.

## 문서 정리 범위

- 기존 `Docs/전술`의 문서 48개와 측정 JSON 11개를 아카이브로 옮겼다. 이전 `Docs/TacticalMapAnalysis.md`, `Docs/TacticalRaidReview.md`도 함께 보관한다.
- 아카이브의 과거 계획·완료·다음 작업 표현은 당시 기록이다. 새 브랜치의 실행 순서는 위 로드맵을 따른다. 상대 링크는 이동한 위치에 맞춰 조정했다.
- 장비·편제의 현재 기준인 [SquadSystem](../SquadSystem.md), [분대 구현 현황](../SquadSystem_Implementation.md)은 원래 위치에 둔다. 장비 정의·텍스처·폰 생성 조건은 이번 계획 작업에서 바꾸지 않는다.
- [TacticalMovement](../TacticalMovement.md)는 플레이어용 CQB/사격 기술 설계이므로 습격 AI 계획과 함께 옮기지 않는다. TCCC와 다른 시스템 문서도 그대로 둔다.
- 프로파일러의 [사용 안내](../../Source/Tools/AgentProfiler/README.md)와 `Source/Benchmarks` 원자료는 유지한다. 과거 측정은 병목의 참고 자료이며 새 체계의 성능 합격 증거가 아니다.
