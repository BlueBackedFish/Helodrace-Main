# A1.4 사격 집중 AI 구현

2026-10-11. [후속 로드맵](습격%20시스템%20후속%20로드맵.md)의 A1.4 구현 기록. A3.1의 조별 집결 보완은 이번 작업에 포함하지 않는다.

## 근접 위협 입력과 제한된 보고 — 완료

기존 사격 LOS 기반 관측에 별도의 근접 위협 스냅샷을 연결했다. 보이는 적이 아군을 대상으로 현재 근접 공격 Job을 수행하거나, 공격적 정신 상태의 근접 대상이 실제 관측 위치 변화로 접근할 때만 위험을 등록한다. 현재 공격 의도만 샘플하고 미래 경로·시야 밖 Job을 조회하지 않는다. 근접 기록은 원거리 접촉 기억과 분리되어 기존 원거리 적격성 필터를 유지한다.

후보는 분대당 최대 6개, 유효 기간은 마지막 관측부터 180틱이다. 공격 의도가 있을 때 3칸 이내/10칸 이내/30칸 이내의 접촉 위험을 구분한다. 같은 위험 구간에서는 활성 방어막을 우선하고, 더 급박한 접촉은 방어막 여부보다 우선한다. 표적 유지 후보는 90틱, 판단 간격은 30틱이다. 방어막은 관측 순간의 바닐라 `CompShield.ShieldState`와 착용한 본 모드의 방탄 방패 컴포넌트를 확인한다. 방어막 소실 자체는 근접 위협 해제 조건이 아니다.

LOW 접촉·High 실제 방탄복 무전 파츠의 기존 채널 검사·전달 지연·64개 공유 큐를 재사용한다. 한 교환에서 근접/원거리 보고를 합해 최대 2개만 보낸다. 근접 보고는 별도 값 객체이며 관측한 후퇴 등은 위험도 0의 최신 샘플로 이전 위험을 해제한다. 오래된 보고가 새 상태를 덮어쓰지 않으며 수신 정보는 다른 분대로 자동 재전송하지 않는다.

검증: 모드 빌드 경고/오류 0개. `--a1-focus`의 근접 우선순위·유지/긴급 전환·방어막 소실·보고 분리/만료·바닐라 Scribe 값 저장 검사 18개, 기존 관측 검사 17개, 접촉 기억 검사, 연락/무전/보고 큐 검사 32개 통과. Unity 실행·게임 기능 시험을 수행했다는 뜻은 아니다.

## 집중 사격 실행과 일반 교전 반환 — 완료

분대가 한 표적을 공유하고 `HD_NewTacticalFocusFire` 작업으로 현재 자리에서 대응한다. 새 이동·엄폐 탐색은 만들지 않고 실제 무기 사거리·사격 LOS를 통과한 인원만 참여한다. 실제 인접 공격은 별도 근접 위험 샘플로 긴급 판단을 깨우며, 밀착된 대상에는 바닐라 근접 반격을 사용할 수 있다. 개구부 관측의 실제 근접 공격자도 같은 별도 입력으로 연결하고 원거리 기억에 섞지 않는다.

사격 참여 후보는 순환 커서로 처리해 앞 인원의 LOS 실패가 뒤 인원을 막지 않게 했다. LOS 실패 인원은 60틱 후 재확인하고 표적 교체 때 재확인 대기를 해제한다. 표적 선택은 30틱 간격, 사격은 30~36틱 간격에 확인한다. 움직인 표적은 마지막 관측 좌표의 반경 3칸·최대 29칸에서 같은 ID 후보를 찾고 실제 LOS를 확인한 뒤에만 새 좌표·위협 정보를 기록하거나 사격한다. 숨은 표적의 현재 좌표를 직접 조회하거나 그 근방을 무제한 확장하지 않는다. 관측/Job 발행/반환은 기존 전역 예산을 공유하며 국소 재관측·LOS·발사·일반 AI Job 복귀의 실제 경과 시간을 예산에 계상한다. 전 폰 쌍 비교나 새 맵 틱 컴포넌트는 추가하지 않았다.

집중 사격 상태는 `Focused → Returning → Normal`로 구분한다. 위협 사망/다운·공격 중단/위험 구간 이탈은 실제 관측 시 위험도 0으로 처리하고, 시야가 끊기면 마지막 샘플의 180틱 유효 기간 후 해제한다. 방어막 파괴 후에도 근접 공격 의도가 남으면 대응한다. 반환은 기존 한 틱당 1개 반환 예산으로 현재 소유한 전술 Job만 끝낸다. 일반 교전에서는 원래 Lord duty와 바닐라 AI가 적 선택·엄폐·사격·이동을 수행하며, 전술 유지 루프는 그 작업을 덮어쓰지 않는다. 최소 90틱과 가까운 유효 원거리 접촉이 있는 동안 일반 교전을 유지한다. 새 근접 위협은 다시 집중 사격으로 전환하고 접촉이 모두 만료되면 보존한 임무로 복귀한다.

진입 중인 폰은 개구부에서 멈추지 않게 보호하고, 관측/투척은 복귀를 마칠 때까지 보호한다. 복귀 후 남아 있는 Hold 작업은 영구 보호하지 않고 집중 사격/일반 교전에 넘긴다. 장비 회수·돌파·의료·CAS 유도·플레이어 강제 작업과 바닐라 도주 작업의 소유권을 존중한다. C4 절차·이미 투척한 개구부 수류탄의 폭발 안전·연막 투척 절차는 기존 컨트롤러가 완료한다. 본인이 알고 있는 가까운 폭발물은 집중 작업을 예산에 따라 해제해 바닐라 회피를 허용하며, 안전 이동을 다시 집중 사격으로 덮어쓰지 않는다. 위협 중에는 새 치료를 시작하지 않고 기존 치료의 안전 중단 경로를 사용한다.

분대 임무 단계·계획·확보 이력·화력 구역과 개구부 통과 플래그는 보존하고 집중 대응으로 멈춘 시간을 기존 임무/야전/접촉 응답 시계에 한 번만 반영한다. 새 표적 ID·마지막 관측 좌표/시각·판단/유지 시각·일반 교전 시작·단계·반환/참여 커서는 Scribe로 저장한다. 로드에서는 원래 Pawn Job ID 재연결을 재사용하고, 기억이 없거나 만료된 집중 표적은 안전하게 반환 단계로 전환한다. 숨은 Pawn을 조회하여 복원하지 않는다.

검증: 최종 모드 빌드 경고/오류 0개. `--a1-focus`에서 A1.4 45개(우선순위·국소 재관측 상한/ID 분리·반환/재개·원본 Job 소유권·진입/관측/의료 보호·임무 보존·모든 단계의 바닐라 Scribe 값 저장/로드), 기존 관측 17개, 접촉 기억, 연락/무전/큐 32개, 개구부/폭발/투척 안전 정책, 전역 작업 예산 검사가 통과했다. 저장 검사는 실제 Scribe 값 페이로드 및 복원 메서드 분석이며 Unity 게임 전체의 저장/로드 기능 테스트는 아니다. 정기 성능 수집이나 전체 기능 시험은 하지 않았다.

게임 기능은 [사용자 F16](습격%20기능%20약식%20테스트%20목록.md) 확인 대기다. 개발자 `Inspect squad commands`에 집중 단계·표적 ID·근접 후보 수를 표시한다. A3.1 조별 집결 보완과 이후 A2~A7은 이번 완료에 포함하지 않는다.
