# CQB 진입 후 목표 판정 정체 수정

2026-10-13. 진입 자리에 고정된 상태에서 다음 목표를 고르지 못한다는 보고를 바탕으로 코드 경로를 확인했다. 플레이 중 발생한 해당 장면을 세이브에서 재현한 결과는 아니며, 아래 정체 조건을 코드 검사로 재현하고 수정했다.

## HIGH 화력조의 작업 배정과 확보 이력 불일치

부모 분대는 공유 확보 정보만 확인해 다음 방을 배정했다. 실제 실행 조는 자체 확보 칸과 통과한 개구부 이력도 확인하므로, 부모가 배정한 방을 건너뛸 수 있었다. 이 경우 작업은 남은 채 후보만 끝나 600틱마다 재시도하고 현재 진입 자리를 유지했다. 공유 확보 기록이 재검토 상태가 되거나 기록 한도에서 밀려나면 자체 이력과 차이가 생길 수 있다.

작업 시작·배정·실행 전 유효성 검사를 같은 미진입 방 판정으로 통일했다. 배정 이후 다른 조가 그 방을 확보하면 아직 진입하지 않은 조의 오래된 작업을 종료하고 다음 배정으로 넘긴다. 이미 진입한 조의 조사와 살아 있는 폭발물 안전 절차는 기존 상태 흐름을 따른다.

할 일이 없는 조의 후보 확인은 전역 계획 계산 몫을 소비하지 않는다. 실제 후보를 찾았지만 계산 몫이 없으면 해당 후보의 인덱스를 보존해 다음 기회에 이어 간다.

## 끝나기 전에 초기화되던 돌파 대상 탐색

확보 공간 연결 탐색은 최대 128칸, 목표 구조물 탐색은 최대 256칸을 32칸씩 나눈다. 기존에는 확보 연결 캐시의 120틱 만료나 다른 분대의 공유 보고 변경, 구조물 캐시의 600틱 만료가 미완성 탐색까지 지웠다. 여러 분대가 계산 몫을 나눠 쓰는 동안 만료되면 앞부분만 반복하고 판단을 끝내지 못할 수 있었다.

이제 완료된 판단만 만료시키고 미완성 큐·방문 기록은 끝날 때까지 보존한다. 실제 목표나 대상 세력이 바뀌면 기존 목표 증거 탐색은 초기화한다. 계산 상한은 그대로이며, 필요한 갱신을 매틱 전역 재계산으로 바꾸지 않았다. 탐색 중 구조나 확보 상태가 달라진 결과는 다음 완료 판단의 만료 때 다시 확인할 수 있어 일시적으로 오래된 판단을 허용한다.

다음 계획 재시도 시간을 기다리는 Clear 상태는 조사·장비 회수가 필요하지 않으면 계획 계산 몫과 캐시 갱신을 건너뛴다.

## 검증과 남은 확인

- 빌드 오류·경고 없음.
- HIGH CQB 검사: 자체 확보/통과 이력의 재배정 방지, 배정 도중 확보 시 작업 종료, 대기 조의 계산 몫 보존, 계산 지연 시 같은 후보 재개. 기존 화력조 소유권·폭발 안전·저장 검사 포함.
- 목표/방 진행 검사: 매 계산 사이에 캐시 수명보다 긴 지연과 공유 보고 변경을 넣어도 탐색이 원래 총 칸수 상한 안에서 종료. 실제 목표가 있는 방의 판정 유지, 목표 변경 시 초기화, 완료 결과 만료, 재시도 대기의 계산 몫 보존 확인.
- 게임 내 재확인은 약식 목록 F47에서 수행한다. 원래 장면의 정체가 이 두 조건으로 모두 설명되는지는 아직 확인하지 않았다. 실제 CPU 감소율은 측정하지 않았다.
