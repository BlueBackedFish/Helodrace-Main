# CQB 적 접촉 기억과 동적 경계

## 1. 접촉 기억과 개발자 표시

전술 실행 조직별 `RaidContactMemory`에 적 ID, 관측 당시 이름·위치·방·관측자·시각·무장 사거리와 관측된 문/개구부를 저장한다. 적 Pawn 참조를 저장하지 않으므로 시야가 끊긴 뒤 실제 이동을 따라가지 않는다. 개구부 관측은 첫 적 하나만 확인하고 즉시 복귀하는 기존 동작을 유지하면서 그 접촉을 조직 기억에도 추가한다.

일반 관측은 분대 주변 24칸 안에서 20틱 간격으로 실제 LOS와 연막 차폐를 검사한다. 전술 실행의 기존 10틱 처리에 분산한다. 같은 적의 연속 관측 사이가 40틱 이하인 경우에만 이동 방향과 통과한 개구부를 기록하며, 시야 상실 후 재발견에서는 이동 경로를 추정하지 않는다. 문 칸은 인접 방 기준으로 처리한다. 목격한 사망·다운만 접촉을 제거한다.

기억은 최대 16개다. 시야 상실 후 마지막 관측으로부터 2초까지 최근 위치, 10초까지 방·개구부 경계, 20초까지 낮은 우선순위로 보관한 뒤 제거한다. 마지막 칸이 비어 있는 것을 실제로 보면 정확한 칸에 대한 신뢰만 해제하고 방 전체를 안전 처리하지 않는다. 다음 방 계획과 담당자 교체에서도 기억을 유지하고 저장/로드 후에는 다시 관측하기 전까지 현재 보이는 상태로 취급하지 않는다.

개발자 View의 **습격 적 관측 기억**에서 빨강 현재 접촉, 노랑 최근 접촉, 회색 오래된 기록과 마지막 통로를 확인한다. 기존 전술 표시처럼 0.5초마다 갱신하며 전술 상세 창에는 위치·방·관측 시간·방향·관측자·빈 칸 확인 여부를 표시한다. 화면 표시는 관측이나 전술 판단을 실행하지 않는다.

## 2. 후방·문·복도 경계 대응

실내에 진입한 조직은 현재 가까운 적, 진행 방향 뒤쪽 12칸 안의 적, 반대 방향에서 동시에 관측되는 적을 확인하면 기존 돌파 계획을 보존한 채 작업과 추가 진입을 잠시 중단한다. 일반 공병 도구와 발사 전 수류탄 준비·개구부 관측은 중단할 수 있지만 설치한 C4, 이미 발사한 수류탄과 효과/복귀 대기는 초기화하지 않는다. 폭발 회피·저격 대응과 명시적인 외부 지원 방어는 계속 우선한다.

관측한 문/개구부 또는 마지막 위치에 경계 인원을 지정한다. 보통 분대의 1/3, 최대 2명이고 복도 양쪽에 실제 적이 보이면 소규모 분대도 최대 2명을 배정한다. 공병·투척자·관측자·의료/장비 작업자는 평상시 경계 담당자로 고르지 않는다. 적이 사라지면 전체 중단을 해제하고 문 경계는 마지막 관측 후 10초까지 유지한다. 같은 통로의 여러 적은 하나의 경계로 묶고, 복도 앞뒤의 서로 다른 접촉은 각각 유지한다.

경계 자리는 현재 방에서 상하좌우 이동으로 연결된 반경 5칸 안에서 고르며 분대 기준점에서 10칸 이내로 제한한다. 담당자·자리를 유지하고 자리 소실, 큰 방향 변경 또는 실제 노출 시에만 120틱 간격으로 재탐색한다. 바닐라 이동/대기/사격을 사용하고 기본 스택업 명령이 경계 명령을 덮어쓰지 못하게 한다. 경계 인원은 일반 집결/진입 완료 인원 계산에서 제외하되 전원이 제외되면 기존 진입 인원을 유지한다. 경계 해제 때는 정상 임무 명령을 복원한다.

개발자 접촉 표시에는 경계 자리도 추가하고 상세 보고에는 담당자·경계 방향·만료 시각·작업 중단 여부를 표시한다.

## 3. 방 경계 상태와 재확인

기존 `ClearedRoomCells`는 돌파/정리 이력으로 유지한다. 별도의 `RaidRoomSecurity`에는 방별 마지막 위협 시각·접촉 지점·재확인 시각·다음 시도 시각을 저장한다. 적이 다시 관측되면 정리 이력을 지우지 않고 경계 상태만 재확인 필요로 바꾼다. 문이나 열린 벽 칸은 직접 붙은 방들의 경계 상태에 반영한다.

방 확보 판정, 확보 후 후퇴, 다음 방의 적 목표 후보, 방 내부 경계 이동과 닫힌 문 대응은 숨겨진 적의 현재 위치를 직접 조회하지 않고 관측 기억을 사용한다. 최근 적 접촉이 남아 있으면 방 정리 진행을 보류하고, 시야 상실 후에는 같은 방 안에서 마지막 접촉 구역을 확인한다. 접근해야 한다면 반경 3칸의 관측 후보 중 현재 인원에서 10칸 이내인 곳으로 최대 2명을 보낸다. 재탐색은 120틱 간격이다. 이는 마지막 접촉 구역의 재확인이며 숨은 방 전체에 적이 없다는 확정 정보가 아니다.

다음 방 계획 전에 최근 20초 이내에 재침입이 확인된 정리 방을 재확인 후보로 올린다. 국소 맵에서 현재 방과 기존 정리 방을 통해 열린 경로로 연결된 경우에만 이동한다. 도달 가능 영역은 한 번 계산해 후보들이 공유한다. 닫힌 적 문·새 벽·미확보 방을 지나야 하면 재확인을 보류하고 경계 기록을 남긴다. 재확인 계획에서는 반복 벽 돌파·개구부 재관측·진입 지원 수류탄을 요청하지 않으며, 이후 원래 최종 목표와 남은 방 정리를 계속한다. 오래된 기록은 재방문을 강제하지 않지만 확인 없이 안전 상태로 바꾸지도 않는다.

첫 관측 적의 ID를 수류탄 준비에 연결한다. 같은 적을 새로 관측했으면 최신 관측 위치를 사용한다. 투척 준비 중 목표가 바뀌거나 마지막 칸이 비어 있는 것을 확인하거나 위치 정보가 2초보다 오래되면 투척을 취소한다. 다른 적이나 빈 구역으로 임의 대체하지 않는다. 개구부 최소 2칸 거리, 투척 LOS·사거리·아군 안전 검사를 유지한다.

개발자 방 클리어 표시는 **분홍 적 관측 / 주황 재확인 필요**를 추가한다. 초록 이력이 있는 방도 현재 위협이 있으면 이 색을 우선 표시한다. 상세 창에는 마지막 위협/재확인 시각과 재확인 계획 여부를 표시한다.

## 검증과 실전 확인

게임 클래스 기반 검사에 접촉 기억·감쇠·동일 적 재발견·동시 전후방 접촉·문 경계 묶음·수류탄 목표 유효성·방 경계 재활성화·재확인 지원 투척 생략 등 43개 검사를 추가했다. 방 표시 검사에는 클리어 이력 보존·접촉 상실·재확인 완료의 3개 회귀 조건을 추가했다. 순수 경로 검사에는 이미 확보한 방을 통한 재확인과 닫힌 경로 거부를 추가했다. 기존 수류탄 준비·관측·사망 대응·연막·바닐라 Harmony 연결 검사도 함께 실행한다.

실제 게임에서 후방 침입, 다른 문으로 적 후퇴, 복도 양쪽 적의 시야 상실, 재확인 도중 문 폐쇄, 수류탄 준비 도중 적 이동, 저장/로드 후 재관측을 확인해야 한다. 자동 검사는 Unity 안에서의 사격·이동 애니메이션과 실전 전투 결과를 재현하지 않는다.
