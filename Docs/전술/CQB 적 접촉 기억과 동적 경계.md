# CQB 적 접촉 기억과 동적 경계

## 1. 접촉 기억과 개발자 표시

전술 실행 조직별 `RaidContactMemory`에 적 ID, 관측 당시 이름·위치·방·관측자·시각·무장 사거리와 관측된 문/개구부를 저장한다. 적 Pawn 참조를 저장하지 않으므로 시야가 끊긴 뒤 실제 이동을 따라가지 않는다. 개구부 관측은 첫 적 하나만 확인하고 즉시 복귀하는 기존 동작을 유지하면서 그 접촉을 조직 기억에도 추가한다.

일반 관측은 분대 주변 24칸 안에서 20틱 간격으로 실제 LOS와 연막 차폐를 검사한다. 전술 실행의 기존 10틱 처리에 분산한다. 같은 적의 연속 관측 사이가 40틱 이하인 경우에만 이동 방향과 통과한 개구부를 기록하며, 시야 상실 후 재발견에서는 이동 경로를 추정하지 않는다. 문 칸은 인접 방 기준으로 처리한다. 목격한 사망·다운만 접촉을 제거한다.

기억은 최대 16개다. 시야 상실 후 마지막 관측으로부터 2초까지 최근 위치, 10초까지 방·개구부 경계, 20초까지 낮은 우선순위로 보관한 뒤 제거한다. 마지막 칸이 비어 있는 것을 실제로 보면 정확한 칸에 대한 신뢰만 해제하고 방 전체를 안전 처리하지 않는다. 다음 방 계획과 담당자 교체에서도 기억을 유지하고 저장/로드 후에는 다시 관측하기 전까지 현재 보이는 상태로 취급하지 않는다.

개발자 View의 **습격 적 관측 기억**에서 빨강 현재 접촉, 노랑 최근 접촉, 회색 오래된 기록과 마지막 통로를 확인한다. 기존 전술 표시처럼 0.5초마다 갱신하며 전술 상세 창에는 위치·방·관측 시간·방향·관측자·빈 칸 확인 여부를 표시한다. 화면 표시는 관측이나 전술 판단을 실행하지 않는다.

## 이후 연결 순서

2. 후방·다른 문·복도 양방향 접촉을 경계 인원 배치와 임시 작업 중단에 연결한다. 경계 자리와 담당자를 유지해 대형 왕복을 막고, 실제 폭발 회피와 저격 대응을 우선한다.
3. 돌파/정리 이력과 현재 방 경계 상태를 분리하고, 방 재확인·다음 방 선택을 관측 기억 기준으로 바꾼다. 이미 열린 통로는 재사용하고 오래된 적 위치만으로 수류탄을 던지지 않는다.
