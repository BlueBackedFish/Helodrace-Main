# CQB 관측 LOS와 진입점 유지

## 문 칸의 적 관측

기존 접촉 기억은 `GenSight.LineOfSight(관측자 중심 칸, 적 중심 칸, skipFirstCell: true)` 한 줄만 검사했다. 바닐라 `Verb.TryFindShootLineFromTo`는 관측자 원래 위치와 `ShootLeanUtility.LeanShootingSourcesFromTo`의 사격 출발 칸, 그리고 `CalcShootableCellsOf`가 반환하는 적의 노출 칸을 함께 검사한다. 문/벽 옆에서 폰의 중심은 가려져도 몸을 내민 칸으로 사격이 가능한 경우에 두 판정이 달랐다.

접촉 발견과 야전의 무장 적 발견은 이 바닐라 사격 기하를 사용한다. 사거리, 탄약, 장착 무기, 최소 사거리 등은 관측 자격에 적용하지 않는다. 기존 관측 반경(접촉 24칸, 야전 70칸)과 각 후보 LOS의 연막 차폐는 유지한다. 기억에는 노출 칸이 아니라 실제 관측한 폰 위치를 저장하므로 문 칸은 기존 인접 방/통로 연결 처리에 들어간다.

개구부 관측은 지정된 몸 내밀기 출발 칸에서 적의 사격 노출 칸을 검사한다. 지정 출발 칸에서 다시 다른 모서리로 몸을 내밀지는 않는다. 빈 위치 확인은 원래 중심 LOS를 유지하여, 적을 보지 못했다는 이유만으로 벽 너머의 마지막 위치가 비었다고 단정하지 않는다.

검증: 빌드 경고/오류 0, 기존 실행 바인딩 검증 및 추가 19개 검증 통과. 네 방향의 벽 옆 노출 칸, 중심 LOS 차단, 연막, 지정 관측 출발 칸 제한을 실제 게임의 `GenSight`로 검사한다. CLI에서는 Unity quaternion 호출을 실행할 수 없어 바닐라 lean 후보 생성 전체의 실행 비교는 하지 않았다. 실제 플레이에서 열린 문 칸 사격 → 접촉 표시/기억 갱신을 추가 확인해야 한다.

## 보이지 않는 문 개폐와 진입점 왕복

기존 30틱 주기의 국소 맵은 창 안의 모든 문 개폐/건물 변경을 실시간으로 읽었다. 변경 후 목표방까지 걸어갈 수 있으면 아직 진행 중인 벽 돌파 계획을 취소하고 열린 통로로 새 스택업 계획을 만들었다. 반대편 문을 번갈아 열면 이 최적화가 반복되어 진입점과 대형이 바뀔 수 있었다. 방 정리의 문 상태 서명도 시야 밖 문을 포함했고, 엄폐 위치/주시 문 선택에서 실제 `door.Open`을 읽었다.

이제 국소 맵의 방 식별은 습격 시점 정적 레이아웃을 사용하고, 통행 가능 여부와 구조 ID/통로 여부는 관측한 변화만 덧씌운다. 처음 보는 구역의 미관측 문/벽은 통과 가능하다고 간주하지 않는다. 관측하지 못한 변화는 직전 관측값을 유지한다. 관측 반경 24칸 안에서 분대원 중 한 명이라도 출발 칸 또는 바닐라 몸 내밀기 칸으로 LOS를 확보해야 갱신하며, 연막은 이를 차단한다. 건물/통행 상태가 달라진 칸에만 이 관측 검사를 수행한다.

실제로 관측한 변경 칸만 희소 사전에 기록하므로 정적 바닥 전체를 중복 보관하지 않는다. 국소 창 중심이 이동하거나 다음 방 계획을 만들 때도 같은 조직의 관측 사전을 공유한다. 관측 사전은 실행 중 임시 캐시이고 저장 후 재로드 때는 정적 레이아웃에서 보수적으로 다시 관측한다. 별도 저장되는 방 클리어/접촉 기억과 문 상태 서명은 기존 방식으로 유지된다.

다른 문이 열리는 것은 현재 진입점 교체 조건이 아니다. 선택한 개구부 또는 접근 지점이 막혔고 분대가 그 지점을 관측한 경우에만 Assemble/Breach 단계에서 재계획한다. C4, 발사된 수류탄 효과 대기 및 투척자 복귀 대기는 그대로 보호한다. 선택한 벽이 파괴되면 원래 계획의 개구부 관측/진입 단계로 진행한다. 관측한 새 구멍은 이후 방 선택이나 새 계획에서 사용 가능하다.

방 정리의 문 상태 서명은 실제 관측한 문 개폐만 누적 갱신한다. 문이 시야에서 사라진 것만으로 개폐 이벤트를 만들지 않는다. 엄폐 점수와 주시 문의 개폐 우선도 역시 이 관측값을 사용하고, 문 닫힘 대응도 현재 보이는 문에서만 실행한다. 바닐라 이동 작업의 실제 통행/도달 가능 검사 자체는 물리 맵을 사용한다.

검증: 추가 57개 관측 지형/진입점 유지/문 상태 기억 검증 통과. 미관측 반대편 문의 반복 개폐, 첫 관측 전 열린 문의 차단, 시야 상실 후 직전 상태 유지, 다시 본 문 닫힘, 관측한 벽 파괴, 변경 없는 칸의 LOS 생략 및 실제 CQB BFS 경로 불변/관측 후 변경을 검사한다. 빌드 및 기존 실행·계획 회귀 검증도 통과했다. 실제 플레이의 대형 이동과 프레임 시간은 별도 확인이 필요하다.

## 다음 단계: 분대별 진입 경로 분산

목표는 여러 분대를 하나의 진입 대열로 모으는 것이 아니라, 분대별로 가능한 한 서로 다른 접근 경로와 진입점을 사용하게 하는 것이다. 다음 단계에서 분대별 계획/진행 상태와 진입점 점유를 분리하고, 이미 선택한 다른 분대의 경로·개구부와 중복이 적은 후보에 우선순위를 부여한다. 사용할 만한 진입점이 부족할 때의 공유/시간차 진입, 각 분대의 돌파 장비 및 대형 가능 공간, 투척 안전을 함께 검토한다. 이번 수정에는 이 기능을 넣지 않았다.
