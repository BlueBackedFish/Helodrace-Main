# A1 관측과 기본 교정 구현

2026-10-11. [후속 로드맵](습격%20시스템%20후속%20로드맵.md)의 A1 구현 기록. 개발·커밋은 `main`에서 진행한다. 사용자가 F01~F02를 확인했으며, F02의 화력 집중 배치를 수정했다. 수정 후 야전 배치 확인은 사용자 목록에 별도로 남긴다.

## A1.1 원거리 위협 관측

- `TacticalThreatEligibility.Ranged`를 일반 관측과 개구부 관측에 공통 적용한다. 장착 무기·종족 공격·의류 공격·신체 상태의 공격 Verb·생존한 장착 포탑을 확인한다. 근접 전용/공격 불가 폰과 연막 전용 발사체는 관측에서 제외하며 EMP와 빔 등 실제 원거리 공격은 포함한다. 동물/메카노이드 종별 예외는 없다.
- 관측자가 지금 맞출 수 있는 사거리, 조준 상태, `Available()`에 의존하지 않는다. 사거리 밖 접근 감지 및 재장전·쿨다운 중 관측을 유지한다. 기존 관측 후보16개·회전 관측·전역 예산을 유지하며 전역 폰/통계 검색은 추가하지 않는다.
- 기억의 `Remember`는 적격성을 요구한다. 보고에는 발신자의 `RangedThreat` 값이 복사되며 수신자는 적격하지 않은 보고를 거절한다. 적 Pawn 참조나 시야 밖 현재 장비 조회는 추가하지 않는다.
- 실제 인접 공격의 피해 알림은 별도의 `DirectAttack` 국소 대응을 깨운다. 공격 좌표만 사용하며 이 대상을 접촉 기억·통신에 넣지 않는다. 지속 전술 Job에서만 연결하고 기존 Job/계획 예산을 사용한다. 이미 발사한 수류탄·C4 안전 대기는 중단하지 않는다. 대응 경비는 인접한 실제 공격자에게 바닐라 근접 반격을 먼저 시도하며, 총이 없거나 인접 사격이 불가능하다는 이유로 계속 대기하지 않는다. 공격 범위·쿨다운·근접 공격 선택은 바닐라에 맡긴다.
- 저장에는 접촉 적격성과 근접 공격 대응 구분을 보존한다. 로드 후 부적격 기억을 제거한다. 구형 저장 호환 처리는 추가하지 않는다.

### 에이전트 검증

모드 빌드: 경고0·오류0. 기존 `RaidTacticalBindings` 검사에서 `--a1-contact`: 원거리 공격 분류·부적격 기억/보고·분리된 보고·Scribe 값 저장/읽기 및 바닐라 근접 반격 API17개, 기존 접촉 기억 및 협력/무전29개 확인 통과. Scribe 검사는 새 값 페이로드 범위이며 Unity의 전체 월드 로드 시험이 아니다. 일반/개구부 관측→기억→보고와 피해 알림→대응, 저장 복구 연결은 코드 흐름을 확인했다. 정기 성능 수집과 게임 기능 재시험은 수행하지 않았다.

## A1.2 화력점의 호 배치 — F02 피드백 반영

2026-10-11 사용자 정정: 호는 폰을 곡선 위에 일렬로 세우는 선이 아니다. 여러 화력점을 잇는 전체 배치가 호가 되며, 측면 인원의 우회와 중앙 후퇴로 같은 교전 지점에 화력을 모으는 것이 목적이다.

- 개별 `Arc` 자리와 전후 보정 금지를 제거했다. 좌·중앙·우3개 화력 구역을 먼저 만들고 각 구역의5×5 범위에서 엄폐·사격선·무작위 선호 위치를 사용해 자리를 고른다. 엄폐에 따라 앞뒤·좌우 이동을 허용한다.
- 좌우 구역 중심은 측면7~9칸, 전방4~5칸에 두고 중앙은4~5칸 물린다. 관측한 적에 너무 가까우면 측면 전진 거리를 줄인다. 개별 인원은 이 중심에 정확히 정렬하지 않는다.
- High는 실제 세 화력조를 각각 구역에 배정하고 분대장은 중앙에 둔다. LOW는 자동화기 우선의 중앙 대응조와 좌우 인원으로 나눈다. 작은 분대도 측면 인원이 남도록 중앙은 살아 있는 인원의 약1/3, 최대4명으로 제한한다. 조직 편제 자체는 변경하지 않는다.
- 모든 경비 Job은 같은 관측/보고 좌표를 향한다. 후보 중 사격선이 있는 자리를 우선하고 그 안에서 엄폐와 무작위 선호를 비교한다. 사격선이 막힌 자리에 엄폐 점수만으로 몰리는 현상을 줄였다. 새 적 정보나 시야 밖 적 상태 조회는 없다.
- 무작위 선호는 교전 시작 값과 폰 ID로 계산하며 자리 배정 때만 적용한다. 대기 중 매 틱 무작위로 움직이지 않는다. 중복 자리·다른 분대 자리·CQB 개구부 경계 금지를 유지한다.
- 기동은 한 조의 공통 화력 구역을 전진시킨 후 그 안의 자리를 다시 선택한다. 고정 선의 모든 자리를 똑같이 이동시키지 않는다. 기존 조 교대/연막 연결을 유지하며, 더 전진할 여지가 없으면 기동 재배치를 시작하지 않는다. 긴 기동·분대장 동행 등의 A3 작업 전체를 완료한 것은 아니다.
- 각 배정은 최대50개의 값싼 후보, 최대16개의 LOS/엄폐 평가를 사용하며 기존 전역 계획/Job/경로 예산과 한 번에2명 배정을 유지한다. 막힌 구역에는 현재 위치 주변의 안전한 대기 후보를 사용한다. 대형을 맞추려고 건물 전체를 돌아가는 경로는 추가하지 않는다.
- `FirePoints`를 값 좌표 목록으로 저장한다. 기존 개별 자리·담당 조·경비 Job·연막 복귀 위치도 그대로 저장/복구한다. 구형 세이브 호환 코드는 추가하지 않는다.

에이전트 검증: 모드 빌드 경고0·오류0, 기존 `--a1-field` 통과. 네 방향의 세 구역 배치, 구역 내 앞뒤·좌우 분산, 실제 High 화력조/LOW 대응조 배정, 교전별 위치 변화, 구역 기동과 적 앞 정지, 사격선 우선 점수 및 기존 관측 이력 검사를 확인했다. 새 `FirePoints`와 위치 분산 기준이 native Scribe 값 저장/읽기 후 유지됨을 확인했다. 전체 Unity 월드 로드나 CPU 측정을 실행한 결과는 아니다. F02 수정 후의 실제 지형/교전 확인은 사용자 담당이다.

## A1.3 High CS 제외

- 현대 분대장 지급 목록에서 M7A2만 제거한다. 13인 분대/3개 화력조와 C4·점화기·M84·HC·M67·슬래지 해머 등 기존 장비는 유지한다.
- CQB/야전의 공통 자동 수류탄 선택에 `TacticalGrenadePolicy.AllowsAutomatic`을 적용한다. High는 이미 보유한 M7A2 및 CS 가스가 연결된 수류탄을 고르지 않는다. 아이템명뿐 아니라 현대 수류탄/폭발 가스 확장도 확인한다.
- CS 아이템·투사체·효과는 삭제하지 않는다. 공통 수동 투척/인벤토리 UI는 수정하지 않으므로 다른 세력 및 플레이어 사용은 유지한다. 방독면 기능 연결은 후속 작업이다.

에이전트 검증: 모드 빌드 경고0·오류0. `--a1-grenades`의 XML 지급·13인 편제·기존 장비·High/다른 세력 정책12개와 기존 HC/WP 연막·사격선14개 확인 통과. 기존 자동 선택 호출자는 CQB 지원 및 야전 연막 두 곳이며 모두 공통 선택 함수를 사용함을 확인했다.

## 완료와 사용자 확인

A1.1~A1.3 구현·빌드·관련 짧은 검사·저장 값/실행 흐름 확인을 완료했다. 사용자가 F01~F02를 확인했다. F01의 근접 접근 조기 대응 제안은 이후 [A1.4](A1.4%20사격%20집중%20AI%20구현.md)에서 구현·사용자 확인을 마쳐 활성 목록에서 제거했다. F02의 호 배치 피드백은 위 구현에 반영했으며 수정 후 재확인은 남아 있다. 전체 월드 저장 재시험이나 CPU 수집을 통과한 것으로 기록하지 않는다.
