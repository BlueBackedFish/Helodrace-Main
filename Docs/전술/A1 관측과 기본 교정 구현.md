# A1 관측과 기본 교정 구현

2026-10-11. [후속 로드맵](습격%20시스템%20후속%20로드맵.md)의 A1 구현 기록. 개발·커밋은 `main`에서 진행한다. 사용자 약식 기능 확인 F01~F02는 별도이며 아직 미실행이다.

## A1.1 원거리 위협 관측

- `TacticalThreatEligibility.Ranged`를 일반 관측과 개구부 관측에 공통 적용한다. 장착 무기·종족 공격·의류 공격·신체 상태의 공격 Verb·생존한 장착 포탑을 확인한다. 근접 전용/공격 불가 폰과 연막 전용 발사체는 관측에서 제외하며 EMP와 빔 등 실제 원거리 공격은 포함한다. 동물/메카노이드 종별 예외는 없다.
- 관측자가 지금 맞출 수 있는 사거리, 조준 상태, `Available()`에 의존하지 않는다. 사거리 밖 접근 감지 및 재장전·쿨다운 중 관측을 유지한다. 기존 관측 후보16개·회전 관측·전역 예산을 유지하며 전역 폰/통계 검색은 추가하지 않는다.
- 기억의 `Remember`는 적격성을 요구한다. 보고에는 발신자의 `RangedThreat` 값이 복사되며 수신자는 적격하지 않은 보고를 거절한다. 적 Pawn 참조나 시야 밖 현재 장비 조회는 추가하지 않는다.
- 실제 인접 공격의 피해 알림은 별도의 `DirectAttack` 국소 대응을 깨운다. 공격 좌표만 사용하며 이 대상을 접촉 기억·통신에 넣지 않는다. 지속 전술 Job에서만 연결하고 기존 Job/계획 예산을 사용한다. 이미 발사한 수류탄·C4 안전 대기는 중단하지 않는다.
- 저장에는 접촉 적격성과 근접 공격 대응 구분을 보존한다. 로드 후 부적격 기억을 제거한다. 구형 저장 호환 처리는 추가하지 않는다.

### 에이전트 검증

모드 빌드: 경고0·오류0. 기존 `RaidTacticalBindings` 검사에서 `--a1-contact`: 원거리 공격 분류·부적격 기억/보고·분리된 보고·Scribe 값 저장/읽기16개, 기존 접촉 기억 및 협력/무전29개 확인 통과. Scribe 검사는 새 값 페이로드 범위이며 Unity의 전체 월드 로드 시험이 아니다. 일반/개구부 관측→기억→보고와 피해 알림→대응, 저장 복구 연결은 코드 흐름을 확인했다. 정기 성능 수집과 게임 기능 재시험은 수행하지 않았다.
