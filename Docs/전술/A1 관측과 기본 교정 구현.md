# A1 관측과 기본 교정 구현

2026-10-11. [후속 로드맵](습격%20시스템%20후속%20로드맵.md)의 A1 구현 기록. 개발·커밋은 `main`에서 진행한다. 사용자 약식 기능 확인 F01~F02는 별도이며 아직 미실행이다.

## A1.1 원거리 위협 관측

- `TacticalThreatEligibility.Ranged`를 일반 관측과 개구부 관측에 공통 적용한다. 장착 무기·종족 공격·의류 공격·신체 상태의 공격 Verb·생존한 장착 포탑을 확인한다. 근접 전용/공격 불가 폰과 연막 전용 발사체는 관측에서 제외하며 EMP와 빔 등 실제 원거리 공격은 포함한다. 동물/메카노이드 종별 예외는 없다.
- 관측자가 지금 맞출 수 있는 사거리, 조준 상태, `Available()`에 의존하지 않는다. 사거리 밖 접근 감지 및 재장전·쿨다운 중 관측을 유지한다. 기존 관측 후보16개·회전 관측·전역 예산을 유지하며 전역 폰/통계 검색은 추가하지 않는다.
- 기억의 `Remember`는 적격성을 요구한다. 보고에는 발신자의 `RangedThreat` 값이 복사되며 수신자는 적격하지 않은 보고를 거절한다. 적 Pawn 참조나 시야 밖 현재 장비 조회는 추가하지 않는다.
- 실제 인접 공격의 피해 알림은 별도의 `DirectAttack` 국소 대응을 깨운다. 공격 좌표만 사용하며 이 대상을 접촉 기억·통신에 넣지 않는다. 지속 전술 Job에서만 연결하고 기존 Job/계획 예산을 사용한다. 이미 발사한 수류탄·C4 안전 대기는 중단하지 않는다.
- 저장에는 접촉 적격성과 근접 공격 대응 구분을 보존한다. 로드 후 부적격 기억을 제거한다. 구형 저장 호환 처리는 추가하지 않는다.

### 에이전트 검증

모드 빌드: 경고0·오류0. 기존 `RaidTacticalBindings` 검사에서 `--a1-contact`: 원거리 공격 분류·부적격 기억/보고·분리된 보고·Scribe 값 저장/읽기16개, 기존 접촉 기억 및 협력/무전29개 확인 통과. Scribe 검사는 새 값 페이로드 범위이며 Unity의 전체 월드 로드 시험이 아니다. 일반/개구부 관측→기억→보고와 피해 알림→대응, 저장 복구 연결은 코드 흐름을 확인했다. 정기 성능 수집과 게임 기능 재시험은 수행하지 않았다.

## A1.2 호 방향

- 적 방향으로 양끝이2칸 전진하고 중앙이1칸 물러난 호를 사용한다. LOW 임시 대응조/후방 인원과 High13인 대형 모두 같은 방향을 쓴다.
- 엄폐 보정은 목표 자리의 전후 깊이를 유지하고, 초기 대형에서는 원래 날개 쪽·대형 폭을 유지한다. 중앙의 좌우 보정은1칸 이내다. 기동 보정에서도 전후 깊이를 유지한다.
- 기존 두 번의25칸 후보 상한·직선 연결/개구부 경계·중복 자리 금지를 유지한다. 부적격 좌표는 LOS/엄폐 계산 전에 제외한다. 대체 후보 중심은 폰의 좌우 위치를 목표 깊이에 투영한다. 사용할 자리가 없으면 기존 자리 유지/기존 대기 처리를 사용한다. 완전히 막힌 지형에서 호를 강제로 만들지 않는다.
- 저장 상태나 갱신 빈도는 추가하지 않는다. 새로 배치하는 대형에 적용한다.

에이전트 검증: 모드 빌드 경고0·오류0, `--a1-field` 통과. 네 방향의4/8/13인 호의 고유 자리·중앙/양끝 전후 관계·폭·반대 날개 침범 금지·중앙 엄폐 보정과 기존 야전 관측 이력/기동 선택 검사를 확인했다. 실제 지형의 기능 확인은 F02에 남긴다.

## A1.3 High CS 제외

- 현대 분대장 지급 목록에서 M7A2만 제거한다. 13인 분대/3개 화력조와 C4·점화기·M84·HC·M67·슬래지 해머 등 기존 장비는 유지한다.
- CQB/야전의 공통 자동 수류탄 선택에 `TacticalGrenadePolicy.AllowsAutomatic`을 적용한다. High는 이미 보유한 M7A2 및 CS 가스가 연결된 수류탄을 고르지 않는다. 아이템명뿐 아니라 현대 수류탄/폭발 가스 확장도 확인한다.
- CS 아이템·투사체·효과는 삭제하지 않는다. 공통 수동 투척/인벤토리 UI는 수정하지 않으므로 다른 세력 및 플레이어 사용은 유지한다. 방독면 기능 연결은 후속 작업이다.

에이전트 검증: 모드 빌드 경고0·오류0. `--a1-grenades`의 XML 지급·13인 편제·기존 장비·High/다른 세력 정책12개와 기존 HC/WP 연막·사격선14개 확인 통과. 기존 자동 선택 호출자는 CQB 지원 및 야전 연막 두 곳이며 모두 공통 선택 함수를 사용함을 확인했다.

## 완료와 사용자 확인

A1.1~A1.3 구현·빌드·관련 짧은 검사·저장 값/실행 흐름 확인을 완료했다. [사용자 약식 목록 F01~F02](습격%20기능%20약식%20테스트%20목록.md)는 미실행으로 유지한다. F01에서는 비원거리 대상의 관측 제외와 실제 근접 공격 시 대응을 함께 확인하고, F02에서는 지형에 따른 호 배치 및 High의 새 지급/기존 CS 자동 사용 제외를 확인한다. 전체 월드 저장 재시험이나 CPU 수집을 통과한 것으로 기록하지 않는다.
