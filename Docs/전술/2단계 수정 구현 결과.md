# 2단계 수정 구현 결과

2026-10-04.

## 적용 내용

- 중간 노드의 2/3 인원 집결, 지휘관·공병 도착 대기, 개인별 도착 자리 점유 조건을 제거했다.
- 선두가 지향점 6칸 이내에 들어오고 벽 없이 연결되면 같은 갱신에서 다음 이동 명령을 발행한다. 중간 HoldPosition은 발행하지 않는다. 마지막 스택업의 정지·경계는 유지한다.
- 후미는 물리적으로 연결되는 앞쪽 일반 지향점으로 합류할 수 있다. 선택한 문·개구부는 건너뛰지 않는다.
- 64칸 이하 같은 정적 방에서는 연결된 기존 경로를 활용해 코너 노드를 압축한다. 문과 방 경계는 유지한다.
- 지향점 중심이 막혀도 주변 같은 방의 이동 가능한 후보를 탐색한다. 후보 개수는 이동 완료 조건이 아니다.
- 외부 경로의 직선 편차 비용을 완화하고 벽 인접 구간과 현재 관측한 적에게 덜 노출되는 구간을 선호한다. 이는 접근 경로 선택이며 새로운 전역 킬존 맵이 아니다.
- 개발자 표시의 arrival 영역을 guidance 후보 영역으로 변경했다.

## 현재 안전장치와 범위

바닐라 이동이 실제 경로를 선택한다. 선택한 문·방 연결과 외벽 진입 제약은 유지하지만 경로 선으로 즉시 복귀시키는 비용은 넣지 않는다. 현재 방향 제한은 연결 구간과 지향점 명령으로 적용한다. 10칸 이상의 큰 이탈이 90틱 지속되면 아직 통과하지 않은 연결 범위 내의 앞쪽 합류점으로 보정한다. 보정 간격은 120틱이며 즉시 직선 복귀는 하지 않는다. 이탈 폭과 지연은 교리 설정으로 조절할 수 있다. 넓은 띠 시각화는 추가하지 않았다. 개인별 저장 상태는 필수 연결의 통과와 현재 이동 목적지를 추적한다.

고정기총의 별도 조기 감지, 새로운 야전 전투 상태, 화력조 교대 이동은 이후 단계 대상이다. 현재 노출 비용은 이미 관측 가능한 적 폰의 화기를 이용한다.

## 검증과 게임 테스트

빌드와 이동 정책·전술 계획·게임 API 연결·편제 검증을 실행한다. 실제 게임에서는 좁은 방 연속 통과, 문 앞 후미 정체, 긴 굽은 복도 합류, 중심이 막힌 지향점, 외벽 접근 우회, 수류탄 회피 후 복귀와 저장/불러오기를 확인해야 한다. 자동 검증은 실제 Unity 이동 실행을 대체하지 않는다.
