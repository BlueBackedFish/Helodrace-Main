# 외벽 경비 인원의 확보 개구부 합류

2026-10-05.

## 문제

외벽 스택업 인원이 진입하고 외부 경비·화력지원 인원이 나중에 따라 들어갈 때, 이미 확보한 개구부 대신 이전부터 열린 진입로를 선택했다.

CrossBreach의 통과와 선택 개구부 제한은 Entry 인원에게만 적용됐다. 다음 방 계획에서는 이전 통과 상태도 초기화하므로 외부 인원의 합류가 일반 실내 목적지 이동으로 바뀌었다.

## 변경

- 외벽에서 실내로 넘어가는 돌파가 CrossBreach에 진입할 때, 아직 밖에 있는 분대 인원별로 원래 개구부·내측 칸·정적 방 ID를 저장한다.
- 외부 경비 지시는 유지한다. 해당 폰이 실내로 이동하거나 실내 교전 지시를 받을 때만 원래 개구부 근처의 내측 이동 목적지로 먼저 연결한다.
- 다음 방 계획과 사상자로 인한 실행 상태 교체에서도 이 기록을 보존한다. 개구부와 다음 방의 돌파점을 혼동하지 않는다.
- 같은 원래 개구부를 사용하는 인원은 이동 마스크 하나를 공유한다. 외부와 첫 진입 방만 허용하고, 다른 외벽 문·개구부는 제한한다. 방별 다음 경로 마스크보다 먼저 적용한다.
- 문칸이 캐시에서 별도 방 ID를 갖더라도 선택한 개구부 타일은 연결점으로 허용한다.
- 실제 타일 이동 검사도 같은 연결을 강제한다. 마스크 비용만으로 생길 수 있는 기존 문 또는 예상 밖의 구멍 우회를 차단한다.
- 실제 폰 위치로 개구부에 도달하고, 안쪽 입구를 벗어난 합류 목적지에 도착해야 해제한다. 경로 요청, 대기 중인 다음 칸, 이미 다른 문으로 들어간 위치만으로는 완료하지 않는다. 개구부를 밟고 밖으로 물러나면 통과 래치를 초기화한다.
- 통과 후에는 다음 방의 원래 전술 지시로 돌아간다. 개구부로 다시 끌어당기지 않는다.
- 수류탄 회피·저격 회피 등 reactive 이동은 연결 제약을 우회한다. 물리적 통과 관측은 비상 이동에서도 계속 반영한다.
- 개구부가 막히거나 예약 가능한 내측 칸이 없다면 다른 기존 진입로로 몰래 바꾸지 않고 대기한다. 외벽 재설치 후 이 합류 기록만으로 새 공병 작업을 자동 시작하는 기능은 이번 범위에 포함하지 않았다.
- 기록은 저장하고 복원한다. 개발자 보고서와 전술 노드 표시에서 미완료 JOIN 개구부를 확인할 수 있다.

## 검증

- 빌드: 오류·경고 0.
- 전술 지형·마스크·이동: 248개 검사 통과. 이전 개구부와 문칸 별도 방 ID, 다른 입구 차단을 포함한다.
- 전술 계획: 133개 결정·돌파 검사와 기존 CQB·연막·수비 검사 통과.
- 실제 게임 클래스 연결: 기존 Harmony 연결 검사 통과. 외벽 진입의 4방향 물리 통과·후퇴·래치·Scribe 로드 26개 검사 통과.
- 실제 다음 방 계획 활성화에서도 외부 인원의 원래 개구부가 보존되고 다른 분대에 공유되지 않는 것을 확인했다.

Unity에서의 실제 이동은 게임 테스트가 필요하다. 이미 열려 있는 외벽 문과 새 돌파 구멍을 함께 둔 뒤, 경비 인원이 다음 방으로 합류할 때 새 구멍을 사용하는지 확인한다. 이어서 합류 중 저장/불러오기, 문 돌파, 수류탄 회피 후 재합류, 개구부 혼잡을 확인한다.
## 후속 인원의 개구부 앞 정체 추가 수정

같은 날 추가 테스트에서 일부 후속 인원이 개구부 앞에서 겹치거나 왕복하는 현상이 보고됐다. 코드에서 다음 불일치를 확인해 수정했다.

- 실내 목적지로 바로 경로를 계산하면서 실제 이동 검사는 개구부 타일을 반드시 밟게 했다. 바닐라가 입구 모서리를 대각선으로 줄인 경로는 계속 거부될 수 있었다.
- 이제 실제 이동 명령도 개구부 타일을 먼저 통과한 뒤 내측 합류 목적지로 이어진다. 작업 선택에서 개구부 도착을 처리할 때 즉시 다음 Goto를 발행하므로 중간 Hold로 바뀌지 않는다.
- 개구부는 통과 경유점이므로 목적지 예약을 독점 대기 조건으로 쓰지 않는다. 내측 합류 지점과 최종 대형은 예약을 계속 확인한다.
- 내측 목적지는 입구 바로 뒤 칸을 제외하고, 다른 폰이 서 있거나 같은 분대가 이미 합류 목적지로 정한 칸도 제외한다. 실제로 연결된 이동 가능 칸이 하나뿐인 방만 입구 칸을 허용한다.
- 입구 바로 뒤로 한 칸 들어오는 것으로 합류를 완료하지 않는다. 내측 목적지까지 이동하는 동안 연결을 유지해 중간 대형 대기로 입구를 막지 않게 한다.
- 모서리 옆 칸은 개구부에서 직선으로 걸을 수 없어도 입구를 거쳐 이동 가능하다. 반경 6칸의 같은 정적 방 안에서 작은 cardinal 연결 탐색으로 후보를 확인한다. 전역 맵 재계산은 하지 않는다.
- 원래 요청 목적지도 저장한다. 개발자 보고서는 현재 경유점, 내측 합류점, 원래 목적지를 함께 표시한다.

검증: 빌드 오류·경고 0, 물리적 경유점 전환·입구 이탈까지 합류 유지·저장 복원 39개 검사 통과. 경로 정책 테스트에 통과 지점의 비독점 예약과 모서리 옆 합류 공간 검사를 추가했다. Unity 이동에서의 실제 정체 해소는 게임에서 다시 확인해야 한다.
