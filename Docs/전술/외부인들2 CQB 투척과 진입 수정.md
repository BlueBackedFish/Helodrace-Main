# 외부인들2 CQB 투척과 진입 수정

2026-10-13. `외부인들2.rws` 복사본을 바닐라 Autostart로 로드해 원래 건물·문·지붕·플레이어 무장과 저장된 모드 목록을 유지했다. 중앙 건물 바깥 `(125,0,151)` 부근에 LOW 12인 분대를 생성했고, 실제 돌파점은 `(130,0,151)`이었다. 원본 저장 파일은 변경하지 않았다.

## 확인된 투척 병목

수정 전 실내 투척 후보가 만들어지고 LOS도 성립했지만, 모든 유효 궤적이 `UnsafeFriendly`로 거절됐다. grenade/LOS/unsafe 누적 검사는 `48/10/10`, 실제 투척은 0회였다. 따라서 장비 미지급이나 LOW의 투척 판단 자체 누락이 원인은 아니었다.

벽 파괴 뒤 바닐라 `Room`이 실내와 야외를 합치면서, 대상 방과 무관한 비적대 야생동물까지 방 내부의 보호 대상으로 판정했다. 수정 후 동일 장면에서 구형 검사만 별도로 기록해 보니 투척 목표 `(135,0,151)`에서 약 38칸 떨어진 Vulture와 약 100칸 떨어진 Ostrich가 거절 원인이었다. 둘 다 야외에 있었다.

투척 안전 검사에 개구부와 문을 경계로 막고 지붕 상태가 같은 바닥만 연결하는 국소 방 범위를 추가했다. 개구부마다 한 번 계산하며, 전역 계획 예산 안에서 틱당 새 이웃 검사 최대 64회, 바닥 최대 256칸으로 제한한다. 열린 야외와 실내가 같은 바닐라 방이 되어도 이 범위 밖 동물을 실내 아군으로 보지 않는다. 방 내부 및 인접 문칸 아군은 계속 보호하며, 실제 폭발·파편 범위와 LOS 검사는 이 범위 밖 폰에도 그대로 적용한다.

상한을 넘는 큰 방의 원거리 아군 판정은 근사값이다. 물리적 위험 검사는 생략하지 않는다. 범위와 준비 완료 상태는 저장하고, 계산 중 저장된 경우 계산만 다시 시작한다. 소방(16칸 이하) 절약·관측 적 우선·최소 투척 거리·폭발/복귀 대기는 유지한다.

## 진입 중 교전으로 후속 인원이 멈추는 문제

실제 개구부를 통과하는 `Enter` 단계에서는 분대 접촉·화력점·야전·치료 판단보다 진입 실행을 먼저 처리한다. HIGH의 진입 중인 화력조도 상위 분대가 접촉 대응으로 실행을 막지 않는다. 기존 진입 작업과 통과 기록·접촉 기억·수류탄 안전 상태는 유지하고, 경쟁하는 대응 상태와 추가 자리 점유만 해제한다.

먼저 도착한 인원은 사격할 수 있으며, 후속 인원은 계속 진입한다. 수류탄 회피는 여전히 먼저 처리한다. 전원 도착 후 교전 종료 유예 90틱과 일반 대응은 유지한다. 야외 직접 이동에는 이 예외를 적용하지 않는다.

## 검증과 범위

- 같은 복사 세이브의 4,500틱 실행: 투척 0→1회, 투척자 복귀 1회, 폭발 전 진입 0회, 12명 전원 통과·도착. 진입 작업 중 사격 231회 기록.
- 최종 DLL의 3,000틱 재확인도 투척·복귀 각 1회, 폭발 전 진입 0회, 12명 통과·도착. 방 안전 범위는 144칸으로 상한에 걸리지 않았다. 요약 증거는 [저장 맵 재현 결과](../../Source/Benchmarks/TacticalEngineAudit/Results/2026-10-13-cqb-saved-map.json)에 남겼다. 수정 전 투척 재현에도 진입 우선 처리는 이미 포함되어 있어, 전후 비교는 투척 안전 범위의 효과를 분리한 결과다.
- 관련 자동 검사: 투척 안전 46개, 진입 교전 18개, HIGH CQB·저장 49개 및 기존 후보 분산·접촉·C4·작업 예산 검사 통과.
- 최종 DLL 빌드: 경고·오류 0개. 메서드 프로파일링이나 전체 성능 캠페인은 실행하지 않았다.

격리 테스트는 사망으로 결과가 달라지지 않도록 공격자와 플레이어 방어자의 피해를 막았다. 이동·판단·투척·사격은 실제 게임 코드로 실행했다. 방어자 생존으로 계속 교전하므로 최종 단계가 `Enter`인 것은 다음 방으로의 이동을 막는 정상 교전 유지이다. 이 장면에서는 관측 적 기록 없이 사각 투척이 실행됐다. 적 관측 후 작은 방 투척과 실전 사상자 발생은 약식 목록 F54/F56에서 별도 확인한다.

복사 세이브 재생에서는 기존의 비활성 테스트 컴포넌트 저장 데이터를 읽지 않도록 해 검증 도구의 로드 오류도 제거했다. 최종 실행에서 CQB/재생 도구 예외는 없었지만, 기존 약물 정의의 `ConfigErrors`와 누락 텍스처 등 시작 로그 경고는 이번 수정 범위가 아니다.

재현 도구: `Source/Benchmarks/TacticalEngineAudit/Run-SavedMapAudit.ps1`. 이미 실행 중인 게임이 있으면 시작하지 않고, 새 CreatorTemp 폴더와 원본 복사본만 사용한다. `-SpawnX 125 -SpawnZ 151 -Ticks 3000`으로 중앙 건물 장면을 짧게 재생할 수 있다. 검증 모드 플래그가 없는 일반 게임에는 피해 방지나 자동 분대 생성이 적용되지 않는다.
