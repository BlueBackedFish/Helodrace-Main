# 습격 설계 추가 계획 검토

2026-10-11. [사용자 설계](습격%20설계.md)를 현재 구현과 대조한 후속 계획 초안이다. 게임 코드·정의 변경과 테스트 재개는 수행하지 않았다. R7 수집은 사용자 요청에 따라 일시중지 상태다.

## 판단과 범위

설계의 방향은 현재 최적화 구조 위에 추가할 수 있다. 기존 전술 동작 수정 → 임무 지속과 정보 공유 → High 화력조 CQB → 습격 생성·지원 자원 → 새 습격 종류 순서가 적절하다. CPU 우선순위는 유지하고, 새 기능마다 전체 지도 갱신이나 폰 간 상시 비교를 추가하지 않는다.

사용자가 적은 성능 합격·약 1.3~1.7배의 플레이 관측은 후속 설계의 실용적 출발점으로 받아들인다. 기존 R7의 반복 CPU 게이트는 미완료라는 기록을 유지하지만, 이 검토를 위해 남은 전체 행렬을 다시 돌릴 필요는 없다. 확장 후에는 관련 메서드만 수집하는 짧은 확인을 기본으로 한다.

## 현재 구현과 차이

| 요구 | 확인한 현재 구조 | 추가 작업 |
|---|---|---|
| 의료인 1명과 장비 회수 | 안전 구간 TCCC·매딕가방 사용 AI는 있음. 편제에 기본 가방 지급은 없음 | 기존 인원 중 1명을 의료 담당으로 지정·지급하고 분대 내 회수 연결 |
| 외벽 이후 떨어진 건물까지 소탕 | `BeginRoomClear`는 지붕 있는 바닥만 탐색. `PlanRoomFrontier`도 지붕 있는 안쪽 자리 사용 | 야외 중정 이동과 다음 건물 진입을 별도 임무 구간으로 연결 |
| 적 쪽으로 오목한 호 | `Arc`는 중앙이 forward +1, 양끝이 -2여서 적 방향으로 중앙이 돌출 | 중앙 뒤·양끝 앞의 오목한 형태로 수정하고 엄폐 보정에도 방향 유지 |
| 긴 화력조 기동·응집 | 각 인원의 기존 자리에서 forward 5칸 이동. 화력조 공통 목적지는 없음 | 화력조 중심 목적지와 작은 대형, 기동 거리 조정 |
| 분대장 동행 | 화력조 없는 분대장은 `FieldMover`의 High 이동 대상에서 제외 | 임시 동행 화력조 지정. 지휘 소속은 유지 |
| 고양이 등으로 야전 대응 금지 | `ScanContacts`는 적대·생존·LOS만 검사 | 관측 기록과 전술 전환에 쓰는 위협 자격 분리 |
| High의 CS 제외 | 현대 분대장 슬롯에 `HD_Grenade_M7A2_Item` 지급 | 방독면 도입 전 지급·자동 선택 경로에서 제외 |
| High의 CQB 화력조 분리 | `RaidTacticalUnit`가 분대와 하위 팀을 한 실행 단위로 묶음 | 분대 지휘 아래 독립 CQB 하위 작업 추가 |
| 확보한 방 공유 | 연락은 접촉 기억·준비·완료·목표 확보·사용 가능한 개구부를 전달. 방별 확보 영역은 전달하지 않음 | 제한된 확보 구역 보고와 재돌파 억제 |
| 지정 편제·잔여 지원 포인트 | 완전한 편제 선택과 잔액 계산·소비 API는 이미 있음 | 새 편제·생성 상한·지원 소비 정책 연결 |
| 의료 가방 쿨타임 | 현재는 저장 물자 소비 방식 | 정상 사용 쿨타임과 물자 소비를 통한 조기 사용으로 변경 |

외벽 직후 해제의 구조적 원인 후보는 지붕 없는 중정에 대한 탐색 종료다. 실제 상황의 `LastPlanFailure`·임무 단계·목표 확보 상태를 확인해야 정확한 종료 경로를 확정할 수 있다. 이 문서는 해당 플레이 사례를 재현해 원인을 확정한 결과가 아니다.

## A1. 저비용 동작 수정

위협 판정, 호 방향, High CS 제외를 먼저 다룬다. 새 전술 단계 없이 기존 조건·대형을 수정하므로 범위를 작게 유지할 수 있다.

- 위협 자격은 적대 관계가 전제이며, 사용 가능한 원거리 무기 보유 또는 근접 DPS 6 이상을 기본으로 한다. DPS는 관측된 후보만 계산하고 짧게 재사용한다. 전 폰의 스탯을 매 틱 구하지 않는다.
- 무기 없는 비전투 대상은 야전 엄호·기동을 시작시키지 않는다. 실제 공격을 받는 경우에는 위 자격과 별도로 긴급 대응한다. 포탑·공격 가능한 메카노이드 등 기존 대응 대상도 별도 유지한다.
- 호는 공격자 쪽으로 양끝이 나가고 중앙이 물러나는 곡면으로 한다. 각 엄폐 후보를 따로 고르더라도 전방 축과 대형 폭을 제한해 방향이 뒤집히지 않게 한다. 중앙 사격 방향으로 화력을 모으되 다른 아군을 쏘는 위치는 피한다.
- High의 M7A2 지급을 제외하고 자동 장비 선택에서도 CS를 고르지 않게 한다. 이미 존재하는 CS 아이템 자체의 삭제나 효과 변경과는 별도 작업이다.

짧은 확인: 적대 고양이만 있는 상황, 무장 적 접근, 공격자 방향 4가지의 호, High 분대 생성 장비 목록.

## A2. 소탕 임무 지속과 확보 정보 공유

소탕 완료를 한 개구부 통과나 한 건물 정리와 분리한다. 이름 있는 침대는 최초 목표이고, 해당 목표 확보 이후에는 알려진 미확보 구역을 계속 정리한다. 침대가 없는 경우의 대체 목표는 명시 목표를 우선하고 별도 정책으로 정한다.

분대가 사용하는 현재 국소 계획은 유지한다. 상위 임무에는 최초 목표·다음 이동 목적지·정리한 구역·남은 알려진 입구·진행 실패 사유를 둔다. 외벽 너머가 야외라면 방 클리어로 끝내지 않고 중정 통과/야전 대응 구간으로 넘어간 뒤 다음 건물 입구를 계획한다. 열린 지역을 무제한 flood fill 하거나 전역 전략 가치 맵을 다시 만들지 않는다.

다음 건물 선택은 목표 방향과 실제로 확인한 가까운 경계 후보에 한정한다. 후보를 다 소진해도 임무를 바로 해제하지 않고, 제한된 재탐색·진행 불가·퇴각을 구분한다. 전체 정착지의 숨은 방을 미리 아는 완벽한 소탕은 목표로 하지 않는다. 임무 완료는 알려진 미확보 구역 소진과 제한된 추가 탐색 종료를 기준으로 하며, 발견하지 못한 공간이 남을 수 있다.

확보 보고는 개구부 좌표·연결 방향·구역 범위의 작은 묶음·보고 시각·원본 분대를 포함한다. LOW는 실제 접촉, High는 유효한 장착 무전이 있어야 전달한다. 모든 분대가 전역 `SecuredCells`를 읽게 하지 않는다. 이미 보낸 보고는 변경분만 전달하고 패킷 크기·큐 길이·틱당 적용량에 상한을 둔다.

자신이 확보한 상태와 다른 분대가 확보했다고 보고한 상태는 분리한다. 보고된 구역으로 이동할 때 기존 개구부를 재사용하고 불필요한 재돌파를 생략하되, 과거 확보 보고가 현재 적 부재를 보장하지는 않는다. 새 적 관측은 재확인 필요 상태만 만들며 물리 개구부 이력은 보존한다. 문 파괴·방 병합으로 낡은 방 ID가 생기지 않도록 기존 좌표 기반 기록을 사용한다.

짧은 확인: 외벽→야외 중정→서로 떨어진 건물 두 개, 두 분대의 접촉 전/후 재돌파 여부, 확보 구역으로 적 재침입.

## A3. 야전 기동과 의료 담당

High 기동은 화력조 공통 목적지를 먼저 정하고 그 주변에 4명의 자리를 배치한다. 현재 각자의 자리에서 5칸씩 전진하는 방식은 길게 이동할수록 응집이 깨지므로 교체한다. 최초 조정 후보는 10~15칸의 기동 구간이며, 엄폐·시야·후속조 거리·도착 가능성을 제한된 후보로 확인한다. 이 수치는 검증 전 제안값이다.

기동 중 매 틱 대형으로 복귀시키지 않는다. 목적지와 허용 거리만 주고, 크게 이탈하거나 진행이 끊겼을 때만 재합류 작업을 준다. 한 조가 이동하고 다른 조는 준비된 자리에서 엄호한다. 사상자 후에는 생존 조를 기준으로 교대하며, 기동 불가 시 짧은 접근이나 수비로 내려갈 수 있다.

분대장은 임시로 한 화력조에 붙어 움직인다. 조직 트리의 소속을 바꾸지 않고 실행상 동행 관계만 저장하며, 사망·다운·해당 조 해산 때 재선택한다. 분대장만 뒤에 남거나 별도 네 번째 기동조처럼 행동하지 않게 한다.

의료 담당은 새 PawnKind나 추가 인원 없이 기존 분대 슬롯 중 1명으로 지정한다. 12인/13인 편제 인원수와 기본 무장은 유지한다. 기존 TCCC·가방 처치 작업을 재사용하며, 안전 구간에서 처치하고 위협 시 중단한다. 6인 정찰분대에도 동일하게 1명을 둘지는 편제 정의에서 명시한다.

가방은 소지자 변경에 대한 작업 소유권을 가진다. 다운/사망·실제 드랍 이벤트로 분대가 아는 장비 후보를 등록하고, 한 명만 회수 작업을 소유한다. 장비가 아직 착용 중인 다운 폰에게서 벗겨 가져오는 행동은 바닥 아이템 줍기와 별도다. 최초 구현은 실제 드랍된 장비부터 지원하는 것이 안전하다. 전 맵 장비 검색·처치 가능한 인원의 지속적인 전수 조회는 추가하지 않는다.

## A4. 장비 효과와 의료 가방 자원 규칙

| 항목 | 제안 | 주의할 영향 |
|---|---|---|
| 매딕가방 | 정상 사용은 물자 소모 없이 쿨타임 시작. 쿨타임 중 조기 사용만 충전 물자 소비 | 쿨타임은 폰이 아닌 가방에 저장해 교환으로 초기화되지 않게 함. 중단한 처치의 소비/쿨타임 시작 시점 명시 |
| 지혈/혈장 | 우선 가방의 공유 쿨타임으로 단순화하고 조기 사용 비용을 종류별 정의 | 혈장 반복으로 출혈 피해가 사라지지 않도록 기존 처치 제한 유지. 쿨타임·비용 수치는 아직 미확정 |
| 수류탄 건물 피해 | 대인 수류탄의 폭발·파편 건물 피해에 별도 배율 적용. 0.1을 첫 후보, 1/30은 추가 후보 | C4·돌파 폭약·슬래지 해머는 제외. 폭발만 줄이고 파편 피해를 그대로 두면 목적을 달성하지 못함 |
| CS＋섬광탄 | 이동 감소의 합산부터 줄이고 시야·조작 저하를 주요 효과로 유지 | 현 CS 고단계 Moving -0.50, 섬광 최고단계 -0.30 외에 CS 고통 0.55·호흡 -0.40도 있음. 이동만 고쳐서는 다운을 전부 막지 못할 수 있음 |

쿨타임은 종료 틱을 저장하고 사용 시 비교한다. 매 가방의 별도 틱 업데이트는 필요 없다. 효과 조정은 AI 코드와 독립된 작은 변경으로 검증·커밋한다. 건물 피해 감소는 LOW가 작은 방에도 수류탄을 자주 쓰는 교리를 넣기 전에 적용하는 것이 좋다.

## A5. High CQB 하위 작업과 교리 구분

가장 큰 구조 변경이다. 분대는 임무·통신·접촉 기억·작업 예산을 소유하고, 화력조는 담당 입구/구역·스택·브리치·관측·투척·진입 실행 상태를 가진다. 전체 분대 스케줄러를 화력조 수만큼 복제하지 않는다. 같은 전역 예산 안에서 각 조를 순환 처리한다.

폰별 명령 소유자는 항상 하나여야 한다. 분대의 야전/의료/긴급 회피와 CQB 조의 이동/진입 명령이 동시에 같은 폰을 제어하지 않게 하위 작업 중지·재개 규칙을 둔다. 분대장의 임시 동행 관계, 무전/의료/공병 사상자 승계도 이 소유권을 따른다.

가능한 경우 다른 화력조는 다른 알려진 방·입구를 맡는다. 단일 입구나 한 방뿐이면 직렬 통과하고 다른 조는 경계한다. 세 조를 항상 동시에 돌입시키는 규칙은 두지 않는다. 폭발 안전은 인접 조까지 확인하고 같은 개구부의 사용권·자리 중복 제한은 유지한다.

| 교리 | 제안 적용 |
|---|---|
| LOW CQB | 스택→개척→관측→장비 판단→진입. 문 선호를 낮추고 방 확보 중심으로 진행 |
| High CQB | 스택→가능한 사전 관측 장비→개척→관측→장비 판단→진입. 현재 미구현인 사전 관측 장비는 단계 건너뛰기 |
| High 입구 우선순위 | 알고 있는 국소 후보에서 통로→열린 문→닫힌 문→벽. 미관측 문이 열렸다는 사실로 계획을 바꾸지 않음 |
| LOW 수류탄 | 수감실 예외를 두고 낮은 사용 문턱. 16칸 이하 절약 규칙과의 관계는 아래 미확정 사항 참조 |
| High 살상 도구 | 관측한 무장 위협·교전 상황 등 명시 조건으로 허용. 조건 미충족 시 관측/비살상/직접 진입 선택 |
| LOW 야전 | 자동화기사수 중심 임시 대응조, 수비 선호. 전진 시 연막 우선. 완벽한 저격/고정기총 대응은 요구하지 않음 |
| High 야전 | 화력조별 호 배치·엄호/기동 교대. 각 조 안에서는 응집 유지 |

LOW의 수감실 예외는 관측·이미 알려진 정보로 판단한다. 숨은 수감자의 현재 상태를 매번 조회해 전술 정보를 얻지 않는다.

짧은 확인: High 한 분대의 서로 다른 두 방, 단일 입구, 한 조의 공병 사상자, 옆 조 수류탄 대기, CQB 중 야전 긴급 전환과 복귀.

## A6. 스폰 규칙·지원 포인트·퇴각

현재 LOW는 6인 정찰/12인 보병이 있지만 소대는 보병 3개와 다른 인원/지원팀을 포함한 45명이다. 설계의 4개 보병분대 소대와 다르다. High는 4인 화력조 3개＋분대장 1명의 13인 분대, 3분대＋본부 4명의 43인 소대다. 의료 담당은 이 인원을 늘리지 않는 슬롯 변경으로 넣는다.

완전한 편제만 생성하는 기존 계획기를 수정해 허용 편제를 명시한다. LOW의 독립 지원팀 생성 허용도 함께 정리한다. 남은 포인트는 이미 지원 잔액으로 계산되지만 실제 지원 소비와 연결된 것으로 간주하지 않는다. 편제 포인트 허용 오차로 원래 포인트를 초과하는 현재 규칙도 새 지원 회계와 함께 검토한다.

CPU 목표에는 최대 1소대 생성이 유리하다. 우선 설정값으로 두고 상한 초과 포인트를 지원으로 전환하는 방식을 추천한다. 단, 대규모 습격의 압박을 지원 효과가 대신해야 하므로 상한과 지원을 함께 검증한다. 예산이 최소 편제 비용보다 낮을 때의 사건 선택/포인트 보정 정책도 명시해야 한다.

지원은 한 습격/조직의 제한된 요청 큐와 잔액을 사용한다. LOW 방탄장비·신식무기는 생성 시 보급부터, 연막 박격포는 교전 중 요청으로 추가한다. 반복 보급으로 장비가 무한히 늘어나거나 초과 포인트를 중복 소비하지 않게 한다. 요청 승인 시 예산을 예약하고 실제 시행 시 소비하며, 취소/실패 환불 기준을 고정한다.

저격 지원은 최근 관측한 한 폰과 알려진 사격 방향을 사용한다. 해당 방향의 LOS·차폐 조건을 통과해야 하며 벽 너머 임의 피해나 시야 밖 현재 위치 추적을 허용하지 않는다. 대상 이탈 시 취소/실패로 처리한다. 무전 재밍은 High의 실제 무전 채널에 한정하고 LOW 접촉 보고까지 중단시키지 않는다. 적용할 플레이어/다른 모드의 무전 체계는 별도 정의가 필요하다.

기존 박격포/CAS 호출 중 전술 수비 전환 연결은 재사용 후보지만, 정착지 피해를 제한하는 새 지원 자원 규칙과 동일한 기능은 아니다. CAS·장거리 포격은 기본 지원에서 제외하고 명시 설정을 켠 경우만 허용한다.

퇴각은 사상자·전력 상실·지연·지원 고갈 같은 사건을 낮은 빈도로 판단한다. 소탕은 보통 약탈/납치/부분 피해만으로 끝내지 않는다. 그러나 전멸할 때까지 계속하는 규칙도 아니며 지연전·전력 손실에 따른 철수는 유지한다. 치료·살아 있는 폭발물 안전·장비 회수는 철수 준비에 제한된 시간을 준다.

## A7. 습격 종류 확장

공통 임무 체계와 철수·지원 회계가 정리된 뒤 추가한다. 각 종류는 새 상시 맵 컴포넌트가 아니라 동일 실행 체계의 임무 정책으로 넣는다.

| 순서 | 종류 | 필요한 별도 동작 |
|---|---|---|
| 1 | LOW/High 소탕 | 이름 있는 침대 최초 목표, 구역 정리, 야외 연결, 일반 약탈/납치 종료 제거 |
| 2 | 박격포·LOW 화학탄 습격 | 설치/사격·교전 시 이른 철수·박격포 회수. 회수 불가 시 포기하는 제한 시간 |
| 3 | LOW 배회·임시기지 | 제한된 순찰 지향점 또는 고정기총 설치/경계/철수. 지원 포인트와 추가 폰 스폰 혼동 금지 |
| 4 | High 사보타주 | 외벽에서 접근 쉬운 소수 알려진 대상 선정·피해 후 철수. 전역 전략 중요도 맵은 재도입하지 않음 |
| 5 | High 암습 | 첫 시끄러운 행동을 사건으로 알람 발생. 단순 알람 지연과 은밀 이동/피탐 제어의 범위를 분리 |
| 6 | High 헬리본 | 운송/착륙/하차/회수 동작과 추가 자산 필요. 드랍포드 금지와 별개의 진입 수단으로 정의 |

암습에서 폭약 설치는 조용하지만 폭발은 알람을 발생시키는 식으로 사건 목록을 명시한다. 대상이 이미 전투를 시작했는데 알람이 계속 숨겨지는 경우도 처리한다. 사보타주의 기지 가치 판단은 실제 발견한 후보 또는 최초 임무 정보 안에서만 수행한다.

## 구현 전에 확정할 사항

1. 최대 1소대는 기본 규칙인지 선택 설정인지. LOW 4분대 소대의 본부 인원 유무, High 43명 소대를 유지할지 39명으로 줄일지도 별도 결정한다.
2. 문서의 “3인 화력조”는 현재 4인 화력조와 다르다. 이 초안은 기존 13인 편제를 유지하고 분대장 동행만 추가하는 것으로 해석했다.
3. “퇴각 포인트가 더 낮음”이 사상자 임계값 감소로 더 일찍 철수한다는 뜻인지, 남은 전력/포인트의 다른 기준인지 명시해야 한다.
4. LOW의 거의 항상 수류탄 사용이 기존 16칸 이하 절약 규칙을 대체하는지. 새로운 설계 방향에는 LOW만 작은 방에서도 사용하도록 바꾸는 쪽이 맞지만, 이 초안에서 확정하지 않는다.
5. 매딕가방 쿨타임 길이·조기 사용 비용, 대인 수류탄 건물 피해 0.1과 1/30 중 기본값, High의 살상 장비 허용 조건은 아직 수치/규칙 확정이 필요하다.
6. 의료 담당 장비가 기존 매딕가방인지 새 파우치인지, 다운 폰의 착용 장비까지 즉시 회수할지. 최초에는 기존 가방과 실제 드랍 회수를 추천한다.

## 검증과 성능 비용 관리

각 작은 변경은 해당 대표 사례와 관련 메서드만 짧게 확인한다. 모든 변경마다 44개 기능 시험이나 24그룹/96회 CPU 행렬을 돌리지 않는다. 순수 수치·지급 변경은 생성/실제 효과 확인으로 충분하고, CQB 하위 작업처럼 명령 소유권을 바꾸는 단계는 이동·사상자·폭발 대기를 함께 확인한다.

메서드 경과 시간은 기존 Core 레퍼런스 대비 비율, 호출 수, 긴 호출을 기록한다. Core 비율을 OS CPU 비율로 취급하지 않는다. 새 조별 실행과 정보 보고에 대해서는 짧은 동일 조건 N/V 틱 CPU와 전체 메인 CPU 대조를 추가하고, 특히 동시 Job/경로 요청에 의한 스파이크를 별도로 본다.

화력조가 세 개가 돼도 전역 계획·관측·작업 발행 예산을 세 배 늘리지 않는다. 보고 구역 크기, 기동 후보 수, 다음 건물 후보 수, 지원 요청 수에 상한을 두고 여러 틱에 나눠 처리한다. 이 방식은 반응이 조금 늦어질 수 있지만 기존 CPU 우선 목표와 맞는다.
