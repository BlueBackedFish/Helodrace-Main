## A4.1 의료 가방

지혈과 혈장이 가방에 저장된 종료 틱을 공유한다. 정상 사용은 물자를 소비하지 않고 게임 내 1시간(2500틱) 쿨타임을 시작한다. 쿨타임 중 조기 재사용은 종류별 기존 비용인 구성품 1개를 소비하고 종료 틱을 다시 설정한다. 착용자 변경·드랍·회수로 값이 초기화되지 않는다. 별도 가방 틱은 없다.

실제 효과를 적용한 뒤에만 비용과 쿨타임을 확정한다. 작업 중단·처치 부위 없음·이미 혈장 상태인 대상은 소비하지 않는다. 지혈 4부위/주요 장기 제외·30초 작업과 혈장 중복 금지는 유지한다. 전술 의료 AI와 플레이어 버튼이 같은 사용 가능 조건을 사용한다.

빌드 및 관련 자원/쿨타임·실제 Scribe 검사 통과. 게임 전체 로드 검증이나 F07 완료를 의미하지 않는다.
