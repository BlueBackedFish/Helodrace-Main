# A4 장비 규칙 구현

2026-10-12. 후속 로드맵 A4의 구현 기록. 게임 기능 확인은 단일 약식 목록 F07~F09에서 사용자가 진행한다.

## A4.1 의료 가방

지혈과 혈장이 가방에 저장된 종료 틱을 공유한다. 정상 사용은 물자를 소비하지 않고 게임 내 1시간(2500틱) 쿨타임을 시작한다. 쿨타임 중 조기 재사용은 종류별 기존 비용인 구성품 1개를 소비하고 종료 틱을 다시 설정한다. 착용자 변경·드랍·회수로 값이 초기화되지 않는다. 별도 가방 틱은 없다.

실제 효과를 적용한 뒤에만 비용과 쿨타임을 확정한다. 작업 중단·처치 부위 없음·이미 혈장 상태인 대상은 소비하지 않는다. 지혈 4부위/주요 장기 제외·30초 작업과 혈장 중복 금지는 유지한다. 전술 의료 AI와 플레이어 버튼이 같은 사용 가능 조건을 사용한다.

빌드 및 관련 자원/쿨타임·실제 Scribe 검사 통과. 게임 전체 로드 검증이나 F07 완료를 의미하지 않는다.

## A4.2 대인 수류탄의 건물 피해

MK II·MK III·M67·M111의 폭발과 MK II/M67 파편에 건물 피해 0.1배를 적용한다. 바닐라 Bomb/CutBase에서 파생한 전용 DamageDef를 사용하며 인체 피해·방어구 판정·폭발 전파는 그대로 따른다. 바닐라 Bomb의 통과 가능/불가능 건물 추가 배율에도 이 0.1배가 곱해진다. 피해를 받는 건물 종류에 상관없이 적용한다.

C4·돌파 폭약·해머·유탄발사기·포탄·WP는 이 정의를 사용하지 않는다. 전역 피해 패치나 매 틱 계산을 추가하지 않았다. 관련 XML 파싱·원본 DamageDef 상속/적용 범위 확인 완료. 실제 건물 비교는 F08에 남긴다.
