# A3 야전 집결과 의료 담당 구현

2026-10-12. A3.1~A3.3 구현 및 관련 검증 완료. 실제 게임 기능 확인은 [단일 약식 목록](습격%20기능%20약식%20테스트%20목록.md)의 F02·F05·F06에 둔다. 사용자 확인은 아직 미실행이다.

## 조별 집결과 기동

LOW는 야전 대응 시작 때 자동화기사수 중심 중앙조와 두 측면조를 고정한다. HIGH는 실제 조직의 세 화력조를 유지한다. 좌우 전진·중앙 후퇴 화력점 주변에서 4방향 플러드필로 최대 49칸, 중심에서 각 축 3칸 이내의 연결된 공간을 한 번 계산한다. 문칸·벽·약속된 CQB 경계를 넘지 않는다. 조 안에서는 사격선·엄폐·불규칙 분산 점수로 다른 타일을 선택한다.

공통 구역에 도착해 경계 중인 인원이 75% 이상이고 준비된 총기 사수가 최소 한 명이면 준비된 조로 본다. 사거리 밖 조기 대응에서도 집결할 수 있도록 현재 적까지의 사격 가능 거리는 준비 조건으로 요구하지 않는다. 정확한 개별 지정 칸 일치는 요구하지 않는다. 이동 중 공통 구역에 들어온 폰도 그 자리에서 경계·사격을 시작할 수 있다. 구역 밖 임시 대기는 준비 인원으로 세지 않는다.

360틱 후 집결이 부족하면 조 전체에 최대 두 번 대체 구역을 제공한다. 첫 대체는 대표 조원에서 목표 방향으로 벽을 넘지 않는 최대 6칸 중간 합류점, 두 번째는 대표 조원 근처의 연결된 수비 구역이다. 각 폰의 고립된 위치를 별개의 완료 화력점으로 확정하지 않는다. 부족한 자리는 180틱 간격으로만 재시도한다. 처음 집결은 360틱 이후 대응 대기 상태로 내려가므로 미도착 인원 때문에 전원이 무기한 준비 단계에 갇히지 않는다. 준비 기준을 충족하지 못한 조는 진격하지 않는다.

HIGH는 한 실제 화력조씩 기본 12칸 기동한다. 엄호 구역과 중심 거리 30칸을 넘는 후보는 5칸 짧은 기동으로 낮춘다. LOW는 5칸 접근이며 연막 확보를 먼저 요구한다. 조별 준비 판정과 같은 구역 생성 방식을 다음 기동에서도 사용한다. 이동 단계는 75% 도착 또는 600틱 대기 후 수비로 전환하며, 잔류 인원은 합류 대상으로 남는다.

화력조가 없는 HIGH 분대장은 가까운 생존 화력조에 임시로 동행한다. 지휘자 교체 또는 동행조 소멸 때만 다시 선택한다. 조직 소속·편제는 바꾸지 않으며 별도 네 번째 기동조를 만들지 않는다.

## 비용과 저장

준비된 다수가 있어도 구역에서 12칸 이상 떨어진 인원이 있으면 다음 진격을 보류하고 제한된 합류/대체 수비를 먼저 적용한다. 짧은 기동도 엄호 구역에서 30칸을 넘으면 해당 기동을 보류한다. 스냅샷처럼 재사용하는 구역에서도 현재 자리의 바닥 유효성은 저빈도 판단 시 확인한다.

기존 전역 계획·이동·작업 예산을 공유한다. 자리 배정은 한 진행에 최대 2명, 사격선/엄폐 평가는 1명당 최대 16후보다. 연결 공간은 조별로 재사용하고 매 틱 다시 계산하지 않는다. 전체 맵 탐색이나 폰 쌍 거리 비교, 추가 맵 틱 컴포넌트는 없다. 구역·고정 조 구성·합류 재시도·동행 관계·기동 상태를 기존 실행 상태에 저장한다.

빌드 경고/오류 0. 관련 콘솔 검증에서 벽을 넘지 않는 연결 공간, 소수 지연을 허용하는 준비 기준, 긴 기동, 실제 Scribe의 구역/동행 값 저장·읽기를 확인했다. Unity 월드 전체 로드나 게임 기능 시험 완료를 의미하지 않는다.

## 의료 담당과 가방 회수

현재 생성되는 각 `Squad` 편제에서 기존 비지휘 슬롯 1명을 의료 담당으로 지정한다. 호환되는 소총수 슬롯을 먼저 고르며 기본 무기·수류탄·군복·편제 인원은 유지한다. 작은 LOW 정찰분대도 한 명 지급 대상으로 정했다. 6/12/13명 및 소대 인원수 개편은 A6 범위이며 이번 변경은 현재 편제 숫자를 바꾸지 않는다. HIGH는 분대마다 한 명으로, 각 화력조마다 추가하지 않는다.

기존 `HD_Apparel_GreatWarMedibag`를 사용하고 기존 재료 물자 5회분을 실제 아이템으로 지급·충전한다. 새 파우치나 PawnKind는 없다. 의료 담당 표식과 TCCC 자격을 부여하며 LOW는 지정된 의료 담당만 비플레이어 TCCC를 사용할 수 있다. 안전한 확보 방·정착된 야전 수비에서 담당의 가방 처치를 우선하고, 적격한 가방/물자가 없으면 기존 자가·동료 TCCC 지혈로 내려간다. 혈액 손실 후 혈장 후속 처치도 기존 작업을 사용한다. 바닐라 치료 작업은 추가하지 않았다. 가방 쿨타임 변경은 A4로 남긴다.

분대 등록 시 실제 착용 가방 참조를 기억한다. 다운/사망 알림과 가방 탈착 알림은 다음 제한된 회수 확인을 깨운다. 회수는 같은 맵에 실제로 떨어진 알려진 가방만 허용하고, 착용 중인 다운 폰/시체에서 벗기는 작업이나 전 맵 장비 탐색은 하지 않는다. 알려진 가방을 600틱 간격으로 확인하며, 안전한 구간의 20칸 이내 호환 인원 한 명을 소유자로 지정한다. 후보 하나의 바닐라 예약/도달 검사만 전역 계획 예산 안에서 수행한다. 문/벽을 돌아가는 회수 경로는 선택하지 않는다.

회수 작업은 이동 예산을 따르고 60틱 수거 후 가방을 착용한다. 분대당 하나의 회수 실행 상태와 바닐라 아이템 예약을 함께 사용한다. 회수한 인원에게 의료 담당·TCCC 자격을 넘기고 기존 가방 물자를 그대로 보존한다. 교전·폭발 위험·담당 다운·600틱 지연이면 회수를 중단한다. 다른 인원은 현재 자리에서 엄호하고 이후 기존 임무로 돌아간다. 분대 해제 시 실행 상태도 정리한다.

의료 담당 표식, 알려진 가방 참조, 회수 담당·가방·시작 시점·바닐라 작업 ID를 저장한다. 로드 시 ID·작업 종류·대상 가방이 모두 맞는 원래 작업만 재연결하며 복제하거나 새 회수를 시작하지 않는다. 개발자 `Inspect squad commands`에는 연결 구역 크기/대체 횟수, 동행조, 의료 담당, 회수 담당을 표시한다.

`--a3` 관련 검사에서 조 편제 유지·의료 슬롯 선택·실제 드랍 조건·작업 재연결·의료 표식 Scribe·회수 정의 연결·전역 예산을 확인했다. `--a1-focus`의 기존 집중 사격/관측/협력/폭발 안전 회귀 검사도 통과했다. 정기 CPU 프로파일링과 전체 세이브/게임 반복 테스트는 실행하지 않았다.

## 의료 가방 착용 충돌 수정

2026-10-12 최근 `Player.log`의 `No compatible medic slot in HD_Formation_GW_RifleSquad`는 필수 체스트리그와 매딕가방이 모두 `Belt` 레이어·`Shoulders` 부위를 사용하는 데서 발생했다. A3 지급 과정의 예외가 `OrganizationGenerator.Generate`까지 전파되어 생성한 분대 전체를 취소했다.

매딕가방에 별도 `HD_MedicalBag` 레이어를 지정하고 `Inherit="False"`로 부모의 `Belt` 상속을 제거했다. 이 레이어만 바닐라 유틸리티 팩 표시로 분류해 기존 가방 텍스처 경로·표시를 유지한다. 체스트리그·군복·방탄복을 벗기지 않고 가방을 착용한다. 모든 의료 후보의 착용이 다른 모드 등의 이유로 불가능할 때는 명시적인 경고를 남기고 가방 지급만 생략하여 레이드 생성은 유지한다.

관련 검사에서 실제 Helod 신체 그룹과 바닐라 `ApparelUtility.CanWearTogether`로 기존 충돌을 재현한 뒤 수정된 가방과 LOW/HIGH 필수 장비의 동시 착용을 확인했다. 부모 레이어 차단·새 레이어 정의도 검증했다. 빌드 경고/오류 0, `--a3` 통과. 재시작 후 레이드 생성·가방 지급 확인은 단일 목록의 F06에 남긴다.
