# R5 연락과 협력 진입

상태: 구현 전 범위·대표 검증 조건 확정. main에서 의미 있는 검증 완료 단위마다 커밋한다.

## 구현 계약

- 기존 조직과 착용 무전 파츠 판별만 재사용한다. 구형 통신 프레임/분대 간 폰 그래프/맵 캐시를 새 실행에 연결하지 않는다.
- 대표 연락자 중심으로 전 맵 공통 작업 예산을 사용한다. 한 번에 한 분대 쌍을 조사하고 메시지 큐는 최대 64개, 처리량은 최대 2건/틱으로 제한한다. 전체 분대 쌍을 한 틱에 재구축하지 않는다.
- LOW는 가까운 실제 LOS/연막 없는 접촉에서만 새 보고·협력 메시지를 교환한다. 접촉에서 확정한 역할·예정 시각은 분리 후에도 따르지만 새 준비/실패/적 상태를 원격으로 읽지 않는다.
- High 무전은 정상 착용 방탄복의 실제 설치 무전 파츠, 가능한 운용자, 호환 네트워크·사거리 조건을 송수신 시점에 확인한다. 인벤토리/지면 장비와 태블릿은 인정하지 않는다. 운용자 사망·다운·파츠 제거 시 진행 중 메시지는 무효로 하고 대체 운용자를 제한된 탐색으로 선택한다.
- 목격 보고는 원래 관측 시각·좌표의 값 복사다. 수신 시각으로 신선도를 부풀리거나 더 최신인 자체 관측을 덮어쓰지 않는다. 다른 분대의 확보 칸 전체를 실제 진입 이력으로 복사하지 않는다.
- 협력은 제안→수락→확정, 준비 보고, 시작, 완료/중단으로 표현한다. 분대별 합의 상태는 별개이며 상대 준비 상태는 받은 메시지로만 갱신한다.
- 다른 외벽 입구와 담당 구역을 우선 배분한다. 현재는 두 분대의 합의 단위로 구성하며 여러 쌍을 병행할 수 있다. 해당 구역의 실제 진입/확보가 필요하다. 공동 최종 목표와 맡은 구역의 완료를 구분한다.
- 같은 입구밖에 없으면 기존 물리 사용권과 대기 자리를 사용해 차례로 진행한다. 상대가 사용권 때문에 준비하지 못해도 서로 기다리며 멈추지 않도록 사전 예정 시각·시간 제한·독립 진행 복구를 둔다.
- 실내에서 다른 아군 분대와 실제 조우하면 짧은 식별 지연을 둔다. 오인 사격/프래깅은 만들지 않는다. 이미 발사한 수류탄·C4 안전 절차를 식별/통신 대기 때문에 중단하지 않는다.

## 검증 범위

먼저 관련 정책·프로토콜·보고 신선도·작업 제한과 기존 실제 무전 파츠 판별을 로컬 검사한다. 실제 게임은 필요한 대표 사례만 각 1회 실행하고 실패/수정 영향만 재검증한다.

| 사례 | 발생 조건 | 성공 조건 |
|---|---|---|
| LOW 다중 진입 | 접촉 가능한 2개 완전한 분대, 실제 분리된 외벽 진입·방 배분 | 합의 3단계, 서로 다른 입구/담당 구역의 실제 진입·확보, 분리 후 새 보고 없음, 실내 재접촉/식별 지연, 전체 임무 진행 |
| LOW 공유 입구 | 유일한 통과 가능 개구부, 다른 돌파 수단 없음 | 합의/대기 후 두 분대의 선두·후미가 같은 개구부를 실제 통과, 후속 분대 영구 정지 없음 |
| High 연락 단절·승계 | 음성 범위 밖의 2개 13인 분대, 실제 방탄복 무전 파츠 제거/재설치 및 운용자 사망 | 무전 없이 보고/확정 없음, 착용 무전 복구 후 교환, 사망 발신자의 진행 중 메시지 무효·대체 운용자 사용·임무 진행 |
| 순수 정책 | 오래된/중복/미확정/취소 메시지와 최대 큐 부하 | 신선도/역행 방지, 미확정 협력 금지, 시한 후 독립 복구, 전역 메시지 처리량 제한 |

현재 프로파일러로 연락 조사·송수신·협력 게이트·관련 계획 함수와 Core/전체 틱만 수집한다. 메서드 경과 시간과 OS CPU를 구분하고 상위/하위 비용을 중복 합산하지 않는다. 약식 결과를 정식 N/V 2배 합격으로 표시하지 않는다. 대규모 반복·저장/로드·다중 맵 전체 검증은 R7에 남긴다.

디스크 공간이 부족해 로컬 테스트는 기존 게임 DLL을 직접 해석하도록 실행 진입점을 분리하고 Unity 참조 복사를 제외했다. 같은 관련 검사 실행이 통과했으며 불필요한 게임 런타임 사본 생성을 줄인다.
