# A5 HIGH CQB와 교리 구현

2026-10-12. 후속 로드맵 A5.1~A5.2 구현 기록. 실제 게임 기능 확인은 단일 목록 F10~F11에서 사용자가 진행한다.

## 실행 단위와 진입

HIGH는 분대 스케줄러·관측/기억·통신·의료 담당을 그대로 유지한다. 최초 접근과 외벽 개척은 분대의 공통 작업이며, 한 입구를 통과할 때는 역할 순서를 실제 화력조별로 묶는다. 선행 조의 살아 있는 진입 인원이 개구부를 실제로 넘어가면 다음 조를 출발시킨다. 최종 자리 도착·교전 종료까지 뒤의 조를 기다리게 하지 않는다. 분대장은 중간 조에 배치한다.

첫 실내 공간을 확보하고 다음 실내 경계가 확인되면 실제 생존 화력조 최대 3개의 CQB 하위 작업을 만든다. 조직 트리·최소 13인 스폰 규칙은 바꾸지 않는다. 분대 직속 인원은 가까운 생존 조에 임시 동행한다. 조마다 별도 입구·스택·브리치·관측·투척·진입·방 조사 상태를 갖는다. 분대는 알고 있는 경계를 배분하고 완료 시 새 경계를 받아 다음 작업을 배분한다. 야외 연결과 다음 건물 탐색은 분대가 수행한다.

같은 개구부·같은 도착점·근접한 같은 방향 경계를 동시에 배분하지 않는다. 추가로 최대 64칸의 문을 넘지 않는 국소 공간을 한 번 계산해 다른 입구로 같은 작은 방을 맡는 일을 줄인다. 대형 방 전체의 동일성을 보장하는 전역 방 그래프는 아니다. 실제 자리/입구 예약과 공통 확보 기록도 그대로 확인한다.

입구 하나뿐이면 한 조가 개척하고 다른 조는 자기 경계 자리를 유지한다. 확보 후 후속 조는 확인된 같은 개구부를 다시 스택업/투척하지 않고 직접 통과한다. 작은 방에서는 가능한 인원만 안에 들어가고 남은 인원은 입구 양옆의 별도 자리를 사용한다. 새 분기 임무가 있으면 이를 후속 통과보다 우선 배분한다.

## 예산·소유권·중지

하위 작업은 게임 스케줄러와 통신 대상 목록에 등록하지 않는다. 분대 판단 한 번에 하위 작업 하나만 순환 처리하고 전역 계획·작업·경로 예산을 공유한다. 후보는 한 번에 최대 12개, 미완성 계획과 자리 배분은 기존 분산 계산을 사용한다. 일반 대기는 10틱 간격이며 계획/조사 진행 중에만 다음 틱을 요청한다. 전체 맵 캐시나 추가 맵 틱은 없다.

폰의 실행 기록은 분대와 화력조가 같은 객체를 참조한다. 작업 완료·관측·진입 콜백은 해당 조를 찾고, 의료/가방 회수·집중 사격·야전 연막 콜백은 상위 분대를 찾는다. 공병 장비 후보는 분대가 공유하고 실제 회수·설치 담당은 해당 실행 작업 하나가 소유한다. 분대 공통 대응 동안 조의 새 명령을 멈추고 재개 시 같은 입구·진입 이력을 사용한다.

진행 중인 C4와 발사된 수류탄은 일반 공통 대응이 덮어쓰지 않는다. 인접 조의 진입은 살아 있는 폭발물의 국소 범위에서 안전 대기한다. 목표 변경·전체 반환은 조의 폭발 안전과 반환을 먼저 마친 뒤 수행한다. 하위 작업 종료/맵 제거 때 자리·입구 예약과 폰 소유권을 정리한다.

## 저장·개발자 표시·검증

조 ID·분대원 인덱스·입구/자리·단계·후속 통과 순서·폭발물 상태를 저장한다. Pawn/Job 실행 기록은 분대에 한 번만 저장하고 로드 시 조가 같은 기록을 다시 참조한다. 원래 바닐라 Job ID를 재연결하며 새 작업을 복제하지 않는다. 미완성 계산은 기존과 같이 로드 후 재개한다.

Inspect squad commands와 계획 노드 View에 화력조 하위 작업이 표시된다. 스케줄러의 분대 수 집계는 화력조 수만큼 늘리지 않는다.

빌드 경고/오류 0. `--a5`에서 조별 소유권·동행·단일 입구 출발·64칸 상한·입구 배분·안전 반환·실제 Scribe의 중첩 값 저장/읽기를 검사했다. 콘솔 환경은 모드 타입 목록만 제공하며 구버전 변환을 사용하지 않는다. `--a3`, `--cadence` 회귀 검사 통과. 전체 Unity 세이브 로드나 F10~F11 게임 확인 완료를 의미하지 않는다. 정기 성능 수집은 실행하지 않았다.
