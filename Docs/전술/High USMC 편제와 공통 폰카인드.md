# High USMC 편제와 공통 폰카인드

2026-10-04 적용. 기존 M16A4 장비와 맞는 전통적 USMC 소총분대 구성을 기준으로 삼는다. 최신 USMC의 모든 무장·지원 편제를 재현하는 변경은 아니다.

## 편제와 생성 비용

| 단위 | 구성 | 인원 | 현행 생성 비용 |
|---|---|---:|---:|
| 화력조 | 조장/유탄 사수, 자동소총수, 보조사수, 소총수 | 4 | 660 |
| 소총분대 | 분대장 1명 + 화력조 3개 | 13 | 2,275 |
| 소총소대 | 본부 4명 + 소총분대 3개 | 43 | 7,445 |

소대 본부는 소대장, 소대 선임하사, 가이드에 해당하는 본부 소총수, 전령에 해당하는 본부 소총수로 구성한다. 소대장→선임하사→가이드→전령 순으로 직속 인원의 승계 순서를 지정한다. 화력조는 조장→자동소총수→보조사수→소총수 순이다. 기존 하위 지휘자의 상위 지휘 대행 규칙도 유지한다.

High 예산 허용 오차 10%는 유지한다. 예를 들어 600점이면 화력조 1개, 2,100점이면 분대 1개, 6,800점이면 소대 1개를 생성할 수 있다. 예산이 부족해도 일부 인원만 빠진 불완전 편제를 만들지 않는다.

편제 기준 자료:

- [USMC MCRP 3-10A.4, Marine Rifle Squad](https://www.marines.mil/Portals/1/Publications/MCRP%203-10A.4.pdf): 13인 분대와 4인 화력조 3개 구성.
- [USMC 1/2 소총분대 훈련 기록](https://www.marines.mil/News/Article/1397362/charging-forward-12-assaults-the-objective-completes-live-fire-range/): 조장, 자동소총수, 보조사수, 소총수의 화력조 역할.
- [MCRP 5-12D, Organization of Marine Corps Forces](https://www.trngcmd.marines.mil/Portals/207/Docs/TBS/MCRP%205-12D%20Organization%20of%20Marine%20Corps%20Forces.pdf): 소총소대 장교 1명과 병 42명 기준.

## 폰카인드와 장비

모든 슬롯은 기존 `HD_MW_HelodRifleman` 한 종류를 사용한다. 지휘 역할은 `commandRole`, 전투 보직은 `combatRole`, 수류탄과 돌파 장비는 슬롯의 추가 장비 목록으로 구분한다. 조장·분대장·보조사수 전용 폰카인드를 만들지 않는다.

조장은 `HD_Role_Grenadier`와 `HD_Role_TeamLeader`를 함께 가진다. 자동소총수는 기존 `HD_Role_AutomaticRifleman`, 보조사수는 새 `HD_Role_AssistantAutomaticRifleman`을 사용한다. 무장은 슬롯의 weaponPreset으로 지정하고 폰 생성 직후 기존 모듈 무기 프리셋 적용기를 통해 교체한다.

화력조장은 HD_WeaponPreset_M16A4_UBGL(M16A4＋M203A2), 자동소총수는 HD_WeaponPreset_M249_USMC를 적용한다. 나머지 인원은 기존 M16A4를 유지한다. IBTV·FASTMT 방어구는 공통이다. 조장에게 M381 HE 40mm 유탄 6발을 지급한다. 이번 연결은 생성 장비 배정이며, CQB/야전 전술에서 M203 발사를 자동 선택하는 기능은 별도 구현 대상이다.

기존 조장/분대장의 ZAPER, 분대장의 C4 3개와 점화기, 연막 및 수류탄 지급은 유지한다. 추가 소총수와 본부 지원 인원도 현행 수류탄 정의를 사용한다. 역할 분리는 자동소총의 지속 화력이나 유탄발사기의 실제 발사 기능을 대신하지 않는다.

## 전술 실행과 검증

13인 High 분대는 기존 실행 단위 하나로 동작하고, Alpha/Bravo/Charlie에 해당하는 3개 Team 소속은 보존한다. 소대 본부는 분대와 분리된 단위이며 조직 지원 예산을 복제하지 않는다. 화력조별 독립 엄호·기동은 기존 통합 계획의 후속 구현 대상이다.

검증은 실제 편제 XML을 읽는 조직 테스트에서 인원·비용·보직·승계·예산별 완성 편제를 확인한다. 실행 단위 테스트도 3개 화력조와 13인 분대를 사용해 한 계획 아래 소속이 유지되는지 확인한다. 실제 게임에서는 새 High 습격을 생성해 4/13/43 인원과 역할 표시, 장비 지급을 확인해야 한다.
