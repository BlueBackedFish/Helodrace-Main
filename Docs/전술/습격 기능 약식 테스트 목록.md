# 습격 기능 약식 테스트 목록

2026-10-12. 게임에서 사용자가 확인할 남은 항목을 이 파일에서만 관리한다. 사용자 확인이 끝난 항목은 삭제했다. 빌드·코드 검사 통과는 게임 확인 완료와 구분한다. 기존 F번호는 유지하며 삭제한 번호를 재사용하지 않는다.

## 확인 방법

- 기본은 한 분대다. 정보 공유 확인에만 두 분대를 사용한다. 같은 장면에서 여러 항목을 함께 확인해도 된다.
- 상태는 미실행 / 재확인 / 문제로 기록한다. 통과하면 해당 행을 삭제한다. 일부만 확인했으면 남은 조건과 증상만 남긴다.
- 복잡한 메서드 분석·세이브 안정성 검증은 에이전트가 담당한다. 이 목록에는 사용자에게 넘길 간단한 게임 기능 확인만 둔다.
- 정기 CPU 수집·반복 성능 시험은 하지 않는다. 성능 문제가 보고되면 해당 부분만 조사한다.
- 필요할 때 개발자 Inspect squad commands의 phase, opening/depth/inside, passed/entered, stack party, entry order, furniture, mission/next, secured own/shared를 참고한다.
- 문제 기록은 상태 칸에 날짜 / 증상 / 세이브 또는 오류 로그 위치 정도로 적는다. 미실행 항목 때문에 다음 개발을 멈추지 않는다.
