# 습격 기능 약식 테스트 목록

2026-10-11. [추가 계획](습격%20설계%20추가%20계획%20검토.md)의 게임 내 기능 확인을 개발 작업과 분리한 목록이다. 목록을 작성하는 것은 시험을 실행했다는 뜻이 아니다. 아래 항목은 후속 변경을 위한 초안이며 아직 미실행이다.

## 진행 방식

- 작업 구간에서는 빌드와 직접 관련된 짧은 기존 검사만 수행한다. 게임에서 쉽게 확인할 동작은 이 목록에 기록하고 다음 작업으로 진행한다.
- 사용자가 플레이하면서 확인하거나 별도 약식 기능 확인을 요청했을 때 해당 항목만 실행한다. 매 구간마다 게임 실행·전체 목록 순회·장시간 관측을 자동으로 시작하지 않는다.
- 테스트는 결과가 눈에 보이는 최소 규모로 한다. 기본은 한 분대이며, 연락/협력 확인에만 두 분대 또는 필요한 화력조를 사용한다. 한 장면으로 여러 항목을 확인할 수 있으면 묶는다.
- 메서드별 분석·프로파일링·CPU 수집·성능 비교·저장/로드 안정성·반복 재현은 이 목록에 포함하지 않는다. 별도 문제가 보고됐거나 사용자가 요청한 경우에만 그 부분을 조사한다.
- 결과는 `통과 / 문제 / 미실행`과 짧은 증상으로 남긴다. 미실행 항목은 다음 개발 구간의 진행을 막지 않는다. 보고된 문제와 직접 확인한 진행 불가는 해당 수정 범위에서 처리한다.
- 새로운 기능마다 새 테스트 도구를 만들지 않는다. 기존 게임 UI·개발자 표시·이미 있는 짧은 검사로 확인하고, 확인 수단이 없는 항목은 사용자 테스트에 필요한 관찰 지점을 적는다.

## 결과 기록

확인한 행에 상태를 갱신하고 아래 형식으로 짧게 남긴다. 대량 원본 묶음·세이브 반복·메서드 수집 보고서는 요구하지 않는다.

`날짜 / 변경 또는 커밋 / F번호 / 확인자 / 통과 또는 문제 / 실제 관찰·필요한 오류 로그`

관찰하지 못한 동작은 미실행으로 유지한다. 문제 보고가 오면 관련 행만 재현·수정·재확인한다.
