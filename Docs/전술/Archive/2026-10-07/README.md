# 이전 전술 AI 체계 아카이브

보관일: 2026-10-07. 원본 기준 커밋: `b837a006`. 기존 `Docs/전술`의 Markdown 48개·측정 JSON 11개와 `Docs/TacticalMapAnalysis.md`, `Docs/TacticalRaidReview.md`, 총 61개 파일을 보관한다. 본문과 측정 내용은 유지하고 이동에 필요한 상대 링크만 조정했다.

**이 폴더의 계획과 다음 작업은 과거 체계의 기록이다.** `experiment/tactical-ai-rewrite`의 새 실행 순서는 [새 로드맵](../../최적화%20전술%20AI%20로드맵.md)을 따른다. 옛 1~8단계, A~D, 최적화 1~4순위의 완료 상태를 새 R0~R7의 완료로 해석하지 않는다.

아카이브 이동은 실제 코드 제거가 아니다. 기존 체계는 아직 동작하며 새 구현은 미착수다. 편제·장비처럼 현재도 사용하는 정의의 설명은 계속 참고할 수 있지만, 옛 계획의 맵 캐시·이동 마스크 구조를 새 엔진에 유지할 의무는 없다.
