# AI 수류탄 준비와 신속 투척

조직 AI의 진입 지원·야전 연막·문 닫힘 대응에는 별도 작업 `HD_RaidPrepareGrenade`를 사용한다. 플레이어의 기존 근거리/일반 투척은 각각 90/180틱 준비 시간을 유지한다.

AI 작업은 **준비 30틱 → 수류탄을 든 채 지정 투척 위치로 이동 → 도착 후 투척 동작 18틱(0.3초) → 발사** 순서다. 이미 투척 가능한 위치에 있으면 이동 단계는 바로 완료된다. 이동 목적지와 투척 목표는 작업에 함께 보관해 두므로 이동 후 새 사격/투척 작업을 다시 선정하지 않는다. 지원 목표 탐색은 가까운 투척자부터, 목표 최대 16개·위치 최대 10개로 제한한다.

시작 순간부터 해당 작업의 `neverShowWeapon` 및 `canUseRangedWeapon=false`를 적용한다. 장비 Verb의 사격 시작과 연사 가용성도 차단하고 기존 조준/연사를 초기화한다. 준비 완료 뒤에는 소지품 수류탄의 텍스처를 손 위치에 그린다. 실제 무기를 벗기거나 수류탄을 장비 슬롯·운반 슬롯으로 이동시키지 않는다. 근접 방어 기능을 전역 비활성화하지 않는다.

작업 중단·긴급 회피·피격에 따른 바닐라 작업 재선정·실행 계획/지원 역할 변경으로 준비를 취소할 수 있다. 중단된 작업은 큐에서 재개하지 않는다. 사격 제한과 손 표시 여부는 현재 작업 드라이버에서 읽으므로 다른 작업으로 넘어가면 바로 해제되며, 별도 전역 준비 상태가 남지 않는다. 준비·이동 중에는 탄약을 소비하지 않는다. 투척의 마지막 18틱 동안 시야·거리·아군 노출 안전을 다시 검사하고 발사 직전에도 기존 안전 검사를 거친다. 실패하면 던지지 않는다.

진입 지원은 현재 위치·개구부 밖 대기 위치 중에서 투척 시야와 안전이 확보된 곳을 고른다. 아군 위험 계산에는 투척자가 앞으로 설 위치도 반영한다. 준비 작업이 끝나거나 취소되면 스택으로 복귀하도록 하고, 이미 발사한 수류탄은 기존처럼 실제 발사체·폭발 효과 종료와 투척자 복귀가 확인될 때까지 진입을 막는다. 0.3초는 투척 동작 시간이며 수류탄의 비행·신관·폭발 대기를 단축하지 않는다.

준비 여부·발사 여부·소유 조직·계획 시점은 작업과 함께 저장된다. 로드 후에도 준비 중 사격 금지 및 남은 투척 시간을 유지한다. 현재 준비가 진행 중인지에 대한 실행/연막 판단에도 새 작업을 포함했다.

자동 검증: 실제 게임 클래스에서 AI 작업 중 사격 시작·연사 차단, 준비 완료 후 이동 중 차단, 종료·다른 작업 전환 시 즉시 해제, 플레이어 작업 보존, 실제 생성 Toil의 이동-도착-18틱-발사 순서, 중단 가능 및 총 숨김 XML, 지원 담당자/계획 변경 시 취소와 야전 연막 담당자 유지 조건을 확인하는 19개 검사와 새 Harmony 연결 3개를 추가했다. 게임 내 손 표시 위치, 긴급 회피와 저장/로드 재현은 별도 실전 확인이 필요하다.
