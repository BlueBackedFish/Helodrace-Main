# 습격 시스템 후속 로드맵

2026-10-11. 기존 [R0~R7 재설계는 완료](최적화%20전술%20AI%20완료%20기록.md)했다. 이 문서는 이후 구현의 기준이다. 요구사항은 [습격 설계](습격%20설계.md), 세부 구조와 검토 근거는 [추가 계획 검토](습격%20설계%20추가%20계획%20검토.md)에 둔다. A1 구현과 관련 에이전트 검증을 완료하고 사용자가 F01~F02를 확인했다. 호 배치 피드백을 반영한 수정 후 F02 재확인은 남아 있다. [A1.4 사격 집중 AI](A1.4%20사격%20집중%20AI%20구현.md)도 구현·관련 에이전트 검증을 완료했으며 F16도 사용자가 정상 작동을 확인했다. [A2 소탕 지속·확보 보고](A2%20소탕%20지속과%20확보%20보고%20구현.md)도 구현·관련 검사 완료이며 F03·F04·F17은 사용자 확인 대기다. [A3 집결·기동·의료 담당](A3%20야전%20집결과%20의료%20담당%20구현.md)도 2026-10-12 구현·관련 검증을 완료했다. F02·F05·F06은 사용자 확인 대기이고 A4~A7은 아직 미구현이다.

## 작업 원칙

2026-10-12 후속 변경: 확보 구역과 확인된 개구부는 [맵 공통 기록](공통%20확보%20기록%20구현.md)으로 전환했다. 기존 A2의 확보 보고 연락/무전·ACK·분대별 사본은 제거했다. 적 접촉 보고와 협력 작전 통신은 유지한다. 단일 목록의 F03·F17 사용자 확인 표시는 유지하며 F04는 새 공유 규칙으로 재확인한다.

- 모든 개발·커밋은 `main`에서 수행한다. PR은 완료분 검토용이며 개발용 별도 브랜치로 전환하지 않는다.
- CPU와 틱 지연을 낮추는 기존 구조·전역 예산·제한된 후보·낮은 갱신 빈도를 유지한다. 화력조가 늘어도 예산과 폰별 판단을 그대로 배수로 늘리지 않는다.
- 정기 성능 테스트·반복 N/V 대조는 하지 않는다. 사용자가 플레이 중 문제를 보고하면 해당 부분만 분석한다.
- 에이전트는 빌드·관련 기존 검사·메서드/실행 흐름·필요한 세이브 안정성을 직접 확인한다. 약식 게임 기능은 [사용자 목록](습격%20기능%20약식%20테스트%20목록.md)에 넘기고 중복 실행하지 않는다.
- 의미 있는 작은 변경마다 확인 후 커밋한다. 미실행 사용자 기능 테스트는 명시하고 다음 작업을 막지 않는다. 확인된 코드/복구 오류는 해결한다.
- 구형 호환 코드·전역 전략 가치/킬존 맵·시야 밖 적 상태 조회는 추가하지 않는다.

A1과 A1.4는 구현했고 F02 배치 피드백을 추가 반영했다. 추가로 보고된 호 형성 중 산개는 A3.1의 조별 집결·응집 교정에 연결한다. 화력 구역의 공통 목적지는 초기 집결과 이후 기동에 재사용하고, 현재 위치 근처의 대체 자리를 조 집결 완료로 간주하지 않는다. 이 보완은 A3에서 구현했고 A1의 기존 구현과 구분한다. A3 구현까지 완료했으며 이후 A4부터 순서대로 진행한다. 단계 안의 서로 무관한 변경은 한 커밋에 묶지 않는다. A5는 가장 큰 구조 변경이므로 앞 단계의 실행 소유권·확보 보고·동행 규칙을 기반으로 한다. 약식 기능 확인은 사용자 목록의 결과와 분리하여 기록한다.

F16 테스트 중 보고한 자연 생성 구조물 돌파는 집중 사격과 별개로 A2.0에 구분 계획을 추가했다. 최초 제안인 [구분 방안](정착지와%20자연%20생성%20구조물%20구분%20방안.md)을 바탕으로 공통 후보 필터·야외 연결·확보 보고를 구현했다. 실제 범위와 보수적 탐색 한계는 [A2 구현 기록](A2%20소탕%20지속과%20확보%20보고%20구현.md)을 따른다.

## 확정된 편제와 관측 규칙

LOW는 6인 정찰분대·12인 보병분대·보병분대3개＋지휘부4명의40인 소대다. High는 4인 화력조3개＋분대장1명의13인 분대·분대3개＋지휘부4명의43인 소대다. 의료 담당은 기존 인원 중 지정하며 편제 인원을 늘리지 않는다.

적 관측은 원거리 위협으로 볼 수 있는 공격 수단의 적격성을 등록 전에 확인한다. 특정 동물 예외가 아니며 근접 DPS만으로 원거리 위협으로 등록하지 않는다. A1.4는 관측한 공격적 근접 접근과 실제 인접 공격을 별도 근접 위협 입력으로 받아 집중 사격하며, 이를 원거리 위협 기억에 등록하지 않는다. 사거리 밖 원거리 적 접근·정상 무기의 재장전/쿨다운 때문에 관측을 잃지 않게 한다.

## 해당 단계 시작 전에 정할 세부값

- A3 확정: 최대 49칸 연결 구역, 75% 준비·총기 사수 1명, 360틱 집결 대기·2회 대체, 12칸 합류 거리, HIGH 12칸/LOW 5칸 기동·엄호 중심 최대 30칸. 작은 정찰분대도 의료 담당 1명, 기존 가방·물자 5회분, 실제 드랍만 회수. 상세 제한은 A3 구현 기록 참조.
- A4: 가방 쿨타임·조기 사용 비용·중단 소비, 건물 피해 배율, CS/섬광 수치.
- A5: LOW의16칸 이하 수류탄 절약 유지 여부, 관측된 수감실 예외, High 살상 장비 사용 문턱.
- A6: LOW 지휘부4명의 무장/역할, 최대1소대의 기본/선택 설정 여부, 퇴각 기준, 지원 비용/환불/적용 대상.
- A7: 암습 알람 사건 범위, 사보타주 목표 후보, 헬리본 운송 방식과 자산.

세부값은 해당 변경 직전에 정한다. 미확정 값을 임의의 합격 조건으로 만들거나 이를 이유로 선행 A1 작업을 보류하지 않는다.
