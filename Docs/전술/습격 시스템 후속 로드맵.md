# 습격 시스템 후속 로드맵

2026-10-11. 기존 [R0~R7 재설계는 완료](최적화%20전술%20AI%20완료%20기록.md)했다. 이 문서는 이후 구현의 기준이다. 요구사항은 [습격 설계](습격%20설계.md), 세부 구조와 검토 근거는 [추가 계획 검토](습격%20설계%20추가%20계획%20검토.md)에 둔다. 아래 단계는 아직 구현 완료로 표시하지 않는다.

## 작업 원칙

- 모든 개발·커밋은 `main`에서 수행한다. PR은 완료분 검토용이며 개발용 별도 브랜치로 전환하지 않는다.
- CPU와 틱 지연을 낮추는 기존 구조·전역 예산·제한된 후보·낮은 갱신 빈도를 유지한다. 화력조가 늘어도 예산과 폰별 판단을 그대로 배수로 늘리지 않는다.
- 정기 성능 테스트·반복 N/V 대조는 하지 않는다. 사용자가 플레이 중 문제를 보고하면 해당 부분만 분석한다.
- 에이전트는 빌드·관련 기존 검사·메서드/실행 흐름·필요한 세이브 안정성을 직접 확인한다. 약식 게임 기능은 [사용자 목록](습격%20기능%20약식%20테스트%20목록.md)에 넘기고 중복 실행하지 않는다.
- 의미 있는 작은 변경마다 확인 후 커밋한다. 미실행 사용자 기능 테스트는 명시하고 다음 작업을 막지 않는다. 확인된 코드/복구 오류는 해결한다.
- 구형 호환 코드·전역 전략 가치/킬존 맵·시야 밖 적 상태 조회는 추가하지 않는다.

## 확정된 편제와 관측 규칙

LOW는 6인 정찰분대·12인 보병분대·보병분대3개＋지휘부4명의40인 소대다. High는 4인 화력조3개＋분대장1명의13인 분대·분대3개＋지휘부4명의43인 소대다. 의료 담당은 기존 인원 중 지정하며 편제 인원을 늘리지 않는다.

적 관측은 원거리 위협으로 볼 수 있는 공격 수단의 적격성을 등록 전에 확인한다. 특정 동물 예외가 아니며 근접 DPS만으로 원거리 위협으로 등록하지 않는다. 실제 근접 공격을 받으면 별도 긴급 대응한다. 사거리 밖 원거리 적 접근·정상 무기의 재장전/쿨다운 때문에 관측을 잃지 않게 한다.

## 해당 단계 시작 전에 정할 세부값

- A3: 기동 거리/응집 허용 거리, 6인 정찰분대 의료 담당 지급, 기존 가방/새 파우치 선택과 다운 폰의 착용 장비 회수 범위.
- A4: 가방 쿨타임·조기 사용 비용·중단 소비, 건물 피해 배율, CS/섬광 수치.
- A5: LOW의16칸 이하 수류탄 절약 유지 여부, 관측된 수감실 예외, High 살상 장비 사용 문턱.
- A6: LOW 지휘부4명의 무장/역할, 최대1소대의 기본/선택 설정 여부, 퇴각 기준, 지원 비용/환불/적용 대상.
- A7: 암습 알람 사건 범위, 사보타주 목표 후보, 헬리본 운송 방식과 자산.

세부값은 해당 변경 직전에 정한다. 미확정 값을 임의의 합격 조건으로 만들거나 이를 이유로 선행 A1 작업을 보류하지 않는다.
