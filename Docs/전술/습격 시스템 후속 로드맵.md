# 습격 시스템 후속 로드맵

2026-10-15 현재 기준. 요구사항 원문은 [습격 설계](습격%20설계.md), 기획의 세부 검토는 [추가 계획 검토](습격%20설계%20추가%20계획%20검토.md)에 둔다. 기존 R0~R7은 사용자 판단으로 완료했다. 과거 구현·검증 기록은 Git 이력에서 확인하며 이전 수집 큐를 재개하지 않는다.

## 현재 후속 작업

1. [야전 최종 설계](야전%20AI%20최종%20목표와%20바닐라%20기반%20설계.md)의 W0~W4: 엄폐/작업 소유권 기반 교정 → 일부 조·분대 우회와 밀집에 따른 빗나간 적탄 피탄 감소 → 선제 엄폐·방어적 명사수 → 연락 가능한 엄호·이동 교대.
2. [CQB 개편 검토](CQB%20자율%20실행과%20전환%20지연%20개편%20검토.md)의 C0~C4: 역할별 준비/진입 이력 → 사건 기반 전환 → 지속 개인 작업 → 진입 후 국소 엄폐·교전 자율성. 야전의 단일 Job 공급 구조와 맞추고 CQB 안전·교리·90틱 교전 유예를 유지한다.
3. 미구현 A7 배회·임시기지·사보타주·암습·헬리본은 이후 종류별 계획으로 남긴다. 자산/정책 확정 전에 자동으로 구현을 시작하지 않는다.

2026-10-15까지 야전 W0~W4를 구현하고 관련 코드 검사를 완료했다. 접근 관측 선제 엄폐·태그 총기 준비와 실제 음성/무전 전달에 따른 교대, 분대 지원자 역할 교환이 포함된다. 상세 값·검증 한계는 최신 야전 문서를 따르며 게임 확인은 F75~F80·F84~F92에 남긴다. CQB C0~C4도 구현·관련 코드 검사 완료다. 역할별 준비/실제 진입 이력, 버전 사건 큐, 지속 개인 명령, 같은 방13칸 국소 엄폐와 검증된 복귀/후방 사격이 포함된다. 관측·투척·폭발 안전 시간과90틱 교전 유예는 유지하며 게임 확인은 F95~F101에 남긴다. 아래 A단계의 기존 구현 완료와 구분한다. 현재 동작의 부족한 점은 후속 교정 대상이며 기존 기능을 미구현으로 되돌리지 않는다.

## 작업·검증 원칙

- 개발·커밋은 `main`에서 진행한다. 의미 있는 작은 변경마다 관련 검증 후 목적을 구체적으로 적어 커밋한다.
- CPU와 틱 지연을 우선하고 제한된 후보·전역 예산·낮은 갱신 빈도·지속 Job을 사용한다. 화력조 수만큼 예산/관측/폰 판단을 무조건 늘리지 않는다.
- 정기 성능 테스트·반복 Vanilla/New 대조는 하지 않는다. 사용자가 성능 문제를 보고하면 해당 상황과 관련 메서드만 조사한다.
- 에이전트는 빌드·변경 관련 기존 검사·메서드/실행 흐름과 필요한 저장 상태 검증을 맡는다. 약식 게임 확인은 [사용자 목록](습격%20기능%20약식%20테스트%20목록.md)에서 관리하며 중복 재생하지 않는다.
- 사용자 테스트 완료를 기다리며 다음 개발을 보류하지 않는다. 미실행/재확인은 명시하고 확인된 실제 오류는 해결한다.
- 구형 호환 코드·전역 전략 가치/킬존 맵·시야 밖 숨은 적 상태 조회는 추가하지 않는다.

## 확정된 편제·공유·관측 규칙

- LOW는6인 정찰분대·12인 보병분대·보병분대3개＋지휘부4명의40인 소대다.
- HIGH는4인 화력조3개＋분대장1명의13인 분대·분대3개＋지휘부4명의43인 소대다. 최소 생성 단위는 완전13인 분대이며 단독 화력조 생성은 하지 않는다.
- 의료 담당은 기존 인원 중 지정한다. LOW 소대 지휘부는 카빈3명/소총1명이다.
- 생성은 기본 최대1소대이며 설정으로 상한을 해제할 수 있다. 상한 해제 때도 완전 편제만 생성한다. 초과 예산은 지원 포인트로 관리한다.
- 확보 구역·확인된 개구부는 연락 없이 공통 기록을 사용한다. 적 접촉/추적/역할 합의는 LOW 접촉·HIGH 실제 무전 조건을 유지한다. 태블릿은 사용하지 않는다.
- 원거리 관측은 적격성 필터를 통과한 위협만 등록한다. 특정 동물만 예외로 다루지 않는다. 근접 접근/실제 공격은 별도 입력으로 집중 사격하며 원거리 기억에 억지로 넣지 않는다.
- 정상 무기의 쿨다운/재장전 때문에 관측을 잃지 않는다. 기억한 위치를 숨은 현재 위치로 자동 갱신하지 않는다.

## 확정 값과 미확정 사항

A3의 기존 집결·기동 값은 당시 구현 값이며 야전 W설계의 새 응집/간격 기준을 대신하지 않는다. 현재 실행 값은 소스와 단일 기능 목록을 참조한다.

- A4: 가방2500틱 공통 쿨타임·성공한 조기 사용1개 소비·중단 소비 없음. 대인 수류탄 건물 피해0.1배. CS/섬광의 최고 단계 이동 직접 감소 합계-20%.
- A5: LOW16칸 이하 수류탄 절약과 관측 적 예외 유지. 관측한 헤로드 수감자 보호. HIGH 살상 투척에는 관측 위협/교전 증거 필요, 미확인 큰 실내는 섬광. 최대3개 CQB 하위 작업·국소 공간64칸·후보12개/처리.
- A6: 지원 예약 최대4건·요청1800틱 간격. 소탕 손실25%/지연45000틱, 철수 준비 최대600틱.
- W설계의 후보/간격/교대 값은 초안이다. 실제 구현 단계에서 확정하고 기존 실행 값으로 오인하지 않는다.
- 이후 A7: 암습 알람 사건 범위, 사보타주 목표 후보, 헬리본 운송 방식/자산이 미확정이다.

세부값은 해당 변경 전에 정한다. 미확정 후속 값을 임의 합격 조건으로 만들거나 선행 작업을 보류하는 이유로 사용하지 않는다.
