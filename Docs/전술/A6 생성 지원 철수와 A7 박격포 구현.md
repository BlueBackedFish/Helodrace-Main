# A6 생성·지원·철수와 A7 박격포 구현 — 2026-10-14

경량화 실험 브랜치를 취소하고 기존 전술 AI를 유지하는 `main`에서 진행한다. 범위는 A6와 A7의 소탕·박격포·LOW 화학탄 습격까지다. 배회·임시기지·사보타주·암습·헬리본은 이번 작업에 포함하지 않는다.

## A6.1 생성 — 구현 완료

- LOW는 6인 정찰분대·12인 보병분대·40인 소대만 선택한다. 소대는 12인 분대 3개와 지휘부 4명(소대장·선임부사관·연락병: 카빈, 보조병: 소총)이다. 기존 소대의 별도 기관총/바주카/저격팀은 제외했다.
- HIGH의 13인 분대·43인 소대는 유지한다. 독립 화력조 생성은 없다.
- 사용자 확인에 따라 기본 최대 1소대다. 설정의 `습격 인원을 최대 1소대로 제한`을 끄면 완전 편제 단위로 상한을 해제한다. 편제 비용이 예산을 초과하는 10% 허용 오차는 LOW/HIGH에서 제거했다. 최소 예산은 전체 최소 편제 비용이며 낮은 예산에서 부분 편제를 생성하지 않는다.
- 비용은 LOW 분대 1000/소대 3320, HIGH 분대 2275/소대 7445다. 남은 포인트만 지원 잔액이 된다. 편제 예제/실제 생성은 같은 설정을 사용한다.
- 빌드 및 실제 XML을 포함하는 조직 검사 통과. 게임의 생성·상한 확인은 F12에서 사용자가 수행한다.

## A6.2~3 지원 — 구현 완료

지원 예약은 조직당 최대 4건이며 승인 시 잔액에서 분리한다. 성공하면 예약을 소비하고 실패/취소하면 한 번만 환불한다. 완료 토큰 재사용과 과다 요청을 거부한다. 실제 Scribe 저장/추출·참조 해결·PostLoadInit 단계로 보류 예약과 소비 잔액을 검사했다. 독립 콘솔 검사에서는 Unity 프로파일러에 의존하는 FinalizeLoading 래퍼만 생략하고 같은 내부 저장 단계를 호출했다.

LOW 생성 시 잔액이 충분하면 비의료 소총수에게 M1952A 방탄 장비 1개(120점), 다른 소총수에게 M14 보급 1회(220점)를 적용한다. 실패하면 환불한다. 추가 인원은 생성하지 않는다. 야전 교전 증거가 있을 때 기존 분대 판단에서 90틱 간격으로 지원을 확인하고 요청 사이에 1800틱 간격을 둔다. 연막 지원(100점)과 LOW 저격 지원(180점) 또는 HIGH 재밍(150점)을 교대로 요청한다.

연막은 알려진 접근 경로에 HC 지원탄 하나를 맵 가장자리에서 발사하며 피해는 없다. 저격은 최근 관측한 폰 1명만 대상으로 하고, 요청 이후 4칸 초과 이동·시야 소실·외부 사격 방향의 LOS 차단이면 환불한다. 건물/구역 포격은 없다. HIGH는 실제 착용 무전기와 정상 신호가 필요하다. 플레이어로 관측한 상대에 대한 재밍은 이 모드의 SCR-300 호출만 1800틱 차단하며 LOW 음성·접촉 보고 및 다른 모드 무전 기능은 건드리지 않는다. CAS/장거리 피해 지원의 제한 해제는 이번 범위에 넣지 않았다.

개발자 메뉴 `Inspect raid support`에서 초기/편제/잔여/예약 포인트와 보류 요청을 확인한다. 게임 약식 확인은 F13에 둔다.

## A6.4·A7.1 소탕/철수 — 구현 완료

`HD_SweepAssault`는 기존 CQB 소탕 AI와 이름 있는 침대 목표를 사용한다. 약탈·납치·정착지 일부 피해에 따른 종료는 없다. 인원 손실 25% 또는 45000틱 지연, 전체 분대 소탕 완료, 적대 관계 해소 시 철수 준비로 전환한다. 준비 중 기존 반환 경로가 투척물/C4 효과 대기와 작업 해제를 수행하며, 최대 600틱 뒤 바닐라 맵 이탈로 넘긴다. 지원 요청도 취소·환불한다. 의료 작업은 중단 요청을 전달한다. 실제 전투의 철수 시점은 F14에서 확인한다.

## A7.2 박격포·LOW 화학탄 — 구현 완료

- `HD_MortarAssault`는 LOW/HIGH, `HD_ChemicalMortarAssault`는 LOW 전용이다. 적대 조직 세력의 자동 습격 선택은 소탕·박격포·화학탄 중에서만 고른다. 다른 세력과 우호 지원군의 바닐라 선택은 유지한다. 드랍포드 없이 EdgeWalkIn/EdgeWalkInGroups를 사용한다.
- 실제 편제를 선택하기 전에 일반 350점/화학 450점을 따로 남겨두고 지원 회계에 키트 예약을 만든다. 따라서 최소 사건 포인트도 최소 완전 편제＋키트 비용이다. 추가 공병/포병 폰을 생성하지 않고 기존 인원 3명이 M1 받침판·양각대·총열을 착용해 운반한다. 생성 단계의 방탄/신식무기 보급은 키트 예약 후 남은 예산만 사용한다.
- 바닐라의 포위 진지 선정·집단 이동을 사용한다. 진지 주변 최대 32칸에서 설치 가능 위치를 제한적으로 확인한다. 운반 인원은 진지 4칸 안, 나머지는 14칸 안에서 바닐라 방어·엄폐·교전한다. 설치 작업 900틱이 성공하면 부품 3개를 소비하고 실제 M1 건물을 만든다. 최대 3회/2400틱 안에 설치하지 못하면 철수한다.
- 장전 120틱·실제 운용 인원의 CompMannable·바닐라 포탑 사격/표적 선택을 사용한다. 포탄은 운반 3명에게 나눠 지급하고 가까운 생존 운반자의 인벤토리에서 한 발씩 소비한다. 일반은 M43 HE 12발, 화학은 BA 6발이다. 화학 습격은 전원에게 천 재질의 CBRN 파우치를 지급하고 방독면을 펼친다.
- 일반은 사용 가능한 인원 25% 상실, 화학은 15% 상실 시 철수한다. 최근 실제 피해가 있으면 300틱 간격 판단에서 일반 25%/화학 60% 확률로도 철수를 선택한다. 탄약 할당 소진·18000틱 지연·적대 해소·박격포 파괴도 종료 원인이다. 사격을 전혀 못 하면 2400틱 뒤 철수한다.
- 철수 때 운용을 중단하고 최대 900틱 동안 가까운 생존자가 분해를 시도한다. 분해 작업 180틱이 성공하면 실제 부품 3개를 생존자의 인벤토리에 나눠 넣고 건물을 제거한다. 접근 불가·인원 손실·회수 실패는 시간 제한 뒤 장비를 버리고 이탈한다. 아직 설치하지 않은 부품은 원래 운반 인원이 그대로 들고 나간다. 생성 위치가 여러 개여도 한 조직에 박격포/키트를 중복 지급하지 않는다.
- 별도 상시 맵 컴포넌트는 추가하지 않았다. 활성 박격포 Lord만 30틱 간격으로 상태를 확인한다. 개발자 `Inspect mortar raids`에서 단계·사격 수·설치 시도·회수 시작 시점을 확인한다.

빌드와 지원 예약/환불, 실제 XML/게임 API, 편제 최소 예산, 박격포 설치·철수 시간 제한, 저장되는 단계·탄약/회수 타이머의 약식 자동 검사는 통과했다. 실제 게임에서 부품 운반·설치·장전·사격·회수를 재생한 결과는 아니다. 게임 확인은 단일 약식 목록 F12~F15·F81~F83에 분리했다. 성능 측정·전체 저장 파일 재생은 수행하지 않았다. 이후 A7 배회/임시기지/사보타주/암습/헬리본은 구현 대기로 남긴다.
