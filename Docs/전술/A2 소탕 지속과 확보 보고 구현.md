# A2 소탕 지속과 확보 보고 구현

## 2026-10-11 후속 수정: C4 후퇴 중 취소와 진입 후 실내 기록

사용자가 C4 후퇴 도중 취소·해머 전환과 붙은 이중벽 개방/연막 뒤 옆 벽을 선택하는 현상을 보고했다. 설치 마감 시간이 후퇴/기폭 대기에도 적용되는 경로를 제거했다. 설치된 C4 또는 진행 중인 설치는 그 마감 시간만으로 취소하지 않는다. 미설치 상태의 실패만 기존 해머 대체를 유지한다. 아군·도선·폭발 안전 조건은 유지하므로 안전 반경 안에 다른 분대가 있으면 계속 기다릴 수 있다.

진입 후 실내 탐색 시작점은 원래 실내 입구가 유효하면 그대로 사용하고, 입구 지붕이 없으면 실제 진입 완료 인원의 실내 도착 칸을 사용한다. 입구 한 칸의 지붕 붕괴를 방 전체의 야외 통과로 오판해 확보 기록을 생략하는 경로를 막았다. 실내 도착 자체가 없는 장면까지 해결했다고 판정하지 않는다.

빌드 경고/오류 0개, `--a2-walls`의 실내 시작점 5조건을 포함한 통로 검사 20개·C4 제한시간 5조건·기존 파편/폭발 대기·방 탐색·확보 보고/저장·전역 예산 검사 통과. Unity 실게임 재현은 수행하지 않았다. [실행 흐름과 사용자 확인 F22·F23](스택업과%20진입%20실행%20흐름.md)에 설명과 확인 범위를 기록했다. 사용자가 직접 수정한 기능 목록의 F21 `해결` 표시는 유지한다.

## 2026-10-11 후속 재수정: 실내 → 야외 → 같은 건물 왕복

사용자가 외벽 진입 뒤 밖으로 돌파하고 다시 안으로 돌파하는 반복을 보고했다. 앞선 두께·연결 검사는 물리 통로를 다루었으나 다음 경로를 남겼다.

1. 방의 외벽마다 기록된 야외 출구가 독립적인 다음 돌파 목표였다. 다음 건물을 발견하지 않아도 실내 후보 처리 후 야외로 나갔다.
2. 후속 탐색은 벽의 소유 세력만으로 야외 바닥을 새 목적지로 인정할 수 있었다. 확보한 건물에서 바깥을 향하는 벽도 새 건물처럼 선택됐다.
3. 야외 통과 때 `NextGoal`을 지웠고, 대기 목표가 없는 경우 확보한 원래 침대로 되돌아가는 기본 경로가 있었다. 알려진 야외 출구만 남아도 임무가 미완료로 판정됐다.
4. 지붕 붕괴 등으로 방 확보 좌표가 비어 있으면 이미 통과한 개구부도 구조 분류에서 다시 허용할 수 있었다. 실제 통과한 입구와 두꺼운 통로의 각 층을 같은 방향의 새 돌파 후보에서 제외한다. 요청된 기존 출구 통과는 별도로 유지하며, 옆 벽과 다음 방까지 통과했다고 확대하지 않는다.

야외 경계를 방 소탕 목표에서 통과 경로로 분리했다. 방 소탕에서 목적지 없는 야외 돌파를 하지 않으며, 후속 건물 탐색은 실제 LOS를 통과한 지붕 있는 미확보 바닥만 새 목적지로 인정한다. 저장된 실내 후보도 계획할 때 실제 입구가 지붕 없는 바닥이면 야외 통과 규칙을 적용한다. 열린 자기 출구 문에서는 탐색 광선을 계속 진행하여 너머 건물 관측을 막지 않는다. 기존 벽·문 뒤의 숨은 건물은 계속 탐색하지 않는다. 분류가 다음 예산 구간으로 넘어갈 때 후보의 방향·두께·실내 여부도 함께 보존한다.

관측한 다음 건물로 가야 할 때 알려진 열린 출구를 우선 사용한다. 출구가 닫혀 있으면 열린 통과 경로로 사용하지 않는다. 적합한 출구 배치를 만들 수 없으면 같은 목적지에 대한 기존 제한된 계획을 재시도하며, 다른 야외 바닥을 새 목표로 바꾸지 않는다. 야외 또는 보고받은 확보 방을 통과해도 미확보 `NextGoal`을 유지하고 다음 접근 계획으로 넘어간다. 새 실내 진입 뒤부터 다음 방의 소탕을 시작한다.

대기 목표 선택과 미완료 판정은 확보 여부·통과 이력·협력 담당 구역을 반영한 실내 방만 사용한다. 원래 목표와 알려진 실내 후보가 모두 확보되었고 관측한 다음 건물도 없으면 완료한다. 목표가 남아 있으면 기존 지연 재시도를 유지한다. 다른 분대의 확보 보고로 목적지가 완료되어도 다시 그곳으로 이동하지 않는다. 야외 출구와 확보한 침대를 빈 대기 목표의 대체값으로 사용하지 않는다.

성능 범위: 기존 후속 경계 목록과 확보 좌표·통과 이력을 사용한다. 출구 선택은 목적지 변경 때만 실행하며, 통로 개방 확인은 후보당 최대 4칸이다. 통과 이력은 최대 4개 입구 좌표를 조회하고 일치할 때만 완료 계획의 방향·두께를 확인한다. 기존 16방향·24칸 탐색, 계획 허가당 32칸·2회 LOS와 공유 작업 예산은 유지한다. 전역 지도·상시 갱신·새 스레드는 추가하지 않는다. 관측 가능한 다음 건물이 없거나 해당 후보의 지붕이 없으면 야외 소탕을 위해 임의로 나가지 않으므로 모르는 건물이 남을 수 있다.

검증: 빌드 경고/오류 0개. `--a2-routing`의 실제 국소 방 탐색을 사용한 왕복 방지·확보 좌표 없는 두꺼운 통로 이력·열린 두 겹 출구 선택·실제 대기/이동 전환·통과 중 바닐라 Scribe·동료 확보 보고 검사 20개와 기존 임무 검사 30개, 확보 이력 유지·방 탐색·전역 예산 검사를 통과했다. `--a2`의 확보 보고 격리/저장 16개·통신/협력 32개도 통과했다. Unity 실게임 재현과 CPU 수집은 수행하지 않았다. F21 사용자 확인 대기이며 F18·F20의 야외 이동 기대 조건도 이번 정책으로 수정했다.

## 2026-10-11 후속 재수정: 같은 벽·이중 벽 반복 돌파

사용자가 앞선 수정 후에도 같은 벽과 이중 벽에서 반복 돌파를 보고했다. 앞선 연결 검사만으로 해결되지 않는 경로를 코드에서 추가 확인했다.

1. 계획의 실내 칸이 항상 `Opening + Inward`였고 첫 벽칸만 열리면 완료였다. 이중 벽의 뒤쪽 벽을 실내로 취급하거나 일부만 열린 통로에서 관측·진입을 시작할 수 있었다.
2. 실제 진입한 첫 바닥도 짧은 개구부 형상으로 분류하면 방 탐색 시작점이 없어 확보 기록이 비어 있을 수 있었다. 진입 시작 바닥은 실내 바닥으로 유지한다.
3. 작은 방에서 기존 출구의 역방향 계획을 만들 때 분대 전체를 실내 스택업하지 못하면 다른 외벽 후보로 넘어갈 수 있었다. 자기 개구부를 통한 야외 이동은 기존 배치를 대기 위치로 사용하고 바로 통과한다. 이미 야외에 있던 경계 인원은 다시 실내로 들어갔다 나가지 않는다.

외부 입구 좌표와 `Depth`를 하나의 돌파 통로로 기록한다. 붙어 있는 벽·문은 최대 4칸까지 같은 통로에 포함하며, 벽 사이에 실제 이동 가능한 공간이 있으면 별도 공간으로 취급한다. `Inside`와 실내 배치는 마지막 벽 너머부터 시작한다. 남아 있는 첫 장애물을 선택하고 열린 앞쪽 통로에서 뒤쪽 벽을 순서대로 처리한다. 관측·수류탄·진입은 통로 전체와 실제 실내 입구가 열린 뒤 시작한다. 부분 파괴를 이유로 옆 벽에 새 계획을 만들지 않는다.

진입 경로의 모든 벽칸을 예약하고 기존 열린 후보에 우선순위를 준다. 두꺼운 내부 경계의 다음 방 후보·목표·확보 연결 검사도 실제 안쪽 바닥을 사용한다. 개구부 재사용·보고 복사·세이브에 통로와 후보의 두께를 보존한다. C4는 실제 설치 벽칸으로 폭발 대기·도선 거리·저장 위치를 판정하며, 폭발 후 남은 층이 있으면 같은 계획의 돌파로 돌아간다. 설치 전 다른 폭발로 해당 층이 없어져도 같은 통로의 다음 층으로 진행한다.

성능 범위: 추가 두께 검사는 최대 4칸이다. 전역 방 캐시·새 맵 틱·추가 A* 탐색은 도입하지 않았다. 구조 분류에 임시 계획의 여러 목록을 매번 생성하지 않고 좌표와 두께만 사용한다. 기존 공유 계획/작업/경로 예산을 유지한다. 4칸을 초과하는 연속 벽은 이번 제한된 처리의 지원 범위 밖이다.

검증: 최종 빌드 경고/오류 0개. `--a2-walls`의 층별 진행·부분 개방·출구 역방향·두꺼운 방 경계·상한·바닐라 저장 검사 15개 및 기존 방 탐색·벽면 방향·보고 격리/저장 16개·계획 유지·C4 안전·관측/폭발 대기·전역 예산 검사 통과. 실게임 재현은 수행하지 않았으며 F18·F20 재확인 대기다. 개발자 `Inspect squad commands`에 `depth`, `inside`, 현재 `barrier` 좌표를 추가했다.

## 2026-10-11 후속 수정: 투척 직전 아군 보호

기존 안전 검사는 폭발·파편 반경과 LOS만 보았으며, 섬광탄의 별도 효과 반경과 실내 배율을 빠뜨렸다. 위험 반경에 실제 섬광 효과·가스 방출·착지 후 이동 여유를 포함한다. 벽 너머에도 작용하는 섬광 효과는 해당 반경 안의 아군 때문에 취소할 수 있다.

지붕 있는 투척 대상의 현재 바닐라 방과 아군 위치를 비교하고, 같은 방 또는 그 방에 붙은 문칸에 아군·비적대 폰이 있으면 거리·LOS와 무관하게 자동 투척하지 않는다. 다른 분대와 다운된 아군도 포함한다. 구조 갱신 중 실내 방 정보가 없으면 투척하지 않는다. 이 방 조회는 아군 안전 확인 전용이며 확보 이력이나 적 관측으로 전용하지 않는다. 기존 무해한 HC/일반 연막은 계속 사용한다.

후보 선택 시와 실제 발사 직전 모두 같은 검사를 사용하므로, 준비 중 방에 들어온 아군도 반영한다. 조건이 맞지 않으면 수류탄을 소비하지 않고 해당 투척을 취소한다. 발사 후 다른 분대가 새로 진입하는 것까지 막는 분대 간 폭발 구간 예약은 이번 변경 범위가 아니며 A5 안전 작업에 남는다. 보수적인 판정 때문에 실내 섬광탄 사용이 줄어들 수 있다.

검증: 최종 빌드 경고/오류 0개. `--a2-safety`의 장비 정책·실내 효과 반경·반동 이동 여유·동일 방·인접 문칸 검사 19개, 기존 관측/투척/폭발 대기 정책·전역 예산 검사 통과. 기존 저장 필드와 작업 진행 상태는 변경하지 않았다. 실게임 F19는 사용자 확인 대기다.

## 2026-10-11 후속 수정: LOW 연락 거리

LOW 대전기 교리의 음성 정보 교환 거리를 기본 8칸에서 20칸으로 늘렸다. 교리 유효 범위 상한은 32칸이다. 실제 분대 연락자 사이의 LOS·연막 차단·보고 지연·큐 한도·다른 분대로 자동 재전파하지 않는 조건은 유지한다. 벽을 투과하는 정보 공유와 무전기 지급은 추가하지 않는다. HIGH의 무전/음성 기본 거리는 변경하지 않았다. 빌드 및 기존 `--a2` 통신·보고 검사를 통과했고 XML의 LOW 20칸 설정을 확인했다. 실게임 연락 확인은 F04로 분리한다.

## 2026-10-11 후속 수정: 중복 외벽·확보 공간 돌파

- 실내 탐색이 외벽의 각 칸을 개별 야외 출구로 남겨, 첫 출구 통과 후에도 다른 칸을 반복 돌파할 수 있었다. 외부에서 들어온 개구부의 역방향을 우선 출구 후보로 기록하고, 실제 야외 통과 후 기존 야외 출구 후보를 종료한다. 후속 건물의 새 출구는 별도로 생성한다.
- 확보 이력은 방 ID 대신 바닥 좌표다. 후보 바로 안쪽 한 칸만 검사하던 한계를 보완하여 연결된 실내 바닥에서 자기 분대의 확보 이력을 찾는다. 실제 문은 경계로 유지하고, 합성 개구부 경계는 무시한다. 새 개구부에서는 해당 입구의 폭 전체를 되돌아가지 못하게 하여 미진입 방을 확보했다고 오판하지 않는다.
- 연결 검사 결과는 중복 돌파 후보 제외에만 사용하며 새로운 바닥을 `SecuredCells`에 추가하지 않는다. 총 128칸, 계획 허가당 모든 후보가 공유하는 32칸, 최대 64개 국소 검사, 120틱 결과 재사용이다. 방 확보 완료 시 결과를 폐기한다. 한도를 넘는 넓은 공간에서는 기존 보수적 판정을 유지한다.
- 실내 진입 완료도 통과 개구부 이력에 남기고 같은 개구부의 완료 계획을 중복 추가하지 않는다. 기존 저장 항목을 재사용하며 진행 중인 국소 연결 검사는 저장하지 않고 로드 후 다시 계산한다.

검증: 빌드 경고/오류 0개, `--a2` 관련 검사 통과. 이동한 입구·다른 개방 경로·실제 문 분리·5칸 신규 입구·128칸 한도·예산 지연 검사를 추가했다. Unity 실게임 재현과 CPU 수집은 수행하지 않았다. F18은 사용자 확인 대기다.

2026-10-11. [후속 로드맵](습격%20시스템%20후속%20로드맵.md)의 A2 작업 기록. 게임 기능 확인은 F17·F03·F04로 분리한다.

## A2.0 대상 구조물 필터 — 구현 완료

최초 직선 후보, 벽면 후보, 개구부 재사용, 후속 방 후보와 대기 목표에 같은 대상 구조물 판정을 적용했다. 자동 목표의 대상 세력은 플레이어다. 명시 목표는 해당 칸의 세력 또는 `SetObjective(goal, targetFaction)`으로 지정하며, 세력이 없는 명시 목표는 해당 목표가 속한 국소 구역을 근거로 사용한다.

대상 세력 소유 벽·문은 즉시 허용하고 다른 세력 벽은 제외한다. 무주인 구조는 지붕 있는 연결 바닥과 경계를 최대 256칸, 계획 허가당 총 32칸씩 조사한다. 알려진 목표, 대상 세력 벽/문, 실제 LOS로 확인한 소유 침대/작업대가 근거다. 점유 설비의 LOS도 계획 허가당 2회로 제한하며, 한도 때문에 근거를 놓칠 수 있다. 확보한 대상 실내와 공유하는 무주인 내부 경계도 허용하되 중정 너머로 이 근거를 확장하지 않는다. 분대별 후보 결과는 최대 64개, 600틱까지 재사용하며 관련 후보의 소유권은 매 사용 시 우선 확인한다. 미완료 판정은 임무 해제나 실패 횟수 증가 대신 다음 예산 구간으로 넘긴다.

홈 영역·재질·DefName·주변 거리만으로 유적을 정착지에 포함하지 않는다. 복잡하고 큰 무주인 구조는 탐색 상한 때문에 보수적으로 제외할 수 있다. 전역 방 지도/폰별 검사/상시 맵 틱은 추가하지 않았다. 순수 판정 캐시와 진행 중 탐색은 저장하지 않고 로드 후 필요한 후보만 다시 생성한다. 대상 세력과 제외된 후속 후보는 저장한다.

검증: 빌드 경고/오류 0개. `--a2` 국소 판정 25개 확인과 기존 방 탐색·확보 이력 재계획·전역 예산 검사 통과. Unity 실게임 시험과 CPU 수집은 수행하지 않았다. 야외 임무 연결과 확보 보고는 다음 작업에서 이어간다.

## A2.1 야외 연결과 다음 건물 — 구현 완료

실내의 국소 탐색은 야외로 이어지는 벽/문/개구부를 후속 경계로 기록하며 야외 바닥을 방처럼 채우지 않는다. 실내 후보를 먼저 처리하고 관측한 다음 건물로 이동해야 할 때 기존 열린 출구를 우선 사용한다. 출구는 독립적인 소탕 목표가 아니며 야외 통과 뒤에도 다음 건물 목적지와 본래 침대 목표·확보 이력을 유지한다. 침대 목표를 확보했어도 알려진 방과 관측 가능한 다음 건물에 대한 임무는 계속된다.

추가 탐색은 분대원 위치에서 16방향·각 24칸, 계획 허가당 최대 32칸과 2회 LOS 검사다. 첫 벽 뒤를 투시하지 않고 실제 LOS를 통과한 정착지 경계만 사용한다. 판정이 미완료인 무주인 후보는 다음 예산 구간에 이어간다. 다음 건물 목적지는 처음의 침대 목표와 별도로 저장하고 기존 바닐라 이동/스택업/관측/진입을 재사용한다. 작은 이동 노드나 매 틱 새 경로는 추가하지 않는다.

두 번의 제한된 탐색 사이에 300틱 간격을 둔다. 목표 확보 후 알려진 미확보 후보도 없으면 완료하며, 목표가 남거나 알려진 방 진입이 실패하면 진행 불가 상태에서 600틱 후 재시도한다. 실패 목적지는 최대 32개, 1200틱까지 재선택을 피한다. 후보 실패를 바로 임무 해제해 바닐라가 다른 유적을 공격하게 하는 경로를 제거했다. 따라서 모르는 원거리 건물이 남을 수 있으며 완벽한 전역 소탕은 보장하지 않는다.

임무 단계·별도 목적지·탐색 대기·실제 통과 개구부·실패 목적지를 값으로 저장한다. 중단된 짧은 관측 탐색만 로드 후 다시 시작한다. 실제 Pawn Job은 기존 ID 연결을 재사용하며 복제/재시작하지 않는다. 개발자 `Inspect squad commands`에 mission/next/traversed/blocked를 표시한다.

검증: 빌드 경고/오류 0개. `--a2`의 국소 판정·유한 야외 탐색·야외 출구 구분·별도 목적지 선택과 바닐라 Scribe 임무 값 저장 검사 및 기존 방 탐색/재계획/전역 예산 검사 통과. 실게임 F03·F17은 사용자 확인 대기다. 확보 보고는 다음 작업에서 이어간다.

## A2.2 제한된 확보 보고와 기존 개구부 재사용 — 구현 완료

국소 방 탐색의 확보 좌표 복사 과정에서 최대 16칸과 후속 경계 2개의 패킷을 만든다. 따로 방 전체를 다시 열거하지 않는다. 남은 경계 패킷도 계획 허가마다 최대 2개씩 만들고, 분대별 송신/수신 이력은 각각 최근 64개로 제한한다. 전달 확인은 상대 분대별 최대 8개 커서로 저장한다. 단순 직접 목적지는 실제 개구부로 보고하지 않는다.

기존 64개 공통 큐·전역 통신 예산·LOW 실제 접촉/High 장착 무전 조건·전달 지연·수신 시 채널/연락 인원 재검증을 그대로 사용한다. 같은 상대에게 전달 확인된 변경분은 다시 보내지 않는다. 미전달 패킷은 다음 연락에서 재시도한다. 적 접촉이 계속돼도 진행 보고가 굶지 않도록 한 교환의 2개 보고 한도 안에서 신규 확보 보고 1개 자리를 확보한다. 완료한 분대의 최종 보고는 마지막 기록 후 1200틱 동안 제한적으로 송신할 수 있다. 수신 보고는 자동 재전송하지 않는다.

수신한 좌표는 별도의 최대 1024칸 인덱스로 조회하며 본인의 `SecuredCells`나 송신 이력에 복사하지 않는다. 실제 통과와 보고받은 확보를 구분한다. 기존 개구부를 재사용할 때 실제 통행·소유 세력·목적지 방향·자리·임대와 바닐라 도달성을 검사한다. 공유된 소수 전역 개구부 기록이 없어졌어도 전달받은 입구에서 최대 2개 후보의 국소 자리만 다시 만들어 사용할 수 있다. 보고가 유효한 방은 통과만 하며 관측/수류탄/방 확보 탐색을 반복하지 않는다. 새 적 관측은 해당 방의 보고를 재확인 필요로 만들고 물리 입구 이력은 유지한다. 늦게 온 과거 확보 보고가 새 적 관측을 덮어쓰지 않으며, 먼저 받은 접촉도 지연된 확보 패킷에 적용한다.

받은 후속 경계는 미확보 구역으로의 접근 근거다. 본래 목표가 보고상 확보되었어도 남은 알려진 구역을 계속 탐색한다. 새 후속 경계나 완료 이후 실제 적 관측은 보존한 임무를 다시 깨울 수 있다. 완료 상태의 관측은 600틱 수준으로 낮게 유지한다. 소탕을 끝내는 구형 ‘분담 목표 칸 도달’ 판정과 실패 즉시 바닐라 반환 판정은 제거했다.

송신/수신 기록·패킷·시각/재확인 상태·전달 확인 커서·보고된 방 통과 상태를 Scribe에 저장한다. 수신 좌표 인덱스만 필요할 때 재구축하고 Pawn Job 소유권은 기존 ID 복원 경로를 사용한다. 진행 중 국소 조사/관측 캐시는 재생성하며 상시 맵 컴포넌트를 추가하지 않았다. 최근 기록 한도를 넘긴 오래되거나 아주 큰 방은 확보 정보 일부를 공유하지 못할 수 있다. 중립 구조물을 반드시 파괴해야 하는지를 판정하는 최후 수단은 추가하지 않았으며, 우회 실패 시 진행 불가/재시도 상태를 사용한다.

검증: 최종 빌드 경고/오류 0개. `--a2`의 대상/임무 검사 30개, 확보 보고 격리·재침입·기록 퇴출·변경분 큐·중첩 값 저장/로드 검사 15개 및 기존 방 탐색/재계획·실제 방탄복 무전/통신 검사 32개·전역 작업 예산 검사 통과. `--a1-focus`의 기존 집중 사격·원거리 필터·접촉·개구부/폭발/투척 안전 검사도 통과했다. 콘솔 저장 검사는 Unity 모드 레지스트리 대신 설치 게임의 타입 캐시에 해당 타입을 등록한 상태에서 실제 Scribe로 값을 저장/로드한 범위이며 전체 게임 저장 시험이 아니다. 실게임 F03·F04·F17은 사용자 확인 대기다. 정기 CPU 수집·전체 기능 재시험은 수행하지 않았다.
