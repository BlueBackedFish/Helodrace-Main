# A2 소탕 지속과 확보 보고 구현

## 2026-10-11 후속 수정: 중복 외벽·확보 공간 돌파

- 실내 탐색이 외벽의 각 칸을 개별 야외 출구로 남겨, 첫 출구 통과 후에도 다른 칸을 반복 돌파할 수 있었다. 외부에서 들어온 개구부의 역방향을 우선 출구 후보로 기록하고, 실제 야외 통과 후 기존 야외 출구 후보를 종료한다. 후속 건물의 새 출구는 별도로 생성한다.
- 확보 이력은 방 ID 대신 바닥 좌표다. 후보 바로 안쪽 한 칸만 검사하던 한계를 보완하여 연결된 실내 바닥에서 자기 분대의 확보 이력을 찾는다. 실제 문은 경계로 유지하고, 합성 개구부 경계는 무시한다. 새 개구부에서는 해당 입구의 폭 전체를 되돌아가지 못하게 하여 미진입 방을 확보했다고 오판하지 않는다.
- 연결 검사 결과는 중복 돌파 후보 제외에만 사용하며 새로운 바닥을 `SecuredCells`에 추가하지 않는다. 총 128칸, 계획 허가당 모든 후보가 공유하는 32칸, 최대 64개 국소 검사, 120틱 결과 재사용이다. 방 확보 완료 시 결과를 폐기한다. 한도를 넘는 넓은 공간에서는 기존 보수적 판정을 유지한다.
- 실내 진입 완료도 통과 개구부 이력에 남기고 같은 개구부의 완료 계획을 중복 추가하지 않는다. 기존 저장 항목을 재사용하며 진행 중인 국소 연결 검사는 저장하지 않고 로드 후 다시 계산한다.

검증: 빌드 경고/오류 0개, `--a2` 관련 검사 통과. 이동한 입구·다른 개방 경로·실제 문 분리·5칸 신규 입구·128칸 한도·예산 지연 검사를 추가했다. Unity 실게임 재현과 CPU 수집은 수행하지 않았다. F18은 사용자 확인 대기다.

2026-10-11. [후속 로드맵](습격%20시스템%20후속%20로드맵.md)의 A2 작업 기록. 게임 기능 확인은 F17·F03·F04로 분리한다.

## A2.0 대상 구조물 필터 — 구현 완료

최초 직선 후보, 벽면 후보, 개구부 재사용, 후속 방 후보와 대기 목표에 같은 대상 구조물 판정을 적용했다. 자동 목표의 대상 세력은 플레이어다. 명시 목표는 해당 칸의 세력 또는 `SetObjective(goal, targetFaction)`으로 지정하며, 세력이 없는 명시 목표는 해당 목표가 속한 국소 구역을 근거로 사용한다.

대상 세력 소유 벽·문은 즉시 허용하고 다른 세력 벽은 제외한다. 무주인 구조는 지붕 있는 연결 바닥과 경계를 최대 256칸, 계획 허가당 총 32칸씩 조사한다. 알려진 목표, 대상 세력 벽/문, 실제 LOS로 확인한 소유 침대/작업대가 근거다. 점유 설비의 LOS도 계획 허가당 2회로 제한하며, 한도 때문에 근거를 놓칠 수 있다. 확보한 대상 실내와 공유하는 무주인 내부 경계도 허용하되 중정 너머로 이 근거를 확장하지 않는다. 분대별 후보 결과는 최대 64개, 600틱까지 재사용하며 관련 후보의 소유권은 매 사용 시 우선 확인한다. 미완료 판정은 임무 해제나 실패 횟수 증가 대신 다음 예산 구간으로 넘긴다.

홈 영역·재질·DefName·주변 거리만으로 유적을 정착지에 포함하지 않는다. 복잡하고 큰 무주인 구조는 탐색 상한 때문에 보수적으로 제외할 수 있다. 전역 방 지도/폰별 검사/상시 맵 틱은 추가하지 않았다. 순수 판정 캐시와 진행 중 탐색은 저장하지 않고 로드 후 필요한 후보만 다시 생성한다. 대상 세력과 제외된 후속 후보는 저장한다.

검증: 빌드 경고/오류 0개. `--a2` 국소 판정 25개 확인과 기존 방 탐색·확보 이력 재계획·전역 예산 검사 통과. Unity 실게임 시험과 CPU 수집은 수행하지 않았다. 야외 임무 연결과 확보 보고는 다음 작업에서 이어간다.

## A2.1 야외 연결과 다음 건물 — 구현 완료

실내의 국소 탐색은 야외로 이어지는 벽/문/개구부를 후속 경계로 기록하며 야외 바닥을 방처럼 채우지 않는다. 실내 후보를 먼저 처리하고 야외 경계를 통과하면 본래 침대 목표와 확보 이력을 유지한 채 다음 건물 탐색으로 전환한다. 침대 목표를 확보했어도 알려진 방과 관측 가능한 다음 건물에 대한 임무는 계속된다.

추가 탐색은 분대원 위치에서 16방향·각 24칸, 계획 허가당 최대 32칸과 2회 LOS 검사다. 첫 벽 뒤를 투시하지 않고 실제 LOS를 통과한 정착지 경계만 사용한다. 판정이 미완료인 무주인 후보는 다음 예산 구간에 이어간다. 다음 건물 목적지는 처음의 침대 목표와 별도로 저장하고 기존 바닐라 이동/스택업/관측/진입을 재사용한다. 작은 이동 노드나 매 틱 새 경로는 추가하지 않는다.

두 번의 제한된 탐색 사이에 300틱 간격을 둔다. 목표 확보 후 알려진 미확보 후보도 없으면 완료하며, 목표가 남거나 알려진 방 진입이 실패하면 진행 불가 상태에서 600틱 후 재시도한다. 실패 목적지는 최대 32개, 1200틱까지 재선택을 피한다. 후보 실패를 바로 임무 해제해 바닐라가 다른 유적을 공격하게 하는 경로를 제거했다. 따라서 모르는 원거리 건물이 남을 수 있으며 완벽한 전역 소탕은 보장하지 않는다.

임무 단계·별도 목적지·탐색 대기·실제 통과 개구부·실패 목적지를 값으로 저장한다. 중단된 짧은 관측 탐색만 로드 후 다시 시작한다. 실제 Pawn Job은 기존 ID 연결을 재사용하며 복제/재시작하지 않는다. 개발자 `Inspect squad commands`에 mission/next/traversed/blocked를 표시한다.

검증: 빌드 경고/오류 0개. `--a2`의 국소 판정·유한 야외 탐색·야외 출구 구분·별도 목적지 선택과 바닐라 Scribe 임무 값 저장 검사 및 기존 방 탐색/재계획/전역 예산 검사 통과. 실게임 F03·F17은 사용자 확인 대기다. 확보 보고는 다음 작업에서 이어간다.

## A2.2 제한된 확보 보고와 기존 개구부 재사용 — 구현 완료

국소 방 탐색의 확보 좌표 복사 과정에서 최대 16칸과 후속 경계 2개의 패킷을 만든다. 따로 방 전체를 다시 열거하지 않는다. 남은 경계 패킷도 계획 허가마다 최대 2개씩 만들고, 분대별 송신/수신 이력은 각각 최근 64개로 제한한다. 전달 확인은 상대 분대별 최대 8개 커서로 저장한다. 단순 직접 목적지는 실제 개구부로 보고하지 않는다.

기존 64개 공통 큐·전역 통신 예산·LOW 실제 접촉/High 장착 무전 조건·전달 지연·수신 시 채널/연락 인원 재검증을 그대로 사용한다. 같은 상대에게 전달 확인된 변경분은 다시 보내지 않는다. 미전달 패킷은 다음 연락에서 재시도한다. 적 접촉이 계속돼도 진행 보고가 굶지 않도록 한 교환의 2개 보고 한도 안에서 신규 확보 보고 1개 자리를 확보한다. 완료한 분대의 최종 보고는 마지막 기록 후 1200틱 동안 제한적으로 송신할 수 있다. 수신 보고는 자동 재전송하지 않는다.

수신한 좌표는 별도의 최대 1024칸 인덱스로 조회하며 본인의 `SecuredCells`나 송신 이력에 복사하지 않는다. 실제 통과와 보고받은 확보를 구분한다. 기존 개구부를 재사용할 때 실제 통행·소유 세력·목적지 방향·자리·임대와 바닐라 도달성을 검사한다. 공유된 소수 전역 개구부 기록이 없어졌어도 전달받은 입구에서 최대 2개 후보의 국소 자리만 다시 만들어 사용할 수 있다. 보고가 유효한 방은 통과만 하며 관측/수류탄/방 확보 탐색을 반복하지 않는다. 새 적 관측은 해당 방의 보고를 재확인 필요로 만들고 물리 입구 이력은 유지한다. 늦게 온 과거 확보 보고가 새 적 관측을 덮어쓰지 않으며, 먼저 받은 접촉도 지연된 확보 패킷에 적용한다.

받은 후속 경계는 미확보 구역으로의 접근 근거다. 본래 목표가 보고상 확보되었어도 남은 알려진 구역을 계속 탐색한다. 새 후속 경계나 완료 이후 실제 적 관측은 보존한 임무를 다시 깨울 수 있다. 완료 상태의 관측은 600틱 수준으로 낮게 유지한다. 소탕을 끝내는 구형 ‘분담 목표 칸 도달’ 판정과 실패 즉시 바닐라 반환 판정은 제거했다.

송신/수신 기록·패킷·시각/재확인 상태·전달 확인 커서·보고된 방 통과 상태를 Scribe에 저장한다. 수신 좌표 인덱스만 필요할 때 재구축하고 Pawn Job 소유권은 기존 ID 복원 경로를 사용한다. 진행 중 국소 조사/관측 캐시는 재생성하며 상시 맵 컴포넌트를 추가하지 않았다. 최근 기록 한도를 넘긴 오래되거나 아주 큰 방은 확보 정보 일부를 공유하지 못할 수 있다. 중립 구조물을 반드시 파괴해야 하는지를 판정하는 최후 수단은 추가하지 않았으며, 우회 실패 시 진행 불가/재시도 상태를 사용한다.

검증: 최종 빌드 경고/오류 0개. `--a2`의 대상/임무 검사 30개, 확보 보고 격리·재침입·기록 퇴출·변경분 큐·중첩 값 저장/로드 검사 15개 및 기존 방 탐색/재계획·실제 방탄복 무전/통신 검사 32개·전역 작업 예산 검사 통과. `--a1-focus`의 기존 집중 사격·원거리 필터·접촉·개구부/폭발/투척 안전 검사도 통과했다. 콘솔 저장 검사는 Unity 모드 레지스트리 대신 설치 게임의 타입 캐시에 해당 타입을 등록한 상태에서 실제 Scribe로 값을 저장/로드한 범위이며 전체 게임 저장 시험이 아니다. 실게임 F03·F04·F17은 사용자 확인 대기다. 정기 CPU 수집·전체 기능 재시험은 수행하지 않았다.
