# CQB 연속 돌파 준비와 전환 간격

2026-10-13. 진입 완료 후 다음 돌파까지의 순차 대기를 줄였다. 기존 무거운 계산의 전역 한도와 실제 진입 완료·투척/C4 안전 조건은 유지한다.

## 앞당긴 준비

선두가 실내 진입 자리에 도착하면 후속 인원 이동 중에 기존 방 구조 조사를 진행한다. 한 계산 기회에 최대 128칸을 처리하고, 진입 완료 뒤 동일한 조사 객체를 이어 사용한다. 조사가 끝나도 진입 전 상태에서는 확보 칸·통과 이력·공유 보고를 쓰지 않는다.

LOW는 조사된 경계 중 다음 후보를 최대 12개씩 확인하고 가장 우선하는 후보 하나에 대해서만 돌파 대형·진입 자리 배정을 미리 계산한다. 조사 중인 현재 방의 바닥은 대형 계산에만 사용하며, 실제 확보 이력과 분리한다. 예비 계획은 다른 분대의 자리를 예약하거나 작업을 발행하지 않는다. 가구 파괴 작업도 미리 시작하지 않는다. 막힌 후보는 진입 완료 후 기존 가구 복구·장비 회수 판단에 맡긴다.

HIGH는 확보 뒤 부모 분대가 실제 화력조별 작업과 인원을 배정하므로 조사 결과만 앞당겨 재사용한다. 앞으로 바뀔 13인/4인 배정에 맞지 않는 개인 자리 계산은 하지 않는다.

진입 완료 후 실제로 선택한 개구부가 예비 후보와 같고 목표·원래 진입 계획·인원 순서·협력 합의가 유효하면 미완성 계산을 그대로 넘긴다. 완료된 예비 대형도 출발 직전에 실제 자리·예약·개구부·돌파 도구를 기존 검증으로 확인한다. 조건이 달라졌으면 기존 계획 생성으로 돌아간다.

목표 변경·반환·퇴각·방향 전환·맵 제거 시 예비 계산을 폐기한다. 예비 계산과 구조 조사는 저장하지 않는다. 진입 중 저장 후 로드하면 필요한 준비를 다시 시작하고, 실제 확보 이력과 기존 안전 상태는 기존 저장 방식을 유지한다.

## 전환과 교전 대기

다음 방 준비 객체를 만들기만 한 뒤 기다리던 구간, 배정 객체를 만들기만 한 뒤 기다리던 구간, 배정 완료 후 검증 단계 지정만 하고 기다리던 구간을 줄였다. 탐색과 자리 배정은 계속 나누어 처리한다. 전역 계획 1회/틱·자리 배정 2명/회·이동 명령 2명/10틱 제한을 늘리지 않았다.

교전 종료 유예는 마지막 사격 기회·사격·피격 증거 이후 180틱에서 90틱으로 줄였다. 유예 만료가 다음 30틱 확인보다 먼저면 만료 시점에 판단을 예약한다. 계속 사격할 적이나 진행 중인 사격이 있으면 유예를 연장한다. 공유 상수를 쓰는 수류탄 회피 후 교전 복귀 유예에도 90틱을 적용한다. 폭발물 자체가 사라지고 파편/폭발 효과가 가라앉을 때까지의 안전 대기는 바꾸지 않았다.

전원 진입 완료 조건, 의료 확인의 순차 처리, 실제 화력조 배정은 이번 변경에서 유지했다. 낙오자를 남겨 둔 다음 돌파조 출발이나 의료 작업 중 다른 조의 출발은 별도 후속 변경으로 남긴다.

- 빌드 경고/오류 없음.
- `--entry-preview`: 큰 방의 계산 상한·같은 틱 중복 계산 차단, 선두 도착만으로 확보하지 않는 조건, 기존 조사 재사용, private 대형/예약/보고 분리, 준비 소유권 이전과 인원·목표 변경 취소, HIGH 불필요한 대형 계산 생략 확인.
- 준비/교전 검사: 배정 초기화와 실제 계산의 같은 기회 처리, 예비 결과의 최종 검증 실패, 90틱 유예 경계, 유예 만료 시 판단 예약, 기존 계산 예산 확인.
