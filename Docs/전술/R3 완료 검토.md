# R3 완료 검토

2026-10-08. R3의 CQB 구현과 단계별 약식 검증을 완료했다. [로드맵](최적화%20전술%20AI%20로드맵.md)의 R3 행과 [구현 요구 표](R3%20CQB%20구현과%20검증.md)를 기준으로 현재 소스, 실제 게임 원본 감사/캡처, 현재 빌드의 실제 어셈블리 바인딩·단위 검사를 확인했다. 정식 3회 반복 CPU 게이트는 [사용자 지침을 반영한 검증 기준](최적화%20전술%20AI%20검증%20기준.md)에 따라 R7에서 수행한다. 단일 대조를 정식 합격으로 바꾸지 않았다.

## 204명 다방과 CPU

LOW 204명/17분대, fixture v17, 세 방, 준비 0·측정 15,000틱의 New 실행은 10,274틱에 17분대·204명 모두 실제 지정 자리와 임무를 완료했다. 확보 구역 이력 51개, 목표/대표 바닥 확보·고유 자리·연결 스택·물리 계획·격리를 통과했고 안전 대기 전 진입 0건이다. 작업 실패/중단은 94건이며 완료 전에 회복했다. 실패가 전혀 없는 실행이라고 하지 않는다.

| 실제 OS CPU ms/측정 틱 | Vanilla | New | N/V |
|---|---:|---:|---:|
| 전체 게임 틱 | 6.4673 | 5.6309 | 0.8707 |
| 틱 밖 포함 전체 메인 창 | 15.3969 | 14.0366 | 0.9116 |

이 쌍은 같은 DLL `46aa245cc2b9ee5a98b91766cbbc2c327fa8213af6333af0110b90b05c46ec30`·지도/폰 지문·편제·준비/측정·계측 대상으로 비교기가 승인했다. 60명 단일 쌍의 틱/전체 메인 창 비율은 0.9250/0.8153이다. 서로 다른 DLL의 60명·204명 자료를 동일 반복 그룹으로 묶지 않는다. 두 쌍 모두 `within2x=true`지만 1/1이므로 정식 CPU 게이트는 false다.

204명 New의 전체 틱 최대 경과 시간은 60.1427ms, 지휘 Tick 최대는 18.9851ms다. 단일 동기 호출/JIT/바닐라 처리의 스파이크 제거를 선언하지 않는다. 메서드 분위수는 마지막 2048회 표본이고 경과 시간/Core 배치 비율은 실제 CPU와 다르다. [동일 조건 대조·요약·원본](../../Source/Benchmarks/TacticalEngineAudit/Results/2026-10-08-r3-large-cqb)을 보존했다.

처음의 10,000틱 New 창은 16/17 완료와 한 분대 Clear로 끝났다. 그대로 실패 자료로 남기며 영구 정지로 확정하지 않는다. 확장 창에서 실제 전원 완료를 확인했다. 검증기는 폭발로 연결된 예전 방 수만큼 재돌파를 요구하던 조건을 없앴고, 모든 요청 바닥 구역·목표·실제 고유 진입 이력은 계속 요구한다. 진행하지 못한 실행을 합격 처리한 변경이 아니다.

현재 DLL의 [interrupt 원본](../../Source/Benchmarks/TacticalEngineAudit/Results/2026-10-08-r3-large-cqb/current-interrupt/summary.json)은 12명/4000틱 1회다. capture/audit complete=true, dropped/계측 예외 0, 실제 중단 발생·외부 재통과 없음·전원 완료·안전 진입을 확인했다. 이 작은 회귀를 새로운 대규모 CPU 대조로 취급하지 않는다.

## 단계 경계와 남은 통합 검증

R4의 후방/문/복도 접촉 기억, R5의 LOW 접촉·High 무전·협력 입구, R6의 야전·수비, R7의 400명급·다중 맵·저장/로드·구형 제거·정식 반복 CPU 검증은 완료 대상으로 포함하지 않았다. 로드맵의 해당 단계는 계속 미착수다. 새 엔진은 `-hdTacticalEngine=new`로 선택하는 상태이며 기본 엔진 전환은 아직 하지 않는다.

부분 진입은 확보 쪽이 있는 후속 방에 적용한다. 첫 방/접근 스택은 전체 분대의 연결 공간을 요구한다. 새 구멍 native 회귀는 방 조사 전에 발생한 변화이며 가능한 모든 지도 변형을 검증한 결과는 아니다. 정적 스냅샷이 뒤늦은 변화를 영구적으로 완벽히 반영한다거나 모든 지도·High 편제의 CPU를 보증하지 않는다.
