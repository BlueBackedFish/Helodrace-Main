# 궁극적으로 필요한 기능
일부폰은 진입준비, 일부폰은 사주경계하는 기능
수비상태와 공격상태 분리.
수비상태에서 저격조 대응조 생성같은 유동적인 인력 사용, 구조 변경
수류탄 사용 뿐만 아닌 연막탄을 이용한 시야 차단, 외부에 CAS, 포격 요청등의 지원 사용
공격 상태에서 전선확인후 우회 타격
진입전 스택업 또는 대열 생성 후 동시에 일제 진입.
스택업 단계에서 폰 배치. 예를들어 진입로 fatal funnel 에는 위치하지 않는다, 폭발 범위 밖에서 대기한다, 진입 순서 생성에서 분대장은 2번째 또는 가장 전방을제외한 위치에 위치한다
진입 단계에서의 행동양식 결정. 대전기에서는 같은 팩션 폰이 있는 감방같은 중요지점이 아니면 대부분 수류탄 폭발 이후 돌입후 소탕, 현대는 내부 인원 식별이 불확실하면 수류탄 보류 또는 비살상 투척 사용후 진입 진입 도중에 running the rabbit 같은 CQB 방법론적 행동 수행.
진입이후에도 위협 산정을 통해 열린문, 닫힌문, 통로 같은 요소를 종합해 사주경계 인원 분배를 함.
야전에서의 우회, 기동경로, 시가전에서의 진입, 이동 경로를 노드화 하여 개발자 모드에서 볼수 있게 하기.
전술 판단에 현재 상황에 가장 적합한 행동, 2번째로 적합한 행동같이 적합도로 3개를 뽑고 현재 지휘폰이 승계되어 효율이 떨어졌을떄 비 적합한 명령을 수행하는등의 상호작용.
명령 하달할때, 지휘권 승계할때, 수류탄 던질때등에 폰 옆에 택스트 띄워서 플레이어가 보는등의 몰입감 관련 요소
모드 전용으로 추가된 브리치 기능사용하는 기능.
수류탄을 진입 상황 외에도 야전에서도 활용하는 기능
인원 사망등으로 계획을 재평가 하는기능
