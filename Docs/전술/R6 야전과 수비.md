## 비용 제한과 의도적인 단순화

새 맵/위협 격자·통신 그래프·전역 방 캐시는 만들지 않는다. 관측 후보 수와 전역 작업 예산을 공유한다. 대형 배정은 분대 갱신마다 최대 2명, 각 자리 25후보이며 벽에 잘린 경우 현재 위치 주변 25후보를 한 번 더 확인한다. 실제 경로 요청은 기존 전역 경로 제한으로 입장한다. 자리·위협 방향은 매 틱 다시 계획하지 않는다.

직접 연결된 바닥만 허용하는 가까운 이동 후보를 사용해 벽을 끼고 먼 우회하는 경로를 예방한다. 바위/벽 때문에 이상적인 곡면을 만들 수 없으면 주변 자리를 사용한다. 모든 엄폐를 정밀하게 비교하거나 숨은 적의 현재 작업·목적지·무기 사거리를 조회하지 않는다. 자기 무기 사거리만 사용한다.

## 최초 LOW 실행

`hd-r6-field-low-01`, fixture v20, LOW 12명/4,800틱. 404틱 외부 적 노출, 406틱 56.3칸 적 감지 및 야전 전환, 527틱 적 접근, 541틱 방향 관측, 796틱 소실 후 원래 개구부로 복귀. 전체 임무 2,101틱 완료. 감지·접근·고유 자리·숨은 좌표 고정·복귀·감사 complete 통과. 이후 벽에 잘린 대형의 국소 대체 자리를 보완했으므로 이 실행을 최종 DLL의 모든 분기 증거로 사용하지 않는다.

관련 `AdvanceFieldResponse + ScanContacts + TickGuard` inclusive 경과 시간 합계는 약 0.003428ms/틱, Core 10,000회 배치 대비 약 1.2493%/틱이다. 하위 `AssignFieldPost`를 중복 합산하지 않았다. 각각 최대 2.0852/2.3285/2.4412ms이며 첫 호출/JIT를 포함한다. 개별 메서드 실제 CPU가 아니며 N/V ≤2배의 정식 합격 자료도 아니다.
