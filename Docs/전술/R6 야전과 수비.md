## 비용 제한과 의도적인 단순화

새 맵/위협 격자·통신 그래프·전역 방 캐시는 만들지 않는다. 관측 후보 수와 전역 작업 예산을 공유한다. 대형 배정은 분대 갱신마다 최대 2명, 각 자리 25후보이며 벽에 잘린 경우 현재 위치 주변 25후보를 한 번 더 확인한다. 실제 경로 요청은 기존 전역 경로 제한으로 입장한다. 자리·위협 방향은 매 틱 다시 계획하지 않는다.

직접 연결된 바닥만 허용하는 가까운 이동 후보를 사용해 벽을 끼고 먼 우회하는 경로를 예방한다. 바위/벽 때문에 이상적인 곡면을 만들 수 없으면 주변 자리를 사용한다. 모든 엄폐를 정밀하게 비교하거나 숨은 적의 현재 작업·목적지·무기 사거리를 조회하지 않는다. 자기 무기 사거리만 사용한다.

## 최초 LOW 실행

`hd-r6-field-low-01`, fixture v20, LOW 12명/4,800틱. 404틱 외부 적 노출, 406틱 56.3칸 적 감지 및 야전 전환, 527틱 적 접근, 541틱 방향 관측, 796틱 소실 후 원래 개구부로 복귀. 전체 임무 2,101틱 완료. 감지·접근·고유 자리·숨은 좌표 고정·복귀·감사 complete 통과. 이후 벽에 잘린 대형의 국소 대체 자리를 보완했으므로 이 실행을 최종 DLL의 모든 분기 증거로 사용하지 않는다.

관련 `AdvanceFieldResponse + ScanContacts + TickGuard` inclusive 경과 시간 합계는 약 0.003428ms/틱, Core 10,000회 배치 대비 약 1.2493%/틱이다. 하위 `AssignFieldPost`를 중복 합산하지 않았다. 각각 최대 2.0852/2.3285/2.4412ms이며 첫 호출/JIT를 포함한다. 개별 메서드 실제 CPU가 아니며 N/V ≤2배의 정식 합격 자료도 아니다.

## 계획 연막과 분산 기동 검증

[실행 원본](../../Source/Benchmarks/TacticalEngineAudit/Results/2026-10-09-r6-smoke/README.md). LOW/High 각 4,800틱에서 연막 2회가 실제 투척되고 가스가 형성된 후 다음 구간으로 기동했다. LOW는 임시 자동화기조가 엄호하는 동안 나머지가 먼저 이동하고 다음에는 자동화기조가 합류한다. High는 기존 자식 화력조를 교대한다. 자리 계산도 한 번에 최대 두 명씩 나누며 아직 계산 중인 기동을 도착 완료로 간주하지 않는다.

LOW는 768/1,256틱에 연막 형성을 확인하고 1,661틱 CQB 복귀, 3,008틱 임무 완료. High는 3,018틱 임무 완료, 실제 한 화력조 기동 및 반복 연막·복귀 확인. 연막 목표는 어느 투척자가 선택되든 분대 중심+접근축 8칸과 일치한다. 실제 접근으로 바뀌면 형성된 연막을 확인하더라도 앞으로 기동하지 않고 수비를 유지한다. HC/일반 무해한 연막만 사용하며 WP는 진입용으로 선택하지 않는다.

위 최초 연막 실행은 의료 처치와 실제 대응 사격을 포함하지 않았다. 후속 의료/사격 검증은 아래에 별도로 기록한다. 모든 총격·수류탄·취소 조합과 대규모 반복 CPU 판정으로 확대 해석하지 않는다.

## 부상 안정화 AI와 검증

방의 국소 확보 검사가 끝난 뒤 다음 방/완료로 넘기기 전에 의료 검사를 허용한다. 야전은 대형에 도착한 수비 상태와 실제 엄폐를 요구한다. 분대원 두 명씩 건강 캐시를 읽으며 검사 주기는 600틱, 환자 처치 재선택은 기본 1,800틱, 한 처치 2,400틱 제한이다. 전역/다른 분대 환자나 지면 약품을 검색하지 않는다. 실제 장착 가방에 자기 인벤토리 보급품을 넣고 소비한다. 기본 편제에 새 가방/약품은 자동 지급하지 않는다. 따라서 LOW 기본 편제는 가방이 없으면 처치를 수행하지 않으며, High는 기존 TCCC 자격으로 지혈한다. 매딕 장비 배분은 별도 편제 선택이다.

한 분대에 한 환자+보조자만 작업을 소유한다. 다른 인원은 기존 자리에서 경계한다. TCCC 지혈(최대 6부위/30초), 가방 지혈(기존 4부위/장기 제외/30초), 혈액손실 40% 이상은 가방 혈장으로 안정화한다. 이미 표시된 부위는 AI 처치의 후보에서 제외해 같은 네 부위만 반복 처리하지 않는다. UI 처치는 기존 갱신 동작을 유지한다. 지혈 후 심한 혈액손실이 남으면 수혈을 우선 다시 검토한다.

최근 실제 목격 적이 28칸 이내에서 노출되거나 자기/보조자가 인지한 위험 폭발물이 가까우면 처치를 중단한다. 설치/발사된 CQB 폭발물, 연막 준비·이동, 문 통과·관측 중에는 새 처치를 시작하지 않는다. 실제 확보 이력은 안전을 보장하지 않으므로 최근 관측도 검사한다. 중단/완료는 같은 큐를 깨우며 작업/경로 예산을 공유한다. UI와 AI의 기존 의료 JobDriver를 함께 사용하고 저장 후 Toil 순서가 바뀌지 않도록 이동 예산 gate를 고정 위치에 둔다. 의료 작업의 저장/로드 통합 자체는 R7 검증 대상이다.

바닐라 다운 처리는 원래 Lord에서 폰을 제외하므로 치료받은 생존자는 회복 이벤트에서 원래 습격 Lord로 재합류한다. 다른 Lord로 이미 옮긴 폰이나 정신 상태/사망자는 강제로 빼오지 않는다. 후미가 현재 목표 방 밖에 남았으면 일반 post 이동으로 직접 합류하지 않고 같은 필수 개구부 통과 작업을 복구한다. 현재 자리·원래 통과 이력으로 진입 완료 상태를 복원하며 경계/후미 합류 규칙을 보존한다.

[의료 원본·실패 기록·요약](../../Source/Benchmarks/TacticalEngineAudit/Results/2026-10-09-r6-medical/README.md). LOW 12명은 6,463틱, High 13명은 5,953틱 전원 임무 완료. 각각 실제 출혈 네 부위의 지혈, 혈장, tend 없음, 경계 유지, 환자 분대 재합류와 다음 방 복귀를 확인했다. 중단 시험은 실제 임시 압박을 만든 후 적을 노출하고 처치 중단·압박 제거·대응 사격·후속 치료·같은 개구부의 후미 통과를 확인해 8,252틱에 13인 전원 완료했다.

초기 의료 fixture 불일치, 회복자의 Lord 이탈, 짧은 창과 후미 진입 상태 미복원 원본도 보존한다. 최종 성공을 초기 실패에 덮어쓰지 않았다. 관련 호출·평균·상위/최대·Core 비율은 각 summary에 있다. 대규모 CPU 곡선·모든 피해/취소 조합과 저장/로드는 R7에 남는다.
