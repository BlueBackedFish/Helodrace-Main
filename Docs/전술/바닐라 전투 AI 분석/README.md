# 바닐라 전투 AI 코드 분석

분석 대상은 로컬에 설치된 **RimWorld 1.6.4871 rev590**의 `Assembly-CSharp.dll`과 Core/DLC 정의다. 게임 AI를 수정하지 않고 ILSpy로 추출한 C#과 ThinkTree·Duty XML을 대조한다. 분석은 진행 중이며, 아래 장의 근거가 확보된 범위와 아직 확인할 범위를 구분한다.

## 현재 확인된 구조

바닐라 전투는 하나의 전술 관리자에서 매 틱 전원에게 위치를 배정하는 구조가 아니다. **Lord가 집단 상태와 Duty를 정하고, 각 폰의 ThinkTree가 Job을 고르며, JobDriver/Toil이 실행하고, PathFollower와 Verb/Stance가 이동·공격을 진행한다.** Duty의 XML 순서와 Job의 종료·중단 조건까지 봐야 실제 행동을 설명할 수 있다.

- [01 틱·판단·작업 소유권](01%20틱과%20판단과%20작업%20소유권.md): 판단 시점, 우선순위, 작업 교체·예약·스탠스.
- [02 표적·엄폐·현재 자리 사격](02%20표적과%20엄폐와%20대기%20사격.md): 표적 선정, 엄폐 탐색 조건, `Wait_Combat`와 `AttackStatic`의 차이.
- [03 그룹 이동·개인 경로·접촉](03%20그룹%20이동과%20개인%20경로와%20접촉.md): Lord/Duty, 이동 중 접촉, 비동기 경로 요청, 문·충돌·막힘.
- [04 사격선·조준·공격 실행](04%20사격선과%20공격%20실행.md): lean/LOS 차이, warmup·burst·cooldown, 명중·발사체·근접 반격.
- [05 습격·공병·브리처·포위·퇴각](05%20습격과%20공병과%20브리처.md): 전략에서 Duty까지, 공유 돌파 구역, 역할 재배정, 공격/회수/도주 차이.

## 분석 근거와 한계

전체 어셈블리에서 9,217개 C# 파일을 추출했다. [분석 기준과 소스 목록](분석%20기준과%20소스%20목록.json)에 버전·원본 SHA256·디컴파일러·41개 ThinkTree/Duty XML의 해시를 기록했다. [AI 메서드 후보 목록](AI%20메서드%20후보%20목록.csv)은 1,027개 후보 파일의 3,399개 메서드 서명이다. 이 목록에는 비전투 작업과 의존 코드도 포함하며, 목록 생성은 전부 분석 완료했다는 뜻이 아니다.

근거 링크는 이 컴퓨터의 디컴파일 캐시를 가리킨다. 캐시 루트는 `C:/Users/Public/Documents/ESTsoft/CreatorTemp/vanilla-combat-4871-20261014`다. 저장소에는 디컴파일 원본 전체를 복사하지 않는다. 버전이 바뀌면 줄 번호·상수·구조가 달라질 수 있다. 모드 Harmony 패치, XML 패치와 현재 세이브의 Lord/Duty/Job은 별도로 작동하므로 이 문서가 특정 모드 장면의 원인을 그대로 증명하지는 않는다.

다음 범위는 아직 분석 완료로 판정하지 않는다: 폭발 회피·도주 목적지·입장 위치의 세부 계산, 동물/메카노이드/DLC 전투·능력, 포탑 운용, 명령 입력과 세부 중단 조건. 완료 시에는 장별 근거와 주요 메서드 책임 목록을 추가하고 범위 검사를 수행한다.
