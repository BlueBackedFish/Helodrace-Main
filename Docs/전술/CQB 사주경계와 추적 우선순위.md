# CQB 사주경계와 추적 우선순위

## 스택업 경계와 부분 진입 — 2026-10-13

- 스택업 자리 배정 때 각 날개의 바깥 끝 인원은 측면, 추가 뒤쪽 인원은 후방을 보게 한다. 가장 안쪽 인원은 개구부 경계를 유지한다. 자리 부족으로 따라오는 인원도 측면·후방 방향을 나누어 본다. 방향은 계획마다 한 번 정하며 전원에게 매 틱 감시 검색을 추가하지 않는다. 기존 분대 접촉 관측을 사용한다.
- 부분 스택업의 나머지 인원은 먼 이전 진입 자리를 유지하지 않는다. 개구부 앞에서 연결된 확보 바닥을 따라 가까운 빈 경계 자리를 찾는다. 아직 확보하지 않은 바닥·벽 너머·닫힌 문 너머는 사용하지 않으며 개구부 바로 앞과 이미 배정된 칸은 비운다. 탐색은 새 이웃 64개씩 틱에 분산하고 전체 512개·개구부 앞에서 24칸 범위로 제한한다. 공간이 전혀 없으면 해당 돌파 후보를 포기하고 기존 재시도 흐름을 사용한다.
- 진입 자리 배정에서 스택업 참여자를 다시 검사한다. 나머지 인원은 가까운 경계 자리를 유지하며, 실내 자리가 남아도 자동으로 진입 인원이 되지 않는다. 모든 진입자는 실제 스택업 자리 도착을 기록한 뒤 진입한다. 시간 초과로 스택업을 건너뛰었던 인원도 먼저 스택업 자리로 간다. 이미 확보된 통로의 직접 이동은 예외다.
- 부분 스택업의 잔류 경계 인원을 사상자 대체로 즉시 진입시키지 않는다. 스택업 참여 인원이 전부 없으면 계획을 다시 잡는다. 스택업 방향과 실제 도착 기록을 저장한다.

검증: 방향 회전·연결된 근거리 경계·참여자 제한·실제 도착·탐색 상한 21개 검사, 기존 스택업 593개·진입 공간 157개·HIGH 저장 포함 51개 및 기존 C4·투척·예산 검사 통과. 외부인들2 중앙 건물의 2,200틱 격리 실행에서도 투척·복귀 각 1회, 12명 진입, 폭발 전 진입 0회였다. 해당 저장 맵 장면은 전원 스택업 가능한 방이므로 부분 대형과 화면 방향은 별도 약식 확인 대상이다. 공격자와 방어자의 피해를 막은 테스트이며 메서드 프로파일링은 실행하지 않았다.

## 관측 기억을 이용한 추적 우선순위

적을 관측한 방의 돌파를 먼저 하고, 그 방 확보 이후에는 바로 연결된 미진입 방을 우선 대상으로 삼는다. 실시간 숨은 적 위치를 참조하거나 이동 중인 돌파 계획을 계속 갈아끼우지 않는다.

- 기존 원거리 접촉 기억과 실제 공격 의도가 관측된 근접 위협에서 가장 최근의 실내 위치를 선택한다. 문칸 관측은 기존 `Area` 값인 인접 방 바닥을 사용한다. 같은 시점에 여러 적을 보아도 현재 대상을 유지해 방 탐색이 계속 초기화되지 않게 한다.
- 관측 위치에서 문·벽의 개구부·지붕 경계를 막은 연결 바닥을 작은 방 범위로 기억한다. 기존 예산 안에서 새 이웃 64개씩 처리하고 256칸에 도달하면 근사값으로 종료한다. 같은 방의 적을 다시 관측하면 위치와 시각만 갱신해 범위를 재사용한다.
- LOW의 다음 방 점수와 진입 중 미리 준비하는 다음 방 후보, HIGH의 새 화력조 방 배정에서 관측 방을 최우선으로 둔다. 그 방을 실제 확보한 뒤에는 방 스캔에서 얻은 연결 실내 출입구 최대 16개를 다음 우선순위로 둔다. 이미 확보한 방·다른 조가 작업 중인 입구·불가능한 돌파 후보를 제외하는 기존 규칙은 유지한다.
- 우선순위는 다음 계획/새 과업 배정 때 적용한다. 현재 이동·스택업·투척·진입을 취소하지 않는다. 관측 없이 연결 방의 연결 방으로 무한 추적하지 않는다. 새로운 적 관측이 있어야 추적 근거를 확장한다.
- 마지막 관측에서 1,800틱이 지나면 우선순위와 방 범위를 제거한다. 값으로 된 기억과 진행 상태를 저장한다. HIGH 분대 안에서는 기존 접촉 상태와 함께 공유하며, 다른 분대는 기존 통신으로 받은 관측 기억만 사용한다. `Inspect squad commands`의 `pursuit`에 위치·적 ID·방 범위·준비/진입 상태·연결 출입구 수를 표시한다.

검증: 관측 방 우선·직접 연결 방·스냅샷 재사용·오래된 보고·동시 관측 8개 검사 통과. HIGH의 실제 새 방 배정 메서드에서 침대에 더 가까운 다른 출입구보다 관측 방을 선택하는 검사와 기억의 바닐라 Scribe 저장 검사를 포함해 HIGH 53개 통과. 기존 방 스캔·접촉·진입 교전·예산 검사도 통과했다. 여러 방에서 적이 후퇴하는 실전 추적은 약식 테스트 목록에 남긴다. 넓거나 파괴로 합쳐진 방의 연결 범위는 상한과 개구부 형상 판단에 따른 근사값이다.

최종 DLL의 외부인들2 2,200틱 재생도 투척·복귀 각 1회, 12명 통과·도착, 폭발 전 진입 0회, CQB 실행 예외 없이 완료했다. 원본 세이브 해시와 설치 DLL 일치를 확인했다. [짧은 격리 실행 결과](../../Source/Benchmarks/TacticalEngineAudit/Results/2026-10-13-cqb-security-pursuit.json)에 두 실행의 요약을 보관했다. 이 테스트는 전원 스택업 가능한 단일 진입과 지속 교전이므로 여러 방 추적의 실전 검증을 대신하지 않는다.
