# 야전 수류탄과 투척 통합 — 2026-10-14

인벤토리 수류탄의 근접/일반 투척 버튼과 JobDef를 하나로 합쳤다. 준비 시간은 플레이어·야전·CQB 모두 150틱(2.5초)이며 이동 시간은 별도다. CQB는 자리에서 132틱 준비하고 투척 지점에서 18틱 동작한다. 최대 사거리는 13.9칸의 1.5배인 20.85칸이다. 8.85칸 이하에서는 기존 짧은 투척 궤적, 그보다 멀면 일반 투척 궤적을 자동 사용한다. 산포는 동일한 사격 능력·거리 계산을 사용한다.

LOW/HIGH 야전 교전에서는 분대별로 15틱 간격에 한 인원을 순환 검사한다. 이동·회피·치료·재장전·CQB 전용 작업을 수행 중인 폰은 제외하고, Wait_Combat으로 교전 중인 폰은 사격 준비를 중단하고 수류탄 준비로 전환할 수 있다. 최근 관측 기억 최대 4개를 검사하며, 기억한 칸에 실제 적이 남아 있고 투척 LOS와 사거리를 만족해야 한다. 숨은 적을 맵 전체에서 ID로 찾아 추적하지 않는다. 야전 대인 투척 대상은 지붕 없는 칸이다.

대인 피해를 주는 폭발 수류탄을 사용하며 가스/연막탄은 이 판단에서 제외한다. 여러 종류가 있으면 아군 위험 범위가 작은 것을 우선한다. 기존 HC 연막 계획은 별도로 유지한다. 분대가 대인 투척을 시작하면 600틱 동안 추가 대인 투척을 억제한다. 이는 분대별 규칙이며 서로 다른 분대의 투척을 전역으로 한 건에 제한하지 않는다.

파편·바운스·산포를 포함한 기존 아군 안전 검사를 유지한다. 투척자는 필요하면 자기 활동 구역 안에서 반대 방향 2~4칸의 직선 후퇴를 계획한다. 중간 칸과 뇌관 시간 안의 이동 가능성을 확인하고, 후퇴 경로 예산을 확보한 뒤 발사한다. 다른 아군이 위험 범위에 있으면 후퇴 계획으로 우회 허용하지 않는다. 준비 중 아군이 접근하거나 길이 막힐 수 있으므로 실제 발사 직전에 다시 안전을 확인한다.

투척 준비 중 총기 사격을 막고 수류탄을 표시한다. 대형/야전/집중 사격 갱신은 진행 중인 투척과 후퇴를 덮어쓰지 않는다. 기존 폭발 회피와 바닐라 안전 작업은 유지한다. 후퇴가 끝나면 해당 폰만 기존 야전 교전으로 복귀하며 다른 인원은 계속 교전한다.

엄폐 탐색의 전역 계획 예산을 공유하되, 수류탄이 없거나 이동 중인 폰은 무거운 판단 예산을 소비하지 않는다. 매 준비 틱마다 투척 LOS를 재검사하지 않고 실제 발사 시 검사한다. Inspect squad commands에 field grenade next와 맵 전체 checks/plans/throws 카운터를 표시한다. 이 변경은 모루/망치 개편 계획 자체의 구현은 아니다.

빌드 및 수류탄 안전/야전 관련 약식 자동 검사를 진행했다. 게임 내 준비 시간·궤적·실제 투척/후퇴·아군 접근 취소는 `습격 기능 약식 테스트 목록.md`의 F72~F74로 확인한다. CPU 실측과 전체 세이브 재생은 이번 작업에 포함하지 않았다.
