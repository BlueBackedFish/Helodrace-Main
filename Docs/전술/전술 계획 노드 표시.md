# 전술 계획 노드 표시

2026-10-12. 게임을 재시작한 후 개발자 모드의 디버그 설정 메뉴에서 `View → 습격 전술 계획 노드 표시`를 켠다. 기존 습격 조직 표시처럼 세션 동안 유지하는 개발자 View 설정이며 기본값은 꺼짐이다.

현재 맵의 실행 중인 분대 계획을 다음 색의 십자 표식으로 표시한다.

| 색 | 표시 지점 |
| --- | --- |
| 흰색 | 최종 목표, 계획된 야전 연막 위치 |
| 빨강 | 개구부, 사격 표적, 투척 목표 |
| 노랑 | 접근·스택업 자리, 투척 위치 |
| 초록 | 진입 안쪽과 개인 진입 자리 |
| 파랑 | 잔류 경계·접촉 대응·야전 개인 자리 |
| 청록 | 다음 목적지, 진입 통로, 조별 화력점, 관측 위치 |

목표·개구부·화력점 등의 주요 지점에는 이름을 표시한다. 개인 집결/진입/경계 자리는 가까이 마우스를 대면 번호를 표시한다. 앞 숫자는 현재 표시하는 분대 번호, 자리 뒤 숫자는 계획 안의 인원 인덱스다. 같은 지점의 역할 이름은 합치고 여러 분대가 같은 칸을 가리키면 라벨을 위로 나눠 표시한다. 반환 중이거나 완료·해제된 분대의 이전 계획은 표시하지 않는다.

기존 실행 상태의 목표·자리·투척 값만 읽는다. 표시를 위해 경로·LOS·엄폐·방 구조·전술 계획을 새로 계산하지 않는다. 실제 이동 경로를 그리는 기능은 아니며 전체 확보 구역이나 방 레이아웃도 그리지 않는다. 새 맵 컴포넌트/틱 작업 없이 기존 전술 컴포넌트의 프레임 표시 콜백을 사용한다. 표시가 꺼져 있거나 개발자 모드가 아니면 캐시를 비우고 바로 반환한다.

계획 값은 30프레임 간격으로 캐시에 갱신한다. 현재 화면 안의 표식만 그리며 최대 256개 노드와 96개 라벨로 제한한다. 일시정지 상태에서도 프레임 표시를 갱신할 수 있다. 캐시는 세이브에 저장하지 않는다.

빌드 경고/오류 0, 한국어/영어 키 대응과 XML 구문 확인 완료. 게임에서 메뉴 토글·색 표시·마우스 번호 확인은 [단일 약식 목록](습격%20기능%20약식%20테스트%20목록.md)의 F44에 둔다.
