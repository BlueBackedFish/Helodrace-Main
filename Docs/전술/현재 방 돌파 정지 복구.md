# 현재 방을 돌파 목표로 잡는 문제

진입조의 가장 큰 방별 집단을 기준으로 출발 폰과 점유 방을 고른다. 전체 분대 중심이나 뒤에 남은 지원 인원이 실내 계획의 기준을 끌어내지 않도록 한다.

계획의 `CqbIntent`와 `OccupiedRoom`을 저장한다. 현재 방 목표가 국소 통행 그래프로 연결돼 있으면 `ClearCurrentRoom` 계획을 만들어 집결·돌파·지원 투척을 거치지 않고 공격/방 내부 정리로 간다. 미확보 다른 방은 `EnterRoom`, 같은 원래 방 안의 새 장애물로 연결이 끊겼으면 `RemoveInteriorObstacle`이다. 현재 방이라는 이유만으로 침대나 적을 목표에서 제거하지 않는다.

실내 돌파 후보는 현재/확보 구역에서 준비 지점까지 국소 이동 가능한지 검사한다. 이미 걸어갈 수 있는 돌파 안쪽, 다른 확보 방, 실외를 향하는 불필요한 돌파는 제외한다. 확보 상태는 정적 캐시에 넣지 않고 조직 실행 기록에서 읽는다. 같은 원래 방이 새 벽으로 끊긴 경우는 내부 장애물 제거를 허용한다. 국소 다음 방 탐색은 문 자체의 방 번호를 목표로 잡지 않고 경계 셀 너머의 실제 방을 고른다.

실행 중에도 30틱마다 논리적 목표 오류를 검사한다. 진입조 절반 이상이 이미 목표 방에 있고 국소 통로가 연결돼 있으면 내부 정리 계획으로 교체한다. 잘못된 돌파 안쪽이 연결된 현재 방/확보 방이면 같은 목표의 계획을 다시 만든다. 구조 변화가 없어도 복구하며 재계획은 최소 60틱 간격이다. 진행 중인 수류탄 준비·발사체·폭발 효과·투척자 복귀 및 C4 과정은 건드리지 않는다. 실패한 재계획으로 기존 진행/확보 기록을 지우지 않는다.

전술 상세 보고에 행동 의도와 점유 방 번호를 추가했다. 자동 검증은 행동 구분, 현재/확보 구역으로의 중복 돌파 거부, 새 내부 장애물 예외, 미확보 방을 통과한 준비 지점 거부, 문 방 번호 처리에 대한 13개 검사를 포함한다. 실제 정지 사례의 게임 내 재현 확인은 별도로 필요하다.
