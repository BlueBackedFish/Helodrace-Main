2026-10-10. **진행 중이며 최종 합격 판정이 아니다.** [로드맵](최적화%20전술%20AI%20로드맵.md), [검증 기준](최적화%20전술%20AI%20검증%20기준.md), [구현·회귀 기록](R7%20통합%20검증과%20구형%20제거.md)을 기준으로 최종 증거를 대조한다. 이전 DLL의 부분 결과를 마지막 DLL의 합격 증거로 합산하지 않는다.

## 최신 범위 변경

2026-10-10 사용자가 “전체 44개 넘겨 그냥”으로 전체44 재검증 생략을 지시했다. 아래 전체44 계획과 이전 수집 기록은 보존하되 전체44 통과를 현재 완료 조건으로 요구하지 않는다. 후속 기능 큐는 중단했으며, 같은 DLL의 통과 부분과 실제 관련 연막 저장 복구 증거를 유지한 채 CPU 비교로 넘어간다. 생략된 사례는 이번 빌드에서 전부 검증한 것으로 표시하지 않는다. AllowPartialFunctional 사용과 finalFunctionalSkipped=true를 성능 원본/최종 보고에 남긴다. CPU24그룹/96회·실제 기능 진행·같은 SHA·반복 중앙값의 두 CPU2배 기준은 유지한다.

[비계측 비교](../../Source/Benchmarks/TacticalEngineAudit/Compare-R7Unprofiled.py)의 여섯 unprofiledMainControlPassed도 별도로 확인한다.

Core 기준은 NumCellsInRadius 반지름8+(i%16) 10,000회 배치 중앙값이다. 이것은 환경 보정용 경과 시간 기준이며 실제 CPU 분모가 아니다. 메서드별 cpuMeasured=false는 미측정이고 무비용이 아니다. 실제 반복의 분산/최대와 제한을 공개하고, 다른 DLL의 과거 약식 수치를 최종 중앙값에 포함하지 않는다.

## 종료 조건

1. 사용자 요청에 따른 전체44 재검증 생략을 기록한다. 현재 최종 DLL/정의의 실제 완료 부분 원본과 관련 저장 복구를 검사·보존하고 미실행 범위를 공개한다.
2. 전체24그룹/96회 수집을 검사하고, 모든 대표 profiled/unprofiled CPU 게이트·진행·제외/실패를 확인한다.
3. 실제 인원 곡선, 메서드/Core 비용, 초기/활동/완료 이후 창, 틱 스파이크와 큐 지연, 협력의 실제 수행 범위를 보고한다.
4. 구형 제거·공통 기능 유지·종료 후 갱신 없음과 위 기능 표 전체를 마지막 결과에 연결한다.
5. 누락·간접 증거·실패는 미완료로 남긴다. 현재 표를 실제 원본으로 갱신해 생략 요청을 반영한 범위가 충족된 뒤에만 R7 완료를 선언한다.
