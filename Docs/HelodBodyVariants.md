# 헤로드 체형 분리

모드 설정의 **헤로드 체형 분리 (실험적)**에서 활성화한다. 기본값은 꺼짐이며 재시작 없이 적용된다. 성인의 외형만 바꾸며 신체 크기·능력치와 유아·아동의 기존 외형은 바꾸지 않는다.

## 체형과 저장

제공된 `None`, `Tiny`, `Small`, `Mid`, `Big`, `Huge` 텍스처를 사용한다. 남성은 `None` 95%, `Tiny` 5%의 확률로 배정하며 pawn ID를 시드로 사용해 같은 pawn의 결과가 바뀌지 않게 한다. 여성은 기존과 같이 pawn ID에 따라 여섯 체형 중 하나를 배정한다. 배정값은 `CompHelodBodyVariant`에 저장하며 기능을 껐다 켜도 유지한다. 이미 저장된 체형은 다시 배정하지 않는다. `story.bodyType`은 기존 `Female` 계약을 유지하고, 몸과 의류의 텍스처 경로를 함께 선택한다.

각 pawn에는 마지막으로 적용한 설정도 저장한다. 현재 설정과 다르면 성인을 후드티와 바지로 갈아입힌다. 켤 때는 새 윤곽에 맞는 UCP 바지, 끌 때는 기존 헤로드용 일반 바지를 사용한다. 벗긴 옷은 지도에 내려놓거나 월드 pawn의 소지품으로 옮겨 품질·염색·내구도·부착물을 보존한다. 방탄복·모자·장비는 함께 착용할 수 있으면 그대로 남긴다. 사망자는 갈아입히지 않는다.

현재 지도·다른 지도·월드 pawn에 설정 저장 시 적용하고, 세이브 로딩·스폰·성장 후에도 동기화한다. 새로 생성되는 pawn은 현 설정의 착용 제한으로 의류를 생성하므로 해당 군복을 유지한다.

## 의류

| 구분 | 적용 |
|---|---|
| 체형별 전용 텍스처 | 후드티, 기병 군복, 참호군 내의·외투, 돌격군 내의·외투·흉부 리그, ACS 상의, UCP 블라우스 |
| 새 체형 공통 하의 | 제공된 UCP 바지 |
| 기존 그래픽 유지 | IBTV, M1952A, 서부시대 가죽·금속 조끼, 바닐라 방탄조끼·판금갑옷·강화갑옷·정찰갑옷·캐터프랙트 갑옷 |
| 체형과 무관한 장비 | 머리 의류, 벨트, 배낭형 장비, 의무 가방, 착용 그래픽이 없는 도구 |
| 제한 | 전용 텍스처가 없는 일반 셔츠·코트·일반 바지 등. 기존 종족 허용 목록도 함께 적용 |

원래 정의가 없던 **헤로드 후드티**와 **헤로드 야구 모자**를 추가했다. 두 의류 모두 손·전기 재봉 작업대에서 제작한다. 후드티는 성인용이며 기존 단일 체형에서도 착용한다. 기존 몸과 제공된 Huge 후드티의 남·북·동 방향을 대조한 뒤, 원래 체형에서는 그 후드티의 가로 폭만 1.16배로 보정해 어깨와 가슴의 기존 윤곽을 덮는다. 새 여섯 체형은 제공된 비율을 그대로 사용한다.

`.temp` 원본에서 PNG 225개를 `Textures/Helod/BodyVariants`로 복사했다. 일반 의류는 엔진의 `_Female` 접미사에 맞춰 파일명을 정규화하고, 벨트인 흉부 리그는 체형 접미사를 엔진이 덧붙이지 않는 경로를 사용한다. 기존 텍스처는 덮어쓰지 않았다.

## 검증

`Source/Tests/BodyVariants/Start-Checks.ps1 -RuntimeRoot <격리 경로>`로 실제 RimWorld 1.7 검사를 실행한다. 여섯 체형·전용 의류의 네 방향 그래픽, 착용 허용·제한, 지도·월드 pawn의 설정 전환, 벗긴 의류 보존, 실제 저장·재로드 후 반대 설정 적용과 체형 복원, 반복 적용의 중복 교체 방지를 검사한다. 기존 단일 체형과 Huge 후드티의 원본 합성 비교도 수행했다.

2026-11-10 최종 검증: `.codex-staging/body-variants/runtime-05`의 실제 1.7 런타임에서 **421개 검사 통과**, 저장·재로드 완료. 아동·인간의 기존 의류 권한, 남성의 None 체형, 실제 후드티 렌더러 패치 설치도 확인했다. 제품·검사 프로젝트는 경고·오류 없이 빌드했다. 로그의 유일한 오류는 존재하지 않는 Workshop 폴더 `3781143823`에 대한 기존 환경 오류이며, 체형·의류 경로 오류나 Harmony 적용 실패는 없었다.

남성 체형 확률 변경 검증: `.codex-staging/body-variants/male-tiny-01`의 실제 1.7 런타임에서 **425개 검사 통과**. 20,000개 pawn ID 중 Tiny 1,035개(5.175%)였으며 남성에게 None·Tiny 이외의 체형은 배정되지 않았다. 남성 Tiny의 저장·재로드와 설정 재활성화 후 유지도 확인했다.
