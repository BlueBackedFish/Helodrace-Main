# Native M2A2/M114 howitzer geometry checks

Build Main and the Main engine bridge, then run serially against actual RimWorld 1.7, Harmony 3 and required Blancas:

```powershell
dotnet build Source/Helodrace/Helodrace.csproj -p:IntermediateOutputPath=obj/Migration17/ -v:minimal
dotnet build Source/Tests/EngineMigration/EngineMigration.csproj -v:minimal
Source/Tests/EngineMigration/Run-Migration.ps1 -Case native-howitzer -RuntimeRoot .codex-staging/migration17/howitzer-native17 -NoWindow
Source/Tests/EngineMigration/Wait-Migration.ps1 -RuntimeRoot .codex-staging/migration17/howitzer-native17 -TimeoutSeconds 45
```

Use a fresh runtime. An observation timeout leaves the game running; wait on the same recorded PID/runtime instead of starting another instance.

FrozenHowitzerGraphic.cs copies the original properties/comp bodies from fee3972e with only the namespace changed; the external Harmony patch classes are excluded. The frozen body keeps game vectors/quaternions/TRS and the existing shared native scalar Mathf alias. It uses the unchanged current AnimatedTurretUtility and warmup binding. Actual XML property fields are cloned into each properties type, leaving published/current Def data untouched. No product API is widened.

The product now owns native BCL vectors/quaternions for recoil/layers, both lever layouts, chamber offsets/open rotation, ejected casing flight/bounce/landing, dust and smoke positioning. Quaternion multiplication explicitly normalizes the result, matching the actual 1.7 game operator. Native SpatialMath TRS is converted at Graphics.DrawMesh; FleckMaker and grid-cell checks convert at current game boundaries. Shader/texture/material/mesh caches, camera/audio/particle APIs and their ownership remain game contracts. No GPU/resource-lifetime/performance improvement is claimed, and no firing, crew, loading, RNG, tick or save rule changes.

The fixture creates actual spawned M2A2 and M114 Building_TurretGun Things, tops, gun comps and real authored graphics/materials. Each paired comp shares its actual turret but has independent cloned properties/state. Material caches are warmed before seeded comparisons. Draw tests cover six directions (including wrapped/negative angles), recoil/casing/opening/minimum-open age boundaries and sixteen warmup ages across the motion windows. Actual/default, all-missing and outline-missing material sets exercise both submission and layer-cursor progression. Every submitted matrix component, mesh/material identity/layer/order and every private primitive state field are compared.

Warmup remaining ticks, current target and next-round-loaded results are controlled. The game tick is anchored at at least 10,000 so all intended warmup starts and closing timestamps are nonnegative; the original tick is restored. Before each draw pair, actual and frozen WarmupAnimationProgress must equal the intended sentinel/progress value. This avoids accidentally testing only the first warmup frame because a start timestamp collided with the negative uninitialized sentinel.

Actual NotifyWarmupStarted and NotifyShotFired are called under equal seeds. Post-shot CompTick is paired from age -1 through minimum-open plus close completion with both loaded/unloaded states. Firing dust/rear bands/front smoke, casing smoke, drop sound Maker/Def and all primitive state are compared. Each pair runs inside balanced Rand.PushState/PopState and compares following Rand.Int and Rand.Value bits. The real FleckMaker methods execute (including their RNG/data initialization); mote visibility is forced true and FleckManager.CreateFleck is intercepted before particle-system creation. Every public FleckCreationData field and original effect entry parameters are compared. Sound, camera shake and mesh submission are intercepted. Thus these are caller RNG/data evidence under controlled boundaries, not full particle/audio/GPU lifecycle or natural world RNG progression claims.

This does not execute crew admission, actual warmup/launch jobs, external IAnimatedTurret implementations, projectile ballistics, save/load or visible rendered frames. Actual map bounds are used, but the fixture turrets are placed at map center, so boundary culling is not an exhaustive edge-map test. The comparison uses existing relative 2e-5 numeric criteria and records the observed maximum/nonzero differences; state bits, RNG continuation, field identities, discrete values and submission ordering/counts use exact comparisons. Fixture Things and Harmony prefixes are removed after completion.

The initial run passed with zero numerical differences. On coverage review, its absolute start tick was not recorded and could overlap the negative warmup/closing sentinels. The final fixture anchors/reports the tick and explicitly asserts each intended warmup window. Product and original numerical/state/RNG comparison criteria are unchanged; first-run evidence is retained.
