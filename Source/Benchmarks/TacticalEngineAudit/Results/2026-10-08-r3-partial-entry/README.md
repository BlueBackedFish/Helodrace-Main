[multiroom-60-comparison.json](multiroom-60-comparison.json): 단일 N/V 전체 틱 CPU 0.9250배, 전체 메인 창 CPU 0.8153배, 프로세스 CPU 0.8013배. 실제 OS CPU이며 메서드 경과 시간과 구분한다. 1/1회이므로 정식 반복 CPU 게이트 합격은 false다. 204명급 및 R3 전체 완료 판정 자료를 대신하지 않는다.

각 하위 폴더의 summary와 raw-manifest는 실제 결과/DLL SHA 및 압축 해제한 원본의 SHA256/길이를 기록한다. 작은 방 실행 후 목표 교체 초기화와 개발자 표시를 추가해 DLL SHA가 달라졌으며 두 사례의 성능 개선율은 계산하지 않는다. New/Vanilla 60명 대조만 같은 최종 DLL을 사용했다. 초기 로딩 로그의 기존 누락 텍스처 경고도 보존했다. p95/p99는 마지막 최대 2048호출 표본, 평균/최대는 전체 집계다.
