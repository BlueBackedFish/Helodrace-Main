# R6 최종 야전 사격과 약식 CPU 대조

2026-10-09. 같은 실행의 audit/launcher/capture와 원본 로그 바이트(gzip), SHA를 보존한다. 기능 시험과 고정 입력 CPU 시험을 구분한다.

- `high`: 최종 야전 사격 시험, High 13명/4,800틱. 사거리 밖 관측 → 계획 연막 2회와 실제 가스 → 한 자식 화력조만 기동 → 접근 관측과 실제 사격 1회 → 기억 좌표 고정 → 같은 개구부의 CQB 복귀 → 3,204틱 13인 전원 완료. 고유 자리, 폭발 전 조기 진입 0, 실패 Job 0. 관련 경과 시간/Core 비율은 summary에 있다.
- `low-profiler-rejected`: LOW 12명/4,800틱. 같은 행동과 실제 사격 1회, 3,243틱 전원 완료를 확인했다. 수집 인수의 잘못된 클래스 이름 때문에 프로파일러 초기화가 거부되어 CPU 자료로 사용하지 않는다. `newFieldSingleTeamBounds=false`는 LOW 임시조를 High 자식 화력조 인덱스로 비교한 당시 감사 조건 때문이며 이후 감사만 수정했다. 이 플래그를 통과했다고 표시하지 않는다.
- `vanilla-before-audit-fix`: 고정 틱 CPU fixture의 첫 바닐라 실행. 이후 LOW 감사 조건 수정으로 DLL SHA가 달라져 최종 신규 실행과의 동일 빌드 CPU 대조에서 제외한다.

기능 시험은 실제 단계를 기다려 적을 노출하므로 다른 엔진과의 동일 입력 CPU 비교 자료가 아니다. `r6-field-cpu`는 엔진 진행과 무관하게 400틱에 (84,150) 노출, 1,500틱에 (84,125) 접근, 2,200틱에 (180,180) 숨김을 적용한다. 실제 유니티 프로세스에서 격리된 지도를 사용한다. 피해는 fixture에서 차단하므로 실제 사격 개시를 확인하지만 명중/사상 결과를 검증하지 않는다.

전체 틱의 OS CPU와 관련 메서드의 inclusive 경과 시간을 구분한다. Core 비율은 `NumCellsInRadius` 10,000회 배치 기준이며 전체 CPU 점유율이 아니다. p95/p99는 최대 2,048개 표본이다. 정식 반복·다중 맵·400명·저장/로드·모든 피해 조합은 R7 대상이다.
