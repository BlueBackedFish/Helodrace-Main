# 느린 틱 전체 메서드 집계 검증

schema 7 도구 검증용 단일 짧은 격리 실행. New LOW 60명/5분대, fixture v16, 준비 120틱/요청 수집 120틱(실제 122틱), pawn-spikes, 느린 틱 기준 0.1ms.

- 등록 메서드 116개, complete=true, dropped=0, 계측 메서드 예외 0.
- 감사 complete=true, 환경 통제 및 격리 확인.
- 보존된 8개 느린 틱 모두 전체 메서드 합계 완전. 최대 2,543개 호출 중 2,031개 상세 기록이 잘려도 합계는 유지.
- 모든 보존 틱에서 합계 호출 수와 seen+filtered 일치, 선택 하위 제외 시간 합계와 루트 경과 시간 일치(오차 <0.000001ms).
- CLI 실캡처 조회, Core 기준 연결, 이름 매핑, 추적 schema 비교 보호 검증 통과.

[summary.json](summary.json)은 검증 값과 각 보존 틱의 상위 메서드를 담는다. [raw-manifest.json](raw-manifest.json)의 SHA256과 길이는 gzip을 해제한 원본 기준이다. 원본 Player.log의 초기 로딩 누락 텍스처 경고도 보존했다. 게임/CLI 빌드 및 프로파일러 단위 검증을 통과했다.

전술 동작 변경, 성능 개선율 비교, 전체 CQB 임무 완료 또는 바닐라 대비 2배 CPU 게이트 판정 자료가 아니다. 합계는 선택된 메인 스레드 호출의 경과 시간이며 정확한 메서드별 CPU 시간이 아니다. 상세 계측 오버헤드를 포함한다.
